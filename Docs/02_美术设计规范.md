# 《昆吾禁地》美术设计规范

版本：0.2  
画面方向：竖屏 2D 像素修仙、幽暗古禁地、低饱和材质与高纯度法术光

> 本项目采用“授权版显示名 + 原创版显示名”的双轨制作。美术资产不得临摹《凡人修仙传》动画、漫画、游戏中的人物造型、服装细节、场景构图、Logo 或法宝外形；即使内部原型使用昆吾山设定，也要保持原创视觉语言。

## 1. 美术目标

玩家第一眼应感受到：

- 这里是曾经辉煌、如今封闭万年的古修遗迹。
- 人物只是渺小的闯入者，环境尺度远大于角色。
- 营地提供温暖和秩序，山内则是冷色、潮湿、危险与不稳定灵力。
- 修仙感来自发髻、道袍、符箓、飞剑、阵旗、储物袋和灵兽轮廓，而不是复刻任何现成角色。
- 像素风用于控制成本和规避肖像相似，不等于低完成度。

美术关键词：

```text
古拙、肃杀、雾重、玉石、青铜、朱砂、雷纹、断裂、封印、幽光
```

禁止关键词：

```text
明亮仙侠婚服、Q版大头、过度霓虹、现代科幻 HUD、满屏金光、写实血腥肢解
```

## 2. 五张大地图的视觉体系

五张野外地图不是一条狭窄路线上的连续布景，而是五块可独立探索的完整区域。每张图都要能容纳固定资源点、事件、小型副本、主线小 Boss、支线 Boss 和野外 Boss；视觉设计必须支持未来继续增加第 6–30 张地图。

| 地图 | 主色与材质 | 大地标 | Boss 视觉层级 |
|---|---|---|---|
| 地图 1：破禁山麓 | 灰绿、冷青、土黄；山石、木栈道、残符 | 山门、废营、断崖、外层阵柱 | 教学主线小 Boss 使用石材轮廓；可选精英使用尸傀语汇 |
| 地图 2：白玉广场 | 灰白、青金、朱砂；玉砖、铜灯、阵纹 | 中央祭坛、三座阵眼、古修洞府 | 主线尸将用玉甲；支线木魅用根须；野外尸王用高大银灰轮廓 |
| 地图 3：灵宝遗址 | 铜绿、靛蓝、金点；器架、库门、悬浮残器 | 巨型炉台、封闭库房、断裂运输阵 | 主线傀儡强调机械关节；支线器灵半透明；野外邪修保留人形高速轮廓 |
| 地图 4：古殿群 | 墨黑、玉白、暗红；殿柱、丹陛、帷幔 | 主殿、偏殿、封印令台、议事遗址 | 残魂用古修冠服剪影；玄岩兽低矮厚重；魔道猎手细长锐利 |
| 地图 5：镇魔禁域 | 紫黑、血褐、病绿；封链、塔砖、裂隙 | 巨型封链、倒悬塔影、地脉裂口 | 主线镇塔妖物、支线魔灵、野外古尸必须分别用实体、能量体和尸身轮廓 |

山外营地另用暖褐、灯黄、黛青，作为安全和恢复的视觉对照。

### 2.1 单张地图内部层级

每张大地图内部都使用以下层级，而不是仅靠换一套地砖：

1. 远景地标：玩家在迷雾边缘也能建立方向感。
2. 普通区域：占地图约 55%–65%，承载移动、资源和普通敌群。
3. 事件区域：使用独特小构筑，如石门、毒泉、残阵、断桥。
4. 小型副本入口：尺寸更大、对比更强，连接独立小场景。
5. Boss 地标：主线、支线、野外 Boss 各有独立地面标记和场景剪影。
6. 跨图出口：常规出口与高门槛出口必须有不同视觉语言。

环境整体保持低饱和，技能、交互物和出口使用较高饱和度。固定坐标对象的位置不因重新进入地图改变，因此地标构图也必须保持稳定。

## 3. 像素规格

### 3.1 基础规格

- Tile 源尺寸：16×16。
- 世界显示倍率：3×，单格在 360×640 参考画布上显示为 48×48。
- 探索角色逻辑框：32×32 或 48×48。
- 战斗角色逻辑框：64×64，Boss 可用 96×96 或 128×128。
- UI 图标源尺寸：16×16、24×24、32×32 三档。
- 角色最多使用 24–32 个主色；普通怪不超过 20 色。
- 轮廓线优先使用深色偏色线，不使用纯黑一圈包边。

### 3.2 像素纪律

- 所有像素边缘必须落在整数坐标。
- 禁止缩放产生半像素。
- 禁止使用抗锯齿画笔绘制像素资源。
- 同一物件不混用 1 px 与 3 px 随意描边。
- 法术柔光可以在独立特效层使用非像素渐变，但主体轮廓必须清晰。

## 4. 角色视觉系统

### 4.1 人物比例

- 探索小人：约 2.5 头身。
- 战斗小人：约 3–3.5 头身。
- 肩宽和武器夸张 10%–20%，保证手机屏幕识别。
- 面部仅保留眉眼亮点，不塑造与原著演员/动画角色相似的五官。

### 4.2 六个初始职业

| 初始职业 | 主属性 | 轮廓识别 | 主色 |
|---|---|---|---|
| 武修 | 力量 | 单手兵器、短护肩、稳定中型轮廓 | 青灰 |
| 法修 | 魔力 | 法杖/法珠、长袖、悬浮灵光 | 蓝紫 |
| 医修 | 魔力 | 药篓、葫芦、宽袖 | 朱砂/米白 |
| 潜修 | 技巧 | 短刃、半披风、收紧袖口 | 紫灰 |
| 符修 | 技巧/魔力 | 符匣、阵旗、几何披帛 | 靛蓝/金 |
| 体修 | 力量/体质 | 缠腕、厚肩、无长武器 | 土黄/玄黑 |

同职业换装保留三项不可变轮廓，避免装备改变后职业不可识别。

### 4.3 一转后的视觉变化

一转不是简单换色，要在保留初始职业血缘的同时改变战斗职责：

| 初始职业 | 分支 A | 分支 B |
|---|---|---|
| 武修 | 护山卫：增加盾牌、厚护肩、低重心 | 飞剑客：剑匣、窄袖、向前的锐利轮廓 |
| 法修 | 雷法师：分叉雷纹、短披肩、白蓝高光 | 玄冰师：层叠长袖、霜晶冠、浅蓝轮廓 |
| 医修 | 丹医：药箱、玉针、柔和青绿副色 | 炎丹师：小丹炉、火纹围巾、橙红副色 |
| 潜修 | 绝影客：双短刃、紧身轮廓、长残影带 | 探秘使：机括、工具腰带、护目符 |
| 符修 | 阵法师：大型阵旗、对称几何装饰 | 咒印师：垂落符带、不对称黑紫纹 |
| 体修 | 金刚修：臂甲、宽肩、方形轮廓 | 狂战修：散发、破损护臂、前倾轮廓 |

角色卡同时显示职业树节点图标，不能只靠服装猜测转职。

### 4.4 资质表现

资质是成长潜力，不通过人物“越来越华丽”直接表现。卡牌边框建议：

| 资质 | 名称 | 色彩 | 边框语言 |
|---|---|---|---|
| 1 | 凡品 | 灰 | 单线 |
| 2 | 良品 | 绿 | 双角 |
| 3 | 上品 | 蓝 | 云角 |
| 4 | 玄品 | 紫 | 符纹 |
| 5 | 地品 | 金 | 山纹 |
| 6 | 天品 | 赤金 | 日月纹 |

资质必须同时显示文字，不能只靠颜色。

### 4.5 境界表现

境界与资质分离：

- 筑基：布袍、木/铁制法器。
- 结丹：材质更精炼，出现护身光带和中型法宝。
- 元婴：轮廓更稳定，披帛/剑匣/阵旗有悬浮部件。

不要用单纯加大翅膀或满身金光表现高阶。

## 5. 敌人设计

### 5.1 敌人族群

| 族群 | 视觉语汇 | 常见玩法 |
|---|---|---|
| 尸傀 | 枯肉、铜钉、残符、僵直关节 | 高防、毒、复生 |
| 木魅 | 根须、苔藓、空洞人脸 | 缠绕、吸取灵力 |
| 石灵 | 玉石/玄岩、断裂符纹 | 护甲、反击 |
| 禁制化形 | 几何符阵、无实体核心 | 控制、反伤、区域伤害 |
| 邪修残魂 | 破袍、半透明、魂火 | 恐惧、夺魂 |
| 魔气孽物 | 不对称肢体、紫黑裂口 | 污染、狂暴、召唤 |

### 5.2 Boss 设计原则

- 必须有一眼可读的核心弱点或法器。
- 每阶段改变轮廓，而不是只换颜色。
- 危险技能先用地面阵纹、电弧聚集或符文倒计时预警。
- Boss 像素占屏不超过战斗区高度的 45%，避免遮挡 UI。
- 不直接复刻原著妖物或人物；授权版也优先制作“同类新个体”。

Demo Boss：“封坛尸将”

- 轮廓：石甲巨尸，胸口插有四面阵旗。
- P1：巨刃横扫。
- P2：拔出阵旗，释放尸煞。
- P3：胸口封印破裂，露出魂火弱点。

## 6. 场景设计

### 6.1 山外营地

大厅不是写实可行走场景，而是一张可横向连续滑动的多层营地图。顶部资源/任务层与底部快捷入口层固定，中间营地全景独立横滑且不分页吸附：

- 前景：旗杆、药篓、木箱、走动杂役。
- 中景：七座成长建筑和出征是当前交互主体；竞技场、遗迹、圣迹、教会作为暂未开放的场景锚点。
- 后景：封印山体、瀑布、云层、远处法光。
- 建筑解锁前以工地、破棚或封闭台基显示，解锁时替换为完整建筑。
- 正式资产至少交付背景、建筑、前景三层；建筑与点击热区必须独立，禁止全部烘焙成一张不可拆分长图。

建筑对应：

| 功能 | IP 语境名称 | 原创发行名 | 视觉锚点 |
|---|---|---|---|
| 酒馆 | 招贤台 | 聚贤楼 | 悬榜、酒旗、三个人影 |
| 仓库 | 百宝库 | 纳珍阁 | 货架、储物袋、铜锁 |
| 墓园 | 还魂坛 | 引魂台 | 白幡、魂灯、圆形法坛 |
| 庄园 | 灵圃 | 外门产业 | 梯田、水车、矿洞入口 |
| 铁匠 | 炼器坊 | 铸灵坊 | 炉火、铁砧、悬浮法器 |
| 商人 | 交易行 | 山外坊市 | 帐篷、价牌、驮兽 |
| 城堡 | 议事殿 | 镇岳堂 | 主旗、沙盘、NPC |
| 竞技场 | 暂不实现 | 暂不实现 | 封闭擂台、收起的旗帜或封锁告示，明确表现为未开放场景 |

空间关系以 PRD-01 §4 为准：左部为仓库、墓园、圣迹、教会；中部为城堡、出征、酒馆、市场；中部右缘露出部分竞技场和工坊；右部完整展示竞技场、工坊、庄园和遗迹。

### 6.2 禁地关卡美术

场景采用模块化 Tile：

- 地表层：土、石、玉砖、水、深渊。
- 边缘层：墙、崖、台阶、栏杆。
- 装饰层：碑、灯、藤、尸骸、碎器。
- 交互层：宝箱、法阵、机关、传送门。
- 前景遮挡：树冠、梁柱、雾带。
- 特效层：尘、雨、灵气、魔气。

所有可交互物增加统一的“呼吸高光 + 图标提示”，避免玩家在复杂像素中找不到入口。

## 7. UI 视觉

### 7.1 风格

- 底板：墨色木/石材。
- 边框：青铜与玉。
- 选中：朱砂印章。
- 常规文字：米白。
- 次级文字：灰青。
- 增益：青绿；警告：赭黄；危险：朱红；魔性：紫黑。

### 7.2 字体

Demo 使用现有 Ark Pixel Font：

`ThirdParty/DemoAssets/Fonts/ArkPixel12px_OFL/ark-pixel-12px-proportional-zh_cn.ttf`

必须随发布包保留 OFL 许可证。标题可在 MVP 定制像素篆刻字，但正文继续使用可读性较高的字体。

### 7.3 页面布局

- 顶部：头像、灵粮/灵木/玄铁/灵晶/庚精和头像下方的当前主线提示。
- 中部：主内容和场景。
- 底部左侧：设置、成就、排行榜、邮件、日常进度五个小图标；除设置外均采用统一未开放态。
- 底部右侧：只显示灵石图标和余额；灵石与顶部灵晶是两种独立资源，宝石和全部付费入口隐藏。
- 重要数字使用制表位对齐。
- 不在同一页堆叠超过三个红点。
- 弹窗宽度为屏幕 88%，正文至少 16 px 对应视觉尺寸。

## 8. 图标系统

图标需要做到 24×24 下仍可辨认：

- 灵粮：谷穗 + 灵光。
- 灵木：带符纹的断木。
- 玄铁：黑色矿锭。
- 灵晶：六棱青色晶簇，用作生产与阵法资源。
- 庚精：银白液态金属珠。
- 灵石：打磨后的乳白灵玉小片，带简洁钱纹，用作招募与交易货币。
- 魂晶：蓝白火焰结晶。
- 负重：储物袋。
- 神识：眼形符纹。
- 补给：丹瓶/饭囊。

Demo 可使用 `ThirdParty/DemoAssets/Icons/KenneyRunes_CC0` 占位，MVP 必须替换为同一笔触的原创图标。

## 11. 交付与验收

每个资产必须附：

- 源文件。
- 导出 PNG。
- 规格和锚点说明。
- 使用场景。
- 作者与许可。
- 是否可商用。
- 是否需要署名。

角色验收：

- 25% 缩放后仍可认出职业。
- 四方向武器位置不跳动。
- 不出现与原著动画角色高度相似的发型、面部和服装组合。
- 攻击、受击和死亡剪影清楚。

环境验收：

- 可走与不可走区域不依赖碰撞调试线也能识别。
- 交互点在 3 秒内可发现。
- 迷雾下已探索地形仍可阅读。
- 同一章节不超过三个相互竞争的主色。

## 12. 美术制作优先级

### Demo 必须

- 营地全景 1 张、建筑状态 7×2。
- 探索角色 6 个初始职业。
- 战斗角色 6 个初始职业，并为 Demo 实装武修的两个一转分支。
- 普通敌人 6、精英 2、Boss 1。
- 外山与白玉遗址两套 Tile。
- 资源图标 7、装备图标 20、技能图标 16。
- 主 UI 页面 8 个。

### MVP 扩展

- 6 个初始职业、12 个一转职业；初始与一转通过可复用身体底层控制产量。
- 24 个普通敌人、8 个精英、13–15 个 Boss（主线、支线、野外分层复用部件）。
- 5 张完整野外地图主题，每张都包含主线、支线和野外 Boss 场景模块。
- 120 件装备图标。
- 建筑 1–5 级外观。
