# 《昆吾禁地》美术设计规范

版本：0.2  
画面方向：竖屏 2D 像素修仙、幽暗古禁地、低饱和材质与高纯度法术光

> 本项目采用“授权版显示名 + 原创版显示名”的双轨制作。美术资产不得临摹《凡人修仙传》动画、漫画、游戏中的人物造型、服装细节、场景构图、Logo 或法宝外形；即使内部原型使用昆吾山设定，也要保持原创视觉语言。

## 1. 美术目标

玩家第一眼应感受到：

- 这里是曾经辉煌、如今封闭万年的古修遗迹。
- 人物只是渺小的闯入者，环境尺度远大于角色。
- 营地提供温暖和秩序，山内则是冷色、潮湿、危险与不稳定灵力。
- 修仙感来自发髻、道袍、符箓、飞剑、阵旗、储物袋和灵兽轮廓，而不是复刻任何现成角色。
- 像素风用于控制成本和规避肖像相似，不等于低完成度。

美术关键词：

```text
古拙、肃杀、雾重、玉石、青铜、朱砂、雷纹、断裂、封印、幽光
```

禁止关键词：

```text
明亮仙侠婚服、Q版大头、过度霓虹、现代科幻 HUD、满屏金光、写实血腥肢解
```

## 2. 1.0四张大地图的视觉体系

四张野外地图不是一条狭窄路线上的连续布景，而是四块可独立探索的完整区域。每张图都要能
容纳固定资源点、事件、小型副本、精英和唯一Boss；视觉设计仍需支持后续增加`map_05`以后内容。

| 地图 | 主色与材质 | 大地标 | Boss 视觉层级 |
|---|---|---|---|
| 地图1：破禁山麓·万修之门 | 灰绿、冷青、土黄；山石、木栈道、残符 | 山门、废营、断崖、外层阵柱 | 守门石灵使用石材与残禁轮廓；精英使用尸傀或禁制语汇 |
| 地图2：白玉广场 | 灰白、青金、朱砂；玉砖、铜灯、阵纹 | 中央祭坛、四座阵眼、古修洞府 | 封坛尸将使用玉甲、魂旗与复生军阵；木魅等支线强敌按精英层级表现 |
| 地图3：灵宝遗址 | 铜绿、靛蓝、金点；器架、库门、悬浮残器 | 昆吾殿外苑、灵宝阁、铸灵堂 | 四臂铸灵傀强调四个功能部位、炉火与机械关节 |
| 地图4：镇魔塔外层 | 紫黑、血褐、病绿；封链、塔砖、裂隙 | 倒置塔壁、巨型封链、空间裂口 | 银翅夜叉·尸煞化身以残翅、尸煞和封链形成唯一终局轮廓 |

山外营地另用暖褐、灯黄、黛青，作为安全和恢复的视觉对照。

### 2.1 单张地图内部层级

每张大地图内部都使用以下层级，而不是仅靠换一套地砖：

1. 远景地标：玩家在迷雾边缘也能建立方向感。
2. 普通区域：占地图约 55%–65%，承载移动、资源和普通敌群。
3. 事件区域：使用独特小构筑，如石门、毒泉、残阵、断桥。
4. 小型副本入口：尺寸更大、对比更强，连接独立小场景。
5. Boss地标：每图唯一Boss拥有独立地面标记和场景剪影；精英不得误读为第二Boss。
6. 跨图出口：常规前进出口与返回捷径使用不同视觉语言。

环境整体保持低饱和，技能、交互物和出口使用较高饱和度。固定坐标对象的位置不因重新进入地图改变，因此地标构图也必须保持稳定。

## 3. 像素规格

### 3.1 基础规格

- Tile 源尺寸：16×16。
- 世界显示倍率：3×，单格在 360×640 参考画布上显示为 48×48。
- 探索角色逻辑框：32×32 或 48×48。
- 战斗角色逻辑框：64×64，Boss 可用 96×96 或 128×128。
- UI 图标源尺寸：16×16、24×24、32×32 三档。
- 角色最多使用 24–32 个主色；普通怪不超过 20 色。
- 轮廓线优先使用深色偏色线，不使用纯黑一圈包边。

### 3.2 像素纪律

- 所有像素边缘必须落在整数坐标。
- 禁止缩放产生半像素。
- 禁止使用抗锯齿画笔绘制像素资源。
- 同一物件不混用 1 px 与 3 px 随意描边。
- 法术柔光可以在独立特效层使用非像素渐变，但主体轮廓必须清晰。

## 4. 角色视觉系统

### 4.1 人物比例

- 探索小人：约 2.5 头身。
- 战斗小人：约 3–3.5 头身。
- 肩宽、武器和职业器物可夸张 10%–20%，保证手机屏幕识别。
- 面部仅保留眉眼亮点，不塑造与原著演员/动画角色相似的五官。

### 4.2 四个 1.0 初始职业

| 初始职业 | 主属性 | 轮廓识别 | 主色 |
|---|---|---|---|
| 金刚禅修 | 力道/肉身/护体 | 剃度光头、赤足旧僧衣、黑木念珠、赤铜肉身、宽厚无武器轮廓 | 旧褐/赤铜/土金 |
| 五行法修 | 法力/神识 | 深蓝束冠长发、长袖法袍、悬浮法盘与小型法镜 | 深蓝/蓝紫/冷白 |
| 玄箓修 | 法力/神识/定力 | 白青道袍、朱砂符匣、悬浮法印与符纸长带 | 白青/朱砂/青金 |
| 剑修 | 力道/神识/遁速 | 墨青长袍、束袖、剑匣与悬浮剑胚；面部完整露出 | 墨青/青白/暗银 |

同职业换装保留三项不可变轮廓，避免装备改变后职业不可识别。

### 4.3 一转后的视觉变化

一转不是简单换色，要在保留初始职业血缘的同时改变战斗职责：

| 初始职业 | 分支 A | 分支 B |
|---|---|---|
| 金刚禅修 | 护法金身：金色禅纹、金轮、沉稳站姿与反伤回光 | 魔相力士：暗金魔纹、短暂臂影、近身多段重击与回吸 |
| 五行法修 | 雷法术式：蓝紫雷符、引雷针、分叉电光 | 蜃景幻法：水雾、法镜重影、镜光与神识蚀纹 |
| 玄箓修 | 镇幽符脉：镇魂符宝、青金符火、安魂经脉符纹 | 万象符脉：符矢、六甲增元箓、黄褐力士符傀 |
| 剑修 | 青冥剑修：剑不入手、青白飞剑、分光剑影与剑煞蚀痕 | 玄岳剑修：手持巨剑、厚重站姿、剑脊震击与大幅横斩 |

角色卡同时显示职业树节点图标，不能只靠服装猜测转职。

### 4.4 资质表现

资质是成长潜力，不通过人物“越来越华丽”直接表现。卡牌边框建议：

| 资质 | 名称 | 色彩 | 边框语言 |
|---|---|---|---|
| 1 | 杂灵根 | 灰白 | 单线、五个短断点 |
| 2 | 伪灵根 | 青绿 | 双角、四个短断点 |
| 3 | 三灵根 | 湛蓝 | 云角、三个灵点 |
| 4 | 双灵根 | 靛紫 | 双生符纹 |
| 5 | 天灵根 | 灵金 | 单一完整日纹 |
| 6 | 异灵根 | 玄青底配青紫虹彩 | 不对称变异灵纹 |

资质必须同时显示文字，不能只靠颜色。异灵根不得使用暗红品质框；暗红、血色和紫黑
只用于魔道职业、魔气、血煞与危险状态。

### 4.5 境界表现

境界与灵根资质分离。职业树和角色卡使用八个境界文字徽记：炼气、筑基、结丹、
元婴、化神、炼虚、合体、大乘；不再显示职业星级。当前美术重点为炼气至元婴：

- 炼气：朴素布袍、木制或凡铁法器，无悬浮装饰。
- 筑基：衣料与护具开始制式化，出现一件职业关键法器。
- 结丹：材质更精炼，出现克制的护身光带和中型法宝。
- 元婴：轮廓更稳定，披帛、剑匣或阵旗可有少量悬浮部件。
- 化神至大乘只预留徽记层级，正式形象随对应阶段另立美术清单。

不要用单纯加大翅膀或满身金光表现高阶。

## 5. 敌人设计

### 5.1 敌人族群

| 族群 | 视觉语汇 | 常见玩法 |
|---|---|---|
| 尸傀 | 枯肉、铜钉、残符、僵直关节 | 高防、毒、复生 |
| 木魅 | 根须、苔藓、空洞人脸 | 缠绕、吸取灵力 |
| 石灵 | 玉石/玄岩、断裂符纹 | 护甲、反击 |
| 禁制化形 | 几何符阵、无实体核心 | 控制、反伤、区域伤害 |
| 邪修残魂 | 破袍、半透明、魂火 | 恐惧、夺魂 |
| 魔气孽物 | 不对称肢体、紫黑裂口 | 污染、狂暴、召唤 |

### 5.2 Boss 设计原则

- 必须有一眼可读的核心弱点或法器。
- 每阶段改变轮廓，而不是只换颜色。
- 危险技能先用地面阵纹、电弧聚集或符文倒计时预警。
- Boss 像素占屏不超过战斗区高度的 45%，避免遮挡 UI。
- 不直接复刻原著妖物或人物；授权版也优先制作“同类新个体”。

Demo Boss：“封坛尸将”

- 轮廓：石甲巨尸，胸口插有四面阵旗。
- P1：巨刃横扫。
- P2：拔出阵旗，释放尸煞。
- P3：胸口封印破裂，露出魂火弱点。

## 6. 场景设计

### 6.1 山外营地

大厅不是写实可行走场景，而是一张可横向连续滑动的多层营地图。顶部资源/任务层与底部快捷入口层固定，中间营地全景独立横滑且不分页吸附：

- 前景：旗杆、药篓、木箱、走动杂役。
- 中景：七座成长建筑和入山是当前交互主体；竞技场、遗迹、圣迹、教会作为暂未开放的场景锚点。
- 后景：封印山体、瀑布、云层、远处法光。
- 建筑解锁前以工地、破棚或封闭台基显示，解锁时替换为完整建筑。
- 正式资产至少交付背景、建筑、前景三层；建筑与点击热区必须独立，禁止全部烘焙成一张不可拆分长图。

建筑对应：

| 功能 | IP 语境名称 | 原创发行名 | 视觉锚点 |
|---|---|---|---|
| 酒馆 | 招贤馆 | 聚贤楼 | 悬榜、酒旗、三个人影 |
| 仓库 | 百宝库 | 纳珍阁 | 货架、储物袋、铜锁 |
| 墓园 | 还魂坛 | 引魂台 | 白幡、魂灯、圆形法坛 |
| 庄园 | 灵源院 | 外门产业 | 梯田、水车、矿洞入口 |
| 铁匠 | 炼器坊 | 铸灵坊 | 炉火、铁砧、悬浮法器 |
| 商人 | 交易行 | 山外坊市 | 帐篷、价牌、驮兽 |
| 城堡 | 议事殿 | 镇岳堂 | 主旗、沙盘、NPC |
| 竞技场 | 暂不实现 | 暂不实现 | 封闭擂台、收起的旗帜或封锁告示，明确表现为未开放场景 |

空间关系以 PRD-01 §4 为准：左部为仓库、墓园、圣迹、教会；中部为城堡、入山、酒馆、市场；中部右缘露出部分竞技场和工坊；右部完整展示竞技场、工坊、庄园和遗迹。

### 6.2 禁地关卡美术

场景采用模块化 Tile：

- 地表层：土、石、玉砖、水、深渊。
- 边缘层：墙、崖、台阶、栏杆。
- 装饰层：碑、灯、藤、尸骸、碎器。
- 交互层：宝箱、法阵、机关、传送门。
- 前景遮挡：树冠、梁柱、雾带。
- 特效层：尘、雨、灵气、魔气。

所有可交互物增加统一的“呼吸高光 + 图标提示”，避免玩家在复杂像素中找不到入口。

## 7. UI 视觉

本章只定义整体 UI 美术方向。Figma 文件结构、主题色 Variable、字体层级、通用组件状态与
Cocos 映射见 [`Docs/Figma/README.md`](Figma/README.md)；具体 PNG 制作清单见
[`Docs/ArtAssets/README.md`](ArtAssets/README.md)。

### 7.1 风格

- 底板：墨色木/石材。
- 边框：青铜与玉。
- 选中：朱砂印章。
- 常规文字：米白。
- 次级文字：灰青。
- 增益：青绿；警告：赭黄；危险：朱红；魔性：紫黑。

### 7.2 字体

Demo 使用现有 Ark Pixel Font：

`ThirdParty/DemoAssets/Fonts/ArkPixel12px_OFL/ark-pixel-12px-proportional-zh_cn.ttf`

必须随发布包保留OFL许可证。标题可在1.0定制像素篆刻字，但正文继续使用可读性较高的字体。

### 7.3 页面布局

- 顶部：头像、灵粮/灵木/玄铁/灵晶/庚精和头像下方的当前主线提示。
- 中部：主内容和场景。
- 底部左侧：设置、成就、排行榜、邮件、日常进度五个小图标；除设置外均采用统一未开放态。
- 底部右侧：只显示灵石图标和余额；灵石与顶部灵晶是两种独立资源，天符玉和全部付费入口隐藏。
- 重要数字使用制表位对齐。
- 不在同一页堆叠超过三个红点。
- 弹窗宽度为屏幕 88%，正文至少 16 px 对应视觉尺寸。

## 11. 交付与验收

每个资产必须附：

- 源文件。
- 导出 PNG。
- 规格和锚点说明。
- 使用场景。
- 作者与许可。
- 是否可商用。
- 是否需要署名。

角色验收：

- 25% 缩放后仍可认出职业。
- 四方向武器位置不跳动。
- 不出现与原著动画角色高度相似的发型、面部和服装组合。
- 攻击、受击和死亡剪影清楚。

环境验收：

- 可走与不可走区域不依赖碰撞调试线也能识别。
- 交互点在 3 秒内可发现。
- 迷雾下已探索地形仍可阅读。
- 同一章节不超过三个相互竞争的主色。

## 12. 美术制作优先级

### Demo 必须

- 营地全景 1 张、建筑状态 7×2。
- 探索角色为石岩、陆清、白灵、墨言四名固定修士及其四个初始职业。
- 战斗角色为固定四人；D1只选择一组双分支展示，不提前制作全部八条筑基分支。
- 普通敌人 6、精英 2、Boss 1。
- 外山与白玉遗址两套 Tile。
- 资源图标 7、装备图标 20；36 个技能 ID 按复用矩阵去重为 28 张技能图标 PNG。
