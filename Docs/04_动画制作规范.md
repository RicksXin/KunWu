# 《昆吾禁地》动画制作规范

版本：0.1  
形式：探索俯视像素动画 + 战斗侧视像素动画 + UI/场景轻动画

## 1. 动画目标

动画优先服务：

1. 战斗时机：何时出手、何时命中、何时可被打断。
2. 职业辨识：剑修轻快、体修沉重、丹修舒缓、阵修克制。
3. 状态表达：受伤、控制、中毒、濒死、复活。
4. 氛围：营地有生活感，禁地有沉寂与不稳定。

不追求高帧数堆量，而追求关键 Pose、清楚预备动作和有重量的命中帧。

## 2. 动画形式选择

| 场景 | 方案 | 原因 |
|---|---|---|
| 方格探索 | 四方向 Sprite Sheet | 低成本、像素一致、易换装 |
| 半自动战斗 | 单方向侧视 Sprite Sheet | 技能可读、资产量可控 |
| 大型 Boss | 分层骨骼 + 局部序列帧 | 方便阶段变形和部件破坏 |
| 营地 | 局部循环帧 + Tween | 建筑烟火、旗帜、NPC |
| UI | Tween/AnimationPlayer | 响应快、无需大图 |
| 剧情 | 角色立绘切换 + 镜头推拉 | 避免制作大量演出动画 |

Demo 不引入 Spine 付费工作流。MVP 若 Boss 数量增多，再评估 Spine、Creature 或 Godot 内置 `Skeleton2D`。

## 3. 帧率与帧数基线

### 3.1 探索角色

| 动作 | 方向 | 帧数 | 播放速度 |
|---|---:|---:|---:|
| Idle | 4 | 4 | 6 FPS |
| Walk | 4 | 6 | 10 FPS |
| Interact | 4 或复用 | 4 | 8 FPS |
| Alert | 1 | 4 | 8 FPS |
| Hurt | 1 | 3 | 12 FPS |
| Down | 1 | 6 | 8 FPS |

逐格移动总时长建议 0.16–0.22 秒，脚步动画与坐标插值同步。

### 3.2 战斗角色

| 动作 | 帧数 | 速度 | 备注 |
|---|---:|---:|---|
| Idle | 4–6 | 6–8 FPS | 呼吸幅度不超过 1–2 px |
| Attack A | 6–8 | 12 FPS | 常规攻击 |
| Attack B | 8–10 | 12 FPS | 强击 |
| Cast | 8–12 | 10–12 FPS | 明确蓄力帧 |
| Hurt | 3–4 | 12 FPS | 不打断所有技能时用色闪替代 |
| Block | 4 | 10 FPS | 保持防御 Pose |
| Death | 8–12 | 8–10 FPS | 魂火逸散交给特效 |
| Revive | 6–8 | 8 FPS | 可反播部分 Death，但末帧重制 |

Boss 动作可增加到 12–18 帧，但单个普通技能演出不超过 1.2 秒。

## 4. 职业动作语言

### 青锋客

- 重心偏前，起手短。
- 武器先动、身体后随。
- 普攻命中帧清脆，残影短。
- 强技能可有一帧停顿制造“拔剑”力度。

### 玄甲士

- 重心低，双脚间距大。
- 预备时间略长，恢复帧也长。
- 受击位移小，格挡时上身稳定。

### 丹霞子

- 袖口和药葫芦产生次级运动。
- 施法轨迹以圆为主。
- 治疗动作向上托举，攻击动作向前推出。

### 伏阵生

- 手势短而精确，阵旗/符纸负责大幅运动。
- 前摇有固定“点阵眼”Pose。
- 控制技能必须在命中前看出目标范围。

## 5. 动画状态机

### 5.1 探索

```text
Idle
├─ Move → Walk → Idle
├─ Interact → Idle
├─ Alert → Encounter
└─ Down
```

### 5.2 战斗

```text
Idle
├─ Attack/Cast → Recover → Idle
├─ Block → Idle
├─ Hurt → Idle
├─ Disabled → Idle
└─ Death → Dead
Dead → Revive → Idle
```

战斗模拟拥有状态真值，AnimationTree 只负责表现。动画结束信号不能决定技能是否造成伤害。

## 6. 事件标记

每个攻击动画至少标记：

- `windup_start`
- `cast_commit`
- `projectile_spawn` 或 `hit_frame`
- `recover_start`
- `animation_end`

其中伤害由战斗模拟在 `cast_commit` 后安排；表现事件对齐 `hit_frame`。若玩家开启 2× 速度，逻辑和动画时间同时按倍率推进。

## 7. Aseprite 制作规范

### 7.1 图层

```text
guide
body_base
clothes
hair_headgear
weapon_back
weapon_front
fx_reference
shadow
```

- `guide` 和 `fx_reference` 不导出。
- 角色脚底锚点在所有帧保持一致。
- 阴影独立，探索与战斗可以在引擎里统一生成。
- 标签命名：`idle_s`、`walk_n`、`attack_01`。

### 7.2 导出

- PNG RGBA。
- 无边距紧密图集或固定网格二选一；同一动画集不得混用。
- Sprite Sheet 必须带 JSON 帧信息或在文档中注明格子尺寸。
- 禁止导出缩放过的抗锯齿版本。

## 8. Godot 导入

### 8.1 普通 Sprite Sheet

- 导入过滤关闭。
- Mipmaps 关闭。
- Repeat 关闭。
- 压缩使用 Lossless。
- 使用 `AnimatedSprite2D` 建立 SpriteFrames。
- 动画资源按角色集保存，不在场景脚本里逐帧创建。

### 8.2 AnimationTree

适用于：

- 大型 Boss 分层骨骼。
- 带多个装备挂点的战斗角色。
- 需要 BlendSpace 的朝向动画。

普通小人优先 `AnimatedSprite2D`，避免复杂度。

## 9. 换装与挂点

Demo 只实现武器和背部法宝挂点：

- `hand_main`
- `hand_off`
- `back`
- `head_fx`
- `body_fx`
- `foot_fx`

MVP 再增加衣服分层换装。像素角色如果每帧挂点抖动，可为动画帧保存挂点表：

```json
{
  "attack_01": [
    {"hand_main": [18, 22]},
    {"hand_main": [20, 20]}
  ]
}
```

## 10. 动画资源采购与现有素材

本地已收集的免费资源：

| 素材 | 可用动作 | Demo 角色 |
|---|---|---|
| `SamuraiTopdown_CC0` | 移动、斩击、死亡 | 青锋客探索 |
| `SamuraiSideview_CC0` | Idle、Run、Attack、Hurt、Dead | 战斗节奏参考 |
| `Monk_CC0` | Idle、Attack、Fly、Read、Transition | 丹霞子/伏阵生 |
| `AnimatedMonsters_CC0` | Idle、Walk、Attack、Hurt、Dead | 尸傀、残魂 |

路径与许可见 `ThirdParty/DemoAssets/README.md`。

Demo 改造最低要求：

- 武士头盔改为发髻/玉冠。
- 甲胄改为道袍与护肩。
- 刀改为飞剑、阵旗或法器。
- 去除剖腹、断肢等不需要的血腥帧。
- 增加储物袋、剑匣、药篓等轮廓。
- 统一到项目色盘。

MVP 替换原则：

- 不能只在免费素材上简单换色。
- 新角色从剪影和关键 Pose 开始原创。
- 可保留动作时长作为参考，但不得逐帧描摹来源动画。

## 11. 场景动画

### 营地循环

- 旗帜：8 帧，8 FPS。
- 炉火：6 帧，10 FPS，随机起始帧。
- 炊烟：粒子而非大序列帧。
- 杂役：短距离巡逻 + 3 种停留动作。
- 建筑升级：局部脚手架消失、屋檐/灯火逐级增加。

### 禁地

- 石门：分三段开启，0.8–1.2 秒。
- 法阵：符文逐点亮，循环 1.5–3 秒。
- 宝箱：锁断、盖开、光溢出。
- 机关：动作必须早于伤害。
- 传送：角色先溶解，再触发场景切换。

## 12. 剧情演出

MVP 使用轻量演出模板：

1. 背景立绘或像素场景。
2. 角色半身剪影/头像。
3. 镜头平移、推近、轻震。
4. 关键物件特写。
5. 少量表情替换。

不制作长篇逐帧动画。单段不可跳过时间不超过 3 秒，完整对话可快进、可回看。

## 13. 动画性能

- 同屏非战斗环境动画不超过 25 个。
- 离屏 `AnimatedSprite2D` 暂停。
- UI 不可见时停止 Tween。
- 大 Boss 分层不超过 12 个 Sprite。
- 动画贴图按章节加载，返回营地时释放。
- 角色图集单张优先控制在 2048×2048 内。

## 14. 动画交付清单

每套动画需要：

- `.aseprite` 或等价源文件。
- Sprite Sheet PNG。
- 帧数据 JSON。
- 动画列表和 FPS。
- 命中/发射事件帧。
- 锚点与挂点表。
- 10 秒预览 GIF/MP4。
- 许可与作者信息。

## 15. 验收标准

- 探索角色四方向脚底不滑。
- 同职业动作语言一致。
- 普攻从起手到命中不超过 0.45 秒。
- 治疗、护盾、控制的前摇清楚。
- 2× 战斗速度下不漏技能事件。
- 角色死亡后没有继续播放 Idle。
- 低端机同时 10 个单位动画仍保持目标帧率。
