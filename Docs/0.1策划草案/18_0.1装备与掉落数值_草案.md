版本：0.1-draft.4  
日期：2026-08-05  
关联：[总纲](15_0.1版本完整策划案_草案.md)、[成长与战斗数值](16_0.1成长经济与战斗数值_草案.md)

## 1. 装备系统定位

0.1 装备不再按地图提供固定成套路线，也不再维护“每图 11 件、四图 44 件固定成品”。装备分为：

1. **制式装备**：占绝大多数，通过战斗、宝箱、商店和重复打造获得；只有随机七维，没有特殊效果。
2. **特定装备**：固定名称、外观、品质和特殊效果；七维仍在允许池内随机，主要通过任务链、隐藏事件和高难敌人获得。

每名修士启用四个槽位：武器、防具、饰品一、饰品二。武器按初始职业体系限制；防具和饰品
全职业通用。两件同名饰品不能由同一修士同时装备，同一装备实例不能被多人共用。

装备随机词条只允许使用冻结的七维字段：

```text
strength magic technique speed constitution armor resistance
```

生命、命中、暴击、治疗、破甲、嘲讽、反伤、负重、状态抵抗和技能强化都不是随机词条。
这些能力只允许出现在少量特定装备的固定效果中。

## 2. 品质、装备等级与七维预算

### 2.1 五档品质

| 品质 | 颜色 | 随机属性项数 | 同装备等级、同槽位的七维预算倍率 |
|---|---|---:|---:|
| 粗制 | 白 | 1～2 | `0.80～1.00` |
| 精制 | 绿 | 2～3 | `1.10～1.40` |
| 上品 | 蓝 | 2～4 | `1.60～2.10` |
| 珍品 | 紫 | 3～5 | `2.60～3.40` |
| 古宝 | 金 | 4～可用池上限 | `5.50～7.00` |

在同一装备等级和槽位下，古宝最低倍率 `5.50` 必须高于珍品最高倍率 `3.40`。珍品可以因为
属性分布集中而更适合某个构筑，但综合七维总量不能超过同等级古宝。

品质只决定属性项数、七维预算和边框，不自动附加特殊效果；普通紫装和普通金装也可以只有七维。
0.1 的普通掉落和普通打造不产生金装，普通金装模板仅作为后续版本扩展位保留。

### 2.2 装备等级

装备等级 `equipmentLevel` 与品质分离，由产出地图、配方档和特定任务决定：

| 来源 | 装备等级范围 | 普通品质上限 |
|---|---:|---|
| 新档初装 | 1 | 粗制 |
| 地图 1 | 1～6 | 上品 |
| 地图 2 | 7～12 | 上品 |
| 地图 3 | 13～18 | 珍品 |
| 地图 4 | 19～24 | 珍品 |
| 通关后重访 | 21～26 | 珍品 |
| 古宝任务链 | 24 | 古宝 |

同品质的后期装备通常强于前期装备，但高等级绿装不保证超过低等级蓝装；详情页必须同时显示
装备等级、品质和实际七维，不以颜色代替数值比较。

### 2.3 槽位基础预算

令装备等级为 `E`，先计算槽位基础预算 `B`：

```text
武器：B = 6 + floor(E × 0.75)
防具：B = 5 + floor(E × 0.65)
饰品：B = 3 + floor(E × 0.40)
最终七维总点数 = floor(B × 品质随机倍率)
```

品质随机倍率在 §2.1 区间内生成并写入装备实例。特殊效果不占七维预算，也不进入战力数字。

## 3. 制式装备

### 3.1 模板只决定资格与外观

| 模板组 | 可用类型 | 资格与表现 |
|---|---|---|
| 金刚禅器 | 禅杖、金刚轮、降魔杵 | 仅金刚禅修体系使用；不提供七维倾向 |
| 五行法器 | 法盘、法轮、法镜、灵珠 | 仅五行法修体系使用；不提供七维倾向 |
| 玄箓符器 | 符匣、法印、箓册、针匣、符鼎 | 仅玄箓修体系使用；不提供七维倾向 |
| 剑器 | 剑丸、剑匣、剑胚、重锋 | 仅剑修体系使用；不提供七维倾向 |
| 玄甲 | 锁甲、玄甲、战衣 | 全职业通用 |
| 法衣 | 道袍、法袍、法衣 | 全职业通用 |
| 行衣 | 短衣、行衣、轻袍 | 全职业通用 |
| 饰品 | 玉佩、指环、护镜、灵囊、骨环 | 全职业通用；不提供七维倾向 |

显示名可以由地图材质前缀与模板名组合，例如“白玉法盘”“玄铁重锋”。显示名不参与逻辑判断，
同名制式装备可以存在多个随机实例。

旧草案中不再列为特定装备的既有装备 ID 不删除，改作对应制式外观模板 ID；它们不再代表固定七维、
固定效果或固定唯一来源。§5 表内特定装备继续保留原 ID。由此保持数据引用稳定，但“44 个旧 ID”
不再等于 44 件固定成品，也不限制随机实例数量。

### 3.2 通用七维池限制

| 装备类型 | 可随机七维 | 禁止/削弱规则 |
|---|---|---|
| 所有制式武器 | 力道、法力、神识、遁速、肉身 | 不出现护体、定力 |
| 所有制式饰品 | 力道、法力、神识、遁速、肉身 | 不出现护体、定力 |
| 玄甲 | 力道、法力、神识、遁速、肉身、护体 | 不出现定力 |
| 法衣 | 力道、法力、神识、遁速、肉身、定力 | 不出现护体 |
| 行衣 | 全部七维 | 护体、定力最终值仅为正常分配值的 `35%～50%`，超出部分回流到其他已抽中七维 |

除上表硬限制外，七维完全等权随机，不按职业、分支、装备外观、当前队员或已穿装备调整概率。
禅杖可以主要增加法力，法盘可以主要增加力道，玄甲也可以出现高神识和高遁速。

### 3.3 实例生成

1. 确定装备模板、职业资格、装备等级和品质。
2. 按品质确定本次属性项数，不得超过该装备的允许七维池大小。
3. 从允许池中等权抽取互不重复的七维；同一装备内同一字段最多出现一次。
4. 按 §2.3 生成七维总点数，在已抽中的字段间随机分配，每项至少为 1。
5. 行衣若抽中护体或定力，分别限制为正常分配值的 `35%～50%`；超出点数随机分给已抽中的
   其他七维。若已抽字段全部为护体/定力，必须把其中一个替换为非护体、非定力字段承接差额，属性项数不变。
6. 保存随机种子与最终七维；刷新、回放和领取重试不得重新生成。

## 4. 普通掉落、宝箱与地图上限

### 4.1 完整装备出现率

普通敌人仍主要提供材料，完整装备获取保持稀缺：

| 来源 | 完整装备规则 |
|---|---|
| 普通敌群 | 胜利后 `6%` 概率生成 1 件当前地图制式装备 |
| 精英首次击杀 | 固定生成 1 件；重复击杀 `18%` 概率生成 1 件 |
| Boss 首杀 | 固定生成 2 件；不固定职业、槽位和属性 |
| 普通宝箱 | `35%` 概率为制式装备，否则为材料或灵石 |
| 隐藏宝箱/高危区宝箱 | 固定生成 1 件，不固定具体模板 |

装备实例只在战斗或交互结算事务成功时生成；刷新不能重新抽品质与七维。

### 4.3 新档与主线最低保障

- 新档四人各装备一件 Lv1 粗制职业武器和一件 Lv1 粗制行衣，七维照常随机。
- 地图 1 Boss 首杀的两件装备至少为精制，其中一件至少为上品；不固定职业或部位。
- 地图 2 Boss 首杀的两件装备至少为上品。
- 地图 3、4 Boss 不保证珍品，更不直接发放古宝成品。
- 主线突破材料继续确定获得；主线通关不要求取得指定随机装备。
- 最终 Boss 数值以“高等级上品混搭 2～4 件任务珍品”为通关基线，古宝只提供显著优势，不是入战门票。

## 5. 特定装备

### 5.1 共通规则

特定装备拥有稳定定义 ID、名称、外观、固定品质和固定效果，但七维仍按装备等级与品质随机。
若未明示“七维池覆盖”，继续使用 §3.2 的槽位限制；明示覆盖的特定武器和饰品可以出现护体、定力。

任务首次完成通常解锁配方并提供第一次打造所需的唯一核心，不直接锁定七维结果。特殊效果不参与
随机、不占七维预算，也不能通过重铸改变。

## 6. 打造、重复打造、重铸与分解

### 6.1 重复打造

- 制式装备配方按模板组与装备等级档解锁，不指定最终品质和七维；每次打造生成独立实例。
- 地图 1、2 配方最高生成上品；地图 3、4 配方按对应地图概率生成珍品，永不生成古宝。
- 特定装备配方固定名称、装备等级、品质和效果，但每次重新生成七维。
- 特定珍品与古宝允许重复打造；任务只负责首次解锁与第一份核心。后续核心只能由对应任务回访、
  通关后委托或任务专属兑换获得，不从普通掉落和装备分解中生成。
- 同名特定装备允许存放多个实例，但同一修士不能同时装备两件同名饰品。

制式装备与非古宝特装使用以下单次打造成本；特装另消耗对应任务核心：

| 装备等级档 | 武器 | 防具 | 饰品 |

| Lv7～12 | 灵木40、玄铁35、灵晶8、灵石140 | 灵木30、玄铁45、灵晶6、灵石120 | 玄铁15、灵晶10、灵石90 |

打造固定成功；预览只显示品质规则、允许七维池、属性项数范围和固定效果，不能提前显示最终七维。

### 6.2 降尘丹炼制

炼器坊在地图 3 章末解锁降尘丹配方 `rcp_dustfall_pill`。每次消耗凝丹灵草 `1`、灵晶 `15`，
固定产出降尘丹 `1`；配方可重复使用。降尘丹不是装备，不生成品质、七维、随机种子或固定效果，
也不占装备待处理区。炼制与保存必须原子完成，失败时返还全部材料且不生成产物。

### 6.3 重铸

重铸保留装备实例的定义、槽位、职业限制、装备等级、品质、外观和固定效果，只重新生成全部七维：

1. 校验装备未处于野外、未锁定且材料足够。
2. 扣除材料并以新随机种子生成完整七维候选。
3. 同屏展示旧七维与新七维。
4. 玩家选择保留旧结果或接受新结果；无论选择哪组，材料均已消耗。
5. 选择与最终实例状态原子保存，刷新不能重复选择或重新抽取。

0.1 不提供锁定单条、指定属性、只洗数值或逐条重铸。

### 6.4 重铸成本与分解产物

新增通用材料“锻纹尘”，只由装备分解和少量高阶事件获得：

| 品质 | 分解所得锻纹尘 | 单次重铸成本 |
|---|---:|---|
| 粗制 | 1 | 锻纹尘2、灵石20 |
| 精制 | 3 | 锻纹尘6、灵石60 |
| 上品 | 8 | 锻纹尘16、玄铁8、灵石160 |
| 珍品 | 25 | 锻纹尘50、灵晶20、器灵残片1、灵石480 |
| 古宝 | 80 | 锻纹尘160、灵晶50、庚精3、古宝残片1、灵石1200 |

分解不再按固定打造成本返还50%，而是按品质返还锻纹尘，并返还该装备普通打造材料估值的 `25%`。
任务唯一核心、特定效果和古宝任务进度不因分解返还。已装备、锁定、任务保护和待比较中的装备不能分解。

## 7. 商店、存档与阵亡

- 商店普通栏可以刷新制式粗制、精制和上品装备，属性在商品生成时确定并进入刷新状态存档。
- 地图 3 解锁低概率珍品商品栏，但只出售无特殊效果的制式珍品；古宝与特定装备不进入普通栏。
- 剧情保底栏只保证打造材料、重铸材料和突破物，不保证指定七维或指定职业武器。
- 装备实例至少保存定义 ID、实例 ID、装备等级、品质、随机种子、最终七维、固定效果引用、来源和锁定状态。
- 全队阵亡时普通装备继续进入稳定实例 ID 减半池；任务核心与尚未领取的特定装备配方不参与损失。
- 仓库满时所有掉落、打造和重铸结果进入待处理区，不静默删除。

## 8. 战力、配装与通关口径

- 装备战力只统计最终随机七维之和；特殊效果不进入当前战力数字。
- 取消每职业、每地图固定推荐套装。配装建议只描述所需属性和机制，不指定必须装备的物品清单。
- 武器职业不符时可以存仓库、出售或分解，不能自动转换职业或重抽模板。
- 普通装备没有“毕业装”标签；高等级珍品可以因属性集中长期使用。
- 古宝综合七维远高于珍品，并附少量固定机制，但不是 0.1 主线门槛。
- 最终 Boss 检查结丹、群体恢复、承伤与对空方案，不检查指定装备 ID、品质数量或固定套装。

## 9. 装备验收

1. 制式装备只出现七维随机属性，不生成生命、命中、暴击、治疗、负重或技能强化随机词条。
2. 制式武器与饰品不出现护体、定力；玄甲不出现定力；法衣不出现护体；行衣护体与定力处于削弱区间。
3. 除硬限制外属性抽取等权，不读取职业、分支、当前队员或已穿装备改变概率。
4. 同等级同槽位古宝最低七维预算严格高于珍品最高预算。
5. 地图 1、2 不生成珍品，地图 3、4 只小概率生成珍品；任何普通来源都不生成古宝。
6. 特定装备的效果固定、七维随机；重铸不会改变品质、装备等级、名称和特殊效果。
7. 重复打造创建新实例；重铸候选只能确认一次，刷新不改结果、不复制装备、不退还材料。
8. 不依赖指定随机装备、珍品或古宝也能完成突破并通关；古宝只显著降低构筑压力。
9. 打造、重铸、保留旧结果、接受新结果、分解、装备、卸下和阵亡减半均原子保存。
