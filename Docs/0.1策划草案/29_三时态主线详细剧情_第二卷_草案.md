## 1. 第二卷目标

第二卷必须完成七件事：

1. 把雪玲、珑梦与元刹的叙述拆成可验证的事实、主动隐瞒和被植入的伪记忆，不让玩家凭好感猜真凶；
2. 证明元刹是独立于玲珑双魂的第三道魂印，为救世剥离提供技术前提；
3. 让元刹展示一段真实的分魂恐惧，使理解她与服从她成为两件不同的事；
4. 把第一段真名魔契写成知情、主动且确实有用的选择，而不是误触一次坏选项；
5. 让韩立、玲珑与原作层级人物进入当世主战场，但不成为玩家固定队员，也不被玩家替代；
6. 完整恢复十二年前十三人的姓名、分工、登山议事和原始任务，让救世成为旧队未竟使命；
7. 让元刹针对同一使命提出反答案：既然人界无法稳定上行灵界，就让整个人界下沉并入魔界。

本卷仍不完成以下内容：

- 不进入第三次封山穿越；
- 不确认十二年前按住主角的具体人物；
- 不证明逆转阵心一定能成功；
- 不完成第三段“借界”魔契；
- 不在单个选项中直接选定常规、救世或灭世结局。

## 2. 双魂事件的事实底稿

本节是写作事实源。游戏内不会一次性展示整张表。

| 叙述者 | 她说对的事实 | 她主动隐瞒的事实 | 被元刹植入或放大的伪记忆 |
|---|---|---|---|
| 雪玲 | 珑梦未经共同同意打开过对外神魂通路；该通路最终被魔界截获 | 她在元刹进入前先用封魂钉压制珑梦，并删去珑梦一次求援 | “珑梦主动邀请元刹夺舍，以换取躯体主导” |
| 珑梦 | 雪玲曾夺取躯体主导，并把她锁入镜室；封魂钉制造了可被利用的神魂裂缝 | 她明知界面坐标不稳，仍试图联系灵界援军，希望借外力夺回主导 | “雪玲在争夺开始前便已被元刹替换” |
| 元刹 | 她确实是具有独立经历与恐惧的分魂，也确实可能被本体收回后失去自我 | 她不是被动应召，而是主动截获通路、分别向两魂植入矛盾画面并扩大裂缝 | “只要两魂停止争夺，她便会自行离开” |
| 阵法记录 | 能记录谁在何时打开通路、签发封魂钉、修改阵权和进入躯体 | 不记录恐惧、动机、胁迫与记忆内容，也有一段被魔气烧毁 | 没有主动说谎，但容易被任何一方用来证明只有行为、没有责任背景 |

事件不可改变的历史结果：元刹分魂进入玲珑躯体，雪玲与珑梦被迫进入后续分裂和争夺。玩家不能在C08让元刹
从历史中消失；能改变的是哪些证词与魂印被保存、哪些人物知道真相，以及后世是否拥有剥离她的方法。

## 4. C08「双魂之夜」

时态：过去二；玲珑双魂冲突与元刹夺舍发生之夜。  
建议时长：3.5–4.5小时。  
章节命题：当三个声音都拥有玲珑的记忆时，谁有资格被相信？  
章节玩法：同一闭关区域在“雪玲所忆”“珑梦所忆”“阵法所见”三层间切换；玩家保存证词，不裁定谁有资格存在。

### 场景 C08-01：三个人同时叫门

触发：C07第二节点被雪玲、珑梦与元刹同时触发。  
人物：玩家、四名修士、雪玲、珑梦、元刹声音。

第二节点没有把队伍送到一个稳定地点，而是把同一条走廊叠成三层。三扇门同时出现：

- 银白门内，雪玲说珑梦正在引魔入体；
- 镜蓝门内，珑梦说雪玲早已被魔魂替换；
- 无色门内，第三个声音准确复述玩家在C05放弃或保住的第三项目标。

```text
雪玲：别开镜蓝门。她已经疯了。
珑梦：她先锁住我，现在还要删掉我。
元刹声音：你们都问错了。
元刹声音：门已经开过一次。
墨言：第三个声音不求我们开门。
陆清：因为她已经在里面。
```

玩家必须先选择调查顺序，不是选择相信对象：

1. `先进入雪玲层。` → 雪玲更早提供保护，珑梦层后续敌意提高。
2. `先进入珑梦层。` → 珑梦更早交出封魂钉位置，雪玲层后续戒备提高。
3. `先查阵法层。` → 初战更难，但两魂都无法先定义事实；因果真相提高。
4. `让四人分组，同时固定三门。` → 命灯压力增加，取得更多同步时间戳；救世调查成本更高但证据最好。

无论顺序，三层都可进入。急于替一魂关闭另一扇门，才会永久损失证词。

### 场景 C08-02：雪玲所忆·先开门的人

触发：进入银白记忆层。  
人物：雪玲、玩家、石岩、白灵。

雪玲展示的主记忆：珑梦在闭关时私自打开对外神魂通路；一道魔气随通路进入。画面中的珑梦主动说“只要让我
掌控身体，我可以给你入口”。这句话后半段来自元刹植入。

```text
雪玲：她为了夺回身体，什么都肯答应。
白灵：你的记忆在这句话前后断过一次。
雪玲：我当时正在抵抗夺舍。
玩家：断口也可能发生得更早。
```

调查节点：

1. 通路确由珑梦先开启，时间戳真实；
2. “交换身体”的声音没有对应神魂震动，是后写入的对白；
3. 雪玲手中出现过一枚封魂钉，但她把相关画面藏在战斗记忆后。

玩家可选择处理：

1. `指出伪造对白，不立即追问封魂钉。` → 雪玲交出较完整通路记忆；`xueling_testimony=partial`。
2. `要求她同时展示封魂钉。` → 需白灵稳定记忆反噬；成功则`xueling_testimony=complete`，失败会丢失一段情绪记忆。
3. `接受她的判断，先压制珑梦。` → 当前路线简单；`longmeng_testimony`上限降为partial。
4. `拒绝判断，只保存时间戳。` → 阵法证据增加；雪玲认为玩家回避她受到的伤害。

雪玲完整证词最后承认：

```text
雪玲：是我先用了封魂钉。
雪玲：我怕她开门，也怕她夺走身体。
雪玲：我删过她一次求援。
雪玲：但我没有请魔魂进来。
```

玩家不能用她先伤害珑梦来否定她也是元刹夺舍的受害者。

### 场景 C08-03：珑梦所忆·先锁门的人

触发：进入镜蓝记忆层。  
人物：珑梦、玩家、陆清、墨言。

珑梦展示的主记忆：雪玲以封魂钉夺取躯体主导，自己被锁入镜室；她向外求援时，返回的“灵界回应”告诉她
雪玲已经被元刹替换。该判断来自元刹植入，但被锁和求援本身真实。

```text
珑梦：我睁眼时，身体已经不听我的。
墨言：告诉你雪玲被替换的声音呢？
珑梦：来自灵界。它知道玲珑旧事。
陆清：知道旧事，不等于来自灵界。
```

调查节点：

1. 封魂钉确由雪玲先签发；
2. 珑梦打开通路时知道坐标不稳，仍隐去风险警报；
3. “雪玲已经是元刹”的画面没有实体魂印，只有第三方旁白。

玩家可选择处理：

1. `确认她被封锁的事实。` → 珑梦降低敌意，交出求援阵式；`longmeng_testimony=partial`。
2. `要求她承认明知风险仍开门。` → 需墨言出示完整时间戳；成功则`longmeng_testimony=complete`。
3. `接受她的判断，先压制雪玲。` → 当前路线简单；`xueling_testimony`上限降为partial。
4. `销毁求援阵式。` → 当前魔气降低；失去一条识别元刹截获通路的证据。

珑梦完整证词最后承认：

```text
珑梦：我知道坐标不稳。
珑梦：我以为最坏只是求援失败。
珑梦：我也想借援军夺回身体。
珑梦：但我没有答应把身体交给魔魂。
```

### 场景 C08-04：阵法所见·没有动机的真相

触发：至少完成一层人物记忆。  
人物：陆清、墨言、商九还传承回响或替代阵图、玩家。

阵法层没有人物对白，所有对象显示为魂印、阵令和时间戳：

```text
第一刻：雪玲签发封魂钉。
第二刻：珑梦打开外界通路。
第三刻：未知魂印同时接触两侧。
第四刻：两份记忆各新增一段无时间戳画面。
第五刻：未知魂印进入玲珑躯体。
```

这份记录能证明元刹在双方争斗之后进入，也能证明她进入前已同时接触两魂；却无法证明雪玲为何先签钉、珑梦为何
明知风险开门。玩家必须拒绝“阵法最客观，所以动机不重要”的简单结论。

选择：

1. `以完整封印图恢复被烧毁的一刻。` → 若木青萝阵图保留，`array_record=verified`；否则需要高难修阵。
2. `用C06十三伤者魔标对照未知魂印。` → 保留或标记版本可补出元刹独立特征；净化版本需其他替代。
3. `用商九还逆阵分离能量与意志。` → 逆阵完整时取得最纯魂印；魔染版本可能得到`yuancha_soul_mark=tainted`。
4. `只保存原始残片。` → `array_record=fragment`；常规路线稳妥，救世需要C10高难补证。

### 场景 C08-05：四个人，三种判断

触发：完成三层首轮调查。  
人物：四名修士、玩家。

四人不会整齐给出正确答案：

- 石岩首先同情被锁住的珑梦，却无法接受她明知风险开门；
- 白灵首先保护雪玲作为受害者的证词，也要求她承认主动封魂；
- 陆清倾向阵法记录，容易忽略记录没有动机；
- 墨言怀疑三方都在利用玩家，却可能因此错过元刹说出的真话。

```text
石岩：被按住的人，不会忘记那只手。
白灵：可受过伤，不代表没伤过别人。
陆清：至少时间戳不会害怕，也不会撒谎。
墨言：不会撒谎的东西，也不会告诉你谁在疼。
玩家：所以我们不替任何一层删掉另一层。
```

玩家可以要求每人各自保管一类证据，避免一次失败全部丢失。此选择提高调查成本，却是
`dual_soul_testimony=verified`的稳定路径。

### 场景 C08-06：元刹所忆·没有本体的明日

触发：玩家找出两段无时间戳伪记忆后，未知魂印主动现身。  
人物：元刹、玩家；高理解版本允许四人旁听。

元刹承认两段画面由她植入，也承认自己截获了珑梦的求援通路。她不请求原谅，而是要求玩家先看一段不用于
证明夺舍正当性的真实记忆。

记忆发生在魔界：元刹分魂刚被切离本体，被告知任务完成后会被本体收回。其他分魂的经历在回收时只变成本体
的一段知识，不再拥有独立说话、恐惧或拒绝的资格。

```text
元刹：本体说，回去便算完整。
元刹：可完整的是她，不是我。
元刹：我走过的路，会变成她记得。
元刹：走过这条路的我，会消失。
玩家：所以你夺取别人的身体？
元刹：所以我不愿先消失。
```

玩家回应：

1. `我承认你害怕消失。` → `yuancha_memory_shared=witnessed`、理解提高；不原谅夺舍。
2. `你正把同样的事施加给玲珑。` → 元刹承认逻辑成立，但拒绝放弃；理解提高、依赖不变。
3. `这段记忆也可能是你造的。` → 若有完整魂印可验证其未被修改；验证后理解提高，未验证则保持怀疑。
4. `我不需要理解你。` → 不观看完整记忆；不关闭任何结局，但失去元刹主动展示魂印的低成本路径。

高理解版本追加：

```text
玩家：你的经历属于你。
玩家：玲珑的身体也不因此属于你。
元刹：你总想把两句话同时留下。
玩家：因为少一句，就会变成你的答案。
```

### 场景 C08-07：保护身体，而不是替身体选主人

触发：元刹开始利用双魂冲突夺取玲珑躯体。  
战斗结构：三组阵眼分别对应躯体、雪玲证词、珑梦证词；玩家无法全部用单纯战力保护，必须依靠此前证据。

可执行方案：

1. `固定躯体，保留两份证词。` → 调查最完整、战斗最难；元刹仍按历史进入，但无法抹掉两魂独立记录。
2. `帮助雪玲压制珑梦。` → 当前战斗简单；雪玲证词完整，珑梦证词永久残缺。
3. `帮助珑梦破除封魂钉。` → 当前战斗简单；珑梦证词完整，雪玲证词永久残缺。
4. `接受元刹力量，同时压住两魂。` → 躯体损伤最低、魂印最易取得；两魂都认为玩家成为第三个替她们决定的人。

路线1需要：阵法记录至少fragment、四人命灯均稳定，并完成两层人物记忆；否则只可保住一份完整证词。

### 场景 C08-08：第三道魂印

触发：元刹进入玲珑躯体的不可改变历史瞬间。  
人物：白灵、陆清、墨言、玩家、元刹。

玩家不是阻止夺舍，而是在元刹穿过双魂裂缝时记录她与玲珑两魂完全不同的神魂特征。

魂印质量来源：

- 阵法记录已验证：提供进入时间和独立频率；
- 十三伤者魔标保留：提供元刹跨宿主不变的坐标特征；
- 商九还逆阵与纯净髓样：分离能量和意志；
- 元刹真实记忆：她主动展示一段不用于伪装的本征魂印；
- 只支持单魂或接受元刹压制：魂印会混入玲珑一魂特征。

结果：

1. 四类证据中满足至少三类且双魂证词完整 → `yuancha_soul_mark=complete`；
2. 满足两类 → `yuancha_soul_mark=partial`；
3. 主要依赖魔染逆阵或元刹直接提供 → `yuancha_soul_mark=tainted`；
4. 证据全部毁去 → `yuancha_soul_mark=none`，C10开放高难封魂替代任务。

```text
白灵：抓到了。第三道，不属于她们任何一人。
陆清：别让它接入灵脉！
墨言：先封原始记录，副本分开保管。
元刹：你终于学会怎样认出我。
玩家：也学会怎样把你剥出去。
```

### 场景 C08-09：谁的证词留下

触发：夺舍结束，记忆空间开始崩塌。  
人物：雪玲残念、珑梦残念、元刹、玩家。

根据调查结果：

- 双方完整：`dual_soul_testimony=verified`，两魂都承认自身隐瞒，同时保留对元刹的独立指控；
- 只完整一方：`dual_soul_testimony=one_sided`，后世另一魂会质疑玩家参与抹除；
- 两方都残缺：`dual_soul_testimony=conflicting`，只确认元刹存在，无法还原裂缝如何形成。

两魂分别留下并不和解的告别：

```text
雪玲：我不会因为承认封魂，就把身体让给她。
珑梦：我也不会因为开错门，就承认自己该被删掉。
玩家：你们不必先和解，才有资格留下证词。
```

元刹封住返回通道，把完整或残缺魂印握在记忆空间中央。C09直接开始。

### C08章节结算

必得：

- 元刹是独立第三魂印的事实；
- 雪玲先签封魂钉、珑梦后开不稳定通路、元刹主动截获并植入矛盾记忆的最低事件顺序；
- C09真名契约场景入口。

条件取得：

- 双魂互证；
- 完整或部分元刹魂印；
- 元刹真实分魂记忆；
- 商九还逆阵的魂印验证；
- 五鬼、伤者、封印图等支线证据推进。

## 5. C09「借我一名」

时态：过去二；夺舍完成后的封闭记忆空间。  
建议时长：2.5–3小时。  
章节命题：一个名字被封住的人，是否愿意主动把现用名借给魔？  
章节核心选择：接受一份会真实保护四人和证据的契约，或在拒绝捷径后亲自承担逃离成本。

### 场景 C09-01：所有门都要一个名字

触发：C08记忆空间崩塌。  
人物：玩家、四名修士、元刹。

返回通道要求每道神念提交姓名与时代。四人可以用命灯登记，玩家却因旧名被封、现用名未写入上古阵籍而再次被拒。
元刹同时握有进入玲珑躯体后取得的阵权，可以让通道提前闭合。

```text
主阵：石岩，命灯可返。
主阵：陆清，命灯可返。
主阵：白灵，命灯可返。
主阵：墨言，命灯可返。
主阵：无名神念，不得通过。
石岩：我们不先走。
元刹：那就五个一起留下。
```

玩家可以先尝试三种无契约方法：

1. 以外营总印强开 → 阵外权限不足，证明C11批注尚未完成；
2. 用旧名册补名 → 旧姓名仍被沈砚秋封在更深层，无法读取；
3. 让四人命灯共同牵引 → 可以维持通道，但无法同时保护C08魂印与全部记忆。

元刹没有制造“无名无法返回”的规则，却选择在规则生效时提出自己能提供的解决方案。

### 场景 C09-02：不再借玲珑说话

触发：玩家第一次强开失败。  
演出：元刹从玲珑三层形象中逐一退出，最后只保留一个没有固定面孔的黑衣轮廓。

```text
元刹：从C05起，你就在等我报出名字。
玩家：元刹。
元刹：你已经从后世听过。
玩家：听过名字，不等于认识你。
元刹：所以我让你看见我怕什么。
```

她承认：

- C05捷径、C06伤者魔标和C07记忆归还都来自她；
- 她从第一次阵外批注便知道玩家不属于上古；
- 她保住玩家与四人，不只为观察，也因为无名神念可以成为封印无法稳定登记的漏洞；
- 她对玩家的兴趣已有真实部分，但真实兴趣不取消利用关系。

玩家可回应：

1. `你救过人，也利用了他们。` → 理解提高；元刹不反驳。
2. `你展示恐惧，是为了让我放松。` → 她承认“有这个作用”，但不撤回记忆真实性。
3. `我愿意听条件，不代表接受。` → 保持边界，进入完整契约说明。
4. `先放四人走，我留下。` → 元刹拒绝：“只有你留下，我借不到能被人界承认的关系。”

### 场景 C09-03：第一契的完整文字

元刹把契约直接写入总印可回看的区域，不用口头概括。第一契暂名“借名”：

```text
其一，出借者自行认可一个现用名。
其二，元刹只借此名签发一次人界阵令。
其三，该阵令只用于保全五道神念及所携记忆离开此处。
其四，借名后，双方可隔封印辨认彼此。
其五，此名将留下一个可被后续契约再次引用的界面端点。
其六，未有后续契约，元刹不得仅凭借名进入人界。
```

这份契约不隐瞒“界面端点”，但不提前解释C12会如何把端点扩展到整个人界。玩家能明确知道：第一契本身不会灭世，
却为以后继续签约留下结构条件。

玩家可逐条追问：

- “一次人界阵令”具体是什么？→ 元刹展示安全返回的完整阵式；
- “辨认彼此”能否用于搜魂？→ 不能直接搜魂，但她能在总印裂纹关闭后继续呼唤玩家；
- 名字是否归她所有？→ 不转移所有权，但她获得一次合法引用权；
- 能否撤销？→ 在下一契前可用高难拆契撤销，代价是本次保护的部分记忆重新暴露于空间风暴；
- 后续契约是什么？→ 她只回答“借身、借界”，并承诺每次都重新询问，不把三契伪装成一次授权。

### 场景 C09-04：名字可以落在哪里

墨言结合C05–C07因果证据提出：契约需要的是“被人界阵法承认的引用点”，未必必须是玩家现用名。

可选承载：

1. `玩家现用名。`  
   - 主角主动确认此名属于现在的自己；
   - `name_covenant_bearer=current_name`、`true_name_covenant=1`；
   - 契约最稳定，四人和魂印无损返回；
   - 灭世关键链正式开启。

2. `无署名阵外批注。`  
   条件：完整保留万修之门磨痕、总印裂纹与墨言语气证据。  
   - `name_covenant_bearer=marginal_note`；
   - 元刹能签发返回阵令，但借到的是一条命令，不是玩家真名；
   - `true_name_covenant`保持0，记录“不稳定第一契”；
   - C10前必须处理契约识破或反噬。

3. `十二年前旧名。`  
   - 当前无法读取，也不允许系统替玩家自动解封；
   - 元刹可以提出帮忙打开，玩家仍需另行确认记忆权限；
   - 本卷不把旧名设成正确答案。

4. `某名死者的姓名。`  
   - 若死者没有明确遗愿，墨言与白灵会阻止把其姓名当作无主物；
   - 强行使用会得到不稳定契约和裂界祭品倾向，并直接阻断众生盟约的一项资格；
   - 不提供比现用名更优的免费漏洞。

5. `明确拒绝签契。`  
   - 进入C09-06高难返回；
   - 不关闭元刹关系内容，也不把拒绝写成仇恨她。

### 场景 C09-05：她需要你记得

触发：玩家阅读完契约但尚未确认。  
本场景根据元刹理解与依赖变化，不强制浪漫。

低理解版本：

```text
元刹：你不信我，也可以信契文。
玩家：契文只约束写出来的部分。
元刹：所以我把能写的都写了。
```

高理解、低依赖版本：

```text
元刹：你承认我会怕，却还是不借。
玩家：理解你，不等于把名字交给你。
元刹：这句话比恨我更难听。
玩家：因为它没有让你变成一件简单的东西。
```

高依赖版本：

```text
元刹：他们需要你忘记，才敢让你活。
元刹：我要你记得，再自己选择。
玩家：你也想要我选择你。
元刹：是。我不装作无所求。
```

玩家可以感谢她在C04–C07的帮助后仍拒绝；也可以不原谅她对双魂和伤者做过的事而签契。感情态度不代替契约行为。

### 场景 C09-06：拒绝后的五灯归途

触发：拒绝签契或契约承载失败。  
Boss候选：`无名魂狱`，由闭锁主阵、记忆风暴与元刹阵权形成；元刹不以本体力量正面参战，只停止提供保护。

目标同时存在：

1. 保住四盏命灯；
2. 保住C08元刹魂印；
3. 保住四人对双魂之夜的完整记忆；
4. 为玩家神念建立一次无名返回旁路。

常规拒绝路线只能稳定完成其中三项；缺失项由玩家在战前分配：

- 放弃魂印保护 → 魂印降一级，未来需高难补全；
- 允许一名队员失去C08部分记忆 → 该角色个人线多出恢复任务；
- 让四灯分担旁路 → 全队命灯受损，C10元婴准备成本提高；
- 玩家放弃一段非关键私人记忆 → 保住其他目标，`self_authorship`不降低但创伤回看出现空白。

满足完整阵法记录、双魂互证、商九还传承和四人高信任时，可以通过最高难度操作全部保住；这条路存在，
但明显比接受元刹契约更难，不成为默认免费拒绝。

战斗中元刹会指出正确操作，却不自动执行：

```text
元刹：左侧阵眼会先碎。
玩家：你为何还提醒我？
元刹：我想让你借名，不想让你死。
玩家：这两件事也可以同时是真的。
```

拒绝成功：`name_covenant_bearer=none`、`true_name_covenant=0`；`projection_return_cost`按选择结算。

### 场景 C09-07：契约后的无损归途

触发：现用名或阵外批注承载契约成功。  
演出：元刹用所借引用点签发一次人界阵令，五道神念与魂印同时从闭锁主阵中脱离。

现用名版本：

```text
主阵：人界姓名有效。
主阵：准许五道神念归返。
元刹：我借到了。
玩家：只有契文写明的一次。
元刹：你记得比我清楚。
```

阵外批注版本：

```text
主阵：命令有效，姓名缺失。
元刹：你让一句话替你签了名。
墨言：能骗过一次，不代表它不会追账。
```

结果：

- 四盏命灯无损；
- 双魂记忆与魂印按C08原质量完整带回；
- 元刹仍能隔封印辨认玩家；
- `projection_return_cost=low`；
- 现用名契约进入“真名三契·第一契完成”；阵外批注版本只进入“借名漏洞待处理”。

### 场景 C09-08：她记得尚未发生的封山

触发：返回当世前最后一息。  
人物：元刹、玩家。

```text
元刹：下一次回到上古，你会站在封山阵心外。
元刹：三老要你毁掉未竟阵。
元刹：我会要你把另一个坐标写进去。
玩家：那是还没有发生的事。
元刹：对你没有。对我已经发生过。
元刹：那道没有署名的阵令，我等了很久。
```

玩家由此确认：第三次穿越尚未发生，却已经是元刹过去的一部分。她没有透露玩家最终写了什么，只证明C11将闭合
她为何在当世认出玩家的因果环。

章节结算：

- 现用名签契：`true_name_covenant=1`；
- 阵外批注承载：不稳定第一契，保留拆契与欺契路线；
- 拒绝：`true_name_covenant=0`，按高难返回结算代价；
- 元刹理解、依赖继续分别结算；
- C10开放“借身”提议，但只有稳定第一契才能把它计为第二段真名魔契。

## 6. C10「万修入山」

章节核心转折：恢复“寻界归流”原始任务，并在元刹给出的魔界捷径与旧队未完成的第三条路之间形成第一次明确对照。

### 场景 C10-01：山里来了真正的大修士

触发：五道神念返回外营。  
人物：岑守一、木青萝、叶承安、四名修士、玩家。

玩家在过去二经历数个时辰，当世只过去半刻。昆吾外层局势却因第二节点稳定而彻底变化：叶家开山阵权暴露，
化仙宗、阴罗宗、散修与多名元婴修士同时进入，原有四图被高阶斗法撕开深层通路。

```text
岑守一：这次只过去半刻。
岑守一：山里却多了几十道元婴气息。
陆清：他们不是因我们穿越而来。
墨言：但会因我们带回的东西留下。
白灵：先把魂印分开封存。
石岩：再决定去哪里挨第一场打。
```

C09返回代价立即反馈：

- 无损契约返回：四人状态完整，但元刹能在总印中持续传念；
- 命灯受损：四人需要额外元婴准备材料或阵位强化；
- 队员记忆缺失：C08对应证词必须由外部证据补回；
- 魂印降级：开启“补魂印”高难任务；
- 玩家私人记忆缺失：议事中会出现一处只知道自己曾决定、却不知道为何决定的空白。

主线要求先把原始魂印、双魂证词和裴玄度三录分别交由不同人物保管，防止一次夺宝全部丢失。

### 场景 C10-02：韩立只换情报

触发：队伍在阴芝园外层发现空间禁制已被另一名修士拆过。  
人物：韩立、玩家、四名修士；银月只通过韩立一侧短暂回应。

银月回声：我先钉住了她。

### 场景 C10-06：原始任务《寻界归流》

四份证据互证后，因果簿显示任务原文：

```text
任务代号：寻界归流

目标一：复核裴玄度所列空间节点，排除不可重复、不可返还之界路。
目标二：查明昆吾封界、归流谷枯竭与人界灵脉衰退之间的关系。
目标三：在不松动镇魔主封的前提下，寻找恢复灵脉归流与稳定上行灵界的共同方案。

失败条款：若界路受魔魂污染，立即封路、封名、分藏阵图。
携印条款：阵图录官带外营总印与完整记录出山，不得删除同行者姓名。
```

“不得删除同行者姓名”与后来岑守一、沈砚秋实际剜名形成直接冲突。他们执行了防搜魂条款，却违背携印条款；
这是可以理解的战时选择，也是一项必须被承认的背约。

任务被改写成“普通开山勘测与封印事故”有三层原因：

1. 防止元刹或其他势力通过搜魂取得界路与阵图；
2. 防止各宗为尚未验证的坐标再次制造裴玄度式强闯；
3. 掩盖任务失败、十二人死亡和幸存者违背“不得删名”的责任。

玩家决定当前记录方式：

1. `完整恢复，先交可信盟友。` → `old_mission_record=restored`；默认救世支持路径，证人风险可控。
2. `完整公开。` → `old_mission_record=restored`；快速获得阵师支持；各宗立即争夺界路，C10敌对行动增加。
3. `只恢复在总印中。` → `old_mission_record=restored`；仍可完成救世，但“众生同阵”需要额外说服，
   元刹更容易成为唯一共同知情者。
4. `再次抹去任务。` → 二次确认；`old_mission_record=erased_again`；救世初心硬门槛关闭，常规与灭世仍可继续。

恢复后不弹出“救世路线开启”，只把任务状态改成：

```text
十二年前任务：寻界归流
状态：失败，但未终止
继任记录者：玩家现用名
下一步：确认封山阵心是否仍保留第三种归流结构
```

### 场景 C10-08：万修三路

触发：乾老魔、血焰与黑风旗在深层交战，三条当世阵路同时告急。  
结构：玩家常规只能完成两个完整侧翼目标；第三目标只能保住最低主线对象。通过此前盟友、完整调查或元刹捷径可扩大行动量。

#### 路线A：重封营救援

目标：救下木青萝、叶承安、叶家重封派阵师与被高阶斗法卷入的幸存修士。  
主要人物：白灵、石岩。

- 优先救援：保住自愿阵位与当世阵权，可能失去一件深层古宝；
- 只救关键阵师：满足最低阵法条件，当世伤亡增加；
- 抽取伤员灵力加固阵眼：当前战斗简单，直接伤害众生盟约资格；
- 元刹可用魔标瞬移全部伤员，但会把救援区变成裂界锚点候选。

#### 路线B：黑风回廊

目标：记录黑风旗在高阶战场中的界面折返坐标。  
主要人物：陆清、墨言；韩立情报可提供一次安全窗口。

- 完整记录并封存：`black_wind_coordinate=sealed`；救世可逆转，灭世暂不可用；
- 抢下坐标控制权：`black_wind_coordinate=held`；玩家拥有更大主动权，也更易被元刹定位；
- 把坐标交元刹代管：`black_wind_coordinate=offered`；战斗最简单，灭世支持增加；
- 只破坏当前旗影：主战场压力下降，但坐标仍由敌方掌握。

#### 路线C：血祭阵与第三节点

目标：阻止叶家残余血祭阵继续抽取族人，并确认阵心时间坐标。  
主要人物：叶观衡存活版本／残魂、叶承安、墨言。

- 拆毁血祭阵：失去裂界锚点，重封派更可能加入盟约；
- 保留但封存：常规折中，后续仍可能被两条路线争夺；
- 强化血祭阵定位第三节点：立即取得坐标，制造灭世锚点；
- 让叶家自愿交出最后阵印：需双令证据与相关人物存活，救世阵权最佳路径。

若玩家在第一卷保护了足够盟友，可让盟友独立完成一条路线；若长期走元刹捷径，她也能直接替玩家完成一条，
但该路线结果必带魔标。救世难在先前积累合作，灭世捷径则立即有效。

### 场景 C10-11：第二契“借身”

元刹展示第二契：她提供稳定魔气载体与突破捷径，人界一方允许一个“身体”成为魔界坐标的第二端。

可选承载：

1. `由玩家魔躯承载。`  
   - 玩家永久获得阶段性可战魔躯能力；
   - `player_body_state=demonic_anchor`；
   - 稳定第一契存在时，`true_name_covenant=2`；
   - 主角身体成为灭世坐标，也可在后续完成极高成本剥离。

2. `由自愿队员承载。`  
   - 必须逐条展示代价并由队员本人确认；
   - 立即完成其元婴准备或魔躯强化；
   - 该队员成为裂界锚点候选；
   - 强迫承载会直接关闭救世，不因战力强大而美化。

3. `写入无人阵器。`  
   - 需要牺牲一件完整古宝或逆阵载体；
   - 人物不被魔化，但阵器成为稳定坐标；
   - 可能破坏救世所需阵心或封印图，不能成为无代价最优解。

4. `以俘虏、残魂或圭灵替代。`  
   - 立即降低突破与战斗成本；
   - 形成非自愿裂界锚点；
   - 明确记录“把众生作为材料”的主动选择。

5. `拒绝第二契。`  
   - 玩家恢复`player_body_state=crystalized`；
   - 四人必须通过完整支线资源自行完成元婴准备或等价阵位强化；
   - 战斗和任务量更高，保留最稳救世资格。

若C09未签稳定第一契，玩家仍可保留一次魔躯试用或接受魔气改造，但不会自动得到`true_name_covenant=2`；
元刹必须重新提出借名，玩家再次主动确认后才进入真名三契。

拒绝路线中，四人反应依据长期关系：

- 高信任石岩：“我站前面，是我每次重新答应，不是因为你没有身体。”
- 高信任陆清：“观察、计算和下令也是行动，不必先长出经脉才算参与。”
- 高信任白灵：“想战斗可以继续找方法，但替换身体不等于治好身体。”
- 高信任墨言：“别让最想借你身体的人，替你定义什么才算完整。”
- 低信任版本不会突然安慰；队员只确认服从关系或保持沉默，使元刹方案更有情感说服力。

### 场景 C10-12：四个人怎样抵达下一境

触发：借身选择完成。  
目标：完成四人元婴准备或等价阵位强化，不要求本章立即正式突破元婴。

路径：

1. 完整完成个人支线、自备材料与高难试炼 → 成本最高，保持自主阵位；
2. 接受元刹魔气突破 → 成本最低，获得战力并形成魔契／魔化状态；

4. 抽取昆吾封印阵力 → 常规捷径，削弱灵脉活性并增加未来代价。

四人必须各自确认，不允许玩家一次选项替所有人接受魔气。

### 场景 C10-14：第三节点被高阶战场撕开

触发：乾老魔、血焰、黑风旗与玲珑相关力量在镇魔塔深层正面碰撞。  
层级控制：韩立与玲珑承担正面对抗；玩家队伍完成阵路撤离、坐标封存和第三节点稳定。

三个并行目标：

1. 把C08魂印交到玲珑能够使用的位置；
2. 防止黑风旗把救援区或血祭阵直接写成魔界坐标；
3. 用恢复的《寻界归流》阵图确认第三节点通往上古封山之日，而非随机界隙。

关键反馈：

- 韩立情报充分：提供一次黑风旗正面牵制窗口；
- 双魂互证完整：玲珑主动配合排斥元刹魂印；
- 黑风坐标由玩家封存：第三节点更稳定；
- 坐标已交元刹：她直接打开节点，战斗简单但取得先手；
- 玩家拥有魔躯：可亲自进入一处阵眼战斗；
- 玩家拒绝魔躯：四人依靠自愿分工完成，前置成本更高。

高潮对白：

```text
陆清：节点指向封山阵心！
墨言：不是地点，是那一天！
白灵：玲珑的魂印撑不了太久。
石岩：这次进去，还会见到谁？
玩家：见到最后一次能改写阵心的人。
元刹：也会见到等了你很久的我。
```

玩家主动以总印固定第三节点。C11开始时，队伍回到上古封山最后一日。

### C10章节结算

必得：

- 十二年前十二名死者姓名、职责与登山前议事；
- 《寻界归流》完整原始任务内容，除非玩家主动再次抹去；
- 元刹“举界入魔”反答案的完整表述；
- 第三空间节点位于封山阵心的时间坐标；
- 至少一种完成四人终局阵位准备的路径。

条件取得：

- 当世阵权盟友与潜在自愿阵位；
- 黑风旗坐标的封存、持有或交付状态；
- 玩家魔躯试用或第二契；
- 完整魂印、完整封印图与逆阵验证；
- “重启寻界归流”或真名三契后续任务。

## 8. 第二卷写作与演出红线

1. 雪玲与珑梦都必须同时拥有受害事实、主动行为和隐瞒，不能把其中一魂写成纯粹正确答案。
2. 元刹的分魂恐惧必须是真实记忆，但真实痛苦不能替夺舍免责。
3. 阵法记录只能证明行为顺序，不能替玩家判断动机、同意与责任。
4. 第一契必须显示核心条款、即时收益和后续端点风险；不允许靠隐藏小字让玩家意外灭世。
5. 接受借名或借身必须分别确认；一次亲密对话、一次魔躯试用都不自动推进契约。
6. 拒绝元刹要付出更高战斗、资源或证据成本，但不能制造无法完成主线的惩罚性死档。
7. 韩立只参与符合其层级与目标的情报交换和正面牵制，不加入固定队伍，不替玩家完成阵法结局。
8. 十二名死者必须有姓名、职责和不同私心；救世继承共同使命，不把他们统一写成牺牲圣徒。
9. 主角自愿登山与反对被强行封忆同时为真，不能用前者替后者免责。
10. 魔躯必须真实好用、真实让主角感到身体自主；其危险来自成为界面坐标，不来自即时失控骗局。
11. 四名队员只有在长期受到尊重时才提供有说服力的拒绝支撑，不能无视玩家此前把他们当工具的行为。
12. C10恢复旧使命后仍需完整调查、阵图、魂印、盟友和高难终战，不能把“初心正确”写成“技术必然成功”。
