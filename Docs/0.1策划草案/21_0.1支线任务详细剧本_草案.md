# 《昆吾禁地》0.1 四条支线任务详细剧本（草案）

版本：0.1-draft.4  
日期：2026-08-05

## 1. 通用规则

四条支线分别服务营地旧案、化仙宗使命、山中异类与魔道残魂。每条4–6个节点，贯穿至少
两张地图。支线不新增Boss，只使用事件、检定、普通战和精英战。任何不可逆选择都先显示
具体失去和获得内容；失败只改变路径或奖励，不锁主线。

本分册中的“净化残魂”“净化魔气”均为任务仪式和叙事选择，不是战斗中的状态净化技能；
仪式只在地图对象或对话节点结算，不进入战斗技能效果表。

## 2. 支线一：岑守一的旧阵簿

任务ID：`side_cen_old_ledger`  
主题：必要的牺牲是否仍需被记录。  
主要NPC：岑守一、旧营主沈砚秋残影、乌婆、顾南炉。

### Q1-01：少了十三个人

触发：地图1阅读废营粮册。玩家发现最后一页记录46人入山，回营栏只有33个名字，死亡栏为空。

```text
墨言：少了十三个人。
白灵：不是死亡。死亡栏一笔没写。
石岩：也不是失踪，墨迹被刮掉了。
陆清：刮痕和岑伯的阵钥同材质。
```

选项：

1. `把整本账带回。` → 占任务栏；岑守一无法否认。
2. `只拓印最后一页。` → 保留现场；地图3可找到后来翻阅者痕迹。
3. `先不告诉岑守一。` → `cen_secretive=true`；墨言在地图2发现晶钥后追加证词。

### Q1-02：账上无名

触发：回营与岑守一对话。

```text
玩家：四十六人入山，三十三人回营。
岑守一：旧账受潮，数字不准。
墨言：名字被阵钥刮掉，不是受潮。
岑守一：……那把钥，早丢了。
```

选项：

1. `给他一次自己说的机会。` → `cen_trust+1`；他说十三人执行北撤任务，但拒绝解释为何阵令只记录十二人闭门。
2. `当面说他在撒谎。` → `cen_trust-1`；他交出断裂阵钥，要求玩家自己去查。
3. `问十三人的家属。` → 解锁乌婆；岑守一：“十二年了，还有谁在等？”
4. `暂时收起账簿。` → 任务保持ACTIVE，地图2晶钥自动触发下一步。

### Q1-03：晶化阵钥

触发：地图2西阵眼后方。断钥与岑守一左腿晶纹产生共鸣。

```text
陆清：钥上封着一段阵令。
白灵：解开它，岑伯的旧伤也会发作。
墨言：不解，十二个死人和一个无名者都没有答案。
```

方法：

1. `远程请岑守一解除。` → `cen_trust≥1`时他同意；营地生产暂停5分钟，岑生命无战斗影响。
2. `由陆清破解。` → 法力SUM≥150；失败全队受法伤并引来四象阵灵。
3. `交给乌婆引魂。` → 需已解锁乌婆；付出玩家一段“初入营地”的回看记录作为仪式代价，
   只影响图鉴文本，不删除实际存档。

阵令残影：

```text
沈砚秋残影：北道已被魔气穿透。
沈砚秋残影：封门后，里面十二人出不来。
岑守一残影：再等一刻，他们也许能到。
沈砚秋残影：再等一刻，魔气也会到。
模糊人影：总印给我。至少把名字带出去。
岑守一残影：……阵钥给我。
```

揭示：命令由旧营主沈砚秋提出，但真正转动阵钥的是岑守一；第十三人已经越过门线，
身份被阵雾遮蔽。若`identity_clues≥2`，总印会与人影手中的裂纹完全重合。

### Q1-04：十三盏小灯

触发：地图3回程捷径附近发现十三盏熄灭小灯。点亮后只出现十二段亡魂，第十三盏不受引魂，
反而与玩家总印同步明灭。

- 点灯：消耗灵晶13；十二段无对白身影向玩家所在方向行礼；`identity_clues=max(当前,4)`、`cen_trust+1`。
- 取灯芯：得器灵残片6；岑守一支线结尾不会公开名册。
- 原样保留：乌婆可在回营后制作十二枚魂牌和一枚空白生牌，消耗灵晶6。

### Q1-05：最后一页写什么

触发：完成地图3后回营。

```text
岑守一：门是我封的。
岑守一：沈营主下令，我转的钥。
岑守一：十二个人死在门里。
岑守一：第十三个，被我藏进眠棺。
玩家：是我。
岑守一：是你。总印一直在等你醒。
岑守一：若重来一次，我仍会转。
岑守一：可我不该刮掉他们的名字。
```

此处可比主线祭坛更早确认玩家是第十三名幸存者，但只由沈砚秋留影在主线 M4-05 确认
阵图录官、继任掌印人与封忆原因。支线不是理解身份真相的必做条件。

不可逆选择：

1. `公开名册和阵令。` → 营地NPC知道真相；岑状态一章为“暂离议事”；获得归营符配方、
   守封者评价+1。
2. `恢复名字，不公开命令。` → 岑继续任管事；获得生产效率+5%和归营符配方。
3. `完整保留旧账，不替任何人下结论。` → 解锁所有残影回看；获得魂晶400。
4. `销毁旧账。` → 二次确认；得灵石300，`cen_trust=-2`，结尾岑另写一本新账。

无论选择，十二名死者进入图鉴；第十三席显示玩家现用名或“生还者·姓名待复”，任务COMPLETED。

## 3. 支线二：化仙宗遗命

任务ID：`side_huaxian_legacy`  
主题：后人是继承遗宝，还是继承责任。  
主要NPC：木青萝、化仙宗木夫人传讯、陆清、白灵。

### Q2-01：半张封印图

触发：地图2木魅庭院救出木青萝；若玩家封死庭院，则地图3由她自行脱困并以`mu_trust=-2`开始。

```text
木青萝：此图传了数千年。
木青萝：宗门只记得它指向灵宝。
木青萝：直到昆吾重开，师门才翻到后半句。
陆清：后半句是什么？
木青萝：持图者，代三老守封。
```

选项：

1. `先拓印，再还给她。` → `mu_trust+1`，玩家持任务拓印。
2. `封印图暂由联营保管。` → `mu_trust-1`，但地图2阵眼检定+10。
3. `图归你，责任也归你。` → 她反问玩家是否会退出昆吾；无数值变化。

### Q2-02：木夫人的命令

触发：修复任意三个阵眼后，木青萝收到宗门传讯。

```text
木夫人传讯：先取化龙玺，再谈封印。
木青萝：师叔，阵眼正在被抽空。
木夫人传讯：没有玺，你拿什么加固？
木青萝：若取宝途中封印先破呢？
木夫人传讯：修仙之人，没有无险之路。
```

玩家回应：

1. `支持先救阵眼。` → `mu_trust+1`；木青萝违令留下。
2. `化龙玺确实是关键。` → 她前往地图3入口等待；灵宝阁路线奖励+1。
3. `你该自己决定。` → 她选择依据当前`mu_trust`；高信任守阵，低信任取宝。

### Q2-03：三老碑文

触发：地图3灵宝阁残层。碑文缺三句，需要从三个机关取拓片。

谜面与答案：

1. “器可镇魔，亦可启魔” → 答“持器者之心”不改变器本身；神识检定。
2. “封链断一，先补何处” → 答“定界链”，否则地图4首次归营延迟。
3. “后人忘使命，遗宝归谁” → 无标准答案，记录玩家选择“宗门/守封者/众生”。

完成后木青萝发现化龙玺既能加固，也能抽取镇魔塔灵力。她承认宗门长期只保留“取宝”部分。

碑后同时显露一只镇幽魂匣，开启珍品装备支链：提交凝丹灵草1，并在五鬼袋支线中完成至少一名
残魂遗愿后，将该残魂安置进魂匣。三个节点全部完成时解锁镇幽符匣配方与首件核心；打造所得七维
按珍品规则随机。残魂只记录已安置状态，不从五鬼袋剧情中删除，也不影响该支线继续结算。

### Q2-04：是否借阵结丹

触发：地图4结丹祭坛前。

```text
木青萝：祭坛的灵力本用于封链。
陆清：借四份，不会立刻断裂。
木青萝：可每个“不会立刻”，都留给后来人。
```

选择：

1. `用自备材料结丹。` → 四人按标准共消耗凝丹灵晶 320；`seal_integrity+1`。
2. `借阵力，战后补回。` → 四人共少消耗凝丹灵晶 80，该 80 份转为“待归还阵力”任务物；最终战后提交则
   `seal_integrity+1`，拒绝提交则转为普通灵晶 80、`demonic_taint+1`并降低结局评价。
3. `以魔气代替灵力。` → 四人不消耗雪灵水；`demonic_taint+2`，木青萝信任-2。未用的 4 份雪灵水立即封存，
   战后可交给木青萝恢复 1 点信任并获得净魔散 4，不能出售或用第二次。

任何方式固定成功。选择 2 的归还发生在最终 Boss 之后，因此永远不影响主线入战资格；
未归还时支线保持 `READY_TO_TURN_IN`。首次完成本节点同时解锁回春玉配方与首件核心，打造时
按珍品规则随机七维。

### Q2-05：化仙宗后人

触发：最终战后回营。

```text
木青萝：我原本想带回一件灵宝。
木青萝：现在只带回一张补过的图。
岑守一：图能告诉后来人哪里会漏。
岑守一：比一件不知道怎么用的宝强。
```

选择：

1. `邀请木青萝留在外营。` → `mu_trust≥0`成功；解锁封印研究NPC和太清符印最终炼制节点；
   仍须满足镇幽符匣、玄箓修个人结丹试炼等前置。
2. `让她回宗门公开遗命。` → 获得灵石600，后续版本化仙宗态度友好。
3. `让她继续深入找木夫人。` → 深层门增加其标记；她暂离营，留下太清护魂符配方与首件核心。

若玩家使用魔气结丹，她会要求净化：提交魔髓碎屑4可恢复信任，否则仍完成任务但不入驻。

## 4. 支线三：失主的本命元牌

任务ID：`side_gui_ling_nameplate`  
主题：解除奴役不等于消除危险。  
主要NPC：圭灵残念、苏七衡、叶观衡、墨言。

### Q3-01：元牌开价

触发：地图3取得本命元牌后回到安全格，苏七衡传讯。

```text
苏七衡：黑底龟纹？那不是寻常禁牌。
苏七衡：叶家出八百灵石收它。
墨言：你怎么知道我们刚拿到？
苏七衡：商路若不比脚快，早断了。
```

选项：

1. `拒绝报价。` → 圭灵信任+1。
2. `让他加价。` → 提至1000灵石；接受则进入售卖分支。
3. `问买家是谁。` → 神识检定成功得知叶观衡；`ye_evidence`风味补充。
4. `用假牌试探。` → 万象符脉可用伪造符傀送牌；其他路线进行神识检定。成功后获得叶家交货坐标，可伏击一组敌人。

### Q3-02A：归还元牌

触发：Q3-01 选择“归还本命元牌”后立即激活，返回元牌密室并与第一根困灵钉交互时进入。  
若主线选择归还：圭灵残念要求玩家击碎三根困灵钉。

每根钉有不同代价：力道破坏会唤醒石傀；法力消融会消耗灵晶5；神识解印无资源但阈值高。
三钉全破后：

```text
圭灵残念：牌已归，锁未尽。
玩家：你答应不伤外营之人。
圭灵残念：我答应不主动入营。
墨言：它很会挑字眼。
```

选项：接受约定→地图3石灵中立；要求更严誓言→圭灵拒绝并离开；以元牌残片再束缚→回到保管分支。

### Q3-02B：暂时保管

触发：Q3-01 选择“暂时保管”后，每累计完成 3 场战斗触发一次，最多 2 次；第 2 次后直接等待 Q3-03。  
圭灵每完成三场战斗提出一次问题：“你与前一个持牌者有何不同？”

1. `我会在离山时归还。` → 圭灵信任+1。
2. `我需要你的力量。` → 获得护体增益，但圭灵信任-1。
3. `没有不同，只是我暂时更强。` → 圭灵认可坦白，信任不变。

地图4入口前必须再次决定归还、封存或交给叶家，不能无限携带跨版本。

### Q3-02C：交给叶家

触发：Q3-01 选择“交给叶观衡”后，在地图 3 下一个叶家传讯点进入。  
叶观衡支付灵石500并交出须弥扣配方线索，随后用元牌召来圭灵残影清理一组敌人。玩家发现残影每次
行动都在损失神魂。

```text
石岩：这不是驱使，是在烧它的魂。
叶观衡：器物本就为人所用。
墨言：那你血祭自己时，也算器物？
```

玩家可在地图4血祭前通过神识+遁速检定偷回元牌，正面索回（战斗），或维持交易。

### Q3-03：最终归属

触发：Q3-02A/B/C 任一分支完成，且玩家在地图 4 处理第二座封链枢纽后。  
三分支在地图4第二枢纽汇流：圭灵残念抵挡一次空间裂隙后要求最终答案。

1. `彻底归还。` → 圭灵离开昆吾外层；给予须弥扣完整配方与首件核心，打造时按珍品规则随机七维。
2. `封存在外营，不再驱使。` → 元牌成为营地关键物；地图探索负重+10；后续可继续其剧情。
3. `继续作为法器使用。` → 全队护体+6永久，`demonic_taint+1`，结局评价扣分。
4. `交给化仙宗保管。` → 需木青萝入驻意向；得洞玄镜片配方与首件核心、灵石300，圭灵不完全满意。

圭灵不会因一次善意就成为宠物或战斗单位。任务完成文本明确“暂时停止敌对”。

## 5. 支线四：阴罗宗的五鬼袋

任务ID：`side_yinluo_five_ghosts`  
主题：证据、力量与死者最后的意愿。  
主要NPC：韩枭、乌婆、五名残魂、白灵。

五名残魂：

| 残魂 | 生前身份 | 所知信息 | 所求 |
|---|---|---|---|
| 叶怀川 | 叶家重封派 | 叶月圣与血焰往来 | 把军令交给族人 |
| 方砚 | 化仙宗外门弟子 | 三老碑文缺句 | 将名字带回宗门 |
| 罗七 | 阴罗宗鬼卒 | 韩枭伏击路线 | 不再被炼成鬼物 |
| 阿蘅 | 山中采药人 | 镇魔塔侧狱捷径 | 找回药篓中的家书 |
| 无名古魂 | 昆吾旧守卫 | 第九层封链顺序 | 只记得“先定界” |

### Q4-01：袋中有人

触发：地图3击败或追踪韩枭取得破损五鬼袋。

```text
乌婆传讯：别直接打开。
乌婆传讯：五魂挤在一只袋里，会互相吃。
白灵：还能分开吗？
乌婆传讯：能。要么费灵力，要么费记忆。
```

选择分离方式：

1. `消耗灵晶25。` → 五魂稳定，后续对话完整。
2. `让乌婆取一段记忆。` → 从已回看剧情中选择一段交出；对应图鉴暂时隐藏，通关后恢复。
3. `让白灵以镇魂符隔魂。` → 镇幽符脉可选；五魂稳定，获得对鬼伤害增益，不增加 `demonic_taint`。
4. `强行打开。` → 随机一魂消散，但叶怀川不会被随机删除，确保主线证据存在。

### Q4-02：五个遗愿

触发：Q4-01 选择暂不打开五鬼袋后，与乌婆对话并完成一次引魂；五个遗愿同时进入 ACTIVE。  
玩家可按任意顺序完成：

- 叶怀川：把军令交给叶承安或留作证据。交出得信任，留下得叶家敌群情报。
- 方砚：在三老碑补刻姓名。木青萝信任+1。
- 罗七：击败一组阴罗宗追兵后选择净化或让其指认韩枭藏物。
- 阿蘅：地图4侧狱找药篓；家书交营地获得灵粮生产+3%，焚化则残魂立刻安息。
- 无名古魂：带到定界链；它补出正确修复顺序，使第一处枢纽材料-2。

每完成一个遗愿，五鬼袋的战斗增益降低一层，但净化奖励提高。UI明确显示该取舍。

### Q4-03：韩枭讨袋

触发：完成至少三个遗愿后。韩枭提出用一只封存的地图3高危制式装备匣换回五鬼袋；匣子不允许
选择职业、槽位或七维，开启时才按稳定种子生成实例。


### Q4-04：净化或炼化

触发：地图4封魂间。不可逆二次确认。

1. `逐一净化。` → 每完成的遗愿使成功率和奖励提高；最低获得太清护魂符配方与首件核心，全部完成额外
   得魂晶600、守封者评价+1。

   直接攻击20%基础命中附加定力-10%/80 tick；`demonic_taint+2`，白灵信任风味下降。
3. `让乌婆封存，待以后寻找轮回法。` → 获得护魂牌配方、首件核心和营地残魂图鉴；无即时高数值奖励。
