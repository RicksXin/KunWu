## 1. 技能定型规则

1. 炼气期每个初始职业有 3 个过渡技能。
2. Lv10 完成筑基转职后，一次性替换为该分支的 3 个核心技能；自此技能 ID、目标类型和核心机制全部锁定。
3. Lv20 突破结丹不更换技能，只将原技能提升到 `mastery` 数值，显示名增加 `【精通】`前缀。
4. 后续版本预留：元婴为`【小圆满】`、化神为`【大圆满】`，仍只增强属性；到炼虚期才允许替换新技能。
5. 0.1 共有 `36` 个稳定技能 ID：12 个炼气过渡技能+8 条筑基分支×3 个核心技能。
6. 0.1 暂不提供战斗净化技能。减益通过持续时间、抵抗、恢复、护盾和机制打断应对。

### 1.1 表格口径

- `I/CD`：基础行动间隔/冷却，单位 tick；20 tick=1 秒。
- `筑基`：Lv11–20 使用的基准数值。
- `结丹【精通】`：Lv21–30 使用的增强数值；未写变化的目标、标签和规则完全沿用筑基版。
- 伤害、治疗、护盾和 DoT 先按属性倍率向下取整，再进入战斗公式。
- 多段技能逐段结算命中和暴击；DoT 不暴击。

## 7. 默认自动策略

- 护山/玄甲：自身无嘲讽→守岳吼；自身无反击势→回锋罡；否则对高威胁单体使用镇岳击。
- 御剑：Boss飞行且无御剑步→御剑步；敌人≥3→剑气分光；否则穿云剑。
- 雷法：全队平均生命<70%→雷泽回元；可命中目标≥2且有导电→雷链；否则引雷术。
- 玄冰：全队平均生命<70%→寒泉回生；敌人≥2→凝霜界；否则玄冰刺。
- 丹医：全队平均生命<75%或有人<40%→百草回元；敌人≥3→丹火涌；否则灵药击。
- 毒丹：自身生命<60%且敌方有毒→吞毒化元；敌人≥3→毒雾；否则腐心毒。
- 绝影：无绝踪且 Boss生命<45%→绝踪；连影刃可用→连影刃；否则无声刺。
- 探秘：Boss无弱点→洞微标记；敌方有盾→破禁刃；否则天机步覆盖后主攻。

## 8. 技能与 Boss 机制对应

| 需求 | 主解 | 替代解 | 装备容错 |
|---|---|---|---|
| 稳定承伤 | 护山剑卫 | 御剑闪避+凝霜迟缓 | 镇魔宝甲、封魔令 |
| 处理飞行 | 御剑步 | 探秘弱点、法术攻击 | 残翅骨环、镇魔剑 |
| 群体续航 | 法修群体恢复 | 丹医百草回元 | 回春玉、太清丹鼎 |
| 尸毒压力 | 高定力+群体恢复 | 毒丹自续航后优先保护其他人 | 清灵囊、太清护魂符 |
| 拆部位/护盾 | 探秘破禁刃 | 雷链、御剑爆发 | 铸灵指环 |

最终 Boss 不要求战斗净化。尸毒只考验持续恢复、定力/装备抵抗、目标保护和阶段输出速度。

## 9. 技能验收

1. 数据表恰有 36 个稳定技能 ID；四个炼气职业和八个筑基分支各引用 3 个。
2. 结丹前后的修士技能 ID 完全相同，只有 proficiency 与数值变化。
3. 结丹后显示`【精通】技能名`，存档不保存带前缀的文本。
4. 法修任意路线恰为 2 输出+1 群体恢复；丹医恰为 2 输出+1 恢复；毒丹恰为 2 输出+1 自吸血。
5. 所有减益都能自然结束，没有战斗必需的净化检查。
6. 自动策略不在全队满生命时使用恢复，不在无毒目标时使用吞毒化元。
7. 在同属性、同敌人和同随机种子下，`【精通】`版不得比筑基版伤害、治疗、护盾或状态强度更低。
