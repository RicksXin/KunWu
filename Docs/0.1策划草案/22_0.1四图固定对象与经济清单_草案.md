## 1. 坐标与刷新规则

坐标原点、Tiled转换和`GridCoord`沿用PRD-05。下列坐标为内容锚点，进入Tiled制作后允许在
不改变区域关系的前提下移动±3格，但任务、数据和文案必须同步引用稳定`objectId`，不能把
坐标直接写进任务判断。

### 1.1 数据边界不等于可玩轮廓

每张地图仍使用矩形 `width×height` 数据边界，便于 Tiled、迷雾位集、存档和寻路索引；但玩家可行走范围
必须由 `walkableMask`、地形碰撞和建筑占地共同塑造成异形。不允许把整个矩形铺成可走地砖。

| 层 | 职责 | 规则 |
|---|---|---|
| 数据边界 | 坐标、迷雾、存档 | 仍为矩形，不直接决定场景外形 |
| 可玩轮廓 | 玩家和敌人寻路 | 使用峭壁、屋体、深坑、封印墙、山脊和水面挖去不可走区 |
| 视觉遮挡 | 树冠、屋顶、拱门、山石前景 | 可遮住角色，但不单独决定碰撞 |
| 交互可读性 | 任务、宝箱、出口、危险预警 | 遮挡透明后仍显示轮廓与交互图标，不得用遮挡制造无提示陷阱 |

遮挡物数据使用 `occluderId + polygon + fadeAlpha + fadeTicks + sortingBand`。角色进入遮挡多边形时，
前景在 6 tick 内降到 35% 透明度；离开后 10 tick 恢复。Boss 预警区、任务目标和玩家头顶状态始终绘制在
可渐隐遮挡层之上。

### 1.2 对象刷新

| 对象 | 同次入山 | 重新启程 | 跨存档刷新 |
|---|---|---|---|
| 普通敌群 | 击败后消失 | 刷新，魂晶按重复比例 | 刷新 |
| 精英 | 击败后消失 | 按对象配置刷新 | 首次奖励不重置 |
| Boss | 首杀后永久完成 | 不刷新 | 不刷新 |
| 普通资源点 | 采完进入COOLDOWN | 刷新为首次产量50% | 刷新状态保存 |
| 地标资源/宝箱 | 一次性 | 不刷新 | 不刷新 |
| 剧情事件 | 保存分支结果 | 不重置 | 不重置 |
| 小副本敌人 | 本次清除 | 刷新 | 宝箱和剧情不刷新 |
| 捷径/传送 | 激活后保持 | 保持 | 永久保存 |

## 2. 地图1固定对象

尺寸48×64；入口`(24,61)`；主路径约58步，最短Boss路径约44步。任意连续12步内至少有

- 可玩轮廓是“上窄—中宽—下窄”的山谷长条，南北主路清晰，适合第一张教学图。

- 地图 1 不使用多层桥梁或视觉传送，主要教会“遮挡会渐隐、山体不可穿越”。

## 3. 地图2固定对象

尺寸64×64；入口`(31,60)`；开放环形结构，四阵眼任意顺序。入口到任一阵眼最短20–30步，
四阵眼之间均有横向连接，玩家无需每次回入口。

### 3.1 地形轮廓与遮挡

- 可玩轮廓是一个圆角十字广场，四条玉道通向四个庄园式阵眼庭院；结构开放但仍容易识别方位。
- 西北、东北、西南、东南四角分别放置叶家行院、荒废丹院、木魅庭院和封尸坛。建筑屋体不可通行，但每个庄园都有
  一个中庭、一个侧门和一条绕墙小路，不是整块封死的方形障碍。
- 中央白玉广场为不规则八边形，四条玉道宽 4–6 格；外环被树根、倒塌玉墙和院落挤压成宽窄不一的环路。
- 屋顶、树冠和门楼是主要遮挡物；进入庭院后屋顶渐隐，但墙体底座仍保留，让玩家知道哪里不能走。
- 地图 2 不使用立体跨层；异形感主要由四角庄园、八边形中心和不规则外环形成。

## 4. 地图3固定对象

尺寸56×72；入口`(27,68)`；三大区域呈三角：昆吾殿外苑、灵宝阁残层、铸灵堂地宫。
先后顺序改变伏击和宝物数量，但主线最终遍历三处。

### 4.1 地形轮廓与遮挡

- 可玩轮廓是三个大小不同的岛状建筑区，由山腹石桥、斜坡和机关廊道连成一个不对称三角，地图外轮廓不再接近矩形。
- 一条昆吾山脊从西南`(3,18)`斜穿至东北`(52,65)`，把地图切成两个视觉高差区。只有`(18,43)`断桥、`(33,51)`山洞和
  `(39,18)`铸灵堂升降台能穿越山脊，捷径会改变后续回访路线。
- 昆吾殿外苑为破碎扇形，灵宝阁为崩落的多边形残层，铸灵堂为向下收缩的螺旋坑；三区不使用相同的方院布局。
- 山脊前景、悬桥链条、灵宝阁残顶和铸灵堂吊炉可遮挡角色。吊炉渐隐时仍保留红热边缘，避免玩家误判危险地格。
- 地图 3 允许路线在屏幕上被山体短暂遮断，但地图界面必须显示已发现的洞口和桥头连接关系。

## 5. 地图4固定对象

尺寸72×64；入口`(8,59)`；三条封链构成逐步降低风险的主循环。Boss前必须经过结丹祭坛，
但两个侧副本和多数资源可由筑基圆满队伍先行探索。

### 5.1 地形轮廓与遮挡

- 可玩轮廓是“破碎环带+三条向内收束的封链长臂”，中央是不可走的倒置镇魔塔外壁和魔气深坑。
- 西北入口臂偏宽、定界链臂细长、镇尸链臂被倒塌塔石切成双道、锁魂链臂呈锯齿形；三条路不做镜像对称。
- 地图中部有两块不规则空间裂隙，各占约 9×12 和 7×16 格；只能经封链桥或侧狱地道绕过。
- 黑色塔柱、横跨画面的封链和魔雾是主遮挡物。封链不整体渐隐，只将角色周围 5 格内的链节淡化，保留规模感。
- Boss 区是新月形断台，不是方形房间；台面外缘有三个残羽落点，阶段三召唤物从不同方向进场。
- 地图 4 允许大面积前景和空白深坑塑造压迫感，但主任务路径始终有封链光纹作为导航。

## 7. 回访与补给死锁检查

- 每图入口到首个可补充灵粮食材的固定点不超过18步。
- 开启地图捷径后，从Boss区回入口的最低灵粮分别不超过18/24/32/40。
- UI返程估算包含已开启捷径和地形成本，不把尚未修复的传送当作可走路径。
- 主线任务物不占负重；尸体救援等特殊负重在接取前显示重量和返程变化。
- 无归营符且灵粮不足时，地图至少提供一处可通过战斗获取的野外食材，但不保证无风险。
- 第4个衰竭步不触发终点对象，避免“刚好走到补给点却仍结算奖励”的歧义。

## 8. 固定对象验收

1. 所有任务、Boss、资源、捷径和出口均有稳定objectId，坐标只属于地图数据。
2. 不存在超过20步的无内容空走区，也不存在必须穿越不可战胜精英的唯一主路。
3. 四图所有首次资源总量足以覆盖筑基、结丹和三件地图4武器的确定性打造需求。
4. 普通敌、精英、资源、宝箱和剧情使用各自刷新规则，刷新网页不重置同次入山状态。
5. 每个不可返回出口提前提示，所有捷径激活后跨刷新保留。
