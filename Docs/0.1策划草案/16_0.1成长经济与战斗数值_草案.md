## 1. 数值目标

本分册冻结 0.1 的 Lv1–30 成长、魂晶消耗、筑基/结丹材料、七维与生命计算、战斗二级
属性、状态结算和十小时资源投放。所有数值均为首轮可仿真基线，不允许 UI 另写一份公式。

设计目标：

1. 固定四人无需随机招募即可在 8–12 小时内全员结丹并通关。
2. 等级、装备和策略均有贡献；任何一项都不能单独覆盖最终 Boss 机制。
3. 主线和固定探索提供通关所需资源，重复刷怪只负责容错和通关后培养。
4. 筑基与结丹固定成功，不设置概率、保底、掉境界或付费加速。
5. 杂灵根墨言仍能完成主线，不要求替换为高资质同职业修士。

## 3. 七维成长

### 3.1 计算方式

```text
最终七维
= 灵根缩放后的 Lv1 基础
+ 炼气阶段逐级成长
+ 筑基/结丹所选路线的分段逐级成长
+ 结丹一次性属性
+ 装备
+ 状态
```

成长率使用千分位整数，`3000` 表示每级 `+3.0`；每段内部先累计、后向下取整。不能用
当前职业成长率回算 Lv1 至当前等级，否则转职会篡改已经获得的历史属性。

目标数据模型至少保存 `careerHistory[{careerId, fromLevel, toLevel}]`，或在突破时固化
`accumulatedGrowth`。现有 `HeroFactory` 只根据当前职业和 `(level-1)` 回算，无法满足本规则。

## 4. 战斗二级属性与公式

### 4.1 基础公式

```text
生命上限 = 职业基础生命 + 肉身 × 8 + 装备生命
物理基础伤害 = 力道 × 主倍率 + 神识 × 副倍率
法术基础伤害 = 法力 × 主倍率 + 神识 × 副倍率
物理减伤 = 护体 / (护体 + K(等级))
法术减伤 = 定力 / (定力 + K(等级))
K(等级) = 100 + floor(24 × (等级 - 1) / 10)
行动间隔 = clamp(基础间隔 × 100 / (100 + 最终遁速), 4, 200) tick
```

模拟频率 20Hz，`20 tick=1 秒`。所有乘法先乘后除并向下取整，最终直接伤害至少 1。

### 4.2 命中、暴击与状态命中

```text
命中率 = clamp(90% + (攻方神识-守方神识) × 0.25%, 70%, 100%) + 装备命中
闪避率 = clamp((守方遁速-攻方神识) × 0.20%, 0%, 15%) + 技能/装备闪避
最终命中率 = clamp(命中率-闪避率, 50%, 100%)
暴击率 = clamp(5% + 攻方神识 / (攻方神识+200) × 25%, 5%, 30%) + 装备暴击
暴击伤害 = 150% + 装备暴伤
状态命中率 = clamp(技能基础命中 + (攻方神识-守方定力) × 0.3%, 25%, 100%)
```

治疗、护盾、确定性 Boss 机制技能不做普通命中判定。每次战斗使用稳定随机种子；刷新重打
可以产生新战斗种子，但同一快照回放必须一致。

### 4.3 状态统一语义

| 状态 | 数值语义 | 叠加 |
|---|---|---|
| 护盾 | 先于生命吸收伤害 | 不同来源相加；同来源取较高并刷新 |
| 加速/迟缓 | 最终行动间隔乘以 `(1-加速%)` / `(1+迟缓%)` | 各取最强，互相抵消后结算 |
| 聚灵/嘲讽 | 单体技能优先选取最高嘲讽强度者 | 取最高 |
| 伤害提升 | 最终伤害乘算 | 同来源刷新，不同来源相加，上限 60% |
| 破甲/降抗 | 目标护体/定力按百分比降低 | 相加，上限 50% |
| 中毒/灼烧 | 每 `20 tick` 结算一次，伤害由施加者属性快照计算 | 中毒最多 3 层；灼烧取最高并刷新 |
| 流血 | 每 `20 tick` 结算；不暴击，忽略护体与定力 | 最多 3 层；同来源刷新，不同来源独立 |
| 再生 | 每 `20 tick` 治疗；使用施加时属性快照，不暴击 | 同来源取较高并刷新；不同来源最多 2 个 |
| 导电 | 本身不造成伤害；为雷系技能提供增伤和连锁依据 | 最多 3 层；新层刷新全部剩余时间 |
| 弱点 | 把配置的命中/暴击/飞行命中加成给所有攻击者 | 同目标只保留效果较强者并刷新 |
| 眩晕 | 无法行动，行动计时暂停 | Boss 同战共享硬控计数：前三次持续 100%/60%/30%，第四次起免疫 |
| 冻结 | 无法行动，行动计时暂停；只能等待持续结束 | 与眩晕共用同一硬控递减计数 |
| 缠绕 | 无法行动，不阻止被动效果；只能等待持续结束 | 同上 |
| 沉默/封灵 | 不能使用带法术/状态标签的技能，可普通攻击 | 取最长 |
| 恐惧 | 行动就绪时基础 50% 概率延后 20 tick；每次施加最多触发一次 | 持续时间取最长，等待自然结束 |
| 尸毒 | 中毒类且降低受治疗效果 | 最多 3 层 |
| 空间错位 | 立即把行动计时增加 30 tick，不再另加持续减速 | 每次命中独立执行；天机步只减少惩罚数值 |
| 魔气侵蚀 | 每层造成伤害+4%、受到伤害+6%，地图与战斗跨系统 | 最多 5 层，安全归营清除 |
| 飞行 | 单位标签，使普通近战最终命中-35% | 法术、御剑、弱点和明示可对空效果忽略惩罚 |

持续伤害共同规则：中毒、尸毒和流血忽略护体/定力；灼烧属法术伤害并经定力减伤；全部 DoT
不暴击、不触发“直接攻击”特效，且使用施加时的属性快照。某个效果若明示写“固定伤害”，则不受任何增减伤修正。

“状态抵抗 +X%”从最终状态命中率中减 X 个百分点，仍受 25% 下限约束；“控制抵抗 +X%”只把眩晕、
冻结、缠绕和恐惧的成功持续时间乘以 `(1-X%)`，向上取整，不改变命中率。受伤减免同来源取最高，
不同来源相加后上限 50%；命中、闪避、暴击最后仍分别经 §4.2 的上下限截断。

### 4.4 当前实现缺口

详细技能表落地前必须扩展现有技能 Schema：

- `appliesStatus` 改为 `effects[]`，支持一次技能同时伤害、治疗、护盾、吸血和附加状态。
- DoT 增加 `tickIntervalTicks`、属性倍率、最大层数和来源快照；不得继续每个 20Hz tick 跳伤害。
- 增加 `hitCount`、`baseHitChance`、`baseCritChance`、`cannotCrit`、`tags`。
- 目标规则增加按任意七维取最高/最低、按状态层数和按生命百分比选择；不能继续把
  “最高属性目标”硬编码为只比较力道。
- 护盾数值改为属性倍率而非只能填静态 `magnitude`。
- 加速、迟缓、伤害提升、反击、群体恢复和自吸血真正进入公式。
- 百分比破甲与当前平铺数值削减分开建模。
- 支持生命阈值、目标状态和敌人数等 AI 条件。
- 支持 Boss 阶段、部件、召唤物和不受普通抵抗影响的阶段状态。
- `StatusKind` 补入恐惧、尸毒、魔气侵蚀、弱点、导电、飞行和空间错位；飞行、部件状态和阶段标记是单位/战斗状态，不是常规减益。

## 6. 数值验收

1. 任选四个合法筑基分支组合，都能在全员结丹、队伍战力 1280–1400 时击败最终 Boss。
2. 不做支线仍可结丹并通关，但装备选择更窄、最终战容错更低。
3. 全支线玩家不需要重复清同一张图的普通敌群超过两轮。
4. Lv20 未结丹队伍即使战力达到 1280，也不能进入最终 Boss；UI 明确说明境界条件。
5. 分段成长在转职前后不重算历史属性，存档刷新后面板完全一致。
6. DoT 只按配置间隔跳伤，不随渲染帧率或 20Hz 每 tick 错误放大。
7. 魂晶、突破材料和打造消耗均有事务回滚，任何保存失败不产生半完成角色。
