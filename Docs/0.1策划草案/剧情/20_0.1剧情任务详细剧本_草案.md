## 第一编：0.1主线 P0–C04

### 1. 剧本执行规则

玩家可自定义现用名（醒来后自取，不冒充被封存的旧姓名），表层身份是新任山外联营营主，正式称谓为“掌印人”。玩家在新档开始前三日
从议事殿地下的镇魂眠棺中醒来，只记得醒来后的事；经脉已晶化，不能占据战斗阵位，但可通过外营总印
连接四名修士的命灯，在探索中传念、观察并操作守封机关。剧本中的“玩家”台词默认经总印传出。

0.1 必须回答“我是谁”：玩家是十二年前旧开山队被阵簿抹去的第十三名成员，职责为阵图录官，
也是十三人中唯一仍活着的人。旧营主沈砚秋在北撤退道封闭前将外营总印托付给玩家，并封住其姓名、
阵路记忆与神魂气息，使古魔无法搜魂取得外层封印路径。总印中的继任令使玩家拥有营主权限，
不是血脉、转世或隐藏修为授予的特权。

0.1 暂不完全回答“当年是否自愿”：沈砚秋留影说玩家主动承担，破损记忆中却有一句“按住此人”。
这个矛盾是后续版本钩子，不影响本版本确认玩家的经历、权限来源和与昆吾封印的关系。玩家不扮演韩立，
也不替代原作高阶人物；四名固定修士是掌印人直接指挥的小队。

所有单句推荐不超过36个汉字。可跳过文字表现，但不可跳过状态结算。选项分为：

- `态度`：改变信任、风味台词和结局评价，不阻断主线。
- `方法`：改变资源、战斗或检定路径，最终汇流到同一主线节点。
- `不可逆`：选择前显示后果并二次确认；主线只在章节级汇流，不产生永久失败。

### 4. 序章：接掌外营

#### 场景 P0-01：熄灯十二年

触发：新档完成Boot，第一次进入议事殿。  
人物：岑守一、玩家。  
镜头：镇魂眠棺回闪→玩家手中的裂纹营印→账簿被撕去的一角→岑守一左腿晶纹。

```text
岑守一：三日前，你从地下自己醒了。
岑守一：营印认你。我还没有。
玩家：我为何知道你的名字？
岑守一：这也是我不敢认你的原因。
岑守一：山门外的灯，熄了十二年。
岑守一：想知道自己是谁，先让灯亮。
岑守一：宝物不会跑，人却会饿死。
岑守一：灵圃只剩六名杂役。
岑守一：先让他们动起来，再谈入山。
```

选项：

1. `我是谁？` → 岑守一：“先证明总印没有认错人。”；`identity_clues=max(当前,1)`，身份目标置顶。
2. `十二年，为何无人接管？` → 岑守一回避；解锁支线提示“旧阵簿”；`cen_trust 0`。
3. `营印认我，便先尽营主之责。` → `cen_trust+1`，身份目标仍保留。
4. `我先看阵图。` → 岑守一：“你醒来第一句话也是这个。”；`identity_clues=max(当前,1)`、`cen_trust-1`。

结算：解锁议事殿、灵圃、百宝库；主线同时显示长期问题“总印为何认我”和当前目标
“分配至少1名杂役生产灵粮”。长期问题不占用导航槽，但每获得身份线索都会短暂更新。

#### 场景 P0-02：四个人，一条路

触发：首次生产结算后点击传送阵。  
人物：岑守一、石岩、陆清、白灵、墨言。

```text
石岩：山路若塌，我走前面。
陆清：阵灯熄灭未必是灵力耗尽。
白灵：先备伤药。旧尸也会伤人。
墨言：也可能是活人比旧尸更麻烦。
岑守一：这四个，就是外营的家底。
岑守一：灵息不足，谁也别逞强。
```

选项：

1. `按稳妥路线，先找阵灯。` → 初始任务导航显示最近阵灯。
2. `先搜废营，也许有补给。` → 标出废营方向，但敌群危险提示提前出现。
3. `先查尸体。` → 墨言好感风味；标出叶家尸首，仍需完成阵灯。

结算：解锁入山整备；固定四人进入第一队；发放灵粮35、开山镐1、探灵镜1、归营符1。

### 5. 第一章：山门灯灭

#### 场景 M1-01：第一盏阵灯

触发：进入`map_01`并到达 `(21,52)`。  
人物：四名修士。

```text
陆清：灯芯完整，阵纹却反了。
石岩：反了会怎样？
陆清：它在从山外向山里送灵力。
墨言：不是坏，是有人改过。
白灵：地上有拖痕。人被带走了。
```

方法选项：

1. `让陆清校正阵纹。` → 法力MAX≥18成功；消耗灵晶1；无战斗；`seal_integrity+1`。
2. `用开山镐拆掉外壳。` → 消耗开山镐1；取得玄铁3；引来噬灵鼠群。
3. `保留反阵，追查灵力去向。` → 不立刻修复；揭示一条隐藏路径；稍后必须返回修灯，
   且下一场阵灵敌人伤害+10%。

汇流：阵灯最终修复，记录`ye_evidence`线索“反向阵纹”。

#### 场景 M1-02：顾南炉的求救

触发：山腹暗道入口 `(8,28)`。  
人物：顾南炉、队伍。

```text
顾南炉：别敲！上面整片都要塌！
石岩：里面有人。
墨言：也可能有人学得很像。
顾南炉：我有名字！顾南炉！
顾南炉：叶家雇我修阵器，又要灭口。
```

选项：

1. `用开山镐按他说的位置破岩。` → 消耗1镐；无伤救出；`saved_gu_nanlu=true`。
2. `让石岩强行抬开。` → 全队力道SUM≥55成功；石岩损失15%当前生命；保留镐。
3. `先让他证明身份。` → 顾南炉说出营地旧炉编号；若读过废营粮册可识别，`cen_trust+1`；
   否则延迟救援并触发落石敌群。
4. `离开。` → 明示“继续深入后顾南炉可能死亡”；二次确认。离开后完成两场战斗再回来，
   只能找到遗物，炼器坊延迟到地图2商人事件解锁。

救出后：

```text
顾南炉：他们把阵灯改成了抽灵钉。
陆清：谁给你的图？
顾南炉：叶家监阵使，叶观衡。
顾南炉：可第二张图，又让我改回去。
墨言：同一只手，下了两道反命令。
```

结算：获得两份阵器拓图，`ye_evidence+1`；回营后顾南炉入驻并解锁炼器坊，同时交付符心佩
配方与首件核心。首次打造按上品规则随机七维。

#### 场景 M1-03：两份开山令

触发：叶家先遣尸首事件。  
人物：白灵、墨言、队伍。

```text
白灵：死者胸口没有石灵伤。
白灵：经脉从内侧被抽空了。
墨言：袖中两道命令，印都是真的。
墨言：一道重封，一道抽阵。
石岩：叶家自己人在互杀？
```

选项：

1. `带走两份命令。` → `ye_evidence+1`；占任务物栏，不占负重。
2. `焚去抽阵令，只留重封令。` → 获得短期“叶家善意”风味，`ye_evidence`不增加；墨言反对。
3. `拓印后原样放回。` → 神识MAX≥25成功；`ye_evidence+1`，第三章可伏击回来取令的人。

白灵追问：

```text
白灵：这些人也许还能引魂问话。
白灵：但要把遗体带回去。
```

1. `带回。` → 占负重12；回营解锁乌婆；获得魂晶80。
2. `就地安葬。` → 全队恢复10%生命；`ending_evaluation`倾向守封者。
3. `先搜装备。` → 得玄铁8和灵石60；`demonic_taint`不变，但白灵后续有批评台词。

#### 场景 M1-04：万修之门残碑

触发：到达 `(24,42)`。  
人物：岑守一远程传讯、队伍。

```text
岑守一：碑上原有万修二字。
陆清：现在多了一道新刻痕。
墨言：像门，又像一只竖眼。
岑守一：别碰。十二年前也出现过。
玩家：营印在发热。
残碑：阵录十三，持外印者归位。
```

强制结算：`identity_clues=max(当前,2)`，身份档案新增“阵录十三”。即使玩家立即离开，营印反应也已记录，
不能因未选触碰选项而错过身份主线。

选项：

1. `追问十二年前。` → 若`cen_trust≥1`，岑承认旧队失踪；否则切断传讯。
2. `让陆清记录阵纹。` → 得残碑拓印，地图2检定+10。
3. `以总印触碰刻痕。` → 看见十二道背影和一只握印的手；解锁额外回看，同时获得魔气侵蚀1层和魂晶100。

#### 场景 M1-05：守门石灵战前

触发：接近 `(24,8)`。  
人物：叶观衡首次传讯、队伍。

```text
叶观衡：外营的人，退下。
叶观衡：石灵奉叶家古令守门。
叶观衡：你们无权触碰它的核心。
墨言：活人不露面，只让石头杀人。
石岩：若它还守门，为何朝山外打？
```

选项：

1. `出示两份命令。` → 需持有；叶观衡沉默后称其中一份伪造；`ye_guanheng_exposed`进度+1。
2. `要求叶观衡现身。` → 他拒绝；石灵开场反震计数少1层。
3. `不与他争，准备战斗。` → 全队获得40tick伤害+5%。

战斗后：

```text
陆清：核心里的命令，不是守门。
陆清：是“清除外来见证者”。
白灵：先遣队也被算作见证者。
陆清：可它把营印标作“旧营继任”。
玩家：这道继任令，是十二年前写的。
叶观衡：你们看见的，只是一层命令。
叶观衡：来白玉广场。我给你们解释。
墨言：他说的是“来”，不是“请”。
```

章节选择：

1. `去听他的解释。` → 地图2初见时叶观衡态度缓和。
2. `先把证据交给岑守一。` → `cen_trust+1`；地图2入口多一个伏兵。
3. `公开传讯，通知其他入山修士。` → 获得灵石100；叶家敌群警觉范围扩大一格。

章节结算：`seal_integrity+1`，解锁地图2、炼器坊/替代解锁、第一次全队调息；石灵核心同时
解锁护法令碎片配方与首件核心，不直接发放固定七维成品。

### 6. 第二章：白玉逆阵

#### 场景 M2-01：叶观衡的解释

触发：地图2入口 `(31,60)`。  
人物：叶观衡实体、队伍。

```text
叶观衡：昆吾封了太久。
叶观衡：阵法朽坏，迟早自行崩开。
```

### 10. 主线失败与恢复

- 关键NPC死亡版本均有替代证据、留影或遗物，主线不永久失败。
- 对话选择保存后再播放结果；保存失败返回选项界面，不提前发物或改Flag。
- Boss失败回到战前地图格，保留Boss未完成；消耗品按战斗结算规则处理。
- 章节奖励保存失败时不解锁下一地图，允许在任务页重试结算，不能重复领取。
- 对话可回看，但回看不重新触发检定、奖励、好感或战斗。

- 叶怀川：把军令交给叶承安或留作证据。交出得信任，留下得叶家敌群情报。
- 方砚：在三老碑补刻姓名。木青萝信任+1。
- 罗七：击败一组阴罗宗追兵后选择净化或让其指认韩枭藏物。
- 阿蘅：地图4侧狱找药篓；家书交营地获得灵粮生产+3%，焚化则残魂立刻安息。
- 无名古魂：带到定界链；它补出正确修复顺序，使第一处枢纽材料-2。

每完成一个遗愿，五鬼袋的战斗增益降低一层，但净化奖励提高。UI明确显示该取舍。

#### Q4-03：韩枭讨袋

触发：完成至少三个遗愿后。韩枭提出用一只封存的地图3高危制式装备匣换回五鬼袋；匣子不允许
选择职业、槽位或七维，开启时才按稳定种子生成实例。

```text
韩枭：死人说完话，就该做死人能做的事。
白灵：他们不是你的材料。
韩枭：修仙路上，活人也常是材料。
墨言：所以你总躲在别人后面。
```

选项：

1. `拒绝并迎战。` → 精英战；胜利得护魂牌后续打造核心，不改变既有装备品质、效果或七维。
2. `交空袋骗他。` → 万象符脉用符傀替身送袋，或通过神识检定；成功时避免战斗并得地图3
   高危制式装备匣，韩枭地图4再次出现。
3. `以叶怀川军令交换韩枭证词。` → 他承认乾老魔命令阴罗宗追查血焰；两者各取所需。
4. `接受交易。` → 未完成遗愿的残魂被炼化；获得地图3高危制式装备匣，`demonic_taint+2`。

#### Q4-04：净化或炼化

触发：地图4封魂间。不可逆二次确认。

1. `逐一净化。` → 每完成的遗愿使成功率和奖励提高；最低获得太清护魂符配方与首件核心，全部完成额外
   得魂晶600、守封者评价+1。
2. `保留五鬼袋为法器。` → 获得五鬼噬灵环配方与首件核心；其七维按珍品规则随机，固定效果为
   直接攻击20%基础命中附加定力-10%/80 tick；`demonic_taint+2`，白灵信任风味下降。
3. `让乌婆封存，待以后寻找轮回法。` → 获得护魂牌配方、首件核心和营地残魂图鉴；无即时高数值奖励。
4. `交给木青萝。` → 需`mu_trust≥1`；她用封印图净化，得到太清护魂符配方与首件核心和化仙宗后续友好。

净化结尾：

```text
叶怀川残魂：名字可以不留。
叶怀川残魂：把命令留下。
乌婆：人散了，话还在。
岑守一：那就写到账上。
```

炼化结尾：

```text
五鬼袋：五道声音依次熄灭。
白灵：它变安静了。
墨言：安静，不等于安息。
```

### 6. 支线状态与汇流矩阵

| 支线 | 最低完成条件 | 主线帮助 | 最高数值奖励 | 叙事后果 |
|---|---|---|---|---|
| 旧阵簿 | 解出晶钥并决定账簿处理 | 归营符配方、生产 | 生产+5%或魂晶400 | 岑守一信任与公开真相 |
| 化仙遗命 | 取得碑文并处理借阵结丹 | 封链、净化、结丹材料 | 太清符印/护魂符 | 木青萝入驻或离营 |
| 本命元牌 | 决定元牌最终归属 | 石灵敌群、负重、空间裂隙 | 护体永久+6或负重功能 | 圭灵中立/封存/被驱使 |
| 五鬼袋 | 完成至少一魂遗愿并处理法袋 | 证据、定界链顺序 | 护魂符或五鬼噬灵环 | 净化、封存或炼化残魂 |

四条支线均可在主线通关后补完，但已经发生的不可逆选择不重置。涉及已死亡/离营NPC时，
使用传讯、留影和遗物版本，不复制一个活NPC回来。
