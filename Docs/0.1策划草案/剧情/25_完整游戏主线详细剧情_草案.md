## 第一卷：第一次穿越与旧史生痕（C04衔接、C05–C07）

### 1. 第一卷目标

第一卷必须完成六件事：

1. 让玩家亲自走过尚未封山的上古昆吾，建立“昆吾原本是仙境与界路枢纽”的视觉记忆；
2. 让玩家参与第一次界门破裂，却不取代昆吾三老、玲珑或上古高阶修士的正面战绩；
3. 让逆转阵心从终局公式变成一项有人研究、争论、失败并付出代价的技术；
4. 让元刹第一次提供真实、有效且难以拒绝的捷径，并把理解、依赖与魔契严格分开；
5. 回到当世后，以同一地点的灵脉绝地和裴玄度之死建立“飞升无路”的宏观危机；
6. 只揭开十二年前登山任务的一角：十三人确实循此而来，但完整任务原文留到C10恢复。

本卷不允许提前完成以下揭晓：

- 不揭晓十二年前按住主角的是谁；
- 不确认玲珑、雪玲、珑梦与元刹三方叙事的完整真相；
- 不签订第一段真名魔契；
- 不把逆转阵心证明为必然成功；
- 不把裴玄度的失败写成人界绝对无救。

### 4. C04完整游戏衔接：门合以后

#### 场景 C04-X01：第十三下门响

触发：现有`M4-09 战后封链`共同演出结束；完整游戏模式继续，0.1试玩仍可在上古短镜头后结束。  
人物：玩家、四名修士、元刹神念。  
镜头：三条封链依次归位；前十二下金铁声与玩家破损记忆重叠；第十三下迟迟未落。

```text
石岩：封链还差最后一扣。
陆清：总印传念断了。
白灵：掌印人，能听见吗？
墨言：别碰其神魂。先等回应。
```

玩家视角短暂回到十二年前的北道门缝。画面只见十二盏命灯，听见有人说“按住此人”，不出现说话者面孔。
玩家无法签发最后一道闭锁令，但系统不替玩家自动做决定。

元刹的声音从总印裂纹内响起：

```text
神秘女声：数错了。
神秘女声：门响十二次，是他们留下。
神秘女声：第十三次，才轮到你选择。
神秘女声：抬手。我替你稳住这一息。
```

态度选项：

1. `接受她稳定总印。` → 玩家恢复传念并亲自落下最后一印；`yuancha_dependence`轻微提高。
2. `让四人依次报平安。` → 四人逐一回应，玩家自行恢复；`self_authorship`提高；女声仍替总印挡下一次反噬。
3. `质问她是谁。` → 女声：“一个知道第十三下为何没响的人。”；不会因质问错过闭锁。

无论选择，女声的帮助都真实阻止总印崩裂。她没有篡改闭锁令，却在裂纹中留下一条以后能够继续传念的细线。

第十三下落定后，元刹神念说出与现有0.1尾声衔接的新台词：

```text
元刹神念：原来那道无名阵令，是你写的。
玩家：我从未见过那道阵。
元刹神念：现在没有见过。
元刹神念：往前走。去把它写下来。
```

总印开始核对“当世持印人”与“上古无署名批注”的矛盾年代。黑风空间包住四人肉身，玩家神念与四盏命灯
被抽入最早一条阵外痕迹。

章节结算：C04现有通关奖励、评价和自由探索权限照常成立；完整游戏新增`past_projection_active=true`，进入C05。

### 5. C05「山未成牢」

时态：过去一；魔劫大规模入侵前数日。  
建议时长：2.5–3小时。  
章节命题：昆吾原本是什么，后来为何必须成为监牢？  
章节核心选择：面对救人、保图和留样的三难，玩家是否接受一个可以全部保住、却不说明完整代价的答案？

#### 场景 C05-01：白玉无尘

触发：穿越演出结束。  
人物：玩家、四名修士、上古巡阵修士。  
镜头：玩家熟悉的白玉广场恢复完整。断墙变为长廊，尸窟位置是一片灵药市集，灵气薄雾沿地面自然流动。

四人命灯先在半空亮起，再投成可以战斗的实体；玩家仍只有总印神念，没有肉身。

```text
陆清：这里的灵气……不用吐纳也在入体。
白灵：白玉缝里长的是千年凝露草。
墨言：现在有人踩着它搬货。
石岩：那扇门，原来是完整的。
```

玩家可以观察三组不阻断主线的环境事件：

- 一名炼气修士用少量灵石租借洞府，不把充足灵气写成人人都是高阶修士；
- 山中异类与阵卫共同核对山契，说明上古秩序仍有冲突，但尚未只剩本命牌奴役；
- 三条灵脉在归流谷上空形成肉眼可见的光河，远处空间节点稳定呈现星门状投影。

上古巡阵修士包围四人：

```text
巡阵修士：四具命灯化身，一道无身神念。
巡阵修士：报宗门、姓名、入山年份。
墨言：若说来自后来，他们会信吗？
玩家：先报外营总印。
巡阵修士：昆吾没有外营。
```

选项：

1. `如实说来自未来。` → 对方按“空间乱流残魂”收押，后续由商九还提前出面；因果裂度略增。
2. `自称玲珑援军。` → 暂时通行，但C05-04伪装神念会用同一身份反问玩家；墨言不认同。
3. `只展示总印，不解释年代。` → 主阵自行核验并触发C05-02；默认稳妥路径。

#### 场景 C05-02：阵中无名

触发：巡阵修士把总印置于万修之门主阵。  
人物：玩家、四名修士、商九还。

主阵依次读取四名队员，却无法读取玩家：

```text
主阵：石岩，命灯投影，来岁不明。
主阵：陆清，命灯投影，来岁不明。
主阵：白灵，命灯投影，来岁不明。
主阵：墨言，命灯投影，来岁不明。
主阵：第五位——无姓名，无年代，无阵籍。
主阵：拒绝落位。
```

主阵试图把玩家神念排出，手腕晶纹与十二年前封名反应，传念短暂失焦。商九还阻止巡阵修士强行封魂：

```text
商九还：别给这道神念补名字。
商九还：主阵认不得，未必是它错了。
陆清：你相信我们来自后来？
商九还：我只相信阵法也会少看东西。
```

商九还允许玩家在主阵边缘建立一次性旁路。玩家需要选择旁路署名：

1. `保持无署名。` → 建立第一道“阵外批注”；最稳，不增加元刹识别速度。
2. `写下现用名。` → 主阵仍拒绝正式登记，但元刹以后可以更早用现用名称呼玩家。
3. `只盖外营总印。` → 批注带有裂纹印记，C07更容易证明与当世总印同源。

无论选择，玩家都不是上古阵位、失落席位或转世者，只得到边缘旁路的临时操作权。

#### 场景 C05-03：灵脉如河

触发：商九还带队前往归流谷。  
人物：商九还、四名修士、玩家、圭灵上古本体远影。

本场景以探索代替长篇世界观对白。玩家依次经过：

1. 自行结露的灵药坡；
2. 能稳定观察界面潮汐的观星台；
3. 圭灵与阵师共同维护、尚未被制成本命元牌的地脉门；
4. 三条灵脉汇成光河的归流谷。

```text
白灵：这里不是灵泉，是整条灵脉露在地表。
陆清：空间也很稳。节点有完整潮汐。
墨言：后世只剩裂口与禁制。
商九还：后世？你们那里变成什么了？
玩家：一座人人只记得宝物和封印的山。
商九还：那说明我们后来输得很彻底。
```

商九还纠正“灵气多就没有争夺”的想象：各宗仍在争洞府、节点与灵药，昆吾三老也并非意见一致；区别是此时
灵脉仍能循环，争夺不会直接抽空世界根基。

归流谷边缘放置一块尚未刻字的阵簿石。玩家触碰时，总印留下与C01残碑相同的磨痕，开启支线
“岑守一的旧阵簿·上古磨痕”。

#### 场景 C05-04：三老争界

触发：抵达第一界门议阵台。  
人物：昆吾三老、玲珑本体的公开传讯、商九还、卫殊、玩家与四人。

玩家只参与旁听和提交阵图，不决定三老最终战略。三老的争论分为三种立场：

- 立即封界：魔军将至，先切断所有节点，后果由后世承担；
- 逐节点驱逐：尽量保留人界与外界联系，但短期伤亡可能失控；
- 保留逆转偏阵：先以归流谷缓冲真魔气，争取不永久锁死灵脉的第三条路。

```text
三老之首：门不开，人界尚能自守。
商九还：门全封，灵脉也会失去归流。
另一位三老：那是万年后的代价。
商九还：万年后的人，也活在人界。
玲珑传讯：先守住今日，才有资格谈万年。
玩家：若今日的封印正制造万年后的绝路呢？
```

三老追问玩家后世结果。玩家可回答：

1. `封印仍在，但山已成禁地。` → 三老记录“封而不净”；因果真相增加。
2. `后人开山夺宝，魔气再现。` → 卫殊提高戒备；后续守军支援增加。
3. `我不能让你们照答案改历史。` → 商九还认可谨慎；保留更多中立关系。
4. `告诉他们昆吾终将被毁。` → 因果裂度明显提高；三老仍不会因一句未来预言放弃当日封印。

争论被归流谷警报打断。一缕真魔气已经绕过主门，开始污染灵脉井。

#### 场景 C05-05：未竟逆阵

触发：进入逆灵试验场。  
人物：商九还、陆清、玩家。

商九还展示逆阵原理：不是把魔气凭空变成灵气，而是分离界面坐标、魔魂印记与可被灵脉缓冲的能量，再让后者归流。
当前试验失败的原因有三项：

1. 无法稳定识别藏在能量中的魔魂印记；
2. 没有能跨越封山岁月仍保持活性的阵心；
3. 启阵代价只能由少数阵卫被迫承担。

这三项分别对应后续的元刹魂印、逆转阵心与众生盟约。

```text
陆清：真魔气里并非只有魔性。
商九还：火能煮药，也能把丹炉烧穿。
陆清：要分开的不是善恶，是结构。
商九还：你若真来自后世，替我记住这句。
```

玩家取得三个待保护对象：商九还本人、完整逆阵母图、未受污染的灵脉髓样。警报显示三处即将同时失守。

#### 场景 C05-06：一刻钟，三件事

触发：归流谷污染全面爆发。  
结构：章节主分配事件；玩家正常只能保住三项中的两项，选择顺序会改变战斗和人物反应。

##### 目标A：救出商九还

- 石岩负责撑住坍塌阵梁，白灵稳定商九还神魂；
- 成功后`ancient_array_master=alive_clean`；C07开启可读传承密室；
- 放弃后商九还用最后神念把一段公式写入石壁，`ancient_array_master=dead`，仍保留主线最低信息。

##### 目标B：保住逆阵母图

- 陆清需要在魔气中逐层抄录，墨言守住三轮袭击；
- 成功后`reverse_formula=complete`；
- 放弃后只留下总印自动记录的`reverse_formula=fragment`。

##### 目标C：取出灵脉髓样

- 白灵必须保持样本与伤员神魂隔离；
- 成功后`vein_sample=pure`；
- 放弃后样本随井壁晶化，后续需在C07绝地完成高难取样。

第一次选择后，玩家会听见十二年前北道门响，画面把三个目标短暂叠成“救人／带印／回头”的旧记忆。石岩问：

```text
石岩：先做哪一件？
石岩：你只需下令。后果我们一起担。
```

玩家可以先明确选择，不出现无理由的失控；若停留过久，白灵主动提醒“可以求助，不必一个人决定”。

完成第二项目标后，第三项开始不可逆崩毁。此时“玲珑神念”第一次私下联系玩家。

#### 场景 C05-07：全部都能救

人物：“玲珑神念”、玩家。四人听不见前半段。  
镜头：时间短暂停止，只有总印裂纹内的紫黑细线仍在移动。

```text
玲珑神念：又是三选二。
玲珑神念：你已经知道留下一个是什么滋味。
玩家：你看过我的记忆？
玲珑神念：我看见过有人替你选。
玲珑神念：这一次，我可以全都留下。
```

她给出一条穿过魔气层的折叠路径，确实能让队伍赶到第三项目标。她只说明“会借用总印裂纹定位”，不说明路径会在
商九还、母图和灵脉样本中各留下一枚微小魔标。

不可逆选择：

1. `接受路径，救下第三项。` → 三项目标全部保住；`ancient_array_master=alive_marked`，
   `reverse_formula`和`vein_sample`附加`tainted_hidden`；`yuancha_dependence`提高；C06十三名伤者更容易撤出但全部带标。
2. `要求她先说明完整代价。` → 她承认会“留下能再次找到这里的痕迹”，但不承认真实身份；可再次接受或拒绝；
   `yuancha_understanding`提高。
3. `拒绝捷径，承担原选择。` → 保住正常两项；`self_authorship`提高；未保住项进入后续高难补救。
4. `让四人共同决定。` → 四人意见不一致，最终仍由玩家确认；即使接受，`yuancha_dependence`不增加，
   但全队知道总印中存在陌生声音。

若接受，第三项目标成功后四人会发现路径不属于玲珑常用的空间术：

```text
墨言：这条路太熟悉我们的阵位。
白灵：被救的人都活着。
陆清：样本也没有表面污染。
石岩：先记下疑问。别把救人说成错。
```

元刹的捷径不能在此反噬杀人，否则会把真正的道德选择降格成识破骗局。

#### 场景 C05-08：归流谷守战

触发：分配事件完成。  
Boss候选：`裂界魇兽`，从未完全成形的空间裂口挤入，不是元刹或魔界高阶存在本体。  
战斗职责：昆吾三老在主界门正面施法；四人只守归流谷侧翼，保护幸存目标撤回。

战前：

```text
卫殊：主门那边轮不到我们逞强。
卫殊：守住归流谷，别让灵脉替它开门。
墨言：终于有一场敌我都清楚的仗。
玲珑神念：你确定吗？
```

Boss分为三类机制表现，不冻结数值：

- 吞噬灵脉光河，迫使玩家保护两处归流节点；
- 复制四人投影，强调他们并非上古真实肉身；
- 以空间折返把撤离目标拉回战场，玩家需要用阵外批注改写一次路径。

阵外批注内容由玩家选择：

1. `此路只出不进。` → 撤离最稳，保住更多伤员；
2. `魔气沿原界坐标归返。` → 取得更多逆阵观测数据；
3. `切断整段旁路。` → 战斗简单，但C07少一处历史生痕。

战后，三老关闭污染支路，却确认大规模魔军已经找到昆吾坐标。C06紧接发生。

#### 场景 C05-09：山还没有成为牢

触发：归流谷守战结束。  
人物：商九还存活或最后神念、玩家、四人。

存活版本：

```text
商九还：你问昆吾后来为何成了牢。
商九还：不是因为我们只会封。
商九还：是因为来不及证明别的路。
玩家：若后来的人补完了呢？
商九还：那就别把未竟写成不可行。
```

死亡版本由石壁残字替代：

```text
石壁残字：逆转未竟，非为不可。
石壁残字：后来者若见，先分魂印，再谈归流。
```

章节结算：

- 必得`human_realm_path_evidence+=ancient_kunwu_abundance`；
- 必得第一份三老争界记录与逆阵最低残式；
- 商九还、母图、髓样按C05-06与C05-07结算；
- 元刹理解、依赖按是否追问与是否接受捷径分别结算；
- 不触发真名魔契。

镜头最后，归流谷上空原本稳定的星门被一只巨大的黑影从另一侧撞出第一道裂纹。

### 6. C06「界门初裂」

时态：过去一；C05结束后的同一夜。  
建议时长：2.5–3小时。  
章节命题：为了立即活下来，可以把多少未来交给封印？  
章节核心选择：玩家如何撤出伤员、处理带有魔标的生命，并决定逆灵试验场是否值得继续存在。

#### 场景 C06-01：天裂三声

触发：第一界门被魔军从外侧撞击三次。  
人物：昆吾三老、卫殊、商九还或替代阵师、玩家与四人。

第一次撞击震碎观星台；第二次令一条灵脉倒流；第三次后，天空出现与黑风旗相似的界面阴影。三老正式放弃
“逐节点驱逐”，转为封闭全部外层界门。

```text
三老之首：从此刻起，昆吾只守，不渡。
商九还：全部封死，归流谷也会慢慢枯竭。
三老之首：先问今日有多少人能活。
卫殊：东、西、南三路同时断了。
玩家：把三路情况送入总印。
```

三条侧翼分别承担不同对象：

- 南路：十三名被魔气擦伤的阵师与阵卫；
- 东路：逆阵副盘、灵脉潮汐记录和一批阵器；
- 西路：阻止魔军追入白玉广场的断后阵台。

玩家可以决定处理顺序，但三路都必须进入；先后只改变剩余时间、敌人强度和可保存对象。

#### 场景 C06-02：卫殊不领死令

触发：首次进入西路断后阵台。  
人物：卫殊、石岩、玩家。

主阵自动生成一条“留一人压阵，其余撤出”的阵令，并把卫殊列为默认执行者。

```text
主阵：阵卫统领留驻，闭锁后除籍。
石岩：除籍是什么意思？
卫殊：阵法不再把我算作活人。
石岩：你要留下？
卫殊：我要先知道，还有没有别的办法。
```

玩家选择：

1. `直接签发主阵命令。` → 卫殊服从并死亡；`wei_shu_result=ordered`；西路最容易关闭；石岩开始质疑玩家是否把承伤视作理所当然。
2. `说明代价，询问谁愿意留阵。` → 卫殊在知情后自愿承担；`wei_shu_result=volunteered`；玩家获得其完整姓名与阵誓。
3. `拒绝留人，拆掉阵台。` → 触发高难追击；胜利则卫殊存活、东路阵器必定损失一部分；`wei_shu_result=rescued`。
4. `用四人投影代替活人。` → 四盏命灯各损失一部分稳定度，玩家后续指挥延迟；卫殊存活；
   `wei_shu_result=rescued`，因果裂度提高。
5. `接受“玲珑神念”提供的无痛封阵。` → 卫殊肉身存活但神魂被写成阵器，`wei_shu_result=marked`；短期没有死亡，长期成为魔标与灭世锚点候选。

若玩家询问自愿，卫殊强调：

```text
卫殊：我可以留下。
卫殊：但先把名字写进阵簿。
卫殊：我要后人知道，这是我同意的。
```

石岩在本场景后不立即评价玩家，只在归营式清点命灯时再次提起，避免把复杂选择即时结算成道德分。

#### 场景 C06-03：十三个伤者

触发：进入南路临时救治台。  
人物：白灵、十三名上古伤者、“玲珑神念”、玩家。

十三人外伤不重，神魂边缘却各有同一枚细小黑点。接受C05捷径时，黑点与捷径痕迹完全同源；未接受捷径时，
伤者是在撤离中被界门魔气标记，仍保证本场景必然发生。

```text
白灵：伤口能治，神魂里的点不能碰。
陆清：像坐标，不像毒。
伤者：净不掉就把我们留在这里。
白灵：活人不是一件待销毁的阵器。
```

白灵提出三种可行方案，元刹再提供第四种：

1. `立即净化魔标。` → 救治最稳；伤者记忆与魔标一起缺失一部分；`thirteen_wounded=purified`；后续魂印证据减少。
2. `封存魔标，带人撤离。` → 增加护送战和后续治疗；`thirteen_wounded=preserved`；C07可找到后世回声，C08可提取魂印。
3. `切断伤者与主阵联系。` → 阻止元刹追踪，但十三人从昆吾阵籍除名；`thirteen_wounded=preserved_unregistered`；强化“名字与存活”的主题。
4. `接受神念代为固定神魂。` → 十三人立即稳定、护送战显著简化；`thirteen_wounded=marked`；
   元刹可以在C07直接借其回声传话。

若玩家质问“玲珑神念”为何熟悉魔标：

```text
玲珑神念：因为我见过魔界怎样找路。
玩家：你说的是见过，还是用过？
玲珑神念：此刻有十三个人在等答案。
```

无论选择，至少一名伤者会问玩家为何不报姓名。玩家可回答现用名、保持无名或说“名字不该决定是否救人”。
这一回答只影响后世回声对玩家的称呼，不签订契约。

#### 场景 C06-04：两种灵气

触发：进入东路逆阵副盘。  
人物：陆清、商九还或替代阵师、玩家。

陆清发现少量真魔气穿过逆阵残式后，确实释放出可供阵盘使用的无属性灵力；与此同时，一缕无法分离的意志
会沿阵纹反向寻找操作者。

```text
陆清：能量可以归流，意志没有散。
商九还：所以我一直不敢接入地脉。
陆清：若能先辨认魂印呢？
商九还：那才有资格谈逆转。
```

玩家需要决定本次实验记录如何处理：

1. `只记录现象，封存样本。` → 保留魔理认知；C07陆清请求受控研究。
2. `连样本一起销毁。` → 降低魔标风险；逆阵研究后续需要更高难补样。
3. `让陆清继续导流。` → 多救回一批阵器；陆清命灯出现短暂魔纹，尚不等于主动吸收。
4. `把结果交给“玲珑神念”校验。` → 她准确指出三处误差，却偷偷补入界面坐标；`reverse_formula`转为`tainted`。

若商九还已死，其最后神念只能重复固定公式，无法提醒“意志没有散”；陆清需要结合C05纯净样本自行发现，
否则污染会延迟到C07才暴露。

#### 场景 C06-05：她知道总印怎样疼

触发：完成南、东两路后，墨言提交三份传讯录音。  
人物：墨言、玩家、“玲珑神念”。

墨言指出伪装声音的三处破绽：

1. 她使用的是后世总印术语，而非上古主阵称谓；
2. 她知道主角手腕晶纹会在封门第十二响时发作；
3. 她提供的路径避开三老阵图，却精准穿过玩家刚建立的阵外旁路。

```text
墨言：她未必句句是假。
墨言：正因句句有用，才更该问她是谁。
玩家：你不是玲珑。
玲珑神念：玲珑此刻也不只一个声音。
玩家：伤者身上的标记，是你留下的？
玲珑神念：他们活下来了。
玲珑神念：你后悔吗？
```

玩家态度：

1. `救人不替你免责。` → `yuancha_understanding`提高，依赖不增加；墨言保留完整语气证据。
2. `先回答，你究竟是谁。` → 她说“等你见过两个玲珑再问”；不提前报出元刹真名。
3. `我不后悔，但不会再盲信。` → 理解提高；后续捷径会显示更完整代价。
4. `只要他们活着，代价以后再说。` → 依赖提高；C06终战可继续获得强力支援。
5. `切断她与总印的联系。` → 当前低语暂时消失；因C04裂纹通路仍在，C07她可以借黑风残片重新出现。

若玩家曾在P0–C04告诉神秘声音现用名，她在私下结束前第一次用现用名称呼玩家；否则称“无名的掌印人”。

#### 场景 C06-06：三路归一

触发：三条侧翼全部处理。  
人物：卫殊或副统领、商九还或替代阵师、十三名伤者状态代表、玩家与四人。

所有分支在第一界门外汇流，但保留下列可见差异：

- 卫殊存活时亲自带队；死亡时阵簿新增一行姓名，石岩替他扛起阵旗；
- 商九还存活时可以校正逆阵；死亡时陆清只能使用残式；
- 十三名伤者被净化时保持沉默；保留魔标时能指认界门另一侧的元刹魂印方向；
- 接受元刹固定时，伤者会整齐说出一句不属于自己的阵令。

三老决定闭锁第一界门，并要求拆掉逆灵试验场，把所有灵力并入主封印。

```text
三老之首：未验证的第三条路，会先杀死今日的人。
商九还：拆了它，后来的人连失败都无从继续。
另一位三老：封印落下后，没有后来者能进来。
玩家：我就是后来者。
```

#### 场景 C06-07：试验场最后一夜

触发：第一界门终战前的不可逆处置。  
结构：决定逆灵试验场跨时代状态，不直接决定结局。

1. `保留母图，将阵心藏入偏阵。`  
   条件：至少有完整母图或商九还存活。  
   结果：终战增加一处必须保护的阵眼；`reverse_formula`保留；C07出现传承密室。

2. `拆阵补入主封印。`  
   结果：第一界门战斗难度降低；只保留总印记录的残式；常规路线最稳定。

3. `彻底毁去试验场。`  
   结果：消除当前魔标载体；救世需要后续高难重建；三老对玩家信任提高。

4. `让“玲珑神念”把阵心移入空间夹层。`  
   条件：仍保留其联系。  
   结果：阵心与数据全部保存，终战显著简化；`reverse_formula=tainted_known`，元刹取得未来定位点。

5. `把是否保留交给商九还本人。`  
   条件：商九还存活。  
   结果：他选择保留母图、拆掉可立即调用的阵心，降低被元刹利用的风险；这是救世最稳但资源最少的版本。

#### 场景 C06-08：第一界门终战

Boss候选：`界门魔先锋·无相罗刹`的未完全投影。  
层级控制：三老与玲珑处理投影主体；四人完成三个侧翼目标，不正面击杀魔界高阶存在。

三个任务阶段：

1. 护送伤者与阵师越过关闭线；
2. 将三条侧翼阵路按正确顺序切断；
3. 在主门闭合前，把界面坐标从人界一侧刮除。

关键分支反馈：

- 卫殊自愿或获救：提供一次稳定断后；被命令死亡：其阵位由石岩承担，四人压力上升；
- 母图保留：陆清可短暂把魔气导回；母图已毁：只能硬守；
- 十三名伤者保留魔标：Boss能借标记回拉伤者，但玩家也能反向读取一段元刹魂印；
- 接受元刹支援：她直接指出正确切阵顺序，但会要求玩家不要让墨言记录声音。

最终阶段，第一界门连续闭合十二层。第十二响时玩家再次听见北道门声，总印传念失稳。

```text
石岩：第一阵路已断！
陆清：第二阵路归零！
白灵：伤者都过线了！
墨言：只差你的闭锁令！
```

处理方式：

1. `让四人依次重复当前状态。` → 玩家以现实信息锚定自己，恢复签令；`self_authorship`提高。
2. `接受女声替自己压住记忆。` → 立即恢复，四人不受命灯反噬；`yuancha_dependence`提高。
3. `要求白灵触碰总印共同稳定。` → 若白灵个人线信任足够，保持边界并恢复；否则多承受一轮攻击。

玩家写下本卷第二道阵外批注：

```text
玩家：界门闭锁，魔气循原坐标归返。
主阵：命令无阵籍、无年代、无署名。
主阵：拒绝执行。
商九还或陆清：写在阵外！
玩家：那就让阵外之人，补这一笔。
```

批注生效，三老完成主封。伪装神念在门闭合前第一次明确称呼玩家：

```text
玲珑神念：我记住你了。
玲珑神念：不在阵中的人。
玲珑神念：下一次，别再让他们替你选。
```

#### 场景 C06-09：回返

触发：第一界门完全闭锁。  
镜头：上古人物与场景开始化为被总印记录的线条，四人投影逐一熄灭。

玩家不能把古宝、灵药或灵石带回，只能保留：

- 阵式与操作知识；
- 已被总印记录的姓名；
- 阵外批注；
- 魔标、魂印方向与界面坐标；
- 因果裂度造成的记忆和地图变化。

存活的商九还最后说：

```text
商九还：你回去后，先看同一条灵脉。
商九还：别只看阵还在不在。
商九还：看这座山，还活不活。
```

死亡版本由石壁残字发出同一句回声。

章节结算：

- 必得`human_realm_path_evidence+=ancient_stable_node_record`；
- 根据伤者处理取得`yuancha_soul_mark`的无、局部或污染版本；
- 根据试验场处置决定C07“历史生痕”形态；
- 四人投影返回，现世肉身未经过数日生理时间，但会保留命灯疲劳和记忆。

### 7. C07「旧史生痕」

时态：现在；C04战后一个时辰，外界随后经过三日整备。  
建议时长：3.5–4.5小时。  
章节命题：玩家改变了过去，还是终于看见过去本来就有自己？  
章节核心任务：核对历史生痕，进入归流谷绝地，读完裴玄度三阶段遗录，并找到十二年前旧队循迹登山的第一份证据。

#### 场景 C07-01：一个时辰，三日阵录

触发：四人投影返回现世肉身。  
人物：岑守一、乌婆、四名修士、玩家。  
地点：镇魔塔外层临时阵台。

岑守一守在四具肉身旁，外界只过去一个时辰；总印却新增三日阵录，四盏命灯也各自留下数十场战斗的磨损。

```text
岑守一：你们只闭眼一个时辰。
陆清：我们在那边过了三日。
岑守一：总印也写了三日。
墨言：先别问我们看见什么。
墨言：先问这三日是谁写进去的。
```

玩家恢复传念后第一反应由选项决定：

1. `先数四盏命灯。` → 四人逐一报平安；数到四后玩家仍下意识继续到十三，触发短暂沉默。
2. `先检查总印裂纹。` → 发现紫黑细线仍在，但没有改动闭锁令；元刹帮助真实成立。
3. `先让所有人离开阵台。` → 表现主角对封闭空间的回避；不扣除自主状态，白灵询问是否需要陪同。
4. `立刻记录上古所见。` → 陆清与墨言分别记录阵式和语气证据；因果真相提高。

岑守一听见“上古昆吾”后明显失态：

```text
岑守一：十二年前，沈营主也在找旧昆吾图。
玩家：为何现在才说？
岑守一：因为找图的人都死在门里。
玩家：这不是不说的理由。
岑守一：是我用了十二年的理由。
```

本场景不要求玩家立即原谅或审判岑守一。主线更新为“核对三处不应存在的上古痕迹”。
队伍先回外营休整三日，让命灯从投影磨损中恢复；C07其余场景发生在这三日之后。

#### 场景 C07-02：第一处生痕·万修之门

触发：返回C01万修之门残碑。  
人物：队伍、岑守一远程传讯。

残碑背面出现C05写下的第一道阵外批注。字迹已经风化数万年，裂纹走向却与玩家当世总印完全一致。

```text
墨言：笔迹也是你的。

白灵：它在这里等了几万年。
玩家：所以我不是改了碑。
玩家：这道痕迹原本就在旧史里。
```

若C05保持无署名，碑文只显示操作内容；若写现用名，姓名已经被主阵磨去，只留一个与现用名笔画相近的空缺；
若盖总印，裂纹印记成为最强年代证据。

岑守一旧阵簿支线推进：阵簿卷首残页与碑面纤维拓片发生共鸣，露出“灵脉”“界路”两个残词，但还不能还原完整任务。

2. `切下碑面带回外营。` → 获得强证物，但破坏一处因果锚点；救世执行权恢复更难。
3. `让木青萝现场互证。` → 提前向化仙宗一方公开穿越；其半图开始显出“逆转”二字。
4. `暂不让任何外人知道。` → 保留主动权；元刹成为唯一主动提供解释的外部声音。

#### 场景 C07-03：第二处生痕·未竟阵之后

触发：回访白玉广场深层的逆灵试验场对应位置。  
地点形态根据C05–C06结果变化。

##### A. 商九还存活且传承被保留

后世出现一座被历代修士误认作废炉的“九还密室”。室内阵图明确写着：

```text
石壁：有无名者来，自后来，行于阵外。
石壁：其言灵脉将竭，故留此图待证。
```

玩家取得可读逆阵传承，但必须把阵纹载体永久保留，不能同时炼成强力古宝。

##### B. 商九还死亡、残图被保留

密室只有商九还最后神念与无人能完全解释的残阵。陆清可以读出一半，木青萝从封印角度读出另一半；两人结论暂时冲突，
需要C08魂印证据才能互证。

##### C. 试验场被毁

后世只剩一片被主封印填平的空墙。玩家可以用C06阵外批注定位高难夹层，取得最低残式，但没有传承者姓名与完整失败记录。

##### D. 阵心由元刹移入空间夹层

试验场表面保存得最完整，甚至仍能启动；陆清准备接入时，墨言发现所有阵纹都在向镇魔塔深层回传坐标。
玩家必须选择封存、冒险读取或让元刹继续“协助”。

本场景共同选择：

1. `保留阵纹载体。` → 推进救世技术，放弃即时古宝。
2. `拆出核心炼器。` → 获得显著成长；`reverse_formula`降为残缺并永久预警可能关闭救世路线。
3. `只拓印，不启动。` → 保持常规路线；后续需要商九还或替代阵师解释。
4. `启动受控实验。` → 进入陆清个人线；保存魔气样本、销毁或鼓励吸收的正式选择延后至实验结束。

#### 场景 C07-04：第三处生痕·十三人的回声

触发：回访C06南路伤者在当世对应的封魂夹层。  
人物：白灵、乌婆、伤者后世回声。

伤者状态形成四种结果：

- `purified`：留下十三块无魔标的空白名牌，记忆残缺但没有后世魔灾；
- `preserved`：留下后人、宗脉记录或完整残魂，可提取元刹魂印方向；
- `preserved_unregistered`：十三人的真实姓名不在主阵中，只在民间谱册与玩家总印里存在；
- `marked`：回声保存最完整，却会被元刹同时借用，开启额外魔标战。

共同回声：

```text
伤者回声：我们记得一只没有身体的手。
伤者回声：那只手把门改成只出不进。
伤者回声：阵簿没有其名。
伤者回声：可我们知道，是其让我们活着离开。
```

白灵要求玩家兑现上古选择：

1. `继续治疗或净化后世魔标。` → 增加资源与战斗成本；保住C08魂印证人。
2. `封存全部回声。` → 当前安全，证据不完整。
3. `把回声交给乌婆看护。` → 需支付一段非关键个人记忆或完成替代任务；保持边界。
4. `允许元刹通过回声说话。` → 她会提供归流谷入口位置；依赖提高，回声风险增加。

#### 场景 C07-05：谁可以知道旧史

触发：三处生痕核对完毕。  
人物：岑守一、木青萝、叶承安或重封派代表、墨言、玩家。

玩家在外营召开第一次“旧史议事”。这里不是救世联盟成立，只决定穿越事实的知情范围。

墨言提前指出风险：公开证据会让各宗争夺空间节点，也可能让证人和商九还传承被灭口；完全隐瞒则会让元刹垄断解释。

```text
木青萝：若这张图真来自上古，化仙宗有权知道。
叶承安：叶家也会说同一句话。
岑守一：十二年前，就是从“有权知道”开始死人。
墨言：隐瞒也死过十二个。
玩家：所以这次先决定谁承担知道的风险。
```

不可逆选择：

1. `公开穿越与三处证据。` → `past_disclosure=public`；较快建立跨阵营支持；叶家夺宝派与阴罗宗提前围堵归流谷。
2. `只告知现场盟友。` → `past_disclosure=allies_only`；默认稳妥；需要后续逐个争取众生盟约。
3. `只保留在四人队与总印。` → `past_disclosure=hidden`；探索主动权最高；岑守一和木青萝信任受当前关系影响。
4. `伪造一份不含界路的公开版本。` → 需墨言支持；`past_disclosure=forged_public_record`；
   保护证人但降低公开证据可信度，后续若被识破会伤害联盟。

无论选择，三处证据共同指向一个在当世地图上不存在的区域：归流谷。时代重叠打开一条通往绝地的夹层路。

```text
白灵：现在连残气都不肯停留。
石岩：不是被人采空的。
墨言：像整片天地忘了怎样吐纳。
玩家：商九还让我回来先看山还活不活。
```

必得`human_realm_path_evidence+=present_vein_deadland`。玩家不能用一份样本或一次逆阵立即复苏绝地。

```text
裴玄度留影：他们还有下一个百年。
```

```text

裴玄度留影：他们只是怕我先走。
裴玄度留影：若天门不肯开，便证明它也会怕。
```

最后一段没有连贯语言，只有他一次次把不同节点强行叠到昆吾坐标。白灵确认长期空间回响损伤了其神魂，
但文档明确：神魂损伤加重疯狂，不替他免除最后强闯的主动决定。

玩家态度不改变史实，只决定队伍如何理解他：

3. `他已无法判断，不该继续启动节点。` → 墨言认可，后续更警惕技术权威。

#### 场景 C07-09：裴玄度·《开门篇》

战斗中依次播放最后记录：

```text
裴玄度：第一百八十一次测界。
裴玄度：诸宗皆已退去。
裴玄度：今日不测，我便再无今日。
裴玄度：开门。
```

最后一个坐标被拆除时，玩家看见史实：裴玄度独自闯入尚未稳定的空间节点，护体灵光在第一层界风中破碎，
肉身与元神被错位空间逐层撕开，没有飞升、失踪或暗中成功的反转。

```text
裴玄度残念：起初，我想替人界找路。
```

3. `保留全部并公开其疯癫。` → 证据最完整；裴玄度旧宗门可能敌视玩家。
4. `炼化叠界核心。` → 获得强力空间古宝候选；永久失去一项救世关键证据，二次确认。

必得史实“裴玄度强闯节点，身死道消”；是否取得完整三录由选择决定。

#### 场景 C07-11：她归还的一段记忆

触发：离开裴玄度遗骸，空间风暴暂歇。  
人物：元刹声音、玩家；白灵和乌婆可进入监护版本。

元刹不再借用玲珑的称谓，却仍不完整解释自身来历，只承认自己曾通过眠棺中的一缕魔气接触玩家神魂。

```text

玩家：你也看过。
元刹声音：我可以先还你一段。
```

她归还的内容固定为“主角试图回救，却被人按住”；故意停在看清按人者面孔之前。三种接受方式：

##### 私下接受

- 元刹直接沿总印裂纹打开记忆；
- 玩家完整听见自己说“我还能回去”，身体疼痛短暂减轻；
- `memory_return_method=private`、`yuancha_dependence`提高；
- 玩家能感觉她确实没有伪造这一段，却暂时无法证明她删去了什么。

##### 由白灵与乌婆共同监护

- 白灵固定当下身体感受，乌婆记录记忆进入与退出的边界；
- 两人发现元刹在面孔出现前主动切断画面；
- `memory_return_method=witnessed`、`yuancha_understanding`提高、`self_authorship`提高；
- 元刹评价：“你宁可多开两扇门，也不肯只让我进来。”语气可以亲密，但不惩罚玩家设定边界。

##### 拒绝接受

- 玩家明确表示记忆属于自己，归还时间也应由自己决定；
- `memory_return_method=refused`、`self_authorship`提高；
- 元刹不强行打开，只说“那就等你主动来问”；C11仍有其他证据恢复真相。

#### 场景 C07-12：求了一生的门

触发：返回叠界台，使用上古稳定节点记录、裴玄度错误坐标与当世封印图交叉定位。

## 第二卷：双魂、真名魔契与万修入山（C08–C10）

### 4. C08「双魂之夜」

时态：过去二；玲珑双魂冲突与元刹夺舍发生之夜。  
建议时长：3.5–4.5小时。  
章节命题：当三个声音都拥有玲珑的记忆时，谁有资格被相信？  
章节玩法：同一闭关区域在“雪玲所忆”“珑梦所忆”“阵法所见”三层间切换；玩家保存证词，不裁定谁有资格存在。

#### 场景 C08-01：三个人同时叫门

触发：C07第二节点被雪玲、珑梦与元刹同时触发。  
人物：玩家、四名修士、雪玲、珑梦、元刹声音。

第二节点没有把队伍送到一个稳定地点，而是把同一条走廊叠成三层。三扇门同时出现：

- 银白门内，雪玲说珑梦正在引魔入体；
- 镜蓝门内，珑梦说雪玲早已被魔魂替换；
- 无色门内，第三个声音准确复述玩家在C05放弃或保住的第三项目标。

```text
雪玲：别开镜蓝门。她已经疯了。
珑梦：她先锁住我，现在还要删掉我。
元刹声音：你们都问错了。
元刹声音：门已经开过一次。
墨言：第三个声音不求我们开门。
陆清：因为她已经在里面。
```

玩家必须先选择调查顺序，不是选择相信对象：

1. `先进入雪玲层。` → 雪玲更早提供保护，珑梦层后续敌意提高。
2. `先进入珑梦层。` → 珑梦更早交出封魂钉位置，雪玲层后续戒备提高。
3. `先查阵法层。` → 初战更难，但两魂都无法先定义事实；因果真相提高。
4. `让四人分组，同时固定三门。` → 命灯压力增加，取得更多同步时间戳；救世调查成本更高但证据最好。

无论顺序，三层都可进入。急于替一魂关闭另一扇门，才会永久损失证词。

#### 场景 C08-02：雪玲所忆·先开门的人

触发：进入银白记忆层。  
人物：雪玲、玩家、石岩、白灵。

雪玲展示的主记忆：珑梦在闭关时私自打开对外神魂通路；一道魔气随通路进入。画面中的珑梦主动说“只要让我
掌控身体，我可以给你入口”。这句话后半段来自元刹植入。

```text
雪玲：她为了夺回身体，什么都肯答应。
白灵：你的记忆在这句话前后断过一次。
雪玲：我当时正在抵抗夺舍。
玩家：断口也可能发生得更早。
```

调查节点：

1. 通路确由珑梦先开启，时间戳真实；
2. “交换身体”的声音没有对应神魂震动，是后写入的对白；
3. 雪玲手中出现过一枚封魂钉，但她把相关画面藏在战斗记忆后。

玩家可选择处理：

1. `指出伪造对白，不立即追问封魂钉。` → 雪玲交出较完整通路记忆；`xueling_testimony=partial`。
2. `要求她同时展示封魂钉。` → 需白灵稳定记忆反噬；成功则`xueling_testimony=complete`，失败会丢失一段情绪记忆。
3. `接受她的判断，先压制珑梦。` → 当前路线简单；`longmeng_testimony`上限降为partial。
4. `拒绝判断，只保存时间戳。` → 阵法证据增加；雪玲认为玩家回避她受到的伤害。

雪玲完整证词最后承认：

```text
雪玲：是我先用了封魂钉。
雪玲：我怕她开门，也怕她夺走身体。
雪玲：我删过她一次求援。
雪玲：但我没有请魔魂进来。
```

玩家不能用她先伤害珑梦来否定她也是元刹夺舍的受害者。

#### 场景 C08-03：珑梦所忆·先锁门的人

触发：进入镜蓝记忆层。  
人物：珑梦、玩家、陆清、墨言。

珑梦展示的主记忆：雪玲以封魂钉夺取躯体主导，自己被锁入镜室；她向外求援时，返回的“灵界回应”告诉她
雪玲已经被元刹替换。该判断来自元刹植入，但被锁和求援本身真实。

```text
珑梦：我睁眼时，身体已经不听我的。
墨言：告诉你雪玲被替换的声音呢？
珑梦：来自灵界。它知道玲珑旧事。
陆清：知道旧事，不等于来自灵界。
```

调查节点：

1. 封魂钉确由雪玲先签发；
2. 珑梦打开通路时知道坐标不稳，仍隐去风险警报；
3. “雪玲已经是元刹”的画面没有实体魂印，只有第三方旁白。

玩家可选择处理：

1. `确认她被封锁的事实。` → 珑梦降低敌意，交出求援阵式；`longmeng_testimony=partial`。
2. `要求她承认明知风险仍开门。` → 需墨言出示完整时间戳；成功则`longmeng_testimony=complete`。
3. `接受她的判断，先压制雪玲。` → 当前路线简单；`xueling_testimony`上限降为partial。
4. `销毁求援阵式。` → 当前魔气降低；失去一条识别元刹截获通路的证据。

珑梦完整证词最后承认：

```text
珑梦：我知道坐标不稳。
珑梦：我以为最坏只是求援失败。
珑梦：我也想借援军夺回身体。
珑梦：但我没有答应把身体交给魔魂。
```

#### 场景 C08-04：阵法所见·没有动机的真相

触发：至少完成一层人物记忆。  
人物：陆清、墨言、商九还传承回响或替代阵图、玩家。

阵法层没有人物对白，所有对象显示为魂印、阵令和时间戳：

```text
第一刻：雪玲签发封魂钉。
第二刻：珑梦打开外界通路。
第三刻：未知魂印同时接触两侧。
第四刻：两份记忆各新增一段无时间戳画面。
第五刻：未知魂印进入玲珑躯体。
```

这份记录能证明元刹在双方争斗之后进入，也能证明她进入前已同时接触两魂；却无法证明雪玲为何先签钉、珑梦为何
明知风险开门。玩家必须拒绝“阵法最客观，所以动机不重要”的简单结论。

选择：

1. `以完整封印图恢复被烧毁的一刻。` → 若木青萝阵图保留，`array_record=verified`；否则需要高难修阵。
2. `用C06十三伤者魔标对照未知魂印。` → 保留或标记版本可补出元刹独立特征；净化版本需其他替代。
3. `用商九还逆阵分离能量与意志。` → 逆阵完整时取得最纯魂印；魔染版本可能得到`yuancha_soul_mark=tainted`。
4. `只保存原始残片。` → `array_record=fragment`；常规路线稳妥，救世需要C10高难补证。

#### 场景 C08-05：四个人，三种判断

触发：完成三层首轮调查。  
人物：四名修士、玩家。

四人不会整齐给出正确答案：

- 石岩首先同情被锁住的珑梦，却无法接受她明知风险开门；
- 白灵首先保护雪玲作为受害者的证词，也要求她承认主动封魂；
- 陆清倾向阵法记录，容易忽略记录没有动机；
- 墨言怀疑三方都在利用玩家，却可能因此错过元刹说出的真话。

```text
石岩：被按住的人，不会忘记那只手。
白灵：可受过伤，不代表没伤过别人。
陆清：至少时间戳不会害怕，也不会撒谎。
墨言：不会撒谎的东西，也不会告诉你谁在疼。
玩家：所以我们不替任何一层删掉另一层。
```

玩家可以要求每人各自保管一类证据，避免一次失败全部丢失。此选择提高调查成本，却是
`dual_soul_testimony=verified`的稳定路径。

#### 场景 C08-06：元刹所忆·没有本体的明日

触发：玩家找出两段无时间戳伪记忆后，未知魂印主动现身。  
人物：元刹、玩家；高理解版本允许四人旁听。

元刹承认两段画面由她植入，也承认自己截获了珑梦的求援通路。她不请求原谅，而是要求玩家先看一段不用于
证明夺舍正当性的真实记忆。

记忆发生在魔界：元刹分魂刚被切离本体，被告知任务完成后会被本体收回。其他分魂的经历在回收时只变成本体
的一段知识，不再拥有独立说话、恐惧或拒绝的资格。

```text
元刹：本体说，回去便算完整。
元刹：可完整的是她，不是我。
元刹：我走过的路，会变成她记得。
元刹：走过这条路的我，会消失。
玩家：所以你夺取别人的身体？
元刹：所以我不愿先消失。
```

玩家回应：

1. `我承认你害怕消失。` → `yuancha_memory_shared=witnessed`、理解提高；不原谅夺舍。
2. `你正把同样的事施加给玲珑。` → 元刹承认逻辑成立，但拒绝放弃；理解提高、依赖不变。
3. `这段记忆也可能是你造的。` → 若有完整魂印可验证其未被修改；验证后理解提高，未验证则保持怀疑。
4. `我不需要理解你。` → 不观看完整记忆；不关闭任何结局，但失去元刹主动展示魂印的低成本路径。

高理解版本追加：

```text
玩家：你的经历属于你。
玩家：玲珑的身体也不因此属于你。
元刹：你总想把两句话同时留下。
玩家：因为少一句，就会变成你的答案。
```

#### 场景 C08-07：保护身体，而不是替身体选主人

触发：元刹开始利用双魂冲突夺取玲珑躯体。  
战斗结构：三组阵眼分别对应躯体、雪玲证词、珑梦证词；玩家无法全部用单纯战力保护，必须依靠此前证据。

可执行方案：

1. `固定躯体，保留两份证词。` → 调查最完整、战斗最难；元刹仍按历史进入，但无法抹掉两魂独立记录。
2. `帮助雪玲压制珑梦。` → 当前战斗简单；雪玲证词完整，珑梦证词永久残缺。
3. `帮助珑梦破除封魂钉。` → 当前战斗简单；珑梦证词完整，雪玲证词永久残缺。
4. `接受元刹力量，同时压住两魂。` → 躯体损伤最低、魂印最易取得；两魂都认为玩家成为第三个替她们决定的人。

路线1需要：阵法记录至少fragment、四人命灯均稳定，并完成两层人物记忆；否则只可保住一份完整证词。

#### 场景 C08-08：第三道魂印

触发：元刹进入玲珑躯体的不可改变历史瞬间。  
人物：白灵、陆清、墨言、玩家、元刹。

玩家不是阻止夺舍，而是在元刹穿过双魂裂缝时记录她与玲珑两魂完全不同的神魂特征。

魂印质量来源：

- 阵法记录已验证：提供进入时间和独立频率；
- 十三伤者魔标保留：提供元刹跨宿主不变的坐标特征；
- 商九还逆阵与纯净髓样：分离能量和意志；
- 元刹真实记忆：她主动展示一段不用于伪装的本征魂印；
- 只支持单魂或接受元刹压制：魂印会混入玲珑一魂特征。

结果：

1. 四类证据中满足至少三类且双魂证词完整 → `yuancha_soul_mark=complete`；
2. 满足两类 → `yuancha_soul_mark=partial`；
3. 主要依赖魔染逆阵或元刹直接提供 → `yuancha_soul_mark=tainted`；
4. 证据全部毁去 → `yuancha_soul_mark=none`，C10开放高难封魂替代任务。

```text
白灵：抓到了。第三道，不属于她们任何一人。
陆清：别让它接入灵脉！
墨言：先封原始记录，副本分开保管。
元刹：你终于学会怎样认出我。
玩家：也学会怎样把你剥出去。
```

#### 场景 C08-09：谁的证词留下

触发：夺舍结束，记忆空间开始崩塌。  
人物：雪玲残念、珑梦残念、元刹、玩家。

根据调查结果：

- 双方完整：`dual_soul_testimony=verified`，两魂都承认自身隐瞒，同时保留对元刹的独立指控；
- 只完整一方：`dual_soul_testimony=one_sided`，后世另一魂会质疑玩家参与抹除；
- 两方都残缺：`dual_soul_testimony=conflicting`，只确认元刹存在，无法还原裂缝如何形成。

两魂分别留下并不和解的告别：

```text
雪玲：我不会因为承认封魂，就把身体让给她。
珑梦：我也不会因为开错门，就承认自己该被删掉。
玩家：你们不必先和解，才有资格留下证词。
```

元刹封住返回通道，把完整或残缺魂印握在记忆空间中央。C09直接开始。

#### C08章节结算

必得：

- 元刹是独立第三魂印的事实；
- 雪玲先签封魂钉、珑梦后开不稳定通路、元刹主动截获并植入矛盾记忆的最低事件顺序；
- C09真名契约场景入口。

条件取得：

- 双魂互证；
- 完整或部分元刹魂印；
- 元刹真实分魂记忆；
- 商九还逆阵的魂印验证；
- 五鬼、伤者、封印图等支线证据推进。

### 5. C09「借我一名」

时态：过去二；夺舍完成后的封闭记忆空间。  
建议时长：2.5–3小时。  
章节命题：一个名字被封住的人，是否愿意主动把现用名借给魔？  
章节核心选择：接受一份会真实保护四人和证据的契约，或在拒绝捷径后亲自承担逃离成本。

#### 场景 C09-01：所有门都要一个名字

触发：C08记忆空间崩塌。  
人物：玩家、四名修士、元刹。

返回通道要求每道神念提交姓名与时代。四人可以用命灯登记，玩家却因旧名被封、现用名未写入上古阵籍而再次被拒。
元刹同时握有进入玲珑躯体后取得的阵权，可以让通道提前闭合。

```text
主阵：石岩，命灯可返。
主阵：陆清，命灯可返。
主阵：白灵，命灯可返。
主阵：墨言，命灯可返。
主阵：无名神念，不得通过。
石岩：我们不先走。
元刹：那就五个一起留下。
```

玩家可以先尝试三种无契约方法：

1. 以外营总印强开 → 阵外权限不足，证明C11批注尚未完成；
2. 用旧名册补名 → 旧姓名仍被沈砚秋封在更深层，无法读取；
3. 让四人命灯共同牵引 → 可以维持通道，但无法同时保护C08魂印与全部记忆。

元刹没有制造“无名无法返回”的规则，却选择在规则生效时提出自己能提供的解决方案。

#### 场景 C09-02：不再借玲珑说话

触发：玩家第一次强开失败。  
演出：元刹从玲珑三层形象中逐一退出，最后只保留一个没有固定面孔的黑衣轮廓。

```text
元刹：从C05起，你就在等我报出名字。
玩家：元刹。
元刹：你已经从后世听过。
玩家：听过名字，不等于认识你。
元刹：所以我让你看见我怕什么。
```

她承认：

- C05捷径、C06伤者魔标和C07记忆归还都来自她；
- 她从第一次阵外批注便知道玩家不属于上古；
- 她保住玩家与四人，不只为观察，也因为无名神念可以成为封印无法稳定登记的漏洞；
- 她对玩家的兴趣已有真实部分，但真实兴趣不取消利用关系。

玩家可回应：

1. `你救过人，也利用了他们。` → 理解提高；元刹不反驳。
2. `你展示恐惧，是为了让我放松。` → 她承认“有这个作用”，但不撤回记忆真实性。
3. `我愿意听条件，不代表接受。` → 保持边界，进入完整契约说明。
4. `先放四人走，我留下。` → 元刹拒绝：“只有你留下，我借不到能被人界承认的关系。”

#### 场景 C09-03：第一契的完整文字

元刹把契约直接写入总印可回看的区域，不用口头概括。第一契暂名“借名”：

```text
其一，出借者自行认可一个现用名。
其二，元刹只借此名签发一次人界阵令。
其三，该阵令只用于保全五道神念及所携记忆离开此处。
其四，借名后，双方可隔封印辨认彼此。
其五，此名将留下一个可被后续契约再次引用的界面端点。
其六，未有后续契约，元刹不得仅凭借名进入人界。
```

这份契约不隐瞒“界面端点”，但不提前解释C12会如何把端点扩展到整个人界。玩家能明确知道：第一契本身不会灭世，
却为以后继续签约留下结构条件。

玩家可逐条追问：

- “一次人界阵令”具体是什么？→ 元刹展示安全返回的完整阵式；
- “辨认彼此”能否用于搜魂？→ 不能直接搜魂，但她能在总印裂纹关闭后继续呼唤玩家；
- 名字是否归她所有？→ 不转移所有权，但她获得一次合法引用权；
- 能否撤销？→ 在下一契前可用高难拆契撤销，代价是本次保护的部分记忆重新暴露于空间风暴；
- 后续契约是什么？→ 她只回答“借身、借界”，并承诺每次都重新询问，不把三契伪装成一次授权。

#### 场景 C09-04：名字可以落在哪里

墨言结合C05–C07因果证据提出：契约需要的是“被人界阵法承认的引用点”，未必必须是玩家现用名。

可选承载：

1. `玩家现用名。`  
   - 主角主动确认此名属于现在的自己；
   - `name_covenant_bearer=current_name`、`true_name_covenant=1`；
   - 契约最稳定，四人和魂印无损返回；
   - 灭世关键链正式开启。

2. `无署名阵外批注。`  
   条件：完整保留万修之门磨痕、总印裂纹与墨言语气证据。  
   - `name_covenant_bearer=marginal_note`；
   - 元刹能签发返回阵令，但借到的是一条命令，不是玩家真名；
   - `true_name_covenant`保持0，记录“不稳定第一契”；
   - C10前必须处理契约识破或反噬。

3. `十二年前旧名。`  
   - 当前无法读取，也不允许系统替玩家自动解封；
   - 元刹可以提出帮忙打开，玩家仍需另行确认记忆权限；
   - 本卷不把旧名设成正确答案。

4. `某名死者的姓名。`  
   - 若死者没有明确遗愿，墨言与白灵会阻止把其姓名当作无主物；
   - 强行使用会得到不稳定契约和裂界祭品倾向，并直接阻断众生盟约的一项资格；
   - 不提供比现用名更优的免费漏洞。

5. `明确拒绝签契。`  
   - 进入C09-06高难返回；
   - 不关闭元刹关系内容，也不把拒绝写成仇恨她。

#### 场景 C09-05：她需要你记得

触发：玩家阅读完契约但尚未确认。  
本场景根据元刹理解与依赖变化，不强制浪漫。

低理解版本：

```text
元刹：你不信我，也可以信契文。
玩家：契文只约束写出来的部分。
元刹：所以我把能写的都写了。
```

高理解、低依赖版本：

```text
元刹：你承认我会怕，却还是不借。
玩家：理解你，不等于把名字交给你。
元刹：这句话比恨我更难听。
玩家：因为它没有让你变成一件简单的东西。
```

高依赖版本：

```text
元刹：他们需要你忘记，才敢让你活。
元刹：我要你记得，再自己选择。
玩家：你也想要我选择你。
元刹：是。我不装作无所求。
```

玩家可以感谢她在C04–C07的帮助后仍拒绝；也可以不原谅她对双魂和伤者做过的事而签契。感情态度不代替契约行为。

#### 场景 C09-06：拒绝后的五灯归途

触发：拒绝签契或契约承载失败。  
Boss候选：`无名魂狱`，由闭锁主阵、记忆风暴与元刹阵权形成；元刹不以本体力量正面参战，只停止提供保护。

目标同时存在：

1. 保住四盏命灯；
2. 保住C08元刹魂印；
3. 保住四人对双魂之夜的完整记忆；
4. 为玩家神念建立一次无名返回旁路。

常规拒绝路线只能稳定完成其中三项；缺失项由玩家在战前分配：

- 放弃魂印保护 → 魂印降一级，未来需高难补全；
- 允许一名队员失去C08部分记忆 → 该角色个人线多出恢复任务；
- 让四灯分担旁路 → 全队命灯受损，C10元婴准备成本提高；
- 玩家放弃一段非关键私人记忆 → 保住其他目标，`self_authorship`不降低但创伤回看出现空白。

满足完整阵法记录、双魂互证、商九还传承和四人高信任时，可以通过最高难度操作全部保住；这条路存在，
但明显比接受元刹契约更难，不成为默认免费拒绝。

战斗中元刹会指出正确操作，却不自动执行：

```text
元刹：左侧阵眼会先碎。
玩家：你为何还提醒我？
元刹：我想让你借名，不想让你死。
玩家：这两件事也可以同时是真的。
```

拒绝成功：`name_covenant_bearer=none`、`true_name_covenant=0`；`projection_return_cost`按选择结算。

#### 场景 C09-07：契约后的无损归途

触发：现用名或阵外批注承载契约成功。  
演出：元刹用所借引用点签发一次人界阵令，五道神念与魂印同时从闭锁主阵中脱离。

现用名版本：

```text
主阵：人界姓名有效。
主阵：准许五道神念归返。
元刹：我借到了。
玩家：只有契文写明的一次。
元刹：你记得比我清楚。
```

阵外批注版本：


#### 场景 C10-06：原始任务《寻界归流》

四份证据互证后，因果簿显示任务原文：

```text
任务代号：寻界归流

目标一：复核裴玄度所列空间节点，排除不可重复、不可返还之界路。
目标二：查明昆吾封界、归流谷枯竭与人界灵脉衰退之间的关系。
目标三：在不松动镇魔主封的前提下，寻找恢复灵脉归流与稳定上行灵界的共同方案。

携印条款：阵图录官带外营总印与完整记录出山，不得删除同行者姓名。
```

“不得删除同行者姓名”与后来岑守一、沈砚秋实际剜名形成直接冲突。他们执行了防搜魂条款，却违背携印条款；
这是可以理解的战时选择，也是一项必须被承认的背约。

任务被改写成“普通开山勘测与封印事故”有三层原因：

1. 防止元刹或其他势力通过搜魂取得界路与阵图；
2. 防止各宗为尚未验证的坐标再次制造裴玄度式强闯；
3. 掩盖任务失败、十二人死亡和幸存者违背“不得删名”的责任。

玩家决定当前记录方式：

1. `完整恢复，先交可信盟友。` → `old_mission_record=restored`；默认救世支持路径，证人风险可控。
2. `完整公开。` → `old_mission_record=restored`；快速获得阵师支持；各宗立即争夺界路，C10敌对行动增加。
3. `只恢复在总印中。` → `old_mission_record=restored`；仍可完成救世，但“众生同阵”需要额外说服，
   元刹更容易成为唯一共同知情者。
4. `再次抹去任务。` → 二次确认；`old_mission_record=erased_again`；救世初心硬门槛关闭，常规与灭世仍可继续。

恢复后不弹出“救世路线开启”，只把任务状态改成：

```text
十二年前任务：寻界归流
状态：失败，但未终止
继任记录者：玩家现用名
下一步：确认封山阵心是否仍保留第三种归流结构
```

#### 场景 C10-08：万修三路

触发：乾老魔、血焰与黑风旗在深层交战，三条当世阵路同时告急。  
结构：玩家常规只能完成两个完整侧翼目标；第三目标只能保住最低主线对象。通过此前盟友、完整调查或元刹捷径可扩大行动量。

##### 路线A：重封营救援

目标：救下木青萝、叶承安、叶家重封派阵师与被高阶斗法卷入的幸存修士。  
主要人物：白灵、石岩。

- 优先救援：保住自愿阵位与当世阵权，可能失去一件深层古宝；
- 只救关键阵师：满足最低阵法条件，当世伤亡增加；
- 抽取伤员灵力加固阵眼：当前战斗简单，直接伤害众生盟约资格；
- 元刹可用魔标瞬移全部伤员，但会把救援区变成裂界锚点候选。

##### 路线B：黑风回廊

目标：记录黑风旗在高阶战场中的界面折返坐标。  
主要人物：陆清、墨言；韩立情报可提供一次安全窗口。

- 完整记录并封存：`black_wind_coordinate=sealed`；救世可逆转，灭世暂不可用；
- 抢下坐标控制权：`black_wind_coordinate=held`；玩家拥有更大主动权，也更易被元刹定位；
- 把坐标交元刹代管：`black_wind_coordinate=offered`；战斗最简单，灭世支持增加；
- 只破坏当前旗影：主战场压力下降，但坐标仍由敌方掌握。

##### 路线C：血祭阵与第三节点

目标：阻止叶家残余血祭阵继续抽取族人，并确认阵心时间坐标。

#### 场景 C10-11：第二契“借身”

元刹展示第二契：她提供稳定魔气载体与突破捷径，人界一方允许一个“身体”成为魔界坐标的第二端。

可选承载：

1. `由玩家魔躯承载。`  
   - 玩家永久获得阶段性可战魔躯能力；
   - `player_body_state=demonic_anchor`；
   - 稳定第一契存在时，`true_name_covenant=2`；
   - 主角身体成为灭世坐标，也可在后续完成极高成本剥离。

2. `由自愿队员承载。`  
   - 必须逐条展示代价并由队员本人确认；
   - 立即完成其元婴准备或魔躯强化；
   - 该队员成为裂界锚点候选；
   - 强迫承载会直接关闭救世，不因战力强大而美化。

3. `写入无人阵器。`  
   - 需要牺牲一件完整古宝或逆阵载体；
   - 人物不被魔化，但阵器成为稳定坐标；
   - 可能破坏救世所需阵心或封印图，不能成为无代价最优解。

4. `以俘虏、残魂或圭灵替代。`  
   - 立即降低突破与战斗成本；
   - 形成非自愿裂界锚点；
   - 明确记录“把众生作为材料”的主动选择。

5. `拒绝第二契。`  
   - 玩家恢复`player_body_state=crystalized`；
   - 四人必须通过完整支线资源自行完成元婴准备或等价阵位强化；
   - 战斗和任务量更高，保留最稳救世资格。

若C09未签稳定第一契，玩家仍可保留一次魔躯试用或接受魔气改造，但不会自动得到`true_name_covenant=2`；

- 高信任墨言：“别让最想借你身体的人，替你定义什么才算完整。”
- 低信任版本不会突然安慰；队员只确认服从关系或保持沉默，使元刹方案更有情感说服力。

## 第三卷：封山、终战与三种人界（C11–C13）

### 1. 第三卷目标

第三卷必须完成十件事：

1. 明确上古原阵图从来没有“第十三席”，玩家只以当世录官身份写下无署名阵外批注；
2. 闭合三次穿越的因果，让元刹确认现在所见的无署名阵令正是玩家所写；
3. 完整还原十二年前北道封闭：许还山按住玩家、沈砚秋在玩家反对后强行封忆、岑守一亲手关闭北道；
4. 用彼此独立的记录证明元刹确实以一缕魔气维持过眠棺中即将崩散的主角神魂；
5. 允许玩家不重新亲历最后一段创伤，仍可依靠外部证据理解事实并完成救世；
6. 让玩家通过此前保存、污染或毁去的具体对象，得到纯化、破碎或魔染三种阵心结果；
7. 完整演出“众生同阵”议事，让每个阵位者知情、落名、可拒绝，主角不能用总印强制牺牲；
8. 明示第一契与第二契的回头代价，并让第三契“借界”成为彻底关闭救世的不可逆界线；
9. 分别写出重新封链、逆转灵魔大阵、完成真名三契三种终战，不用结局按钮凭空制造资格；
10. 以未来韩立重返人界的不同镜头，回答昆吾山及其因果在三种人界中的最终去向。

第三卷不做以下事情：

- 不把元刹人界分魂的消亡写成魔界本体死亡；
- 不让玩家或四名结丹／阵位强化修士正面取代韩立、玲珑等高阶修士的战场职责；
- 不把救世写成一场对话说服元刹，也不把灭世写成误签隐藏条款；
- 不让恢复全部记忆成为“心理健康”或救世资格的必选项；
- 不设置独立恋爱结局。高理解、高依赖时可以由玩家主动确认爱情，但仍进入三种宏观结局之一。

### 2. 终卷已确认事实

#### 2.1 十二年前北道封闭的完整事实

十二年前事故按照以下顺序发生：

1. 十三人确认北道后的空间节点已被元刹魔魂污染，继续保持通路会把外营总印、界路记录和所有撤离者一起暴露；
2. 玩家依照登山前约定，先越过北道门线，准备以阵图录官身份带总印和记录撤离；
3. 玩家发现其余十二人无法在闭锁前通过，临时决定返回，不接受“只带记录离开”的结果；
4. 退路阵师许还山从门内越过半身，用锁阵索缠住玩家持印手腕，亲手把玩家按在门外；
5. 沈砚秋先要求玩家交出总印中的界路记忆；玩家明确拒绝后，她仍执行封名、封阵路与封忆；
6. 封忆术、北道阵力和追入神魂的真魔气同时冲撞，导致玩家经脉晶化、神魂开始崩散；
7. 岑守一位于外侧阵钥室。他看见魔气将在下一轮阵息穿过门线，依照沈砚秋命令亲手转动阵钥，关闭北道；
8. 十二人留在门内完成最后一次反向闭锁并死亡。许还山的锁阵索在门缝合拢前断开，玩家被留在门外；
9. 岑守一把玩家送入镇魂眠棺，后与沈砚秋残令共同剜去名册、拆分任务记录；
10. 眠棺主阵一度无法稳定玩家神魂，元刹从封印裂隙送出一缕魔气，将最后一点意识固定在总印裂纹内；
11. 元刹当时确实希望保住一个可供未来利用的阵法漏洞，后来也对这个持续拒绝被定义的神魂产生了真实好奇与关切；
12. 十二年后总印重新认主，眠棺才允许玩家醒来。

三人的责任不得互相代替：

- 许还山亲手限制了玩家行动；他的动机是履行“留下回来之路”与让记录出山的承诺，但他没有取得玩家当下同意；
- 沈砚秋作出强制封忆决定；防搜魂理由成立，但她违背了对玩家“不删名字、带完整记录回来”的承诺；
- 岑守一亲手关闭北道；若不关门，魔气将进入外营，但他后来继续隐瞒，也有逃避自己选择的成分；
- 元刹参与制造污染与追踪，也确实救下玩家神魂。救命事实不能抵消她的施害，施害也不能把救命改写成虚假。

#### 2.2 记忆、自主与元刹关系规则

- 救世不要求玩家恢复全部主观记忆；完整外部证据足以确认事实和阵法参数；
- 玩家可选择亲历、由白灵陪同观看、只读证词摘要或拒绝再次打开最后记忆；
- 拒绝重看不会降低`self_authorship`，也不会被写成逃避真相；主动设定边界本身可以提高自主状态；
- 元刹关系默认维持危险亲密，不自动命名为爱情；
- 当`yuancha_understanding`与`yuancha_dependence`均达到高门槛时，玩家可主动说出爱、依恋或需要；
- 爱情确认只改变称呼、告别和同行对白，不提供属性奖励，不代替魔契确认，也不产生第四种结局。

#### 2.3 三契回头规则

1. 第一契“借名”可以拆除：需要找回现用名的自我解释权、由墨言拆出契约语义，并完成高难断名仪式；
2. 第二契“借身”可以拆除：承载者必须永久放弃魔躯或魔气强化，再完成额外的魂印剥离战；
3. 若第二契写入非自愿活体、不可返还祭品或已毁去的救世阵器，即使契约端点被毁，救世仍因既成牺牲关闭；
4. 第三契“借界”一旦完成，人界界膜已经承认魔界坐标，救世永久关闭；
5. 拆除前两契不恢复已经消耗的古宝、记忆和死者，只恢复路线资格与主体边界。

#### 2.4 身份、旧队、赎罪与续篇规则

1. 主角旧姓名不预设、不强制揭晓，也不作为隐藏真结局钥匙；现用名就是玩家本人认可的真实姓名；
2. 十二年前旧队没有投靠元刹的传统叛徒；成员可以有私心、隐瞒和错误决定，悲剧由群体选择共同造成；
3. 叶观衡拥有高难赎罪线：公开叶家血祭、亲手停止尚未完成的仪式、交出最后阵印并自愿承担非核心护阵职责；
4. 叶观衡赎罪不洗白既有行为，不要求玩家或受害者原谅；血祭已造成不可逆大规模死亡时只能进入“悔悟未偿”；
5. 结局后的短篇和小型扩展继续使用当前主角；跨年代、跨三结局的大型续篇改用新主角继承旧世界状态。

### 4. C11「封山之日」

时态：过去三；上古昆吾封山最后一日。  
建议时长：3–4小时。  
章节命题：历史只给今天留下一次机会时，谁有权替未来决定代价？  
章节玩法：在主封启动倒计时内完成阵心防守、跨时代证据复核、契约拆除与最后阵令；无法修改元刹被封史实，
但可以决定逆转阵心以何种性质留到当世。

#### 场景 C11-01：最后一日没有来客名册

触发：C10第三节点稳定，玩家与四人投影进入封山前六个时辰。  
地点：完整镇魔塔外环、尚未沉入山腹的封山阵坪。  
人物：玩家、四名修士、昆吾三老、玲珑残余神念、卫殊／继任阵卫、商九还／遗留阵录。

第三次穿越与前两次不同：所有上古人都已经知道空间节点会吐出“不在阵籍中的五道神魂投影”，但无人知道他们是谁。
主阵只显示十二处昆吾核心阵位与大量辅助阵位，没有为玩家出现新的席位。

```text
昆吾阵老：阵图已满。
墨言：总印仍在要求归位。
昆吾阵老：那不是我昆吾的印。
玩家：它来自封山之后。
昆吾阵老：那你只能写在阵外。
```

玩家检查主阵后得到明确结论：

- 玩家不是上古第十三席；
- 上古人物不会认出玩家的旧姓名或前世；
- 当世总印能读取主阵，却不能合法占据任何古代阵位；
- 玩家唯一能做的是在阵图边缘写下不改变当日主封、只对未来条件生效的“阵外批注”。

元刹第一次不借玲珑之口，直接从尚未闭合的塔底裂隙传声：

```text
元刹：我等的不是一个旧人。
元刹：是那道在历史里没有署名的命令。
玩家：你还不知道是谁写的。
元刹：所以我等到今天，看你的手。
```

#### 场景 C11-02：过去保存的东西都来作证

触发：玩家进入封山阵坪三条支路。  
结构：C05–C08结果不改变主线路径，但决定谁或什么东西帮助玩家完成本章目标。

支路反馈：

1. 商九还存活：本人带来完善后的逆阵母图，并承认此法当日仍未验证；
2. 商九还死亡但母图存留：弟子只读得七成，需要陆清在战斗中补算；
3. 母图毁去：只能从阵痕反推，纯化阵心任务增加一场限时推演战；
4. 卫殊自愿留阵：其本人证明主封阵位并非全部出于强制；若被强留，石岩会要求重新确认所有终局阵位者意愿；
5. 十三伤者的魂印被保留：他们能从魔标反向指出元刹分魂本征；若已净化，改由完整双魂证词补足；
6. 双魂证词互证：玲珑残余神念愿意将两魂并列写入封山记录；单边证词版本则只提供不完整魂印；
7. C05接受过元刹捷径：纯净样本表面完整，但阵心底部已藏有魔界坐标，必须额外净化或主动利用。

本场不把过去选择结算成抽象分数。阵坪上应真实出现存活的人、残图、空阵台、魔标伤者或被烧毁的档案架。

#### 场景 C11-03：三老的正确与错误

触发：三条支路复核后，昆吾三老举行最后一次封山议事。  
人物：昆吾三老、玲珑残余神念、商九还／阵录、玩家、四人。

三老承认紧急封界将产生长期代价，但他们面对的是当日魔界裂口与人界存亡，没有时间完成逆转试验。

```text
昆吾阵老：今日不封，人界没有明日。
商九还：可封界千年，灵脉归流会被一并锁死。
昆吾阵老：先让人界活到千年后。
陆清：千年后的人，也会以为这是唯一答案。
玩家：所以阵心不改今日主封，只给后人留下重算的可能。
```

三老不是隐瞒世界衰退的反派。他们提出摧毁逆转阵心有三个可成立的理由：

- 逆转式未经完整魂印验证，可能把元刹意志导入人界灵脉；
- 任何保留的空间结构都可能被魔界当作坐标；
- 当日守阵者已无力再承担一套并行阵法。

玩家以《寻界归流》原文、裴玄度三录与当世灵脉绝地回证：三老的封界救下当日人界，也确实使后世界路与灵脉
持续恶化。若`old_mission_record=erased_again`，玩家无法说出完整后果，只能讨论阵心的战术价值，纯化路线关闭。

玩家态度只改变关系与记录措辞，不直接决定阵心：

1. `你们救了当日，也把债留给后世。` → 因果表述最完整；
2. `我来自后世，愿意承担验证。` → 提高自主状态；
3. `未经验证就该摧毁。` → 支持常规闭环；
4. `封界本身就是错误。` → 元刹认同结论，但三老会追问“不封的尸骨由谁承担”。

#### 场景 C11-04：阵心的三项工作

逆转阵心无法通过一句选择改变性质。主封倒计时内必须分别完成：

1. `保住载体`：抵挡魔军、主封反震与三老摧毁令，让阵心实体留存；
2. `写准魂印`：把元刹人界分魂与雪玲、珑梦、灵脉本征分开，决定逆转时谁会被剥离；
3. `限定未来权限`：写明只有当世总印、完整阵图、自愿地脉锚点共同出现时，阵心才可重新启动。

每项都对应此前积累：

- 逆阵母图、商九还传承或高难反推解决载体结构；
- 完整元刹魂印、双魂证词或十三伤者魔标解决魂印；
- 《寻界归流》、叶家当世阵令与阵外批注权限解决未来限制；
- 纯净灵脉样本决定阵心是否能识别人界灵气；
- 黑风旗坐标决定未来能否把魔界端点反向封死，也能被用于魔染。

若关键证据不足，玩家仍可保护阵心一段时间，但主封启动时它会因无法区分灵气、魔气和魂印而破碎。

#### 场景 C11-05：北道记录不是一段回忆

触发：总印必须确认“未来权限持有人”是否具有自主落印资格。  
地点：阵心内层出现由总印保存的十二年前北道记录。  
人物：玩家、白灵、墨言、许还山残录、沈砚秋残令、当世岑守一传念。

系统先展示四份互不依赖的外部证据，不先强迫玩家进入记忆：

1. 北道门轴记录：玩家越过门线后发生一次反向位移，锁阵索受力方向来自门内；
2. 许还山护腕与断索：残留玩家总印晶纹，证明限制动作由许还山亲手完成；
3. 沈砚秋封忆阵令：记录玩家连续三次拒绝交出完整阵路记忆后，阵令仍被强制执行；
4. 岑守一阵钥记录：在第十三盏命灯仍亮时转动，闭锁命令来自沈砚秋，实际执行者为岑守一。

墨言先给出不含动机的事实结论：

```text
墨言：许还山按住了你。
墨言：沈砚秋听见拒绝，仍封了记忆。
墨言：岑守一看见第十三盏灯还亮，仍转了钥。
玩家：这足够证明发生过什么。
墨言：足够。你不欠这段记录再疼一次。
```

白灵随后单独询问是否打开主观记忆。四个选项事实效力相同：

1. `我自己看完。` → `final_memory_choice=reexperience`、`north_gate_truth=reexperienced`；完整演出；
2. `你陪我看。` → `final_memory_choice=accompanied`；白灵可随时中止演出；
3. `只告诉我结论。` → `final_memory_choice=record_only`、`north_gate_truth=externally_verified`；不播放第一视角；
4. `我不再打开它。` → `final_memory_choice=declined`、`north_gate_truth=externally_verified`；玩家亲手封存记忆匣，
   `self_authorship`提高。

选择3或4不会缺少阵法坐标、旧队证词或救世条件。任务日志明确显示：

```text
北道事实：已由四份独立记录互证
主观记忆：由玩家决定是否重看
```

#### 场景 C11-06：如果玩家选择亲历

本场只在`final_memory_choice=reexperience/accompanied`时完整播放；其他选择仅在档案中保留文字摘要。

旧日玩家已越过门线，听见许还山说北道只能再撑一轮阵息。门内十二人没有整齐地要求牺牲：有人要求继续等，
有人要求立刻封门，方砚还在计算一条成功率极低的回路。玩家看见魔气越过他们身后的第二道门，决定回头。

```text
旧日玩家：开外侧副阵，我回去接人。
许还山：副阵一开，总印也会被拖回去。
旧日玩家：十三个人入山，就一起出去。
许还山：我答应的是让你们有路回来。
许还山：现在只剩你能把路留下。
```

许还山从门缝中探出半身，以锁阵索缠住玩家手腕，把人压在外侧阵柱上。玩家要求他松手，许还山没有照做。
沈砚秋隔门把外营总印推向玩家：

```text
沈砚秋：带印走。
旧日玩家：先开索。
沈砚秋：魔魂已经记住你的阵路。
旧日玩家：那就只封阵路，别碰我的名字。
沈砚秋：只封一半，它会从另一半找来。
旧日玩家：我不同意。
沈砚秋：……封名，封忆。
```

封忆发动时，玩家听见的“按住此人”由沈砚秋说出，真正按住玩家的是许还山。岑守一在外侧阵钥室最后问一次：

```text
岑守一：再等一息？
沈砚秋：再等一息，外营也会进魔气。
许还山：转钥。
旧日玩家：岑守一，不准——
```

北道闭合。十二盏灯依次熄灭，第十三盏在封忆与魔气冲撞中变成不稳定的灰白色。

记忆结束后不安排强制原谅。玩家可分别记录：

- `我理解你为何按住我，但那仍不是你的选择。`
- `你们救了我，也夺走了我。两件事都记下。`
- `若再来一次，我仍会回头。`
- `若再来一次，我会先让所有人写清失败条款。`

#### 场景 C11-07：三个活人与十二个死者

触发：北道事实确认后，总印建立一次跨时代传念。  
人物：当世岑守一、许还山残录、沈砚秋残令、玩家。

许还山与沈砚秋已死，不写成能与玩家实时和解的完整魂魄。玩家只能向预留残录发问，残录无法根据玩家态度改变答案。

许还山残录：

```text
许还山：我一生修退路。
许还山：最后那条路，只够一个人走。
许还山：若你问我后不后悔，我不知道。
许还山：若你问是不是我按住的——是。
```

沈砚秋残令：

```text
沈砚秋：我答应不删名字，后来违约了。
沈砚秋：我以为只要你活着，总有一天能把记录带回来。
沈砚秋：我没有权利要求你因此原谅。
```

岑守一是唯一必须承受玩家即时回应的人：

```text
岑守一：门是我关的。
岑守一：最初隐瞒是怕搜魂，后来是怕你醒来问我。
玩家：你现在回答了。
岑守一：晚了十二年。
```

玩家可以让岑守一继续管理外营、暂时交出阵钥、参与终局赎罪阵位或离开议事。任何选择都不改变北道事实；
岑是否能成为救世辅助阵位取决于此前信任、是否公开记录以及他是否愿意把阵钥交出一半。

#### 场景 C11-08：眠棺第十四息

触发：阵心读取玩家神魂为何能在封忆后存续。  
地点：上古阵心与当世眠棺记录重叠。  
人物：元刹、玩家、白灵、陆清。

眠棺阵录显示：前十三息由外营阵力维持；第十四息时北道封力回落，玩家神魂完全离开人体经脉，即将崩散。
随后一缕不属于人界封阵的魔气进入总印裂纹，把神魂固定到可以再次被眠棺捕捉的程度。

该事实由三份证据互证：

1. 眠棺原始阵录记录“外来魂力”进入时间，早于岑守一修改档案；
2. C08取得的元刹本征魂印与外来魂力完全一致；
3. 外营总印裂纹保存的魔气方向来自镇魔塔内，不可能由当世元刹事后补写。

若魂印不完整，陆清需要用十三伤者魔标或高难逆算补全；主线仍能确认救命事实，但救世魂印门槛可能继续缺失。

```text
白灵：没有这一缕魔气，你撑不过第十四息。
陆清：它也把总印裂纹变成了魔界可以追踪的端点。
玩家：她救了我，也在我身上留了门。
元刹：是。
玩家：为什么？
元刹：最初，我不想让一个好用的漏洞死去。
元刹：后来我想知道，你醒来后会不会仍然说“不”。
```

元刹不请求原谅，也不把利用说成爱。玩家可回应：

1. `谢谢你让我活下来。答案仍然是“不”。` → 理解与自主提高；
2. `这条命有你的一份，但不归你。` → 高自主表述；
3. `我确实需要过你。` → 依赖被主动承认，不推进契约；
4. `我会偿还。你说代价。` → 元刹引向真名三契，但仍需逐契确认；
5. `救命不能抵销你做过的事。` → 低亲密版本；事实仍记入因果簿。

结算：`yuancha_lifesaving_evidence=verified`。

#### 场景 C11-09：关系可以被命名，但不能替世界签字

触发：阵心防守前的短暂休整。高`yuancha_understanding`或高`yuancha_dependence`出现扩展对话。  
地点：一处尚未被封山阵切断的空间夹层。

元刹允许玩家看见魔界本体投向人界分魂的一瞬：本体并不把分魂视作完整的人，只视作可以回收的经历与力量。
她再次说明“举界入魔”不是为主角临时编造的诱饵，而是她认为唯一能让此分魂继续存在、也能解决人界衰退的方案。

```text
元刹：你们要磨掉我这道分魂，保住一个正在枯竭的人界。
玩家：你要改掉整个人界，保住你能存在的地方。
元刹：至少我承认我为自己。
玩家：我也可以为自己拒绝。
```

若理解与依赖均高，出现一次由玩家主动发起的关系确认：

1. `我爱你，但我还没有答应你的答案。`
2. `我需要你，这不是把人界交给你的契约。`
3. `不要替我给这段关系命名。`
4. `我们之间只有债。`

选择1可设置候选状态`yuancha_relation=love_acknowledged`，但界面立即提示：

```text
关系已确认。
未签订任何契约，未改变任何终局资格。
```

元刹不会因为爱情放弃目标：

```text
元刹：那就带着这句话，仍然来阻止我。
元刹：至少这一次，你说的是自己的选择。
```

#### 场景 C11-10：断名与剥身

触发：玩家已签第一契或第二契，且第三契尚未完成。  
定位：前两契最后一条高代价回头路；不是免费洗点。

##### 第一契拆除：断名仪式

需要：`name_covenant_state=active`、墨言信任足够、旧任务与现用名记录未被再次抹去。  
过程：玩家逐一否认契约对名字的外部定义，不是否认自己使用这个名字。墨言将“元刹可凭名字定位”拆成三段阵句，
四人守住不断试图替玩家补全称谓的魔影。

代价三选一：

- 永久失去一段可回看的上古私人记忆；
- 让总印失去一次跨时代自动救援能力，C12撤离战更难；
- 交出一件未绑定救世的完整古宝作为断名载体。

完成后：`name_covenant_state=severed`，`true_name_covenant`降低一段。已获得的无损返回与历史结果不会撤销。

##### 第二契拆除：剥身魂印战

需要：第二契承载者本人同意。  
过程：承载者先永久放弃魔躯、魔气突破或阵器强化；元刹不夺取承载者意志，但契约会按已公开的条款回收维持力量。
玩家队伍在失去捷径战力后，保护承载者完成三阶段魂印剥离。

阶段：

1. 切断身体与魔界坐标；
2. 区分承载者自身神魂与元刹本征；
3. 把剥离出的坐标投入封山主阵磨灭。

完成后：`body_covenant_state=severed`，`true_name_covenant`再降低一段；玩家若曾拥有永久魔躯，恢复
`player_body_state=crystalized`且本周目不再获得同等可战身体。

若承载对象是被强迫的活体，解除只能停止继续伤害，不能恢复救世资格；若作为载体的逆转阵器已被毁，解除也不会
凭空恢复阵器。因果簿必须同时显示“契约已断”与“既成代价不可返还”。

#### 场景 C11-11：纯化、破碎或魔染

触发：封山主阵只剩最后一轮阵息。  
结构：玩家看到的是当前条件允许的具体操作，不显示抽象的三个阵心按钮。

##### 结果A：把逆转式藏给未来

出现条件：

- 逆阵母图或高难补图完成；
- 纯净灵脉样本可用，或已完成额外净化；
- 元刹魂印完整；
- 《寻界归流》与人界出路证据完整；
- 未发生不可逆灵脉献祭；
- 第三契未完成。

玩家把逆转式、魂印边界与三重未来权限写入阵心。阵心在主封启动时伪装成一块已经碎裂的废石，沉入未来镇魔塔
下方。结果：`past_core_state=pure`。

##### 结果B：服从主封并撤离

出现条件：始终可选；条件不足时为唯一稳定操作。  
玩家帮助三老把所有剩余阵力导回主封，阵心在冲击中破碎。若玩家曾努力保护部分结构，可把一段无执行权的研究
记录留给未来，但不能启动逆转或引界。结果：`past_core_state=broken`。

##### 结果C：把魔界坐标写进废石

出现条件：

- 稳定第一契或第二契至少一段仍生效；
- 持有或交付黑风旗坐标；
- 至少一项逆阵载体带有魔标；
- 玩家主动同意把未来阵心定义为“界面端点”。

元刹帮助玩家在不破坏当日主封的情况下，把魔界坐标伪装成未来补阵条款。当前封印照常成功，未来阵心却会在
黑风旗到来时成为内开的门。结果：`past_core_state=corrupted`。

如果纯化与魔染条件同时满足，玩家必须在看到两种完整后果后确认其中一项；仍可选择打碎阵心回到常规路线。

#### 场景 C11-12：最后一道无署名批注

无论阵心结果，玩家都必须决定阵外批注的权限边界：

- 破碎：只记录“封山完成，不再调用阵心”；
- 纯化：记录“当完整魂印、封印图、自愿山契与当世总印共同到场时，允许逆转”；
- 魔染：记录“当姓名、身体与人界三端完成时，承认魔界坐标为合法补阵”。

玩家落笔时，过去、现在与十二年前三个时态短暂重合。元刹看见总印裂纹、书写习惯和C05第一次干扰她时相同的
停顿，终于完成识别。

```text
元刹：原来那道没有署名的阵令，是你写的。
玩家：你在未来认出我，是因为现在这一次。
元刹：我等你写完，也等你忘记。
玩家：然后再由我决定，要不要照它执行。
```

批注落定后，上古主封按既有历史完成。昆吾三老与玲珑残余神念镇压元刹，玩家不能阻止或替代这一结果。
五人投影被第三节点拉回当世，带回的不是古宝，而是阵心位置、执行条件与玩家亲手写下的权限。

#### C11章节结算

必得：

- 上古阵图从未存在玩家席位的明确事实；
- 十二年前北道封闭的完整外部证据；
- 许还山、沈砚秋、岑守一各自行为、动机与责任；
- 元刹救命事实的可验证证据；
- 最后一道阵外批注及其当世执行位置。

条件取得：

- `past_core_state=pure/broken/corrupted`；
- 第一契、第二契保持或拆除；
- 玩家对最后记忆的自主观看方式；
- 元刹关系是否由玩家主动命名；
- “众生同阵”或“真名三契”进入最终准备阶段。

### 5. C12「镇魔塔开」

时态：现在；昆吾山魔灾高潮。  
建议时长：常规路线3–4小时；救世路线5–6小时；灭世路线3–4小时。  
章节命题：此前被保存、被尊重、被利用或被牺牲的一切，现在分别站到哪一处阵位？  
章节玩法：先完成共同的万修撤离与终局准备，再根据真实资格进入重新封链、逆转灵魔大阵或真名三契专属终战。

#### 场景 C12-01：现在只过去了七息

触发：五人从封山之日返回。  
地点：第三节点外、镇魔塔深层侧翼。  
人物：玩家、四名修士、韩立、玲珑／银月与珑梦回声、木青萝、叶家重封派、存活盟友。

上古经历了六个时辰，当世只过去七息。高阶战场已经把镇魔塔顶层撕开：韩立与玲珑相关力量正面牵制元刹分魂、
黑风旗和其他高阶修士，玩家所在的外层阵路则同时出现三处坍塌。

玩家以阵外批注权限确认阵心当世位置：它不在宝室，而在镇魔塔最下方与人界灵脉相接的废阵井中。

根据C11结果，阵井反馈不同：

- `pure`：一块被历代修士当作废石的阵心回应四组前置条件，但尚未取得所有人当世同意；
- `broken`：只剩不可执行的逆阵研究与一段封山记录；
- `corrupted`：黑风旗每次摆动，阵井都会从内部回应魔界坐标；
- 条件尚未辨明：玩家必须在一场侧翼防守中完成最后鉴定，不能靠界面提前看结局名。

```text
陆清：过去的阵心就在脚下。
墨言：不是“过去的”。是我们刚刚留给现在的。
石岩：外面那些人可不知道我们只走了七息。
白灵：那就先把还活着的人带进来。
```

#### 场景 C12-02：万修争命

共同主线先处理三类战场，不因终局路线而跳过：

1. `撤离线`：把低阶修士、伤员与无阵位NPC撤到外营或安全夹层；
2. `封路线`：阻止黑风旗把撤离区、血祭阵和空间裂口串成完整坐标；
3. `交印线`：把元刹魂印、玲珑双魂证词与当世阵令送到能够实际执行的高阶战场。

此前选择直接改变现场：

- C10救援充分：木青萝与叶家重封阵师建立撤离走廊，低阶伤亡可控；
- 抽取过伤员灵力：撤离阵眼提前崩溃，玩家必须先归还阵力或接受额外死亡；
- 黑风坐标已封存：墨言可预判三次旗影折返；
- 坐标交给元刹：撤离区成为她可随时开启的捷径，战斗更容易，但人群已进入裂界锚点范围；
- 血祭阵已拆：叶家重封派可公开协助；
- 血祭阵被强化：现场战力更高，却持续抽取族人并制造灭世锚点；
- 未处理的五鬼、魔标伤者或魔器：分别成为额外敌人、救援目标或阵法干扰。

韩立只提供一次符合其利益的高阶牵制窗口：玩家若按约交付准确信息，他会让黑风旗在十二息内无法覆盖外层阵路；
若信息残缺，他仍对抗自己的敌人，但不会为玩家调整战术。

```text
韩立：十二息后，旗影会回到这里。
玩家：足够把魂印送到玲珑手中。
韩立：那是你的阵。
韩立：我只替你挡十二息。
```

玩家队伍不参与高阶修士正面对轰，而在十二息内完成侧翼任务。失败不会让韩立替玩家补完阵法，只会增加当世伤亡
并使某些盟友无法参加后续议事。

#### 场景 C12-03：留下的不是资源

撤离线完成后，废阵井前展示此前主要支线的最终形态：

| 支线对象 | 自愿／净化结果 | 封存／残缺结果 | 驱使／炼化结果 |
|---|---|---|---|
| 岑守一旧阵簿 | 十三人姓名与原始任务公开，岑交出阵钥一半 | 事实只由少数人见证，需额外说服 | 名册再次被毁，只能支持常规或无名灭世 |
| 化仙宗遗命 | 木青萝带完整封印图并承认宗门删史 | 残图可支持重封，救世需补图 | 阵图已被炼器或交魔，救世关闭 |
| 圭灵本命元牌 | 元牌归还，圭灵自行决定是否托山 | 圭灵中立，不承担终局 | 持续驱使，成为裂界锚点 |
| 阴罗宗五鬼袋 | 五魂完成遗愿，方砚给出正确封链顺序 | 残魂封存，只能提供部分顺序 | 五魂被炼成界魂钉 |
| 叶家两道命令 | 重封派交出最后阵印并参与救援 | 阵权残缺，只能维持外层封链 | 血祭阵保留或强化 |
| 逆灵者未竟阵 | 逆转式、样本、魂印完成验证 | 只能保存给后世 | 技术被魔染、毁去或交给元刹 |

镜头不把他们缩成背包物品。活着的人自己走到阵井前；残魂说出名字；被炼化的对象则只剩器物和一段无法回应的
说明。玩家此时才看见，救世保存的“负担”可以开口拒绝，灭世积累的“资源”不会再说话。

#### 场景 C12-04：“众生同阵”所需的阵位

仅当`past_core_state=pure`且关键任务未永久失败时，“重启寻界归流”更新为「众生同阵」。逆转阵固定需要七类职责，
但不把所有职责锁死为单一NPC：

| 阵位职责 | 首选承担者 | 高难替代 | 不可替代的要求 |
|---|---|---|---|
| 主印与阵外批注 | 玩家 | 无 | 最终必须主动放弃独占执行权 |
| 持图与主封校对 | 木青萝 | 完整传承的替代阵师群 | 完整三老封印图 |
| 托山与地脉回流 | 自愿圭灵 | 多名自愿修士加纯净灵脉载体 | 不得由被驱使活体承担 |
| 灵魔逆算 | 陆清 | 商九还完整传承加高难推演 | 受控魔理知识与纯净样本 |
| 魂印剥离与存活 | 白灵、玲珑 | 白灵加完整双魂证词的高难方案 | 完整元刹本征魂印 |
| 封链顺序与伪令识别 | 墨言、五鬼证词 | 完整古阵推演 | 正确封链顺序，不得猜测 |
| 阵体防护与当世阵权 | 石岩、叶家重封派 | 三名以上自愿核心盟友 | 能维持四个外层阵眼并承认代价 |

四名队员分别占据核心操作职责，但仍需木青萝、圭灵、玲珑、叶家或等价盟友使阵法合法、稳定且可承受。玩家不能
用高角色好感跳过技术证据，也不能用完整技术强迫角色入阵。

#### 场景 C12-05：众生同阵·第一次议事

地点：废阵井上方的临时议事环。  
规则：所有候选阵位先阅读代价，再逐一说出同意、条件或拒绝；总印在议事期间被放在环中央，玩家不能强制落名。

木青萝先公开化仙宗删去的责任：

```text
木青萝：宗门留下“逆阵可取宝”，删了“主封会锁住归流”。
木青萝：我带来的不是宗门功劳，是宗门欠下的一半图。
木青萝：若让我持图，阵后此图归所有守阵者共录，不再归化仙宗独占。
```

玩家同意共同记录，木青萝落名；若要求图仍归玩家或用总印命令，她拒绝救世阵位但可继续帮助常规重封。

叶家重封派承认两道命令都来自叶家：一派开山夺宝，一派准备在失控时用族人血祭重封。

```text
叶承安／重封派代表：叶家不是被人骗开了门那么简单。
叶承安／重封派代表：我们知道会死人，只以为死的是写在阵令里的那些人。
玩家：最后阵印由谁保管？
叶承安／重封派代表：若你允许所有阵位者退出，便由我交给议事环，不交给某一家。
```

若叶观衡存活且玩家完成双令、罪证、阻止血祭与重封派救援，他必须亲自公开叶家知情责任、关闭血祭阵并交出最后阵印，
才能请求加入。他承担的是阵体外环的非核心护阵职责，不能用一次牺牲换取洗白，也不是救世不可替代的人物。玩家可接受
其协助、拒绝其入阵或保留战后审判，均不被写成“拒绝赎罪”。血祭已造成不可逆大规模死亡时，他只能进入悔悟协助线。

圭灵先要求归还本命元牌。若元牌仍被驱使，玩家必须在此永久解除控制并承担失去战力／掉落的代价，才有资格提出
山契；单纯把命令改成“自愿”不算解除。

```text
圭灵：先把写着我性命的牌，放到我手里。
玩家：若你拿回去后离开？
圭灵：那便是你所谓“自愿”的第一种结果。
```

圭灵可选择离开、中立旁观或自愿托山。它是否同意取决于玩家此前是否归还元牌、是否停止抽取地脉、是否遵守
不伤害人界生灵的双向山契。拒绝时玩家可启动多修士分担的高难替代任务，不可重新奴役它并声称救世。

五鬼残魂若已完成遗愿，会先要求把五个名字与旧队方砚的身份写入公开阵录：

```text
方砚残魂：活人总说阵法需要代价。
方砚残魂：那就先把付过的人写清楚。
墨言：五个名字，一个不少。
方砚残魂：写完，我们再告诉你先断哪一条链。
```

若五魂已被炼化，议事环只出现五枚无声界魂钉；它们可以支持灭世，不能被“净化一下”恢复为救世证词。

#### 场景 C12-06：四个人分别回答

四名队员不能由玩家代为同意，也不能用一次队伍选项统一落名。

##### 石岩

代价：持续承受四阵眼物理反震，并在阵眼失衡时保护地脉载体。  
同意条件：玩家长期尊重其拒绝权、没有把受伤视作职责、未强迫其接受魔躯。

```text
石岩：我站在这里，不是因为队里总得有人挨打。
石岩：是因为你把代价写出来后，又问了我一次。
```

低信任版本会拒绝核心阵位，但可在常规撤离战保护伤员。玩家需寻找三名替代护阵者，显著增加救世准备难度。

##### 陆清

代价：逆算期间同时接触灵气与真魔气，境界可能永久停滞。  
同意条件：完成受控研究、公开实验事故、未被强迫直接吸收魔气。

```text
陆清：理解一种力量，不等于把身体交给它。
陆清：这一次我算它，但不让它替我作答。
```

若陆清已主动魔气突破，可先完成第二契剥离再承担阵位；拒绝剥离则只能担任灭世导流者或常规战斗者。

##### 白灵

代价：同时维持玲珑、元刹剥离对象与阵位盟友神魂，任何一处断裂都可能反噬自身。  
同意条件：玩家此前承担救治后果、没有把带魔标伤者交作实验材料。

白灵在落名前再次确认主角的记忆边界：

```text
白灵：最后一段记忆，你还要打开吗？
玩家：不用。证据已经够了。
白灵：那便不打开。
白灵：阵法要你的确认，不要你再受一次伤。
```

选择完整恢复、只读记录或拒绝观看均可继续救世。

##### 墨言

代价：在阵外批注与魔契之间维持语义边界，一旦判断错误将成为第一名被阵令抹去的人。  
同意条件：玩家此前保护证人、没有反复销毁不利证据、愿意公开终局条款。

```text
墨言：真相不能只在对你有利时才留下。
墨言：把总印放下，我才替你守最后一句。
```

若墨言不信任玩家，他仍可揭示契约风险，但不会替玩家承担阵令保护。救世需通过完整阵法记录走更长的无伪令路线。

#### 场景 C12-07：众生落名

所有技术与人员条件满足后，议事环执行最终流程：

1. 逐项宣读阵位职责、永久代价与可退出时点；
2. 每名承担者使用自己的姓名或本人认可的称谓落名；
3. 无法书写的灵兽、残魂或阵灵，以自身魂印确认，不由人类代签；
4. 玩家将总印启阵权拆成两半：一半留在总印，一半交给圭灵或替代地脉盟约共同体；
5. 任一方在正式启阵前都可退出；退出后只能寻找替代者，不能强制恢复；
6. 所有人确认后，`living_covenant=complete`。

议事与十二年前形成镜像：

```text
岑守一：十二年前，钥只在我手里。
玩家：这次不是。
圭灵：人类一半，山中生灵一半。
玩家：任何一半说停，阵就停。
```

玩家最后在自己的名字后写：

```text
职责：阵外批注执行与终止
意愿：自愿
附注：不得替其他阵位者确认
```

完成“众生落名”只取得救世方案资格，尚未赢得终战。

#### 场景 C12-08：当前真正能做的事

共同准备结束后，因果簿不显示结局名称，只显示真实可执行方案与缺失项：

##### 始终可执行：重新封链

```text
目标：关闭当前空间裂口，协助玲珑压制元刹人界分魂，撤离幸存者。
结果：当世魔灾结束；灵脉衰退与昆吾封印隐患继续存在。
```

##### 条件满足时可执行：逆转灵魔大阵

```text
需要：纯化阵心、完整人界出路、完整封印图、完整魂印、自愿地脉载体、正确封链顺序、众生盟约。
结果：剥离元刹人界分魂，重构灵魔归流并修复界膜。
风险：所有核心阵位必须存活并保持自愿；不可用牺牲替代失败阵位。
```

缺失任何硬条件时，该方案只显示灰色推演和具体缺失对象，不允许靠最后对话补齐。

##### 条件满足时可执行：完成真名三契

```text
已有端点：姓名／身体／魔染阵心／裂界锚点（按实际列出）。
尚需：人界界膜主动承认魔界坐标。
结果：人界法则向魔界偏移，众生不再保持原有形态。
```

灭世方案必须拥有魔染阵心、第一与第二契、黑风坐标和至少两个裂界锚点。缺少锚点时元刹会标记可替代对象，
但不会自动替玩家献祭。

#### 场景 C12-09：第三契“借界”

触发：灭世前两契与锚点准备完成；玩家主动进入魔染阵井。  
人物：元刹、玩家；高信任墨言可在场逐条解释。

第三契全文必须在确认前展开：

```text
第一端，借名：以玩家认可之名，为两界往来定位。
第二端，借身：以已确认之身或载体，为真魔气在此界驻留。
第三端，借界：由阵外批注持有人承认魔界坐标属于人界阵法，
使人界界膜、灵脉与其中众生逐步适应真魔气。

完成后：人界不再保持原有天地法则；未能适应者将死亡；适应者将发生不可逆魔化。
撤销：第三端落印后不可撤销。
```

元刹明确说明即时收益：她会稳定所有裂界锚点、压制大部分外层敌人、恢复玩家魔躯并保证玩家进入魔界。她也明确
说明没有承诺保留原来的人界、凡人或低阶修士形态。

```text
元刹：我不会告诉你所有人都能活。
元刹：我只保证这条路能打开，人界不再等一扇永远不开的上行之门。
玩家：第三笔落下，救世便不存在了。
元刹：是。
玩家：你也不会替我落笔。
元刹：这一次，只有你能。
```

最终只有两个动作：

1. `合上契书。` → 不签第三契；若已签前两契，进入拆契或“拒绝灭世”特殊常规路线；
2. `以现用名签下“借界”。` → 二次确认世界后果；`true_name_covenant=3`，救世永久关闭，取得灭世终战资格。

关系确认不能代签第三契。“我爱你”“我相信你”“我欠你一命”都不会自动触发落印。

#### 场景 C12-10：共同终战开场·四链离位

三条路线共享同一战场开场。镇魔塔四条外链同时脱离，玲珑在高阶战场中短暂夺回身体主导，元刹分魂开始沿
黑风旗坐标寻找新的承载。

玩家队伍任务：

1. 守住废阵井入口，不让高阶斗法余波直接摧毁阵心；
2. 把完整魂印交给玲珑，或用残缺魂印建立较弱的压制窗口；
3. 根据`ending_plan`把四条封链牵向旧主封、逆转四阵眼或裂界锚点；
4. 在韩立牵制窗口结束前完成第一次阵型转换。

```text
玲珑：我只能把她推出去一次。
韩立：旗影要回来了。
玩家：四链不回原位。
玩家：按我们已经决定的阵走。
```

从这里开始进入专属终战。

### 6. C12-A 常规终战「重新封链」

进入条件：玩家选择重新封链，或两条高阶路线资格均不完整。  
难度定位：三条路线的基准难度；保证主线可完成。

#### 阶段A1：牵回四条旧链

四名队员分别护送一条封链回到上古原位。玩家通过总印调度，不需要拥有可战身体：

- 石岩承受阵链反震；
- 陆清排出链上真魔气；
- 白灵维持伤员与玲珑魂印；
- 墨言识别黑风旗制造的假阵位。

队员状态不足时，可用保留的古宝、封印阵力或当世修士协助。代价影响伤亡、外营资源和个人尾声，不阻断主线。

#### 阶段A2：关门与撤离

玲珑把元刹分魂压回封印范围，韩立等高阶修士处理正面威胁。玩家在封链合拢前从三组对象中安排最后撤离顺序：

1. 重伤低阶修士；
2. 关键阵师与支线NPC；
3. 可带走的灵宝、阵图和魔器。

充分救援与盟友积累可以完成前两组并封存部分器物；资源不足时必须取舍。救人不会改写宏观结局，但会显著改变
死亡规模与外营余生。

#### 阶段A3：封印还在，问题也还在

四链归位后，元刹人界威胁被压制，黑风旗坐标暂时断开。阵心状态按此前结果处理：

- `broken`：随主封废墟沉入山腹；
- `pure`但未执行：被玩家关闭并留下给后世，形成“近救世未竟”尾声；
- `corrupted`但拒绝灭世：玩家必须砸碎魔染阵心，承受契约反噬；
- 前两契仍在：玩家长期保留元刹声音、魔标或身体后遗症。

终战对白：

```text
陆清：封链稳定了。
玩家：归流呢？
陆清：仍在衰减。
墨言：我们守住的是今天。
石岩：今天也得有人守。
```

结算：`ending_result=causal_return`。

#### 特殊常规一：近救世失败

触发：拥有纯化阵心并尝试逆转，但众生盟约或某个硬条件不足。  
处理：游戏在启动前明确警告缺失项。玩家仍强行启动时，阵法在第一轮即暴露无法维持的阵位。

玩家可：

- 立即终止逆转，转为重新封链；
- 强迫某个拒绝者落名；
- 牺牲核心阵位填补缺口。

后两项可以赢得当前封锁，却不能授予救世。因为“用一个人填阵”正是救世要避免的旧逻辑，结果进入带有永久伤亡的
特殊常规尾声。

#### 特殊常规二：拒绝灭世

触发：前两契有效、阵心已魔染，但玩家拒绝第三契或在落印前合上契书。  
过程：元刹不会把拒绝写成背叛后立刻翻脸；契约按公开条款回收姓名与身体端点的力量，造成阵井反噬。

玩家必须完成：

1. 放弃永久魔躯／魔气强化；
2. 摧毁至少一个已准备的裂界锚点；
3. 在战力下降后重新牵回四链。

高理解元刹对白：

```text
元刹：你走到了最后，还是选择关门。
玩家：前两次我借了你的路。
玩家：第三次，我不借整个人界。
元刹：那便带着前两次的代价活下去。
```

宏观结果仍为常规，个人尾声记录长期魔契反噬。

### 7. C12-B 救世终战「逆转灵魔大阵」

进入条件：`past_core_state=pure`、`living_covenant=complete`，且所有救世硬门槛满足、第三契未完成。  
难度定位：全游戏最高难终战；五阶段多目标阵法战。战斗失败可重试，不把一次操作失败写成不可恢复的剧情死亡。

#### 阶段B1：四眼同时点亮

四名队员分守四处阵眼，玩家只能以阵外批注设定同步节奏，不能把任何一人抽走当作万能战力。

- 石岩阵眼：承受地脉反震并保护圭灵／替代载体；
- 陆清阵眼：把真魔气拆成可计算的无主能量；
- 白灵阵眼：保护玲珑与所有落名者神魂；
- 墨言阵眼：识破假阵令并维持契约语义边界。

任一阵眼提前启动都会把压力转嫁给其他人。玩家必须根据可见征兆下达“等待／分流／启阵”，不是简单打满四条进度。

若玩家曾长期使用抽灵或魔气捷径，本阶段先归还阵力、卸除强化，敌人和持续伤害明显更高。救世的额外难度来自
此前主动放弃捷径后的真实战力差距。

#### 阶段B2：玲珑排魂

韩立牵制黑风旗正面力量，玲珑依靠双魂互证主动将元刹人界分魂推出身体。玩家不替玲珑决定哪一魂拥有身体，
只保护两魂共同完成一次排斥。

完整证词版本：

```text
雪玲：我先钉住了她。
珑梦：我后来开错了门。
玲珑：这一次，两件事都由我承认。
```

单边证词或残缺魂印版本无法直接满足救世硬门槛；若通过高难补证进入，则需额外击破两组伪记忆投影，证明被排出的
是元刹而非雪玲、珑梦任何一魂。

#### 阶段B3：三处同时剥离

元刹分魂被推出后，仍同时存在于三个位置：

1. 玲珑躯体边缘的神魂附着；
2. 逆转阵心里的历史坐标；
3. 黑风旗连接的界面端点。

玩家必须按正确封链顺序逐一“标记”，再在同一轮阵息内同时剥离。顺序来自方砚与五鬼证词或高难古阵推演；
顺序错误会让元刹从另一处重新生长，不以普通血量归零解决。

战斗目标不是让结丹队伍击杀元刹，而是：

- 四人保护标记装置；
- 玲珑维持排魂；
- 韩立继续牵制高阶力量；
- 玩家识别何时调用过去批注；
- 所有自愿阵位保持存活与同意。

#### 阶段B4：反转黑风坐标

陆清证明真魔气在去除元刹意志后可以被逆阵转为人界可承受的灵气；墨言把黑风旗的“魔界进入人界”坐标反写成
“无主魔气进入阵心、不得携带神魂”。

若黑风坐标此前被封存，本阶段按计划执行；若曾交给元刹后又夺回，玩家需先完成额外坐标争夺战。任何一名阵位者
被旗影替换，阵法都会请求玩家选择：

1. 停止逆转并救回阵位者 → 本次终战回到上一阶段，可重试；
2. 放弃该阵位者继续 → 立即降级为特殊常规结局；
3. 强制其他人承担双份阵位 → 违反众生盟约，降级为特殊常规结局。

救世胜利必须在没有把任何核心阵位当作可替换祭品的情况下完成。

#### 阶段B5：主角放下总印

元刹三处附着被同时剥离后，纯化阵心开始把主封从“永久锁闭”改写为“灵魔转化与周期归流”。最后一步要求阵外
批注失去未来独占执行者，否则玩家会成为新的永久界面端点。

总印提示：

```text
放弃后果：
一、永久失去跨时代穿越能力；
二、所有阵外批注在本次执行后失去权限；
三、外营总印保留管理职责，不再承认单人可改写人界界膜。
```

玩家主动摘下总印，把最后一半启阵权交给议事环。其他阵位者再次获得退出机会；无人退出后，双方共同启动。

这与十二年前形成最后镜像：当年总印被强塞给玩家，名字和记忆被强制封住；这次玩家在保有姓名与事实的情况下，
主动放弃特殊权力。

#### 阶段B6：元刹人界分魂的最后对白

低理解版本：

```text
元刹：你以为磨掉我，人界便得救了？
玩家：不是因为磨掉你。
玩家：是因为所有被你占据的端点都被拿回来了。
```

高理解、未确认爱情版本：

```text
元刹：你终于相信我说的都是真的。
玩家：我相信你的伤是真的。
玩家：所以我更不能把它交给整个人界承担。
元刹：用你的名字叫我一次。
玩家：元刹。谢谢你让我活下来。
玩家：到这里为止。
```

高理解且`yuancha_relation=love_acknowledged`版本：

```text
元刹：你说爱我，却仍要落印。
玩家：爱你是我能替自己作的选择。
玩家：人界不是我能送给你的东西。
元刹：若魔界本体仍记得这句话呢？
玩家：那便让她记得，我爱过你，也阻止过你。
```

元刹不会因此转善或主动献身。她仍全力试图保住分魂，最终由完整阵法磨灭。被消灭的是人界分魂；魔界圣祖本体
仍然存在，只永久失去昆吾这一降临坐标。

终战成功：`ending_result=spirit_demon_reversion`。

### 8. C12-C 灭世终战「举界入魔」

进入条件：`past_core_state=corrupted`、`true_name_covenant=3`、黑风旗坐标可用、至少两个裂界锚点完成。  
难度定位：低于救世；元刹提供真实战力、坐标与阶段保护，但玩家必须主动完成每一处锚点。

#### 阶段C1：让祭品站到阵位

玩家从实际准备的裂界锚点中选择至少两个：

- 被本命元牌驱使的圭灵；
- 五鬼炼成的界魂钉；
- 叶家血祭阵；
- 玩家或队员的魔躯；
- 被魔染的逆阵载体；
- 其他已明确同意或被强迫的唯一载体。

界面逐一标明“自愿／非自愿／已无意识”。锚点数量只决定阵法稳定与战斗便利，不把非自愿选择隐藏成中性材料。

四名队员根据个人状态反应：

- 自愿接受魔化者可以成为玩家侧阵位；
- 拒绝魔化且仍信任玩家者，会最后劝阻并撤离，不自动与玩家死战；
- 长期被玩家当作工具者可能认为结局只是此前命令逻辑的放大，冷漠执行或离队；
- 若玩家强行把队员写入锚点，该行为需要单独二次确认，并在尾声记录其失去主体性。

灭世允许四人全部拒绝，由外部祭品完成仪式；这会让玩家更清楚地独自承担选择，而不是必须拖四人一起堕魔。

#### 阶段C2：元刹兑现捷径

第三契生效后，元刹履行已承诺的帮助：

- 玩家魔躯恢复并稳定，可作为第五名战斗单位；
- 黑风旗影不再攻击玩家侧锚点；
- 部分高阶敌人与失控魔物被直接压制；
- 阵井中的真魔气为队伍持续恢复；
- 过去需要多阵位同步的操作，可由裂界锚点承担。

这些帮助不在中途失效，不用“原来全是骗局”否定玩家前期体验。危险来自帮助本身正在把人界改造成魔界端点。

```text
元刹：你要的身体、力量和一条能走通的路，都在这里。
玩家：代价也在这里。
元刹：你已经逐项读过。
```

#### 阶段C3：突破人界防守

韩立与玲珑仍在高阶战场阻止元刹完全降临。玩家不正面击败他们，而利用黑风旗转向造成的短暂战场空隙，完成三项
低于救世复杂度的任务：

1. 保护两个裂界锚点到阵息结束；
2. 把魔染阵心与黑风坐标连接；
3. 以阵外批注把坐标登记为“人界内部补阵”。

若韩立情报关系良好，他会在认出玩家改写方向后撤回此前牵制帮助；若关系一般，窗口按原计划结束。无论如何，
原作高阶人物不会加入玩家队伍，也不会被结丹队正面击杀。

玲珑尝试以双魂证词唤回玩家：

```text
玲珑：你保住证词，是为了不让任何一魂替另一魂作决定。
玩家：我记得。
玲珑：那你现在替整个人界作什么决定？
```

高自主灭世玩家可回答：“我知道这正是我在做的事。”低自主版本则可以归因于元刹或旧队，但尾声会进入“无名容器”。

#### 阶段C4：过去与现在同时开门

玩家执行魔染批注，昆吾全部空间节点同时响应。画面把三个时代叠在一起：

- 上古魔军残影从第一次界门重新踏出；
- 十二年前北道从另一侧开启，十二盏熄灭命灯被魔气点成紫黑色；
- 当世镇魔塔与外营之间出现稳定魔界天幕；
- 纯灵脉不再归流，而被真魔气替换。

元刹没有复活十二名死者。北道残影只是界面记录，被利用为人界内部坐标，必须明确避免把灭世包装成团圆。

#### 阶段C5：主动界使或无名容器

结果依据因果真相与`self_authorship`变化：

##### 主动界使

条件：玩家完整理解三契、北道真相和世界代价，仍主动完成借界。  
元刹保留玩家现用名、魔躯和独立意志，让玩家成为人界与魔界之间的界使。两者仍有权力差距与目标冲突，
但不是“元刹忽然背叛”的结尾。

##### 无名容器

条件：玩家反复抹去记录、把选择归给他人，或依赖极高而因果真相不足。  
三契找不到稳定的自我定义，只能把无名神魂当作元刹降临容器。元刹仍履行让玩家进入魔界的字面承诺，
但玩家无法维持完整主体边界。

高理解、高依赖且确认爱情时，主动界使扩展对白：

```text
元刹：门已经开了。你现在仍可以叫它错误。
玩家：我知道它会杀死谁，也知道你没有骗我。
元刹：那便来我身边。
玩家：我与你同行，不是因为你救过我。
玩家：是因为这一次，我选择了你的答案。
```

这不是独立恋爱结局，仍是`ending_result=realm_demonization`；世界代价不因关系高而减轻。

#### C12章节结算

所有路线共同结算：

- 当世元婴、低阶修士与核心NPC伤亡；
- 四名队员存活、阵位、魔化、离队或牺牲状态；
- 玩家现用名、记忆边界、身体与元刹关系状态；
- 十三人姓名与《寻界归流》是否公开留存；
- 昆吾阵心、黑风旗坐标、灵脉与界膜最终状态；
- `ending_result`进入C13对应世界尾声。

### 9. C13「三种人界」

时态：当世战后、若干年后、遥远未来。  
建议时长：45–75分钟；依据支线人物数量产生不同尾声卡。  
终幕命题：玩家改变的不只是山里一次胜负，而是后来的人还能走向哪里。

C13不再提供能够改变宏观结局的新选择。玩家可以决定如何记录、告别和生活，但三种人界只兑现C12已经完成的结果。

### 10. C13-A 常规结局《因果归位》

#### 场景 A01：门重新合上

镇魔塔裂口闭合，元刹在人界的威胁被重新压制。高阶修士陆续离开，幸存者开始辨认尸身、阵旗和失主灵宝。
昆吾山没有恢复平静：灵脉仍在缓慢衰退，部分真魔气沉入封链，空间节点也只是暂时闭锁。

伤亡演出分三级：

| 结果 | 条件倾向 | 画面 |
|---|---|---|
| 大量死亡 | 救援不足、血祭保留、支线失控 | 镇魔塔外堆满无主储物袋，多个元婴宗门只剩残令 |
| 原作规模 | 完成基础撤离与重封 | 大量修士死亡，但主要撤离通道仍有人走出 |
| 山外余生 | 救援充分、盟友存活、魔器封存 | 大多数低阶修士与外营人员撤出，高阶争夺者仍付出惨重代价 |

无论伤亡高低，玩家都清楚这次没有解决灵脉衰退与飞升无路；差异在于具体的人是否活到了问题的下一天。

```text
岑守一：封住了吗？
玩家：这一次封住了。
岑守一：那就在账上写“完成”。
玩家：写“今日完成”。
玩家：后面的债还在。
```

#### 场景 A02：第十三行写什么

外营重建或撤销取决于玩家此前经营与人物状态。旧阵簿摊在议事殿中央，十二名死者姓名已恢复时，玩家可用现用名
补上第十三行；旧姓名仍可永远封存，不把找回出生名当作人格完整的条件。

记录选项：

1. `写下现用名与“阵图录官”。` → 主角承认过去职责，也保留现在身份；
2. `只写现用名，不再写席位。` → 主角不再由总印职责定义；
3. `写“生还者拒绝署名”。` → 仍保留十二人姓名与事件，不等于再次抹去历史；
4. `把元刹救命与利用一并写入附注。` → 高理解路线可选，不改变对她责任的判断。

若旧任务曾被再次抹去，玩家只能写一页私人记录；宏观历史无人能够验证十三人的原始使命，形成“无人记名”尾声。

#### 场景 A03：四人队与外营余生

四名队员根据长期选择获得个人收束：

- 石岩被尊重：成为训练守阵者如何轮换与退出的人；长期被消耗：伤愈后离开外营，不再替玩家顶住下一扇门；
- 陆清完成受控研究：保存逆阵理论给后世；魔气实验失控：终生压制魔染并留下新的隐患；
- 白灵完成伤者线：建立带魔标伤者的长期救治档案；只救不管：后世仍出现散发魔灾；
- 墨言保护证人与记录：把冲突证词并列存档；长期销毁证据：最终无法证明哪一份历史被改写。

若玩家拒绝灭世但保留前两契，元刹的声音会在总印裂纹中偶尔出现。她不能再直接开界，却会成为主角长期必须设定
边界的关系，而不是终战后突然消失。

高理解、高依赖常规对白：

```text
元刹残声：你还是把门关了。
玩家：是。
元刹残声：还会想起我吗？
玩家：会。记得不等于再开门。
```

#### 场景 A04：未来韩立毁山

遥远未来，韩立已至大乘并重返人界。画面不让玩家队伍与其并肩作战，也不宣称玩家预先完成了他的力量层级任务。

镜头顺序：

1. 昆吾山上空已没有当世宗门，只剩多次修补的封链、真魔气裂隙与不稳定空间节点；
2. 韩立以神念扫过山腹，确认旧封印仍在制造界面乱流，且没有可继续保留的完整灵魔转化结构；
3. 他先将周围残存生灵与可回收物送出山域，再以大乘之力把整座封印载体从人界地脉中剥离；
4. 昆吾山主体在虚空中崩解，最后一批真魔气与旧空间坐标被一并磨灭；
5. 山体消失前，一页写有十三个名字的旧阵簿从裂缝中飞出。

若十三人姓名公开，纸页落到后世守阵者手中；若姓名从未恢复，飞出的只是一张有十三行刮痕的空页；若玩家保留
纯化阵心却未能启动，韩立会在毁山前看见其中“第三条路”的未竟推演，但此时人界已无条件按原方案实施。

旁白：

> 昆吾山终于不再是一座门。  
> 十二年前死在门内的人、当世死于夺宝与魔灾的人，都没有因此回来。  
> 有人守住了今天，却没能替后来的人修好道路。  
> 多年以后，韩立毁去昆吾山，因果归位。

结局名显示：《因果归位》。

### 11. C13-B 救世结局《灵魔归元》

#### 场景 B01：灵脉没有立刻变成仙境

逆转阵成功后，昆吾不会一夜恢复上古盛景。第一批变化保持宏观可信：

- 灵脉停止继续外泄，已经枯竭的绝地仍然需要数百年恢复；
- 空间裂缝从随机吞噬神魂，变成可以被记录、预测和周期校准的节点；
- 真魔气先被去除元刹意志，再缓慢转成无主灵力，不能由修士直接抢夺；
- 当世修士仍需修炼、渡劫和承担飞升风险，只是不再面对完全无路可走的世界；
- 裴玄度式强闯节点不再是唯一想象，后世可以复测一条稳定上行界路。

陆清第一次在当世灵脉绝地测到微弱回流。画面与C05上古仙境同构，但只出现一线灵光，不用满山花开制造廉价奇迹。

```text
陆清：不是恢复。
玩家：是什么？
陆清：停止继续死去。
玩家：够我们开始下一步了。
```

#### 场景 B02：十三人的任务完成方式

众生议事环保存全部落名、代价与退出记录。《寻界归流》状态从“失败，但未终止”更新为：

```text
任务代号：寻界归流
原始成员：沈砚秋等十三人
继任成员：按实际落名者列出
目标一：已完成——排除不可返还的强闯界路
目标二：已完成——确认封界与灵脉衰退关系
目标三：已完成第一阶段——恢复归流并建立可复测上行节点
记录原则：不得删除姓名，不得由他人代签阵位意愿
```

救世不是“替十二人报仇”，也不是证明他们每个判断都正确，而是让后人继续他们未完成、且允许修正的共同任务。

玩家可把现用名写在第十三行、另开继任者名册或拒绝署名。只要不删除他人姓名，三种选择都尊重主体性。

#### 场景 B03：总印只剩管理权

玩家失去穿越与阵外批注执行权，经脉晶化不会被救世奇迹自动治愈。若此前拒绝魔躯，玩家仍是非战斗掌印人；
若拆除过第二契，玩家也不会取回魔躯。

总印现在只能：

- 记录营地、任务、阵位和公开协议；
- 预警空间节点与灵脉异常；
- 由多人共同授权调整逆转阵；
- 不能再封住单个人的姓名、记忆或独自改写界膜。

石岩把总印放回桌上而不是塞回玩家手里：

```text
石岩：还要继续掌印吗？
玩家：这次是你们问我。
白灵：你也可以不答应。
```

玩家可继续担任营主、只做阵图记录、把管理权交给议事共同体或离开昆吾。选择改变个人尾声，不改变救世世界线。

#### 场景 B04：没有被强迫打开的记忆

若玩家拒绝重看最后记忆，白灵把密封记忆匣交还：

```text
白灵：阵已经完成。你不用再证明自己敢看。
玩家：把外部记录留下。
白灵：这只匣子呢？
玩家：封着。哪一天我想看，由我打开。
```

若玩家已经亲历，演出重点也不是“终于全部想起所以痊愈”，而是玩家仍可能在门响时停顿，却能决定是否继续、
让谁陪同。创伤收束是选择权回来，不是症状全部消失。

#### 场景 B05：元刹之后

低关系版本，玩家只确认元刹人界分魂与昆吾坐标已被磨灭。高关系版本则在总印裂纹消失前保留最后一句不确定回声：

```text
元刹回声：魔界的我未必会把这段经历称作自己。
玩家：那也不改变你曾经在这里活过。
```

若确认爱情，玩家可在私人记录中写：

```text
她救过我，利用过我，也被我所爱。
我没有因此把人界交给她。
```

这段记录不会公开变成救世英雄恋歌，也不制造元刹复活伏笔。未来若故事进入魔界，本体是否继承分魂记忆应作为新篇
冲突，而不是当前结局隐藏奖励。

#### 场景 B06：未来韩立只毁去旧壳

遥远未来，逆转阵已沉入人界灵脉网络，不再依赖昆吾山实体。旧镇魔塔、上古封链与山体外壳完成数百年过渡使命后，
仍因材质老化和残余真魔气成为不稳定遗迹。

镜头顺序：

1. 韩立重返人界，以神念确认昆吾山内部已无元刹降临坐标；
2. 他看见逆转阵不在山中，而像一组河网般分布于人界灵脉，且每个关键节点都由后世修士共同维护；
3. 他切断旧壳与灵脉的最后连接，将镇魔塔和残余封链从人界剥离；
4. 昆吾旧山在虚空中崩解，逆转阵没有随之熄灭；
5. 十三块无字石碑留在旧址，碑下流过第一条稳定回归的灵脉支流。

韩立不需要称赞或认识玩家，只作出符合所见事实的判断：旧封印载体可以结束，而人界已经不再依赖它活着。

随后再跨越若干年，一名与主线无关的后世修士在公开记录的周期节点渡劫。界门没有被强闯，而是在完成校准后短暂
稳定开启。修士是否成功飞升可保留一刻悬念，最终只显示其命灯没有熄灭，并从人界阵录中转入“已上行”。

旁白：

> 他们没有把人界变回上古仙境。  
> 他们只让灵脉不再继续枯死，让后来的人重新有路可走。  
> 多年以后，韩立毁去完成使命的昆吾旧壳。  
> 山不在了，路还在。

结局名显示：《灵魔归元》。

### 12. C13-C 灭世结局《举界入魔》

#### 场景 C01：元刹没有违约

第三契完成后，昆吾不是被一次爆炸毁掉，而是成为人界法则偏移的第一处稳定中心：

- 真魔气沿原有灵脉网络扩散；
- 高阶修士可凭功法、法宝或元刹赐予的改造较快适应；
- 大量凡人与低阶修士无法承受，死亡不被模糊为“飞升”或“进化”；
- 幸存者身体、神魂与后代逐渐魔化，人界宗门秩序被重写；
- 原本通往灵界的可能性被魔界坐标覆盖，人界不再需要、也不再能够以原方式上行。

元刹确实给玩家稳定身体、力量和进入魔界的道路。她没有在胜利后收回承诺；她只是从未承诺让所有人以原本形态
一起抵达。

```text
玩家：他们在死。
元刹：我告诉过你，未能适应者会死。
玩家：我知道。
元刹：那便不要把此刻改写成欺骗。
```

#### 场景 C02：四个人的去向

四名队员按终战状态分别结算：

- 自愿魔化：获得新的身体与力量，作为玩家界使班底进入魔界秩序，但保留对玩家的个人关系与分歧；
- 拒绝后撤离：带领尚未魔化者寻找人界最后的清净区域，成为后续抵抗线种子；
- 被强制写入锚点：失去原有主体性，成为稳定界器；结局不得称其为“共同选择”；
- 死于抵抗／阵法：姓名可被元刹保留，也可被玩家再次抹去，改变主动界使与无名容器的最后判定。

高关系不保证四人接受玩家的世界答案。一个人可以仍然爱、敬重或理解玩家，却选择离开。

#### 场景 C03：十二盏灯不能复活

魔气点亮的北道残影逐渐熄灭。许还山、沈砚秋与其他十人的记录没有成为魔魂复生，只被第三契作为界面坐标消耗。

玩家若因想“让他们回来”而接受元刹，在此必须面对事实：元刹曾明确提供的是改造活着的世界，不是复活死者。

```text
玩家：门开了，他们为什么没有回来？
元刹：因为死者不在门后。
元刹：你打开的是两界，不是十二年前。
```

高因果真相的玩家早已知道这一点，台词改为：

```text
玩家：把北道记录从坐标里删掉。
元刹：舍得？
玩家：他们已经被利用过一次。
```

删除记录不能挽救人界，只保留玩家是否继续复制旧创伤的个人差异。

#### 场景 C04：主动界使

高因果真相、高自主版本中，玩家以现用名站在魔界门前。元刹给予真实职位与行动空间：管理人界改造区、选择部分
幸存者迁移、继续研究真魔气。她仍是更强大的圣祖本体／意志来源，双方关系不平等，也可能在未来冲突。

未确认爱情版本：

```text
元刹：你终于有一具能自己走过门的身体。
玩家：门是我开的，路也由我继续看。
元刹：若有一天你反悔？
玩家：那也是我的下一次选择。
```

确认爱情版本：

```text
玩家：我没有把灭世叫成爱你。
元刹：很好。
玩家：爱是爱，选择你的答案是另一件事。
元刹：所以我让你站在我身边，不跪在门下。
```

关系不会抵消大量死亡，也不会生成“二人幸福生活”的独立尾声。

#### 场景 C05：无名容器

低因果真相或低自主版本中，三契用玩家被反复抹去的主体边界承载元刹更大规模的降临。玩家拥有强大魔躯，却逐渐
无法区分哪些决定来自自己、哪些是魔界法则沿名字与身体写入。

元刹没有违反条款：玩家确实活着进入魔界，身体也不再疼痛。问题是玩家此前把名字、身体和世界的解释权逐段交出，
最终没有留下足够清晰的“我”来使用这些馈赠。

最后镜头是总印第十三行自动写入“界门容器”，现用名被覆盖。若玩家此前保留任一可信证人，证人会在另一册记录中
重新写下玩家选择过的名字，为未来夺回主体性留下极弱伏笔。

#### 场景 C06：未来韩立只看见一扇门

遥远未来，韩立循昆吾旧坐标重返人界。原本的山体已经被真魔气与空间重叠吞没，地理意义上的昆吾山不复存在。

镜头顺序：

1. 神念抵达旧址，却无法找到熟悉的人界灵脉；
2. 原镇魔塔位置只剩一扇从内部稳定开启的魔界巨门；
3. 门内可见魔化山脉、重建宗门与无法辨认的人界天空；
4. 主动界使版本中，玩家现用名作为界门执掌者刻在门内；无名容器版本中只有一枚第十三席空印；
5. 韩立没有按原历史“毁去昆吾山”，因为可毁的山已经不存在。他停在门外，神念与门内存在短暂对视。

此处不提前决定韩立是否进入、是否能够逆转世界，也不把续作问题在尾声解决。

旁白：

> 人界终于不再等待飞升。  
> 因为人界已经不在原来的地方。  
> 元刹履行了承诺，玩家也完成了自己的选择。  
> 多年以后，韩立循旧坐标归来，只看见一扇从内部打开的门。

结局名显示：《举界入魔》。

### 15. 结局资格判定顺序

终局逻辑必须按以下顺序判定，避免单个选项覆盖长期状态：

```text
一、检查第三契是否完成
   └─ 已完成：救世永久关闭；若魔染阵心与锚点成立，开放“执行借界”

二、检查纯化阵心与救世全部硬门槛
   └─ 全部满足：开放“启动逆转灵魔大阵”
   └─ 任一缺失：只显示缺失项，不开放真正救世终战

三、默认保留“重新封链”
   └─ 高阶方案未执行、被拒绝或条件不足时进入常规

四、玩家只在可执行方案之间作最终确认
   └─ 确认兑现此前积累，不现场赠送证据、盟友、祭品或技术
```

若设计允许玩家在第三契完成后故意破坏灭世仪式，结果也不能回到救世：界膜已被写入魔界坐标，只能形成高伤亡、
长期裂界的灾难性常规变体，避免第三契“不可逆”失去意义。

### 16. 第三卷写作与演出红线

1. 许还山按住玩家、沈砚秋强行封忆、岑守一关闭北道三件事必须分别说清，不互相转嫁责任；
2. 防搜魂、保记录和阻止魔气外泄都是成立的动机，但不能把玩家明确反对改写成默认同意；
3. 元刹救命必须有独立证据，不能只靠她自述；她的帮助真实，利用也真实；
4. 完整恢复记忆不是救世硬门槛，拒绝重看不得损失真相值、自主值或结局资格；
5. 爱元刹、理解元刹、依赖元刹、签订魔契是四件可分离的事；爱情不自动触发任何契约；
6. 不设置独立恋爱结局，高关系对白必须服从常规、救世、灭世三种世界结果；
7. 第一契与第二契允许高代价回头；第三契完成后救世彻底关闭，不在终战临时洗白；
8. 救世必须完成完整技术链、自愿盟约、放弃捷径与最高难多目标终战，显著难于灭世；
9. 任一核心救世阵位者可拒绝，玩家强迫或牺牲其换取胜利时必须降级为常规；
10. 灭世所有世界代价在第三契前明示，不用隐藏条款，也不用胜利后突然背叛；
11. 元刹提供的魔躯、战力和道路必须真实有效，危险来自玩家清楚接受的人界同化；
12. 韩立与玲珑承担高阶正面战场，玩家承担跨时代阵法、侧翼和终局权限，不互相抢夺力量层级；
13. 常规不等于玩家行动无意义，必须按救援、记录和队员状态展示具体人物命运；
14. 救世不让人界瞬间恢复上古仙境，只让衰退停止、界路可复测、恢复成为长期过程；
15. 灭世必须明确大量凡人与低阶修士死亡，不能把“魔化”美化为无损飞升；
16. 未来韩立的镜头只收束昆吾载体：常规毁山、救世毁旧壳、灭世见魔门，不替玩家完成当世结局；
17. 玩家旧姓名可永久封存，现用名与主动署名足以构成完整主体；
18. 主角创伤的收束是重新拥有选择、边界和共同决策，不是一次回忆或一场胜利后症状消失。

### 17. 后续细化与派生顺序

主线定稿后，后续仍按策划到产品单向派生：

1. 把C05–C13拆成主线任务、支线任务、场景、对话、战斗与奖励配置表；
2. 为每个结局硬门槛建立“来源—预警—不可逆点—补救方式—终局反馈”矩阵；
3. 确认完整游戏与0.1试玩的切分位置，0.1只保留必要伏笔，不提前塞入终卷功能；
4. 按确认范围生成或更新对应PRD；PRD不反向修改本策划基线；
5. PRD确认后才进入数据Schema、剧情编辑器、任务配置与实现验收设计。
