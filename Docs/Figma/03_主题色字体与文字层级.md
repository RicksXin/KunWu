# 主题色、字体与文字层级

## 1. 主题方向

整体基调是“幽暗古禁地中的昆吾修行营地”：墨黑与深木承担背景，昆吾青与旧铜建立秩序，暗金用于高价值强调，朱砂只用于选择与危险等明确状态。避免大面积高饱和金色和通用仙侠蓝紫霓虹。

Figma Variable Collection：`KunWu / Theme Colors`  
当前 Collection ID：`VariableCollectionId:55:17`

## 3. 字体策略

当前阶段不需要引入付费或大体积特殊字体包。动态中文 UI 统一使用项目已有字体：

```text
ThirdParty/DemoAssets/Fonts/ArkPixel12px_OFL/ark-pixel-12px-proportional-zh_cn.ttf
```

- Figma 设计机与 Cocos 使用同一字体文件，避免换行、字宽和基线漂移。
- 正文、数值、按钮与动态标题使用 Ark Pixel Proportional。
- 大标题可在后续增加少量定制篆刻字，但动态文案仍使用字体，不烘焙进面板 PNG。
- 发布包保留对应 `OFL.txt`。
- 若 Figma 无法识别本地字体，先安装字体或启用 Figma Font Installer，不用系统宋体临时替代后直接交付。

## 4. 文字层级

以下为 `375×817` 逻辑画布的起始 Token；页面评审时以可读性和信息密度校正：

| Token | 建议字号 | 用途 |
|---|---:|---|
| `Type/Title/Page` | `24` | 一级面板标题、页面标题 |
| `Type/Title/Section` | `18` | 分区标题、建筑名称 |
| `Type/Body/Primary` | `16` | 主要正文、按钮文案 |
| `Type/Body/Secondary` | `14` | 职业·等级、说明、次级信息 |
| `Type/Caption` | `12` | 标签、辅助状态、短注释 |
| `Type/Number/Emphasis` | `18` | 关键资源或数值 |

最小动态正文不低于 `12`；长文本使用可预测的行高和最大行数，禁止靠压扁字体塞入容器。

## 5. 层级与对比规则

- 主要标题、姓名和关键值使用 `Theme/Text/Primary`。
- 说明、职业·等级、道阶·天赋使用 `Theme/Text/Secondary`；灵息值可用 `Theme/State/Info` 建立层级。
- 常规态与选中态优先共用同一文字颜色；通过底板明度、光晕和材质变化表达选择，避免状态切换造成文字闪变。
- 文字背景需要增强可读性时，使用中心较实、四周渐变到透明的矩形柔光；不得使用明显椭圆光斑。
- 柔光层不得形成实质边框，也不得遮盖立绘主体轮廓。
- 禁用状态同时降低底板和文字层级，仍需满足基本可读性；不可只降低整体透明度到无法辨认。
