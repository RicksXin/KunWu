## 4. 通用组件命名建议

```text
Panel/Level1
Panel/Level2
Panel/Decoration/Top
Panel/Decoration/Bottom
PanelItem/V2
Button/Inline
Button/Footer
Button/ToggleSmall
CultivatorCard/Deployed
CultivatorCard/Empty
Progress/Track
Progress/Fill
Icon/System/Settings
```

Variant 属性使用固定英文键：

```text
state = default | pressed | selected | disabled | locked | loading
level = primary | secondary
size = small | medium | large
```

不要在组件名中写页面专属文案；实例文字由页面覆盖。列表背景板、按钮和面板是三种不同语义，不因外形相近而混用。
