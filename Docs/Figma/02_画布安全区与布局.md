# 画布、安全区与布局规范

## 1. 画布基准

- UI 设计 Frame：`375×817`。
- 营地全景内容逻辑尺寸：宽 `1050`，高度按页面视觉确定。
- `360×640` 仅用于世界像素素材内部参考，不参与 UI 布局推导。
- `1080×1920` 是旧 Cocos 工程坐标，不是当前 Figma 设计基准。
- 所有 UI 尺寸优先记录为逻辑尺寸；位图另记实际导出尺寸和倍率。

## 2. 手机安全区

Figma 母版同时保留顶部与底部安全区参考层：

| 区域 | 设计参考 | 运行时要求 |
|---|---:|---|
| 顶部系统状态区 | `44` 高参考线 | 读取设备 Safe Area，不把 `44` 硬编码为所有设备值 |
| 底部 Home Indicator 区 | `34` 高参考线 | 读取设备 Safe Area；底部按钮和 HUD 不得压入不可触控区域 |
| 页面内容区 | 位于上下安全区之间 | 背景可延伸到屏幕边缘，关键文字和操作控件必须留在安全内容区 |

安全区参考层只用于布局，不导出为游戏素材。状态栏时间、信号和 Home Indicator 可用于通用手机预览，不进入游戏运行时 PNG。

## 3. 营地页面分层

| 层 | 是否横滑 | 内容 |
|---|---|---|
| `Viewport/Background` | 是 | 营地大背景、远景 |
| `Viewport/Buildings` | 是 | 建筑、名称、事件标记、点击热区 |
| `Viewport/Foreground` | 是 | 雾、树冠、前景遮挡 |
| `HUD/Top` | 否 | 玩家头像、资源、主线提示 |
| `HUD/Bottom` | 否 | 设置等入口、货币与底部安全区 |
| `Overlay` | 否 | 遮罩、面板、弹窗、Toast、引导 |

移动端 Frame 应开启内容裁切以模拟真实视窗；需要查看被裁切的建筑时，在独立的全景总览 Frame 中展示 `1050` 宽内容，或临时关闭预览 Frame 的 `Clip content`。不要移动建筑来迁就预览裁切。

## 4. 约束与响应

- 固定 HUD 绑定屏幕左右/顶部/底部约束，不放进全景横滑容器。
- 面板居中于安全内容区，而不是机械居中于整张背景图。
- 列表内容使用 Auto Layout；背景图作为 Fill 或绝对定位装饰，不承担内容间距。
- 触控热区与可见图层分离。小图标、加减号和紧凑按钮的热区不得小于 `48×48` 逻辑尺寸。
- 弹窗遮罩覆盖完整 `375×817`，面板本体避开系统安全区。
- Pixel Art 的位置与缩放保持整数逻辑像素；最终显示使用整数倍缩放和 nearest 过滤。

## 5. 页面母版建议

```text
Mobile / 375×817
├── Safe Area / Top Reference
├── Viewport / Clip
│   ├── Panorama / Background / 1050w
│   ├── Panorama / Buildings / 1050w
│   └── Panorama / Foreground / 1050w
├── HUD / Top / Fixed
├── HUD / Bottom / Fixed
├── Safe Area / Bottom Reference
└── Overlay / Fixed
```

页面展示稿至少包含：默认状态、内容溢出、最小/最大文字、空状态、不可用状态，以及一张安全区与触控区标注图。
