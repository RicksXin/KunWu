## 3. 当前可直接执行的结论

- UI 唯一设计基准为 `375×817`；营地全景逻辑宽度为 `1050`。
- Figma 未标状态的页面或组件一律按 `Draft` 处理；只有用户明确确认的 `Approved` 节点可直接作为实现依据。
- 当前明确 `Approved` 的通用组件只有 `Panel Item V2`，详见 [05_面板列表按钮与交互状态.md](05_面板列表按钮与交互状态.md)。
- 动态文字、数字、倒计时、价格、境界和状态不得烘焙进 PNG。
- 每张导出资源必须同时标注逻辑尺寸与实际交付尺寸。
- 新增图片交由 Cocos Creator 导入并生成 `.meta`，禁止手写或脚本伪造 `.meta`。

## 4. 更新规则

1. 新页面先在对应 PRD 中确认功能和交互，再进入 Figma。
2. 新组件先登记状态和复用范围，再进入 `Review`。
3. 用户确认后，只将确认范围内的节点升级为 `Approved`，不连带批准整页其他内容。
4. Figma 交付时同步更新组件索引、资源导出表和 Cocos 映射。
5. PNG 制作需求回写 `Docs/ArtAssets/`；不要把 GPT Image 提示词复制到本目录。
