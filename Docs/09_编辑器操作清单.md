# 编辑器操作清单

记录必须在 Cocos 编辑器 GUI 中完成、无法由文件侧代劳的步骤。

原则：`.scene` 与 `.meta` 里的 UUID 由编辑器分配，手写或脚本伪造会造成引用错乱
（见 CLAUDE.md）。因此凡涉及节点树、资源引用、Bundle 配置的操作一律走编辑器。

---

## `#6` P0-TECH-001 待你操作的部分

文件侧已完成（见 §「文件侧已就绪」），以下三步需在编辑器中做。

### 第 1 步：新建启动场景

1. 在 `assets/bundles/start-scene/` 下新建场景，命名 `Boot.scene`
2. 场景内建立节点树：

```text
Canvas                       （Cocos 自动创建，含 Camera）
└─ AppRoot                   空节点，挂 AppRoot 组件
   └─ SafeArea               空节点，加 Widget 组件（上下左右全对齐）
```

3. 选中 `AppRoot` 节点 → 添加组件 → 自定义脚本 → `AppRoot`
4. 选中 `AppRoot` 节点 → 添加组件 → 自定义脚本 → `ViewportAdapter`
5. 把 `SafeArea` 节点拖到 `ViewportAdapter` 的 `safeAreaRoot` 属性框

`AppRoot` 会调用 `director.addPersistRootNode`，故此节点跨场景常驻，
不要在其它场景重复挂载（重复挂载时代码会销毁多余实例，但不该依赖这个兜底）。

### 第 2 步：设置项目起始场景

项目设置 → 项目数据 → 起始场景 → 选 `Boot.scene`

### 第 3 步：把四个目录配成 Asset Bundle

`assets/bundles/` 下四个目录当前 `userData` 为空，即尚未配为 Bundle。
逐个选中目录，在属性检查器中勾选「配置为 Bundle」，并按下表填写：

| 目录 | Bundle 名称 | 优先级 | 说明 |
|---|---|---:|---|
| `start-scene` | `start-scene` | 8 | 首屏，需最高优先级 |
| `shared` | `shared` | 7 | 首屏共享资源 |
| `camp` | `camp` | 5 | 营地 |
| `map_01` | `map_01` | 3 | 地图 1 |
| `map_02` | `map_02` | 3 | 地图 2 |

注：`start-scene` 目录目前不存在，需新建（第 1 步的场景放这里）。
`career_base`、`career_tier_1`、`map_03`–`map_05` 等包待对应阶段再建，
清单已在 `services/BundleManifest.ts` 声明完整。

压缩类型选「合并所有 JSON」，目标平台勾 Web Mobile。

### 第 4 步：构建

构建发布 → 平台选 Web Mobile → 构建。

构建后确认：

- [ ] 产物能在浏览器打开并显示启动场景（`#6` 完成判定）
- [ ] 控制台无 `AppRoot 尚未初始化` 报错
- [ ] `build/web-mobile/index.html` 含 `viewport-fit=cover`
      （证明 `build-templates/` 的覆盖生效）
- [ ] 首屏网络请求里没有 `map_01`／`map_02` 的资源（`#17` 验收前置）
