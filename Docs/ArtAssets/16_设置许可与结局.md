## 2. 1.0 结局关键画面

1.0 只表现“镇魔塔外层裂隙暂时封住、玩家身份得到确认、深层威胁仍存在”的阶段结局。不同选择
可以改变评价和旁白，但不制作完整游戏 C13 的三种宏观结局。

评价名、玩家现用名或 Credits 烘焙进图。

## 3. 许可与来源要求

- Credits 背景与图标也必须记录原创/第三方来源和许可，不能因出现在许可页而省略自身来源。
- 第三方字体、音频、美术和工具声明从真实清单生成，不使用示意 Logo 代替法定文字。
- 未取得权利的专有名称、角色、法宝或品牌图形不得进入公开结局图和 Credits。
- 第三方素材不得混入原创目录；源文件、许可快照和哈希按仓库规则保存。

## 4. Figma 前置

- 设置六分组、长文本、控件禁用/错误、恢复默认。
- 导入/导出成功/失败、版本冲突、覆盖确认。
- 许可长列表、单项详情、Credits 暂停/跳过。
- 四张结局关键帧的旁白安全区、跳过按钮、进度和通关后动作。

## 5. 验收

- 设置图标不依赖文字仍可区分，但必须配 Label；开关在灰度下可辨 on/off。
- Credits 在安全区和不同文本长度下不遮挡跳过/暂停操作。
- 四张结局图连续观看时构成完整阶段收束，不误导为彻底击败深层魔魂。
- 选择差异通过可替换文本/局部图层表达，不复制四套整张近似画面。
- 低画质关闭高成本粒子后，封印成功与深层威胁两个关键信息仍清楚。
