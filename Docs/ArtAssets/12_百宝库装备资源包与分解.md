## 4. 装备图标生成边界与分层

### 4.1 内容口径

- 每个已经冻结的 `equipment_id` 至少对应一张 `48×48` 逻辑、`144×144 @3x` 的装备主体图。
- 同一制式蓝图的凡品、精制、上品、珍品和法宝实例共用同一张主体图，品质只由运行时品质框、
  品质名称和纹样表达；不得让 GPT 自动生成五套换色装备。
- 制式装备的地图材质前缀、品质和随机器纹不改变主体图。只有上游明确冻结不同外观模板时才新增图。
- 四槽固定为武器、防具、饰品一、饰品二。饰品一与饰品二共用同一饰品图标池，不为两个槽重画。
- 特定装备、两件乌婆魂器和七件古宝必须各有独立主体图，不得用制式模板换色冒充。
- 古宝可以比制式装备具有更完整的遗物结构和年代感，但仍不把金框、品质底板或大面积品质光烘焙进主体。
- 装备没有等级，不出现 `Lv`、强化 `+n`、星级、随机词条数量、战力、价格或职业文字。
- 非古宝七维来自永久器纹；主体图不得画器纹槽、附着器纹、随机属性或“可拆卸宝石孔”。
- 坊级 17 的洞玄四职业武器组在上游只冻结了类别，尚未冻结四个正式显示名、外形和稳定 ID；
  本文不得擅自给它们命名或把古宝外观降级复用，待装备内容表补齐后再写正式生成提示词。
- 坊级 1 的 `青囊符匣`、`铁木剑胚` 与旧外观模板 `青囊针匣`、`铁木重锋` 是不同美术对象；
  可以按已冻结显示名生成主体，但稳定 ID 补齐前只能使用临时美术文件名，不能覆盖旧图。

### 4.2 运行时合成顺序

```text
最下层：通用方形图像槽或物品列表底板
主体层：本节生成的装备透明 PNG
品质层：QUALITY-FRAME-001 六档独立品质框
信息层：名称、品质文字、1/2 器纹槽、固定效果与七维 Label
状态层：锁定、装备中、任务保护、待处理等独立状态标记
```

装备主体自身不包含上述任何底板、边框、文字或状态。通用槽与品质框的边缘都不得侵入装备主体
安全区；主体放入 `48×48` 槽后应在四周保留至少 `3` 个逻辑像素的呼吸空间。

### 4.3 路径与导出字段

| 类型 | 计划路径 |
|---|---|
| 制式外观模板 | `assets/bundles/common/items/equipment/standard/icon_equipment_<equipment_id>.png` |
| 尚无稳定 ID 的制式蓝图 | `assets/bundles/common/items/equipment/standard/icon_equipment_forge_<subject>.png`，ID 冻结后重命名并保留映射记录 |
| 特定装备 | `assets/bundles/common/items/equipment/specific/icon_equipment_<equipment_id>.png` |

| 古宝 | `assets/bundles/common/items/equipment/ancient/icon_equipment_<equipment_id>.png` |

```text

source_license / logical_size / export_size / figma_node / cocos_target / status
```

`equipment_id` 尚未冻结时必须明确填写 `TBD-upstream`，不能由美术文件名反推或新造业务 ID。

## 7. 生成顺序与合成验收

### 7.1 推荐生成顺序

1. 先生成 `乌钢降魔杵`、`聚火灵珠`、`镇幽符匣`、`铁木重锋` 四张，确认四职业武器不会只靠颜色区分。
2. 再生成 `行衣`、`法衣`、`玄甲`，确认它们像可穿戴装备且没有完整人物或西式板甲倾向。
3. 生成 `明心镜`、`流云扣`、`回春佩`，确认饰品不会变成技能图标、品质徽章或资源币。
4. 锁定通过的小样作为图片 3 与图片 5，批量生成其余制式外观模板。
5. 生成上品、珍品特定装备，再生成魂器与古宝；每张仍沿用同一共用提示词，不临时追加品质背景。
6. 最后把同一制式装备主体分别叠加六档品质框，完成品质合成、灰度和小尺寸验收。

### 7.2 单图验收

- PNG 必须为真实 RGBA；主体外 Alpha 为 `0`，没有绿色键色、纯色底、棋盘格、投影板、半透明雾边或绿色残边。
- `144×144` 原图和缩小到 `48×48` 的结果都只包含一件完整装备，尖端、衣摆、绳结与环体不被裁切。
- 武器四体系只看灰度剪影也能区分；防具像甲衣而非人物；饰品像可佩戴物而非品质徽章。
- 图中没有品质框、通用槽、卡片背景、器纹槽、镶嵌孔、文字、数字、等级、强化、星级或状态角标。
- 特定装备、魂器和古宝与同类制式装备轮廓不同，不能只改颜色、加光或加粒子。
- 同系列材质受光、硬边和像素密度一致，不能一张像像素画、一张像3D渲染、一张像厚涂插画。

### 7.3 运行时合成验收

- 同一制式主体叠加凡品至法宝品质框时不换图、不变色、不越过 `40×40` 内容安全区。
- 六品质在灰度下仍由独立框纹样与品质文字区分；装备主体不承担品质识别。
- 叠加 1/2 器纹槽、锁定、装备中、任务保护和待处理标记后，装备关键轮廓没有被遮住。
- 四件职业武器、三类防具和至少五类饰品放进百宝库同屏列表时，首要类别在 `48×48` 下仍可辨认。
- 古宝详情不显示器纹操作；魂器固定器纹由信息层显示，不把器纹画回主体。
- `青囊符匣`、`铁木剑胚` 可先按临时美术文件名进入 Review，但稳定 ID 补齐前不得进入 Approved；
  洞玄四职业武器组在显示名、外形和稳定 ID 冻结前不得开始正式生成。

- 20 个资源包在 48×48 下同时可辨资源种类与包装档位，且不会被误认成装备品质。

- 分解表现只展示材料回收，不展示完整铁胚、完整器纹或锻纹尘。
- 所有任务/唯一物的透明边缘、文件名、来源和许可记录完整。
