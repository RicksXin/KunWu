# 《昆吾禁地》1.0 灵圃生产与储量页面素材

版本：1.0-art-brief.1  
日期：2026-08-06  
状态：正式页面素材分册；部分通用资产已有，页面状态稿待 Approved  
对应 PRD：[灵圃生产与储量](../PRD/03_灵圃与交易行_PRD.md#page-04)

## 1. 正式范围

本分册只维护 1.0 灵圃页面。页面按剧情配置逐步开放灵粮、灵木、玄铁、灵晶、庚精五种生产
资源；未开放的资源行不显示，已开放资源必须覆盖生产、满仓、储量升级和异常状态。

页面包含：

- 五种资源岗位的库存/上限、净产量、岗位人数与增减操作；
- 杂役总数、已分配/空闲人数；
- 生产周期进度和最近结算反馈；
- 杂役招募、储量升级与离线结算模态；
- 满仓、时间回拨、数据缺失、保存失败等正式状态。

成本、人数、周期和产量均由运行时 Label/配置表达，不进入图片。

## 2. 页面结构

```text
营地大厅原位置（变暗且不可穿透）
└─ 灵圃主面板
   ├─ 标题与杂役摘要
   ├─ 已解锁资源列表（最多五行）
   ├─ 生产周期与最近结算
   └─ 杂役招募 / 关闭
      ├─ 杂役招募确认
      ├─ 单资源储量升级确认
      └─ 离线结算结果
```

主面板与二次确认使用同一通用九宫格；主面板可叠加顶部/底部装饰。不得为不同资源或确认类型
各画一套近似边框。

## 3. 正式状态稿要求

Figma 必须先交付并通过：

- 三行已解锁、五行全部解锁及单行新解锁；
- `normal/selected/disabled/locked/loading/error` 资源行；
- 无空闲杂役、单资源满仓、全部满仓、储量满级；
- 杂役招募可执行/灵粮不足/提交中/失败；
- 储量升级可执行/灵木不足/满级/配置缺失；
- 离线结算正常/部分溢出/全部溢出/时间回拨；
- 长库存数字、长产量、375×817 安全区和系统返回层级。

列表优先使用当前唯一 Approved 的 `Panel Item V2`；其他组件仍需独立评审。

## 5. 视觉方向

- 材质沿用深木、黑玉、旧青铜与少量暖色灵光，避免银色欧式浮雕、哥特尖刺和广告经营游戏风格。
- 五种资源图标必须与营地 HUD、百宝库和交易行复用同一文件。
- 普通项与选中项通过完整底板切换；锁定、满仓和错误由图标、文字、Tint 组合，不制作整行截图。
- 面板背景、装饰和按钮不包含标题、资源名、数量、价格、倒计时、红点或水印。
- 离线结算表现是资源入库摘要，不使用双倍收益宝箱、广告或领取奖励动画。

## 6. 交付输入

正式出图前必须提供：

1. 三行和五行两张 Approved 页面稿；
2. 招募、储量升级、离线结算三类模态状态稿；
3. 当前营地背景与已生成灵圃资产合成截图；
4. Panel Item V2、按钮、九宫格切片和 Cocos 节点映射；
5. 每张新图的逻辑尺寸、@3x 尺寸、九宫格边距与透明规则。

灰盒可以用来确定信息密度和触控区，但不能作为正式视觉事实源。

## 7. 验收

- 三行和五行状态均无重叠；未解锁资源不以灰色占位行提前出现。
- 满仓、无杂役、锁定和错误不只依赖颜色，且不遮挡库存/上限。
- 主面板与二次确认复用同一九宫格体系，按钮层级一致。
- 五类资源图标跨 HUD、灵圃、百宝库和交易行完全一致。
- 生产进度在 0%/1%/99%/100% 下无断边，nearest 下无模糊。
- 所有 PNG 无动态文字与数字，透明边缘干净，Figma 到 Cocos 映射完整。

## 8. 不制作

广告翻倍、离线战斗收益、货币礼包、手动领取宝箱、每种资源独立面板、未解锁资源占位行和
任何阶段编号专属视觉。
