> 本 PRD 只把策划中的品质、随机七维、特定装备、掉落、打造、重铸和商店规则转换为
> 页面、状态、命令与验收要求。品质倍率、掉率、特装效果和材料成本只在装备策划分册维护。

## 1. 模块目标与范围

装备应形成“低概率获得—比较随机七维—留下或分解—重复打造/重铸—追求任务特装”的循环，
不能再按地图固定发整套，也不能因未随机到指定装备阻断主线。

0.1 范围：

- 武器、防具、饰品一、饰品二四槽。
- 粗制、精制、上品、珍品、古宝五档品质，对应白、绿、蓝、紫、金。
- 制式装备模板与随机实例。
- 少量拥有固定效果的命名特定装备。
- 装备等级、随机七维、稳定随机种子和来源记录。
- 重复打造、整件重铸、新旧结果二选一、分解与锻纹尘。
- 仓库、待处理区、筛选、锁定、对比、交易行和阵亡结算。

0.1 不开放第五槽、装备强化等级、强化失败、装备耐久、单词条锁定、指定属性重铸、
逐条洗练、玩家交易或付费装备。

## 2. 装备概念

### 2.1 制式装备

- 由模板、装备等级、品质、随机七维和外观引用组成。
- 没有固定特殊效果，也不生成七维以外的随机词条。
- 同一模板可以存在任意多个不同品质、等级和七维的实例。
- 模板只控制槽位、职业资格、外观和允许七维池，不提供职业属性倾向。
- 旧普通装备定义 ID 转为制式外观模板 ID 并保持稳定，不再携带旧固定属性、效果或唯一来源。

### 2.2 特定装备

- 额外保存稳定的特定装备定义 ID、固定名称、固定效果、固定品质和任务来源。
- 七维仍按对应品质与装备等级随机。
- 可以由上游策划声明七维池覆盖，从而让少量特定武器或饰品出现护体、定力。
- 特定效果不进入随机池，重铸不能改变。
- 上游保留的特定装备沿用既有装备 ID，不因系统重写创建新的逻辑 ID。

## 3. 槽位、职业资格与七维池

每名修士启用：

```text
武器
防具
饰品一
饰品二
```

- 武器按初始职业体系限制；筑基分支和结丹称号不改变武器大类。
- 防具和饰品全职业通用。
- 同一修士不能在两个饰品位装备相同定义 ID；同一实例不能被多人共用。
- 正式项目旧五槽 Schema 可以保留，但 0.1 页面、数据和验收不得显示或要求第五槽。

随机属性键只能来自：

```text
strength magic technique speed constitution armor resistance
```

生成器必须遵守上游允许池：

- 制式武器与饰品禁止 `armor`、`resistance`。
- 玄甲禁止 `resistance`。
- 法衣禁止 `armor`。
- 行衣允许全部七维，但 `armor`与`resistance`使用上游削弱系数。
- 特定装备只有显式配置 `statPoolOverride` 时才能突破槽位限制。
- 除硬限制外不得读取修士、职业分支、当前配装或队伍缺口改变属性权重。

## 4. 品质、等级与实例数据

品质顺序：

```text
粗制(白) → 精制(绿) → 上品(蓝) → 珍品(紫) → 古宝(金)
```

装备品质与灵根资质使用不同名称、边框、轮廓和文本，不允许只靠颜色区分。

装备定义至少拆为两类，不能把特装效果直接塞进普通模板：

```text
EquipmentTemplateDefinition
  templateId
  slot
  allowedCareers[]
  defaultStatPool[]
  appearanceRef

SpecialEquipmentDefinition
  specialEquipmentId
  templateId
  fixedQuality
  equipmentLevel
  fixedEffectIds[]
  statPoolOverride?
  sourceRuleId
```

- `defaultStatPool`遵守上游槽位限制，不能携带职业推荐权重。
- `statPoolOverride`只存在于上游明确列出的特定装备定义；未配置时继承模板池。
- 26 个旧普通装备 ID 与特装稳定 ID 的归属读取装备策划分册 §3.4、§5，同一 ID 不能同时注册为
  制式模板与特定装备。

每个装备实例至少保存：

```text
instanceId
templateId
specialEquipmentId?
slot
allowedCareers[]
equipmentLevel
quality
randomSeed
stats: Partial<Record<SevenStatKey, number>>
fixedEffectIds[]
source
ownerHeroId?
equippedSlot?
locked
uniqueGroup?
pendingReforge?
```

其中：

- `stats`只允许非零七维，不保存生命、命中、暴击、治疗等伪词条。
- `fixedEffectIds`只来自特定装备定义，制式装备必须为空。
- `randomSeed`和最终`stats`同时保存；正常读取以已保存结果为准，不重新生成。
- `pendingReforge`保存候选种子、候选七维、材料扣除事务 ID 和创建时间，直到玩家确认。

## 5. 装备生成服务

所有掉落、宝箱、商店、打造和重铸统一调用领域层装备生成器：

```text
GenerateEquipment(template, equipmentLevel, qualityRule, source, seed)
```

生成顺序固定为：

1. 解析模板和允许七维池。
2. 依据来源与地图解析装备等级和品质。
3. 依据品质确定互不重复的属性项数。
4. 从允许池等权抽取属性。
5. 计算总预算并随机分配。
6. 应用行衣削弱或特装覆盖。
7. 创建稳定实例并保存最终结果。

同一输入和种子必须得到完全相同的品质与七维。表现层、奖励弹窗和仓库页面不得自行随机。

## 6. 获取与掉落

- 普通敌人主要掉材料，只有低概率产生完整制式装备。
- 精英、Boss和高危宝箱提高完整装备机会，但不指定职业、部位或七维。
- 地图 1、2 只能生成白、绿、蓝装。
- 地图 3、4 以蓝装为主，小概率生成无特殊效果的紫装。
- 普通敌人、精英、Boss、宝箱、商店和制式配方都不能生成金装。
- 特定紫装和金装只由对应任务、事件、配方与高阶材料链解锁。
- Boss 首杀奖励使用幂等 claim ID；奖励实例首次结算后固定，刷新不能重抽。

主线只检查境界、任务物和战斗机制，不检查指定装备 ID、指定品质数量或固定套装。

## 7. 仓库与待处理区

- 支持按槽位、装备等级、品质、职业资格、七维字段、特定效果、来源和锁定状态筛选或排序。
- 默认排序为品质降序、装备等级降序、七维总和降序，不替玩家判断职业适配。
- 已装备物品单独标记，批量操作不得静默卸下。
- 临时战利品与营地仓库分开保存，同一实例不能同时显示在两处。
- 仓库满时，掉落、打造、任务奖励和商店购买进入待处理区，不得覆盖旧实例。
- 待处理区领取成功前保持原实例和幂等记录；整理仓库后可以继续领取。
- 锁定、装备、卸下、移动和领取均原子保存，失败时恢复操作前状态。

## 8. 装备对比

详情页必须显示：

- 名称、制式/特定类型、装备等级、品质、槽位、职业资格和来源。
- 每一项随机七维及七维总和。
- 特定装备的固定效果；制式装备明确显示“无特殊效果”。
- 当前装备和候选装备的七维逐项差异。
- 换装后的最终七维、战力和受固定效果影响的技能说明。

战力只计算随机七维之和；固定效果不进入战力。页面不得因为金色边框自动标记“推荐替换”，
但必须提示同等级古宝的七维预算高于珍品。

## 9. 炼器坊与重复打造

炼器坊提供：

- 按制式模板与等级档重复打造。
- 按已解锁配方重复打造特定装备。
- 整件重铸。
- 装备分解。
- 探索工具和上游允许的材料制作。

打造流程：

1. 校验配方、等级档、材料、灵石和产出容量。
2. 展示可能品质、允许七维池、属性项数范围和固定效果，不预先显示最终七维。
3. 确认后一次性扣除材料，并用服务端/领域层生成的新种子创建实例。
4. 保存成功后展示最终品质和七维；保存失败不得留下扣款或幽灵实例。

- 打造本身固定成功，不加入失败、降级和装备破坏。
- 制式配方的品质上限与概率读取上游地图档规则。
- 特定装备固定品质、等级与效果，只随机七维。
- 同名特定装备可以存在多个实例；饰品仍受同修士同定义 ID 限制。

## 10. 整件重铸

重铸不能改变模板、特装 ID、装备等级、品质、槽位、资格、外观和固定效果，只重新生成全部七维。

流程：

1. 选择位于营地仓库、未锁定且没有待确认候选的装备。
2. 展示材料、允许七维池、属性项数范围及“无法锁词条”的说明。
3. 确认后原子扣除材料并保存一组新七维候选。
4. 新旧七维同屏逐项对比。
5. 玩家选择“保留原属性”或“采用新属性”。
6. 确认后清除候选并保存；材料无论选择哪组都不退还。

异常规则：

- 候选产生后关闭页面、刷新或重启，必须继续显示同一候选。
- 未解决候选时不能再次重铸、出售、分解、装备或转移该实例。
- 确认请求重复提交时只允许第一次生效。
- 0.1 不提供锁定部分属性、只洗数值、指定七维或撤销已经确认的重铸。

## 11. 分解与锻纹尘

- 分解产出锻纹尘和少量普通打造材料，数量按品质读取上游表。
- 特定效果、任务核心和古宝任务进度不返还。
- 已装备、锁定、任务保护、待处理区未领取和存在重铸候选的装备不能分解。
- 批量分解前按品质统计数量、锻纹尘和材料结果；珍品与古宝必须二次确认。
- 分解与材料发放在同一事务中完成，失败不得销毁装备或重复产出。

## 12. 交易行

- 6 个普通商品栏，每 2 小时刷新；商品实例在刷新事务中生成并固定七维。
- 地图 1、2 只刷新白、绿、蓝制式装备。
- 地图 3 后可以小概率刷新无特殊效果的制式珍品。
- 古宝、特定装备、任务核心和突破材料不进入普通商品栏。
- 剧情保底栏只保证材料、探索工具和防卡死物品，不保证指定七维或指定职业武器。
- 支持灵石购买、出售和回购；回购保存原装备实例及七维，不重新生成。
- 刷新倒计时、商品实例、已购状态和回购队列进入存档；刷新网页不能重刷词条。

## 13. 入山、归营与阵亡

装备随出发修士进入入山状态，不占灵粮、开山镐和探灵镜三类装载行。

正常归营：临时装备实例进入仓库；仓库满时进入待处理区。

全队阵亡：

- 仅处理本次入山携带物、临时战利品和出发修士穿戴装备。
- 非保护装备按稳定实例 ID 排序后保留前 `floor(实例数 / 2)`。
- 任务核心、特装配方、突破材料和未领取奖励不参与损失。
- 装备被保留时必须保留原品质、等级、种子、七维和固定效果，不重新生成。

## 15. 验收

- 制式装备只生成七维，`fixedEffectIds`为空；任何来源都不能生成生命、命中、暴击、治疗等随机词条。
- 制式武器/饰品、玄甲、法衣和行衣分别遵守上游允许池与削弱规则。
- 除硬限制外，生成器不读取职业、分支、队员或已穿装备改变七维概率。
- 地图 1、2 不生成珍品；普通来源不生成古宝。
- 同等级同槽位古宝最低七维预算高于珍品最高预算。
- 特装固定效果跨重复打造和重铸保持不变，七维按对应规则重新生成。
- 重铸候选跨刷新不变；新旧选择只生效一次，材料不重复扣除或退还。
- Boss 首杀、商店商品、宝箱和打造实例跨刷新保持相同品质与七维。
- 仓库满时所有实例进入待处理区；整理后领取不重复、不丢失。
- 阵亡保留下来的实例不改变等级、品质、七维和特效。
- 不获得指定紫装或古宝仍可全员结丹并完成主线。

## 16. 当前不做

- 第五装备槽。
- 单词条锁定、指定属性重铸、逐条洗练和装备强化。
- 强化失败、装备耐久、玩家交易和付费装备。
- 普通来源随机生成特殊效果或古宝。
