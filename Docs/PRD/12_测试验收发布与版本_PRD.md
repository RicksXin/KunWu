# 《昆吾禁地》PRD 12：测试、验收、发布与版本

版本：0.1  
模块：QA  
负责人：QA、产品、技术负责人

## 1. 模块目标

建立每阶段可执行的验收门槛，防止在核心问题未解决时继续增加地图、职业和资产。

## 2. 问题等级

| 等级 | 定义 | 示例 | 处理 |
|---|---|---|---|
| Sev-1 | 无法进入、继续或坏档 | 启动失败、存档损坏 | 阻断 |
| Sev-2 | 主线或核心系统错误 | 出口失效、Boss不结算 | 阻断 |
| Sev-3 | 局部功能/表现异常 | 某技能特效缺失 | 评估 |
| Sev-4 | 轻微体验问题 | 错字、像素抖动 | 后续 |

## 3. 测试层级

### 单元

- 生产。
- 招募概率。
- 七维公式。
- 嘲讽目标。
- 负重和灵粮。
- 属性检定。
- 存档迁移。

### 仿真

- 10万次招贤刷新。
- 1万场自动战斗。
- 30天离线生产。
- 随机移动路径和补给边界。

### 内容校验

- 地图可达。
- 固定对象ID。
- 出口条件。
- 任务引用。
- 技能和职业引用。
- 掉落表。

### 端到端

- 新档到Demo结束。
- 新档到五图结局。
- 战败、逃生、还魂。
- 转职、洗髓、解雇。
- 导出、清理、导入。

## 4. 阶段门禁

### P0

- 浏览器启动、地图、存档、刷新恢复。
- 无Sev-1/2。

### P1

- 15–20分钟核心闭环。
- 测试者理解灵粮双用途。
- 无死状态。

### P2

- 30–45分钟。
- 80%测试者完成地图1。
- 70%理解转职差异。
- 首包<25MB。
- 桌面60FPS，移动≥30FPS。

### P3A

- 地图2三类Boss可用。
- 条件出口信息清晰。
- 至少三种队伍通过主线Boss。

### P3B

- 12一转均有有效队伍。
- 地图2→4可实际通行。
- 连续4小时无泄漏和坏档。

### P3C

- 新档可通关五图。
- 13–15Boss状态正确。
- 8–12小时内容完整。

### P4

- Sev-1/2为0。
- 20个历史存档迁移。
- 五图无不可达POI和出口死锁。
- 连续挂机8小时无泄漏。

## 5. 浏览器测试

- Windows Chrome/Edge/Firefox。
- macOS Chrome/Safari。
- Android Chrome。
- iOS Safari。
- 普通标签页。
- PWA。
- 浏览器后台恢复。
- 断网/弱网。
- WebGL上下文丢失。

## 6. 平衡验收

- 灵粮归零后存在恢复途径。
- 以杂灵根、伪灵根修士为主的合理队伍可完成主线。
- 主线Boss不要求唯一职业。
- 野外Boss奖励匹配难度。
- 招贤手动刷新不是唯一成长方式。
- 十二一转选择率无非设计极端。
- 装备至少一半核心成长为确定来源。

## 7. 发布清单

- 版本号和更新说明。
- Web构建及Hash资源。
- HTTPS和MIME。
- 缓存策略。
- 数据Schema。
- 存档迁移。
- Credits和许可证。
- 隐私说明。
- 原创名称开关。
- 错误回滚方案。

## 8. IP和素材审核

- 对外默认原创名称。
- 不含原著角色姓名、造型、对白和法宝临摹。
- 所有第三方素材有许可记录。
- OFL字体附许可证。
- Demo占位素材和商业替换素材有明确标记。

## 9. 发布策略

```text
Internal
→ Friends & Family
→ Closed Demo
→ Public Demo
→ Alpha
→ Beta
→ Release Candidate
→ Web Release
```

每一阶段单独存档命名空间，公开版升级必须经过迁移。

## 10. 回滚

- 保留上一个稳定Web版本。
- 远程Bundle保留上一版本。
- HTML与资源版本不一致时拒绝进入并刷新。
- 新Schema发布前验证降级不可行时提供存档导出。
- 严重问题可切换维护页。

## 11. 数据指标

- 新手入山率。
- 地图1完成率。
- 首次转职率。
- 各职业选择率。
- Boss尝试和胜率。
- 主动返回/战败返回。
- 灵粮耗尽率。
- 属性检定成功率。
- 存档错误率。

## 12. 验收责任

| 类型 | 最终签字 |
|---|---|
| 产品范围 | 产品负责人 |
| 数值和规则 | 主策/系统策划 |
| 技术性能 | 技术负责人 |
| 资产质量 | 美术负责人 |
| IP和许可 | 项目负责人/法务 |
| Release Candidate | 产品+技术+QA |

## 13. 不做

- 带Sev-1/2上线。
- 未迁移存档直接覆盖。
- 未核对许可的资产发布。
- 用线上玩家替代基本QA。
- Beta阶段继续增加大型系统。
