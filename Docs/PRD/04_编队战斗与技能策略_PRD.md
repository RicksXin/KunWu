## 1. 模块目标

通过四人队伍、固定三技能和自动策略形成低操作、高准备深度的半即时回合战斗。玩家的主要决策发生在职业组合、装备、技能规则和手动技能时机，而不是走位。

## 2. 编队规则

- 每队最多 4 人，至少 1 名存活修士才可发起入山；空位不产生战术含义。
- 无前排、后排、距离和站位承伤。
- 死亡角色不能上阵。
- 同一角色不能出现在多个活动队伍。
- 新档初始只开放第 1 队；第 2 队、第 3 队按顺序消耗灵石解锁，费用从外置配置读取。
- 三支队伍各自保存上阵修士与入山装载方案。切换队伍时恢复该队保存的装载数量，并按
  当前上阵修士重新计算负重，不共用另一队的临时编辑值。
- 队伍最大负重根据当前上阵修士的最终属性计算，包含装备与已生效的永久加成；基础属性、
  未生效预览值和其他队伍属性不得重复计入。
- 打开入山整备面板时，灵粮默认装载为当前库存与剩余负重共同允许的最大整数数量；
  切换队伍或编辑成员后立即按新队伍负重重算。玩家仍可手动减少灵粮。
- 解锁队伍与扣除灵石属于同一结果；保存失败时必须同时回滚解锁状态和灵石扣款。
- 普通编队或装载修改保存失败时保留本次内存状态，并明确提示“保存失败，请重试”，
  不得静默回退或让玩家误以为已经持久化。
- 编队不是独立页面。点击营地传送阵唤起入山整备面板，点击其中“编辑队伍”后，
  再在该面板上方打开选人面板。
- 入山整备面板顶部固定显示 4 个横向槽位。空位显示人物黑影与“人选未定”；已上阵
  槽位以对应修士静态立绘为背景，并显示灵息、姓名、职业·等级、境界和灵根资质。
- 选人面板列出玩家拥有的全部修士，每行显示头像、境界、灵根资质、姓名、职业、等级、灵息、
  战力和“选择/取消”按钮；选中项必须有非颜色唯一的选中态。战力口径以 PRD-03 §8 为准。
- 队伍详情显示负重；治疗、嘲讽、伤害类型覆盖与七维总览留在后续角色/策略详情，
  不挤入本次竖屏入山面板。

## 3. 战斗时间轴

- 每个单位有行动计时。
- 遁速降低行动间隔。
- 技能拥有自身基础间隔和冷却。
- 控制状态可暂停或延迟行动。
- 战斗只提供正常速度 `1×`，不显示、不预留 `2×` 倍速入口。
- 卡顿追帧时可以缩短或跳过部分表现动画，但玩家不可主动切换战斗倍速，结算顺序必须确定。

```text
行动间隔 = clamp(技能基础间隔 × 100 / (100 + 遁速), 下限, 上限)
```

## 4. 技能结构

每个职业节点固定三个主动技能。技能定义：

- 目标类型。
- 属性来源。
- 基础倍率。
- 冷却或行动间隔。
- 命中和暴击规则。
- 状态效果。
- 是否受嘲讽。
- AI 使用条件。
- 动画、特效和音效 ID。

目标类型：

```text
SELF
ALLY_SINGLE
ALLY_LOWEST_HP
ALLY_ALL
ENEMY_SINGLE
ENEMY_LOWEST_HP
ENEMY_HIGHEST_STAT
ENEMY_RANDOM_MULTI
ENEMY_ALL
SUMMON
```

## 5. 七维结算

```text
生命上限 = 职业基础生命 + 肉身 × 生命系数 + 装备生命
物理技能 = 力道 × 力道倍率 + 神识 × 副倍率
法术技能 = 法力 × 法力倍率 + 神识 × 副倍率
物理减伤率 = 护体 / (护体 + 等级常数)
法术减伤率 = 定力 / (定力 + 等级常数)
```

技能必须显式声明属性来源，不能按职业名称推断。

## 6. 目标与嘲讽

默认：

- 敌方单体技能可选择任意存活队员。
- 选择逻辑可按随机、最低生命、最高威胁或脚本规则。

嘲讽：

- 嘲讽生效时，可嘲讽单体技能强制选择嘲讽者。
- 群体、随机多段和 `ignore_taunt` 不受影响。
- 多个嘲讽者先比较嘲讽强度，再按敌人规则决定。
- 嘲讽者死亡或效果结束后立即恢复正常选目标。
- UI显示嘲讽印记和敌方锁定。

## 7. 自动技能策略

玩家可对三个技能分别设置：

- 启用/禁用。
- 目标优先级。
- 自身生命阈值。
- 友方最低生命阈值。
- 敌人数量阈值。
- 目标是否有指定状态。

示例：

```text
若自身没有嘲讽 → 狮吼震心
若友方最低生命 < 45% → 六甲增元箓
若敌方存在高威胁单体且无符傀 → 力士符傀
若敌方数量 ≥ 3 → 横剑断山
否则 → 单体技能
```

规则从上到下判断。若无技能满足条件，使用默认攻击或等待。

## 8. 状态效果

增益：

- 护盾。
- 加速。
- 聚灵。
- 反击。
- 净化。
- 伤害提升。

减益：

- 破甲。
- 降抗。
- 中毒。
- 灼烧。
- 迟缓。
- 封灵。

控制：

- 眩晕。
- 缠绕。
- 沉默。

特殊：

- 污染。
- 尸煞印。
- 空间错位。

同类硬控连续命中按 100%、60%、30% 衰减；Boss单独配置免疫和抗性。

## 9. 反击、反伤与召唤物

- 反击由“受击后”事件触发。
- 反击不能再次触发反击，防止无限链。
- 群体攻击可以对多个反击者分别触发，但有单次技能上限。
- 反击目标默认为伤害来源。
- 金轮反照属于按实际承伤比例计算的反伤，不创建额外主动攻击。
- 金轮反照必须在护盾、减伤和生命扣除后读取实际承伤；DoT和环境伤害不触发，直接群攻可触发。
- 反伤不能暴击、吸血、触发受击恢复或再次触发反伤。
- 力士符傀是独立可选目标，拥有本体生命、临时生命、嘲讽强度和存在时间。
- 符傀初次完整召唤获得等于最大生命100%的临时生命，伤害先扣临时生命，再扣本体生命。
- 符傀到期时连同剩余临时生命消失；存活期间重复释放只再次嘲讽，不恢复本体生命，
  也不补满或增加临时生命。
- 符傀死亡、到期和被替换都必须产生明确 `CombatEvent`，表现层不得自行决定其消失时机。

## 10. 胜负与逃生

胜利：

- 所有必须击败的敌人死亡。
- 结算魂晶、灵石、掉落和任务。

失败：

- 本次入山队伍中的所有修士均已死亡；队伍不满四人时按实际出发成员判断。
- 单个修士死亡，或仍有存活修士只是暂时无法行动，均不触发全队阵亡结算。
- 携带物与临时战利品按 PRD-05 §6.2 的野外全队阵亡规则处理。
- 死亡修士进入还魂殿。

逃生：

- 使用逃生符或允许逃生的技能。
- 保留 50% 临时战利品，比例由数据配置。
- Boss 特殊阶段可禁止逃生，但必须提前提示。

## 11. 功能需求

### 11.1 战斗页面表现与操作

- 页面使用 `375×817` 竖屏基准，底部至少保留 `54px` 安全区。
- 普通敌群在中上方并排；首领居中，召唤单位可在首领周围使用三角阵或环绕阵。阵型只
  影响视觉位置，不产生前后排、距离或承伤规则。
- 我方最多四名修士在底部安全区上方并排。
- 敌我双方都显示动态战斗立绘。敌方单位信息从上到下为“名称 → 族类图标 + 生命条 →
  行动条 → 状态图标”；我方使用相同顺序。
- 名称、族类图标、生命条、行动条和状态图标全部覆盖在对应动态立绘底部，不在立绘外
  另占纵向信息区。
- 敌方行动条就绪后按敌方行动策略自动施法；我方行动条就绪后显示该修士当前职业的
  三个主动技能供玩家选择。
- 多名手动修士先后就绪时进入严格的先到先出选择队列。当前修士完成技能选择与释放前，
  后续就绪修士不得替换当前技能面板；等待队列中的修士行动计时固定为 `0`，行动条保持
  就绪状态，不再推进下一轮行动，也不因等待超时自动施法。
- 点击我方修士名称切换该修士的自动施法状态；开启后按 §7 的技能策略选择技能，不能在
  同一次行动中与手动选择重复施法。
- 技能释放时播放施术动作和技能特效；受击、治疗和阵亡分别播放人物反馈、伤害/治疗
  数字及对应特效。表现层只消费 `CombatEvent`，不得反向决定伤害与胜负。
- 达到敌方总生命阈值或剧情配置条件后，右上角才显示“逃生”；点击后按 §10 结算。
  未满足条件时不显示禁用占位。
- 胜利成立时先原子保存敌人完成态和修士战后状态，再打开战利品二级弹窗；不得等到关闭
  弹窗才记录胜利，也不得直接把掉落写入本次入山所得。弹窗上半区显示当前野外背包，
  下半区显示本场待拾取战利品，底部固定为“全部拾取”和“离开”。
- “全部拾取”按整批战利品总重量校验当前队伍负重；拾取后超过上限时提示负重不足并
  保留弹窗，不允许部分静默拾取。“离开”放弃本场仍未拾取的战利品并返回地图。
- 战利品弹窗中点击当前野外背包物品，每次丢弃该物品 `1` 个并立即释放对应负重；丢弃
  必须保存成功后才刷新数量，失败时恢复原数量并提示。
- 战利品弹窗打开后刷新页面或关闭游戏，按“离开”处理未拾取物；已经保存的敌人完成态
  和修士战后状态不得回滚，因此同一次入山内重新进入地图时已击败敌人不会刷新。
  结束本次入山后再次启程，普通野外敌人必须刷新。

## 12. 验收

- 同一战斗在相同数据和随机种子下结果可复现。
- 动画被跳过、打断或降级播放时不改变结算。
- 嘲讽前后目标行为符合规则。
- 反击不会无限递归。
- 每个主线 Boss 至少有两种有效职业解法。
- 自动战斗 20 分钟无卡死、无对象泄漏。
- 手动技能和自动策略不会在同一行动重复施放。
- 三支队伍分别恢复自己的成员和装载方案，切换队伍后按最终属性重新计算负重。
- 只有本次入山队伍所有修士均死亡才触发全队阵亡，单人死亡和暂时无法行动不误触发。

## 13. 不做

- 手动走位。
- 前后排。
- PVP。
- 多人联机。
- 连携 QTE。
- 实时物理碰撞战斗。
