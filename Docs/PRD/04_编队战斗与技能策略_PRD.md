# 《昆吾禁地》PRD 04：编队、战斗与技能策略

版本：0.2  
日期：2026-08-01  
模块：COMBAT  
负责人：战斗策划、客户端、动画特效

## 1. 模块目标

通过四人队伍、固定三技能和自动策略形成低操作、高准备深度的半即时回合战斗。玩家的主要决策发生在职业组合、装备、技能规则和手动技能时机，而不是走位。

## 2. 编队规则

- 每队最多 4 人，至少 1 名存活修士才可发起入山；空位不产生战术含义。
- 无前排、后排、距离和站位承伤。
- 死亡角色不能上阵。
- 同一角色不能出现在多个活动队伍。
- 新档初始只开放第 1 队；第 2 队、第 3 队按顺序消耗灵石解锁，费用从外置配置读取。
- 编队不是独立页面。点击营地传送阵唤起入山整备面板，点击其中“编辑队伍”后，
  再在该面板上方打开选人面板。
- 入山整备面板顶部固定显示 4 个横向槽位。空位显示人物黑影与“人选未定”；已上阵
  槽位以对应修士静态立绘为背景，并显示灵息、姓名、职业·等级、境界和灵根资质。
- 选人面板列出玩家拥有的全部修士，每行显示头像、境界、灵根资质、姓名、职业、等级、灵息、
  评分和“选择/取消”按钮；选中项必须有非颜色唯一的选中态。
- 队伍详情显示负重；治疗、嘲讽、伤害类型覆盖与七维总览留在后续角色/策略详情，
  不挤入本次竖屏入山面板。

## 3. 战斗时间轴

- 每个单位有行动计时。
- 遁速降低行动间隔。
- 技能拥有自身基础间隔和冷却。
- 控制状态可暂停或延迟行动。
- 普通速度 1×；P3A后评估 2×。
- UI表现可以加速，但结算顺序必须确定。

```text
行动间隔 = clamp(技能基础间隔 × 100 / (100 + 遁速), 下限, 上限)
```

## 4. 技能结构

每个职业节点固定三个主动技能。技能定义：

- 目标类型。
- 属性来源。
- 基础倍率。
- 冷却或行动间隔。
- 命中和暴击规则。
- 状态效果。
- 是否受嘲讽。
- AI 使用条件。
- 动画、特效和音效 ID。

目标类型：

```text
SELF
ALLY_SINGLE
ALLY_LOWEST_HP
ALLY_ALL
ENEMY_SINGLE
ENEMY_LOWEST_HP
ENEMY_HIGHEST_STAT
ENEMY_RANDOM_MULTI
ENEMY_ALL
```

## 5. 七维结算

```text
生命上限 = 职业基础生命 + 肉身 × 生命系数 + 装备生命
物理技能 = 力道 × 力道倍率 + 神识 × 副倍率
法术技能 = 法力 × 法力倍率 + 神识 × 副倍率
物理减伤率 = 护体 / (护体 + 等级常数)
法术减伤率 = 定力 / (定力 + 等级常数)
```

技能必须显式声明属性来源，不能按职业名称推断。

## 6. 目标与嘲讽

默认：

- 敌方单体技能可选择任意存活队员。
- 选择逻辑可按随机、最低生命、最高威胁或脚本规则。

嘲讽：

- 嘲讽生效时，可嘲讽单体技能强制选择嘲讽者。
- 群体、随机多段和 `ignore_taunt` 不受影响。
- 多个嘲讽者先比较嘲讽强度，再按敌人规则决定。
- 嘲讽者死亡或效果结束后立即恢复正常选目标。
- UI显示嘲讽印记和敌方锁定。

## 7. 自动技能策略

玩家可对三个技能分别设置：

- 启用/禁用。
- 目标优先级。
- 自身生命阈值。
- 友方最低生命阈值。
- 敌人数量阈值。
- 目标是否有指定状态。

示例：

```text
若友方最低生命 < 35% → 回春术
若自身无护盾 → 凝霜护
若敌方数量 ≥ 3 → 剑气横扫
否则 → 单体技能
```

规则从上到下判断。若无技能满足条件，使用默认攻击或等待。

## 8. 状态效果

增益：

- 护盾。
- 加速。
- 聚灵。
- 反击。
- 净化。
- 伤害提升。

减益：

- 破甲。
- 降抗。
- 中毒。
- 灼烧。
- 迟缓。
- 封灵。

控制：

- 眩晕。
- 缠绕。
- 沉默。

特殊：

- 污染。
- 尸煞印。
- 空间错位。

同类硬控连续命中按 100%、60%、30% 衰减；Boss单独配置免疫和抗性。

## 9. 反击

- 反击由“受击后”事件触发。
- 反击不能再次触发反击，防止无限链。
- 群体攻击可以对多个反击者分别触发，但有单次技能上限。
- 护山剑卫“护体剑罡”属于受击概率反击。
- 反击目标默认为伤害来源。

## 10. 胜负与逃生

胜利：

- 所有必须击败的敌人死亡。
- 结算魂晶、灵石、掉落和任务。

失败：

- 四名队员均死亡或无法行动。
- 临时战利品按战败规则处理。
- 死亡角色进入还魂坛。

逃生：

- 使用逃生符或允许逃生的技能。
- 保留 50% 临时战利品，比例由数据配置。
- Boss 特殊阶段可禁止逃生，但必须提前提示。

## 12. 验收

- 同一战斗在相同数据和随机种子下结果可复现。
- 动画跳过或 2× 不改变结算。
- 嘲讽前后目标行为符合规则。
- 反击不会无限递归。
- 每个主线 Boss 至少有两种有效职业解法。
- 自动战斗 20 分钟无卡死、无对象泄漏。
- 手动技能和自动策略不会在同一行动重复施放。

## 13. 不做

- 手动走位。
- 前后排。
- PVP。
- 多人联机。
- 连携 QTE。
- 实时物理碰撞战斗。
