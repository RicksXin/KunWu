## 页面 04：灵圃生产与储量

页面 ID：`spirit_farm`  
需求前缀：`V10-FARM`  
状态：规则已同步；数值 `BAL-TBD`

### 1. 上游与边界

资源分类和用途读取 [基础材料与资源循环](../1.0策划案/数值/34_1.0基础材料与资源循环_草案.md)，
离线结算结构读取 [技术实现方案](../01_技术实现方案.md)。本页只生产灵粮、灵木、玄铁、灵晶、
庚精；不生产灵石、魂晶、区域稀有材料、铁胚或器纹。

### 2. 入口与信息架构

- 营地点击灵圃进入主面板，关闭后回到原横滑位置。
- 顶部显示杂役总数、已分配/空闲人数、离线结算状态。
- 主列表按策划解锁顺序显示五种生产资源；未解锁行显示条件，不提前显示产量。
- 每行显示库存/上限、当前岗位人数、净产量、增减分配和储量升级入口。
- 底部显示当前生产周期进度、最近结算提示、杂役招募与关闭。

### 3. 页面状态

| 状态 | 要求 |
|---|---|
| 默认 | 只显示已解锁资源行和真实当前分配 |
| 首次进入 | 解释“先结算旧配置，再保存新分配” |
| 离线结算 | 一次性列出有效时长、各资源实际入库与溢出 |
| 空闲杂役为零 | 增加按钮禁用并说明无空闲杂役 |
| 资源满仓 | 标记停止入库，不继续累计隐藏产量 |
| 储量满级 | 隐藏升级动作，显示当前 1.0 上限 |
| 数值缺失 | 对应行显示“数据未配置”，操作禁用 |
| 时间回拨 | 暂停离线收益并提示重新校时；不倒扣资源 |
| 加载/保存错误 | 保留最后权威分配，允许重试，不显示乐观产量 |

### 4. 核心流程

#### 4.1 调整岗位

1. 点击增减时先以旧配置结算至当前可信时间。
2. 校验空闲杂役、已分配人数和资源是否已解锁。
3. 原子写入新分配与结算锚点，成功后刷新净产量。
4. 连续点击串行执行；不得产生负人数或超过杂役总数。

#### 4.2 离线结算

- 进入营地、打开灵圃、改变岗位和离开游戏前按同一结算器处理。
- 有效时长、周期、净产量、维护成本和离线上限均读取配置；当前未冻结值标 `BAL-TBD`。
- 到达储量上限的部分不进入库存；结算页明确显示溢出量。
- 同一结算锚点重复打开或刷新只返回已保存结果，不再次发放。

#### 4.3 杂役招募与储量升级

- 杂役招募弹窗显示当前灵粮、配置成本和增加人数，执行数值均为 `BAL-TBD`。
- 储量升级按资源分别显示当前/下一级上限与灵木成本。
- 确认时重新校验余额；扣除、人数/等级变化、结算锚点和保存同成同败。

### 5. 命令与数据

- `SetWorkerAllocation(resourceId, workerCount)`
- `RecruitWorkers(quantityConfigId)`
- `UpgradeResourceCapacity(resourceId)`
- `SettleFarmProduction(settlementReason)`

生产只记录时间锚点与状态，不依赖页面常驻 Timer 维持业务真相。显示进度可逐帧更新，但到期入库
只能由结算命令确认。

### 6. Figma 必需稿件

- 三行/五行资源列表、长库存数字、满仓、未解锁、无空闲杂役、单行数据错误。
- 离线结算：正常、部分溢出、全部满仓、时间回拨。
- 招募确认：可执行、灵粮不足、提交中、失败。
- 储量升级：可执行、材料不足、满级、数值未配置。
- 行组件覆盖 `normal/selected/disabled/locked/loading/error`，优先使用 Approved `Panel Item V2`。

### 7. 美术素材

引用 [灵圃生产弹窗](../ArtAssets/03_灵圃生产弹窗.md)、
[营地 HUD](../ArtAssets/02_营地HUD.md) 和 [通用图像槽](../ArtAssets/06_通用方形图像槽.md)。
沿用五类资源图标、通用面板、列表项、进度条和加减按钮；离线、满仓和时间异常图标由
[启动、存档与全局反馈素材](../ArtAssets/09_启动存档与全局反馈.md) 补齐。

### 8. 验收

- `V10-FARM-001`：灵圃只出现五种生产资源，解锁与列表状态正确。
- `V10-FARM-002`：调岗前先结算旧配置，连点和刷新不多产、不吞产。
- `V10-FARM-003`：达到储量上限停止入库，溢出量与原因可见。
- `V10-FARM-004`：招募和储量升级失败不扣资源、不改变人数或等级。
- `V10-FARM-005`：时间回拨不会制造收益，恢复正常时间后可继续结算。
- `V10-FARM-006`：所有未冻结数值由配置提供；缺失时不以 0 代替执行。

### 9. 不做

生产灵石/魂晶、广告翻倍、离线战斗、手动领取宝箱、超过仓储上限的隐藏累积和建筑施工等待。

## 页面 13：交易行、购买、出售与回购

页面 ID：`market`  
需求前缀：`V10-MARKET`  
状态：商品边界已同步；价格、栏位和刷新参数 `BAL-TBD`

### 1. 上游与边界

可交易物、限量物和禁止交易项读取
[基础材料与资源循环](../1.0策划案/数值/34_1.0基础材料与资源循环_草案.md)，地图商品与保底读取
[地图分册](../1.0策划案/地图/README.md)。旧文档中的栏位数和刷新时长在数值系统冻结前不进入 PRD。

### 2. 信息架构

一级标签：`购买`、`出售`、`回购`。

- 购买区按常备、剧情保底、限量/条件商品分组；显示价格、库存、刷新/永久状态和用途。
- 出售区只列合法库存，支持材料数量选择和装备单件出售。
- 回购区显示本档案最近合法出售记录、原实例信息、回购价格和失效条件。
- 顶部固定显示灵石；魂晶不作为交易货币。

### 3. 商品边界

- 普通材料可稳定补购，但不使交易行替代灵圃或探索。
- 引灵砂必须有稳定补购；照影石可按配置限量购买。
- 凝丹灵草不可出售、分解或无限补购。
- 四象阵砂、魔髓碎屑、古宝残片只进入明确剧情/限量/条件商品。
- 任务核心、证据、降尘丹和古宝不可出售。
- 普通随机商品不出售古宝、特定装备或任务核心。
- 价格、回购比例、数量和刷新时间全部读取配置，缺失为 `BAL-TBD` 禁用。

### 4. 购买流程

1. 选择商品与数量，预览灵石成本、购买后余额、储量/仓库容量和用途。
2. 提交时重新校验商品批次、限量状态、余额和容量。
3. `BuyMarketItem` 原子扣灵石、减商品库存、增加物品/资源并保存。
4. 批次变化、余额不足或容量不足时不扣款，保留选择并解释变化。

剧情保底商品不能被随机商品挤掉；满足条件后按上游持续可见或购买一次。

### 5. 出售与回购

- 已装备、锁定、任务推荐和高品质装备出售前逐级警告；任务保护与不可交易物不进入可选列表。
- 数量出售明确显示单价、总价和剩余数量；不得默认“全部”。
- `SellInventoryItems` 原子移除物品/实例、增加灵石、写回购记录。
- 回购恢复原装备实例及器纹/来源，不生成新随机装备；容量不足时不扣灵石。
- 批量出售自动排除受保护物并在确认页列明。

### 6. 页面状态

| 状态 | 要求 |
|---|---|
| 无商品/未解锁 | 显示条件或稍后刷新，不显示假货 |
| 商品刷新中 | 保留旧批次只读，购买禁用 |
| 剧情保底 | 独立标识，不与随机刷新倒计时绑定 |
| 灵石不足 | 购买禁用并显示缺口 |
| 容量不足 | 购买/回购禁用，链接百宝库处理 |
| 回购为空/失效 | 说明记录规则，不伪造占位商品 |
| 批次冲突 | 刷新商品并提示价格/库存已变化 |
| 数据错误 | 对应商品禁用，不以零价出售/购买 |

### 7. 命令与原子性

- `RefreshMarketView(marketId)`
- `BuyMarketItem(offerId, quantity, batchId)`
- `SellInventoryItems(itemRefs, quantities)`
- `BuyBackMarketItem(buybackId)`

所有命令防重复提交；购买、出售和回购均必须在库存/货币/记录之间同成同败。

### 8. Figma 必需稿件

- 购买：常备、保底、限量、售罄、锁定、批次刷新、价格变更。
- 出售：材料数量、普通装备、高品质警告、任务保护、批量排除。
- 回购：装备原实例、材料堆叠、容量不足、空、失效。
- 全部覆盖灵石不足、提交中、保存失败和长价格数字。

### 9. 美术素材

引用 [交易、还魂、招贤与乌婆素材](../ArtAssets/14_交易还魂招贤与乌婆馈赠.md)、
[通用图像槽](../ArtAssets/06_通用方形图像槽.md) 和
[百宝库素材](../ArtAssets/12_百宝库装备资源包与分解.md)。需要商铺背景、购买/出售/回购标签、
限量/保底/售罄标记和交易反馈；物品图标必须复用库存同一资源。

### 10. 验收

- `V10-MARKET-001`：购买、出售、回购物品边界与基础资源分册一致。
- `V10-MARKET-002`：凝丹灵草、任务核心、降尘丹和古宝不会出现在出售列表。
- `V10-MARKET-003`：批次冲突、连点、容量不足和保存失败不重复扣款或复制物品。
- `V10-MARKET-004`：回购装备保持原实例器纹和来源，不重新随机。
- `V10-MARKET-005`：所有价格/栏位/刷新值来自配置，缺失时不允许零价交易。

### 11. 不做

玩家交易、拍卖、充值货币、动态竞价、广告刷新、古宝商店、任务核心买卖和 PRD 内冻结临时价格。
