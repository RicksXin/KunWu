# 《昆吾禁地》PRD 00：产品范围与阶段路线图

版本：0.1  
日期：2026-07-30  
负责人：产品/主策  
关联：所有系统 PRD 的范围基线

## 1. 产品目标

玩家经营山外修士营地，招募和培养四人队伍，在灵粮、负重和迷雾限制下探索五张固定坐标方格大地图，通过职业转职、七维属性检定和半即时战斗推进主线。

## 2. 不可删除的核心体验

- 营地经营与野外探索共享灵粮。
- 每次移动一格并消耗补给。
- 所有地图对象具有固定坐标。
- 六个初始职业、两个一转方向、每阶段三个技能。
- 力道、法力、神识、遁速、肉身、护体、定力七维。
- 四人编队无前后排，嘲讽改变单体攻击目标。
- 从地图 2 开始，每图至少有主线小 Boss、支线 Boss、野外 Boss。
- 条件跨图连接，例如地图 2 高门槛直达地图 4。

## 3. 技术和发行边界

- Cocos Creator 3.8 LTS + TypeScript + WebGL + Cocos UI。
- Web Mobile 竖屏首发。
- 桌面浏览器优先，兼容 Android Chrome 和 iOS Safari。
- IndexedDB 本地存档，提供导入导出。
- 不使用 React 作为游戏内 UI。
- MVP 不包含账号、云存档、充值、广告、PVP、联机和原生安装包。

## 4. 阶段定义

P1 与 P2 的具体执行文档统一维护在 [`Docs/Demo/`](../Demo/README.md)：P1 对应 D0
可玩样机，P2 对应 D1 公开切片。P3 以后属于正式项目，在 D1 通过前冻结内容扩张。

| 阶段 | 周期 | 产品目标 | 通过后才能开始 |
|---|---:|---|---|
| P0 技术底座 | 2 周 | Web、存档、分包和地图可运行 | 核心灰盒 |
| P1 核心灰盒 | 4 周 | 15–20 分钟完整循环 | 正式资产生产 |
| P2 垂直切片 | 4–6 周 | 30–45 分钟公开 Demo | 五图 MVP |
| P3A 地图 2 | 4–5 周 | 完整大地图和三类 Boss | 中期内容 |
| P3B 地图 3–4 | 6–8 周 | 12 一转和地图网络 | 终局内容 |
| P3C 地图 5 | 5–7 周 | 8–12 小时 Alpha | Beta |
| P4 Beta/RC | 4–6 周 | 稳定、平衡、合规、发布 | 上线 |

基准总周期 29–38 周，假设 1 程序、1 策划、1 像素美术、0.5 动画特效、0.5 测试支持。

## 5. 各阶段内容快照

### P0

- Web Mobile 构建。
- 竖屏适配。
- IndexedDB 主档和备份。
- `shared/camp/map_01` Asset Bundle。
- Tiled 固定对象导入。
- 数据 Schema 校验。

### P1

- 灵粮、灵木、玄铁。
- 四名固定修士。
- 一张地图灰盒。
- 迷雾、灵粮、负重、固定对象。
- 时间轴战斗、七维、嘲讽。
- 15–20 分钟闭环。

### P2

- 七座建筑的 Demo 功能。
- 六初始职业，剑修两个一转。
- 地图 1 完整、地图 2 预览。
- 8 个敌人、1 主线 Boss、1 可选首领。
- 30 件物品。
- 30–45 分钟垂直切片。

### P3A

- 地图 2 完整。
- 主线、支线、野外 Boss各 1。
- 六初始职业达到正式质量。
- 装备累计 50 件，任务累计 20 个。

### P3B

- 地图 3、地图 4。
- 12 个一转职业、54 个主动技能。
- 地图 2 → 地图 4 条件出口。
- 装备累计 90 件，任务累计 45 个。

### P3C

- 地图 5和最终 Boss。
- 13–15 个 Boss。
- 120 件装备、60 个任务。
- 七座建筑最高 5 级。
- 8–12 小时主线。

### P4

- 停止增加系统。
- 浏览器兼容、存档迁移、性能和平衡。
- 原创资产替换和许可复核。
- Release Candidate。

## 6. 阶段门禁

每阶段必须同时满足：

1. Must 需求完成。
2. Sev-1、Sev-2 为 0。
3. 存档和数据迁移通过。
4. 性能达到本阶段目标。
5. 用户能理解新增核心规则。
6. 下一阶段内容依赖已冻结。

评审结果：

- `PASS`：进入下一阶段。
- `CONDITIONAL PASS`：只修复，不增加范围。
- `FAIL`：停留当前阶段或停止项目。

## 7. 需求编号

```text
HALL：大厅与导航
BLD：建筑与解锁
ECO：资源与生产
HERO：修士与招募
CAREER：职业与转职
COMBAT：编队与战斗
MAP：野外地图
ENEMY：敌人与 Boss
ITEM：装备、仓库、炼器、交易
QUEST：任务、剧情、NPC

QA：测试、发布和版本
```

编号格式：`阶段-模块-序号`，例如 `P2-MAP-014`。

## 8. 变更控制

下列变更必须由产品、程序、策划和美术共同评审：

- 更换引擎或 UI 技术栈。
- 改变地图固定坐标原则。
- 增减首发地图。
- 改变职业数量、技能槽数量或七维属性。
- 增加商业化、账号或联网系统。
- 改变 Demo/MVP 阶段门槛。

## 9. 减范围顺序

1. 天气只保留表现。
2. 暂停职业天赋。
3. 减少支线任务。
4. 减少装备词条。
5. 每图小副本减少到 1。
6. 一转从 12 减到 6，但每个初始职业至少保留一个。
7. 缩小地图尺寸，不随机填充内容。

不得优先删除核心体验中的任何一项。
