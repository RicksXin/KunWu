## 2. 产品目标

玩家经营昆吾山外营，带领石岩、陆清、白灵、墨言四名固定修士，在灵息、灵粮、负重和
迷雾压力下探索四张固定坐标大地图。四人从炼气成长至结丹，通过八条筑基分支、四槽装备、
七维检定和半即时战斗推进“昆吾开山录”，并在约 10 小时内完成一个有身份答案的阶段闭环。

## 3. 0.1 冻结范围

| 内容 | 0.1 产品范围 |
|---|---|
| 可玩地图 | `map_01`至`map_04`四张完整固定地图；`map_05`只作锁定预告 |
| 固定修士 | 石岩、陆清、白灵、墨言；不开放随机招募 |
| 职业与境界 | 金刚禅修、五行法修、玄箓修、剑修；八条筑基分支；结丹沿路线精通；Lv30 上限 |
| 技能 | 36 个稳定技能 ID；每个职业节点始终恰好三个主动技能 |
| 装备 | 四槽；白/绿/蓝/紫/金五档；制式装备随机七维、少量特装、重复打造与整件重铸 |
| 敌人 | 20–24 个普通基础模板、14 个精英配置、四个 Boss |
| Boss | 每图恰好一个；地图 4 Boss 是银翅夜叉·尸煞化身 |
| 任务 | 一条四章主线、四条支线；支线强敌按精英处理 |
| 玩家身份 | 可改现用名的非战斗掌印人；0.1 主线回答旧身份、幸存原因和掌印权限来源 |
| 结局 | 封住外层裂隙，给出三种评价；深层危险作为后续钩子 |
| 平台 | Cocos Creator 3.8.7、TypeScript、WebGL、Web Mobile、IndexedDB 本地存档 |

不可删除的核心体验：

- 营地经营与野外探索共享灵粮。
- 逐格移动、固定坐标、迷雾、负重、归营与全队阵亡减半。
- 四人编队无前后排；嘲讽改变单体目标，战斗数据保持单向事件流。
- 四职业各有两个可用筑基方向；护法金身提供常驻坦克，万象符脉提供限时符傀坦克，
  选择魔相力士组成无常驻硬坦队时仍可通过自恢复、符傀和高输出通关，但筑基页必须明示风险。
- 随机装备不作为主线门槛；突破物和关键任务物具有确定来源，不被低概率掉落卡死。
- 主线不隐藏永久失败；不可逆支线选择提前显示后果并产生可感知反馈。

## 4. 当前不做

- `map_05`可玩内容和完整镇魔塔终局。
- 招贤台、随机招募、当前四职业之外的新职业、元婴及以上境界。
- 支线 Boss、野外 Boss、世界 Boss、日常任务和 60 任务数量目标。
- 第五装备槽、单词条锁定/定向重铸、强化失败和装备耐久。
- 洗髓、废功重修、职业天赋、自由技能池和解雇固定四人。
- 账号、云存档、充值、广告、PVP、联机和原生安装包。


模块代码：`HALL`、`BLD`、`ECO`、`HERO`、`CAREER`、`COMBAT`、`MAP`、`ENEMY`、

## 6. 变更控制

下列变化必须先修改对应 0.1 策划分册并由用户确认，再同步相关 PRD：

- 增减可玩地图、Boss、任务链、剧情人物或结局。
- 改变固定修士、职业分支、技能 ID/数量、境界上限或七维职责。
- 改变装备槽、品质预算、随机七维池、特定装备效果、古宝来源或关键成长保底。
- 改变玩家身份答案、主线汇流、不可逆选择结果或关系变量语义。
- 把`map_05`、随机招募、元婴、商业化、联网或付费内容纳入 0.1。

只改变页面布局、操作方式、失败提示、可访问性或验收表达时，修改对应 PRD 即可，不反向
修改策划。任何稳定 ID 改名都必须单独评估数据与存档迁移，不能作为普通文案修改。

## 7. 减范围顺序

需要缩减制作量时按以下顺序评审：

1. 天气与非必要环境动画降为静态表现。
2. 减少普通敌人的美术变体，不删除其机制覆盖。
3. 减少支线的可选遭遇和表现资源，不删除四条支线主干、不可逆选择和汇流反馈。
4. 减少制式装备外观变体，不删除五档品质、随机七维、特装任务链和重铸闭环。
5. 每图小副本缩减到一个，但保留主线、支线、Boss和关键恢复路径。
6. 缩小地图可玩轮廓与空白路段，不改固定对象 ID、剧情顺序或四图数量。

不得优先删除固定四人、八条筑基分支、四个 Boss、四条支线、身份答案或主线防卡死来源。

## 8. 发布门禁

0.1 是否可发布以 PRD-12 为产品门禁，并同时满足上游内容依赖与验收矩阵。范围内任一
Sev-1/Sev-2、主线死锁、奖励复制、存档损坏、`map_05`越权进入或内容模式授权问题均阻断发布。
