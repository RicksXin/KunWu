## 页面 01：启动、继续游戏、加载与存档

页面 ID：`boot`  
需求前缀：`V10-BOOT`  
状态：待 Figma 页面稿与技术设计

### 1. 上游与边界

读取 [技术实现方案](../01_技术实现方案.md) 的 Web 容器、IndexedDB、导入导出和存档迁移约束，
版本范围读取 [1.0 总案](../1.0策划案/15_1.0版本完整策划案_草案.md)。本页负责进入游戏前的加载、
档案选择与恢复，不负责游戏内设置详情，导入导出见 PRD 17。

### 2. 入口、退出与返回

- Web 页面打开即进入启动容器，资源加载完成后显示档案动作。
- 有有效主档时主操作为“继续游戏”；无主档时主操作为“开始游戏”。
- “继续游戏”恢复到主档记录的安全位置或有效出征快照；“开始游戏”进入新档创建确认。
- 从设置页返回时回到启动页已加载状态，不重复初始化资源。

### 3. 信息架构

固定信息：游戏标识、当前游戏版本、资源加载进度、当前档案摘要、主操作、设置入口、静音和全屏。

档案摘要至少显示：玩家现用名、当前章节、保存时间、总游玩时长、档案版本、是否存在进行中出征。
不显示未解锁地图、Boss 或结局信息。

### 4. 页面状态

| 状态 | 页面要求 |
|---|---|
| 首次加载 | 品牌画面、真实进度、当前加载阶段；主操作不可点 |
| 可继续 | 显示档案摘要和“继续游戏” |
| 无存档 | 显示“开始游戏”，不显示伪造档案 |
| 读取备份 | 明示主档异常、正在恢复备份 |
| 迁移中 | 显示旧版本与目标版本；禁止关闭事务按钮 |
| 加载错误 | 显示错误类别、重试、进入存档工具；不自动覆盖主档 |
| 不兼容 | 禁止继续，允许导出原档并显示版本说明 |
| 离线/PWA | 可用本地资源时继续；缺少必需 Bundle 时说明无法进入 |

### 5. 核心流程

#### 5.1 继续游戏

1. `LoadProfile(profile_id)` 校验主档版本与校验值。
2. 主档有效则完成必要迁移，读取安全场景或唯一 `ExpeditionState`。
3. 场景资源准备完成后才切页；切页前保持加载遮罩。
4. 进入后立即以已加载 ViewModel 渲染，避免先显示新档默认值再跳变。

#### 5.2 新档

- 点击“开始游戏”显示覆盖风险说明；存在主档时必须再次确认并先创建备份。
- 新档要求输入玩家认可的现用名；显示字符、长度、空白和禁用字符规则读取本地化/数据配置，
  校验失败时保留输入并说明原因。现用名不是战斗修士名，也不自动推导旧身份姓名。
- 新档只创建策划规定的四名固定修士和初始状态。
- 创建、设为主档和首次保存同成同败；失败后仍保留旧档。

#### 5.3 异常恢复

- 主档校验失败时先只读尝试最近有效备份，成功后让玩家确认是否以备份继续。
- 不允许静默删除坏档；“重建新档”必须是玩家明确动作。
- 加载中刷新浏览器应重新执行幂等读取，不产生第二份新档或重复迁移。

### 6. 命令与保存

- `LoadProfile(profileId)`
- `CreateNewProfile(playerName)`
- `RestoreBackup(backupId)`
- `RetryBundleLoad(bundleId)`

新档、迁移、恢复备份均写入操作序列号。存档事务失败时返回错误类型，不以 Toast 假装成功。

### 7. Figma 必需稿件

- `375×817`：首次加载、无档、可继续、备份恢复、迁移中、加载失败、不兼容七张页面稿。
- 新档现用名输入覆盖空、合法、超长、非法字符和提交失败状态。
- 新档覆盖确认、备份恢复确认两张模态稿。
- 进度条 `loading/indeterminate/error`，主按钮 `normal/pressed/disabled/loading`。
- 移动浏览器安全区、横屏阻止提示、PWA/普通标签页差异标注。
- 当前均为 `Draft`；评审后逐节点转 `Approved`。

### 8. 美术素材

引用 [启动、存档与全局反馈素材](../ArtAssets/09_启动存档与全局反馈.md)。需要品牌底图、加载环境图、
存档/备份/警告图标、进度轨道与错误插图；按钮框和模态框优先复用通用组件。版本号、进度、
档案文本不得烘焙进图片。

### 9. 验收

- `V10-BOOT-001`：有档、无档和坏档进入正确状态，主操作不会混淆。
- `V10-BOOT-002`：加载刷新、按钮连点和迁移重试不创建重复档案。
- `V10-BOOT-003`：主档损坏时可从备份恢复，失败不会覆盖原文件。
- `V10-BOOT-004`：进行中出征恢复到唯一快照，不重复启程、战斗或结算。
- `V10-BOOT-005`：资源缺失、版本不兼容和存储不可用均有可执行的退出/重试/导出路径。

### 10. 不做

账号登录、云存档、多角色槽、服务器公告、充值入口、强制联网和未经确认的自动删档。

## 页面 02：营地大厅与固定 HUD

页面 ID：`camp`  
需求前缀：`V10-CAMP`  
状态：页面结构已定义；视觉待 Approved

### 1. 上游与边界

范围读取 [1.0 总案](../1.0策划案/15_1.0版本完整策划案_草案.md) 和
[剧情剧本](../1.0策划案/剧情/20_1.0剧情任务详细剧本_草案.md)。本页只负责大厅导航、全局摘要、
建筑状态和归营入口；各建筑业务在对应页面 PRD 维护。

### 2. 页面分层

```text
375×817 Viewport
├─ 顶部固定 HUD
├─ 1050 宽营地横滑层
│  ├─ 背景与远景
│  ├─ 七座建筑、传送阵、NPC/事件标记
│  └─ 前景遮挡层
├─ 底部固定 HUD
└─ 页面/模态遮罩层
```

顶部、底部 HUD 不跟随横滑。大厅首次进入定位到当前主线相关建筑；从子页返回恢复原横滑偏移。

### 3. 信息架构与入口

- 顶部：玩家头像/现用名、五类生产资源摘要、当前主线任务摘要。
- 横滑层：议事殿、招贤馆、百宝库、还魂殿、交易行、炼器坊、灵源院和传送阵。
- 底部：修士名册、百宝库、任务日志、设置等高频入口，及灵石余额。
- 建筑状态：`locked`、`available`、`attention`、`in_progress`；同一建筑只显示最高优先状态。
- 招贤馆解锁后只进入 PRD 15 的锁定说明页，不显示候选数量、刷新倒计时或馆级。
- 传送阵进入普通入山整备；已满足条件的资源副本快捷入口由整备页分组承载。

### 4. 页面状态

| 状态 | 表现与操作 |
|---|---|
| 默认 | HUD 与横滑建筑可用，主线相关入口突出但不强制跳转 |
| 首次教学 | 分步聚焦横滑、议事殿、灵源院和传送阵，可跳过后从帮助重看 |
| 建筑锁定 | 保留轮廓与锁定原因，不响应进入命令 |
| 建筑事件 | 建筑上显示统一事件标记；进入并处理后按权威状态消失 |
| 数据加载 | 保留场景，HUD 骨架屏；所有资源型操作禁用 |
| 归营结算 | 全屏结算层优先，结算完成后才允许操作大厅 |
| 页面错误 | HUD 单模块错误不遮挡整个大厅；提供该模块重试 |
| 横屏/小视窗 | 显示转回竖屏提示，不重新排成桌面横版 |

### 5. 交互与返回

- 横向拖动只作用于营地层；点击与拖动以阈值区分，拖动结束不得误触建筑。
- 建筑可点区域按视觉轮廓扩展到最小触控热区，重叠时以层级和语义区域裁决。
- 页面弹出后大厅横滑冻结；关闭后恢复原位置与事件状态。
- 主线任务摘要点击进入 PRD 03 的任务日志并定位当前节点。
- 系统返回依次关闭模态、子页面；大厅根层返回显示“返回启动页”确认。

### 6. 数据与命令

- `OpenCampModule(moduleId)`
- `FocusCampAnchor(anchorId)`
- `AcknowledgeCampGuide(stepId)`
- `CompleteReturnSettlement(expeditionId)`

页面读取资源余额、任务摘要、建筑解锁 Flag、事件状态和横滑锚点。归营事务未完成时不提前刷新
余额或战利品，完成后一次性更新所有 HUD 模块。

### 7. Figma 必需稿件

- `375×817` 左/中/右三个横滑位置，另附 `1050×817` 完整逻辑全景标注。
- 顶部 HUD：默认、长数字、单资源加载失败、主线完成待领取。
- 建筑：默认、按下、锁定、可处理事件、当前主线相关。
- 底部入口：默认、按下、禁用、选中、红点；招贤馆只需封印锁定状态。
- 归营结算覆盖层、教学聚焦层、横屏提示。
- 固定区、横滑区、Mask、Safe Area 和触控热区必须单独标层。

### 8. 美术素材

引用 [营地全景与建筑](../ArtAssets/01_营地大厅建筑与传送阵.md)、
[营地 HUD](../ArtAssets/02_营地HUD.md) 和
[通用事件标记](../ArtAssets/07_通用事件标记选项按钮与战利品图标.md)。
招贤馆美术不得出现候选修士剪影、招募榜单或可经营馆级暗示；炼器坊不得出现重铸语义。

### 9. 验收

- `V10-CAMP-001`：375 宽视窗中仅营地 1050 宽内容横滑，顶部/底部 HUD 像素位置不变。
- `V10-CAMP-002`：八个入口按剧情 Flag 正确进入页面或显示锁定原因，返回保持横滑位置。
- `V10-CAMP-003`：招贤馆解锁后只能进入后续版本说明，不出现可执行招募功能。
- `V10-CAMP-004`：拖动不误触建筑，模态打开时不穿透，系统返回遵守层级。
- `V10-CAMP-005`：归营结算只执行一次，完成后 HUD、库存、任务和人物事件同步刷新。
- `V10-CAMP-006`：长数字、资源加载失败和极端安全区下无关键文案截断。

### 10. 不做

自由摆放建筑、昼夜系统、营地缩放、固定 HUD 随横滑、招贤候选预览和建筑升级入口集合页。

## 页面 17：设置、导入导出、许可与 Credits

页面 ID：`settings`  
需求前缀：`V10-SETTINGS`  
状态：功能范围已定义；页面与结局演出稿待设计

### 1. 上游与边界

技术边界读取 [技术实现方案](../01_技术实现方案.md)，1.0 结局内容读取
[剧情剧本](../1.0策划案/剧情/20_1.0剧情任务详细剧本_草案.md)，第三方许可遵守仓库许可记录。
本页不提供账号、云存档、联网遥测或付费隐私授权。

### 2. 设置结构

一级分组：`声音`、`画面`、`操作与辅助`、`存档`、`语言`、`许可与 Credits`。

- 声音：Master、Music、Ambient、SFX、UI；静音与分项数值同步。
- 画面：画质档、环境粒子、允许的特效开关、全屏；低画质按技术方案关闭高成本效果。
- 操作与辅助：震动、文本速度、减少屏幕震动、状态非颜色提示。
- 偏好设置立即保存且不与游戏主档业务事务混写；设置损坏可恢复默认。

### 3. 存档导出

- `ExportSave(profileId)` 生成带 Schema、游戏版本、保存时间和校验的 `.kwsave` 文件。
- 导出前刷新主档快照，显示档案摘要和导出时间；下载失败允许重试。
- 导出不清除或锁定本地主档，不向外部服务器上传。

### 4. 存档导入

1. 文件选择器只接受声明类型/扩展名，但仍必须读取内容校验。
2. 预检 Schema、游戏版本、校验、档案摘要和兼容性，不立即覆盖。
3. 确认页并列显示当前档与待导入档，并先为当前主档创建备份。
4. `ImportSave(file)` 原子完成备份、迁移、写入和重新加载。
5. 任一步失败保留当前档；不允许部分导入库存或修士。

导入包含有效进行中出征时按 PRD 01 恢复唯一快照；非法旧招贤字段不能开放 1.0 招募功能。

### 5. 许可与 Credits

- 显示 Cocos Creator/引擎要求的声明、字体和全部第三方素材许可、作者/项目贡献信息。
- 每项第三方素材显示名称、作者、来源、许可证和本地许可文件入口；不得只写“网络素材”。
- 原创与第三方素材分组，公开发行前不展示无权使用的专有授权名/资源。
- Credits 支持从设置打开，也在 1.0 结局演出后播放；可跳过后进入通关后营地。

### 6. 1.0 结局衔接

- 最终战后先完成剧情 Flag、结局评价和存档，再进入结局演出。
- 1.0 是“封住外层裂隙、确认深层威胁”的单一阶段结局，可因选择改变评价/旁白；不展示完整游戏三种宏观结局按钮。
- 结局记录写入稳定 `ending_id/evaluation_id` 和通关时间；刷新从已保存演出节点或通关后营地恢复。
- 演出结束播放 Credits，随后提供“继续游戏”和“返回启动页”。继续游戏保留通关后自由培养与资源副本。

### 7. 页面状态与异常

| 状态 | 要求 |
|---|---|
| 设置默认/已修改 | 变更即时可感知，恢复默认需确认 |
| 导出中/失败 | 不遮蔽返回，提供重试和错误原因 |
| 导入预检失败 | 明示版本、校验或文件损坏，不改当前档 |
| 导入不兼容 | 允许取消和导出当前档，不强制覆盖 |
| 导入成功重载 | 阻止重复提交，完成后重新读取档案 |
| 许可缺失 | 发布前阻断交付，不用空白页静默通过 |
| Credits 播放 | 可暂停/跳过，跳过不影响通关记录 |

### 8. Figma 必需稿件

- 设置总页及六分组，滑杆、开关、选择项覆盖默认/按下/禁用/错误。
- 导出确认、成功、浏览器下载失败；导入文件选择后预览、版本冲突、校验失败、覆盖确认、成功重载。
- 许可长列表、单项详情、Credits 滚动与跳过确认。
- 1.0 结局演出关键帧、评价差异态、通关后动作；均需安全区和长文案验证。

### 9. 美术素材

引用 [启动、存档与全局反馈素材](../ArtAssets/09_启动存档与全局反馈.md) 和
[设置、许可与结局素材](../ArtAssets/16_设置许可与结局.md)。需要设置分类图标、滑杆/开关状态、
存档文件/备份图标、许可标记、Credits 底图和 1.0 结局关键画面；许可正文与名单不得烘焙进图片。

### 10. 验收

- `V10-SETTINGS-001`：音量、画质和辅助偏好刷新后保持，损坏时可恢复默认。
- `V10-SETTINGS-002`：导出文件含版本与校验，可在兼容环境导入恢复同一业务状态。
- `V10-SETTINGS-003`：导入失败不覆盖当前档，成功导入前始终创建可恢复备份。
- `V10-SETTINGS-004`：许可与 Credits 覆盖所有第三方资产和引擎要求，无来源缺失。
- `V10-SETTINGS-005`：结局保存、演出刷新和 Credits 跳过不重复奖励或丢失通关记录。
- `V10-SETTINGS-006`：1.0 只展示阶段结局，不误做完整游戏三宏观结局。

### 11. 不做

云存档、账号同步、付费隐私弹窗、强制遥测、部分档案合并、从 URL 导入和 1.0 三宏观结局选择。
