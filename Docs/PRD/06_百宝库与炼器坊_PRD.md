## 页面 11：百宝库、资源包、装备、换装与分解

页面 ID：`treasury`  
需求前缀：`V10-TREASURY`  
状态：物品规则已同步；容量和回收数值 `BAL-TBD`

### 1. 上游与边界

物品分类、资源包、分解和出售边界读取
[基础材料与资源循环](../1.0策划案/数值/34_1.0基础材料与资源循环_草案.md)，装备实例读取
[装备与掉落](../1.0策划案/数值/18_1.0装备与掉落数值_草案.md)。本页负责库存与本地操作，不负责打造或商店交易。

### 2. 信息架构

一级分类：`全部`、`装备`、`资源包`、`材料`、`加工品`、`食物`、`任务/唯一物`、`待处理`。

- 列表支持分类、合法筛选、排序和搜索；默认不把任务物混入批量处理。
- 详情显示来源、用途、可堆叠数量、保护状态、相关页面入口和允许动作。
- 装备详情显示槽位、资格、品质、器纹、七维、固定属性/效果、来源和装备者。
- 四槽固定：武器、防具、饰品一、饰品二；装备没有等级字段。

### 3. 品质与器纹展示

```text
凡品 → 精制 → 上品 → 珍品 → 法宝 → 古宝
```

- 非古宝七维全部来自已经附着的 1/2 枚器纹；器纹永久固定。
- 古宝完整数值与效果固定，不显示器纹操作。
- 品质不能只靠颜色识别，须同时显示名称与边框/纹样。
- 页面不提供重铸、锻纹尘、器纹拆卸、替换或转移入口。

### 4. 资源包与食物

- 资源包只覆盖灵木、玄铁、灵石、灵晶、庚精五类，每类四档；开包数量固定且详情可预览。
- 支持单个、指定数量和批量打开；灵石包直接入钱包，其他资源受对应储量上限约束。
- 完整产量无法容纳时不消耗该包；批量只处理当前可完整容纳的数量并说明剩余。
- 资源包不能装入出征、不能在野外/战斗/扎营打开。
- 野外食物在营地可转为公共灵粮，完整产量无法容纳时不消耗；食物不治疗或恢复灵息。

### 5. 换装与比较

- 从修士槽位进入时默认筛选兼容装备，并展示当前/候选对比。
- 换装确认显示七维、固定效果、战力和原装备去向；两个饰品槽必须能明确选择目标槽。
- 已出征快照中的装备不可被营地换装；已装备于其他营地修士时可按规则换下并明确展示。
- `EquipItem` 原子处理两个装备实例、槽位和修士面板，失败恢复原装配。

### 6. 分解

- 仅合法的非古宝装备可分解；已装备、锁定、任务保护和古宝禁止或按上游限制。
- 预览只显示玄铁及按品质配置的庚精/器灵残片，不返还灵石、完整铁胚或完整器纹。
- 批量分解自动排除受保护物，并在确认页逐类列数量和返还。
- 任务推荐装备进入批量处理前必须二次警告。
- `DismantleEquipment` 的装备消耗、材料入库、容量校验和保存同成同败。

### 7. 页面状态

| 状态 | 要求 |
|---|---|
| 空分类 | 说明合法获取路径，不显示虚拟样品 |
| 筛选无结果 | 保留筛选条件并提供清除 |
| 容量不足 | 阻止完整操作，链接储量或待处理区 |
| 受保护 | 动作禁用并显示保护来源 |
| 待处理 | 唯一物/装备可领取、比较或按规则处理，不会被覆盖 |
| 数值缺失 | 开包/分解禁用，显示配置错误 |
| 提交中/错误 | 锁定相关物品，失败后恢复列表和选择 |

### 8. 命令

- `OpenResourcePack(itemId, quantity)`
- `ConsumeFieldFoodInCamp(itemId, quantity)`
- `EquipItem(cultivatorId, slotId, equipmentInstanceId)`
- `DismantleEquipment(equipmentInstanceIds)`
- `SetItemLock(itemInstanceId, locked)`
- `ClaimPendingItem(pendingId)`

每次命令在提交时重新校验实例与容量；重复操作 ID 返回第一次结果。

### 9. Figma 必需稿件

- 七分类有内容/空/筛选无结果，长列表和待处理区。
- 装备详情覆盖六档品质、1/2 器纹、固定效果、古宝、任务保护。
- 换装比较：提升/降低/混合变化、饰品槽选择、装备被占用、出征锁定。
- 开包：单个、数量、批量、储量不足、灵石直入钱包、错误。
- 分解：单件、批量、保护排除、推荐装警告、容量不足、成功回收。

### 10. 美术素材

引用 [通用图像槽](../ArtAssets/06_通用方形图像槽.md)、
[百宝库、装备、资源包与分解素材](../ArtAssets/12_百宝库装备资源包与分解.md)。需要六品质框、四槽图标、
20 个资源包、食物/材料/任务物图标、器纹显示槽、锁定和待处理标记。

### 11. 验收

- `V10-TREASURY-001`：所有装备统一四槽、六档、无等级，器纹不可操作替换。
- `V10-TREASURY-002`：资源包只覆盖五类四档，容量不足时不消耗不完整包。
- `V10-TREASURY-003`：换装失败不丢装备，出征中实例无法在营地重复使用。
- `V10-TREASURY-004`：分解不返还完整铁胚/器纹或打造费，不产出锻纹尘。
- `V10-TREASURY-005`：任务物、唯一物、古宝和受保护装备不会被批量操作吞掉。

### 12. 不做

装备等级、强化、重铸、器纹替换、古宝分解、野外开包、远程仓库和自动出售稀有物。

## 页面 12：炼器坊升级、铁胚、器纹、打造与永久强化

页面 ID：`forge`  
需求前缀：`V10-FORGE`  
状态：24 级结构与制造链冻结；成本、配方数量和七维 `BAL-TBD`

### 1. 上游与边界

完整规则读取 [炼器坊策划](../1.0策划案/数值/33_炼器坊升级与炼制机制_草案.md)，资源关系读取
[基础材料与资源循环](../1.0策划案/数值/34_1.0基础材料与资源循环_草案.md)，装备内容读取
[装备与掉落](../1.0策划案/数值/18_1.0装备与掉落数值_草案.md)。本页不实现重铸、锻纹尘或古宝打造。

### 2. 页面信息架构

一级标签：`坊级`、`铁胚`、`器纹`、`装备打造`、`工具/消耗品`、`永久强化`、`突破物`。

- 顶部常驻显示坊级、灵木、灵石和当前标签相关材料摘要。
- 配方行显示解锁来源、材料、产出、持有量、可制作状态和详情。
- 仅显示已解锁与“下一步可见”的配方；后续境界配方可显示缺少地区辅材，但不得伪装可制作。

### 3. 坊级升级

- 炼器坊共 24 级，只消耗灵木，立即完成，无施工时间、概率、降级或损坏。
- 升级页显示当前/下一坊级、下一等级全部新蓝图、当前灵木和 `BAL-TBD` 成本。
- 只校验等级未满和灵木足够，不追加主线、境界、其他建筑或现实时间门槛。
- `UpgradeForge` 原子扣灵木、提高坊级、解锁蓝图并保存；连点只能成功一次。

### 4. 铁胚与品质

炼器坊可制作五档铁胚：凡品、精制、上品、珍品、法宝；古宝没有铁胚。

- 铁胚只携带品质，不带槽位、职业、七维或器纹。
- 提交的铁胚直接决定最终装备品质，打造完成时不再随机品质。
- 玄铁/庚精数量和解锁门槛读取配置；品质不改变蓝图器纹槽数。

### 5. 器纹

- 固定七种：力道、法力、神识、遁速、肉身、护体、定力。
- 普通炼纹消耗器灵残片、灵晶和灵石，结果随机为一种合法器纹；权重与成本 `BAL-TBD`。
- 结果在产出并保存成功时确定，刷新不重抽；任务/探索可直接给予指定器纹。
- 器纹自身无品质和数值；写入装备后永久固定，不能拆卸、替换或转移。

### 6. 装备打造

```text
蓝图 + 对应品质铁胚 + 蓝图要求的 1/2 枚器纹 + 灵石打造费
+ 特定装备额外材料 → 完整装备实例
```

流程：

1. 选蓝图并查看槽位、资格、器纹槽数、固定属性/效果。
2. 选择一枚铁胚和准确数量器纹；双槽允许两枚同类器纹。
3. 预览最终品质、器纹类型、七维与固定效果。
4. 确认后固定成功，原子扣材料并生成实例。

仓库容量不足、蓝图未解锁、材料变化或配置缺失均不得先扣材料。

### 7. 工具、突破物与永久强化

- 归营符、开山镐按解锁配方制作；开山镐为单次出征有效状态。
- 降尘丹为 1.0 结丹必要物，固定成功；其他大境界突破物只按 24 级表展示未来配方状态。
- 行营阵盘、探灵灯各三阶，必须按顺序各生效一次；完成后对后续出征快照生效。
- 永久强化完成时材料、阶级、幂等记录同一事务保存；不追改进行中的出征。
- 配方数量与材料成本读取配置，不复制策划草案中的临时值。

### 8. 页面状态

| 状态 | 要求 |
|---|---|
| 未解锁配方 | 显示坊级/外部蓝图条件，不允许提交 |
| 材料不足 | 缺口逐项可见并链接合法来源 |
| 可预览不可制作 | 后续地区辅材未投放时明确说明 |
| 制作中 | 锁定配方与材料，防止重复点击 |
| 随机器纹结果 | 保存成功后揭示；失败不展示假结果 |
| 永久强化已完成 | 显示已生效，不再出现重复制作按钮 |
| 24 级 | 显示满级和全部已解锁，不显示 25 级 |
| 数据错误 | 对应配方禁用，不用 0 成本继续 |

### 9. 命令

- `UpgradeForge()`
- `CraftBillet(qualityId, quantity)`
- `CraftRandomInscription(quantity)`
- `CraftEquipment(blueprintId, billetId, inscriptionIds)`
- `CraftForgeRecipe(recipeId, quantity)`
- `CompletePermanentUpgrade(upgradeId)`

所有随机结果由服务层种子生成。扣除、产出、蓝图/永久状态与保存同成同败，重复操作 ID 幂等。

### 10. Figma 必需稿件

- 坊级：1 级、连续可升级、多解锁预览、材料不足、24 级满级。
- 铁胚：五品质、未解锁、批量制作、材料不足。
- 器纹：七种库存、炼制确认、揭示结果、保存失败恢复。
- 打造：1 槽、2 槽、同类双器纹、特装、容量不足、完成装备。
- 工具/突破物：归营符、开山镐、降尘丹、未来辅材缺失。
- 永久强化：三阶进度、前置未完成、完成、进行中出征不追改提示。

### 11. 美术素材

引用 [炼器坊、铁胚、器纹与永久强化素材](../ArtAssets/13_炼器坊铁胚器纹与永久强化.md)、
[通用图像槽](../ArtAssets/06_通用方形图像槽.md) 和

蓝图卷、工具、突破物、阵盘/探灵灯三阶和打造完成表现。

### 12. 验收

- `V10-FORGE-001`：24 坊级只扣灵木，立即且原子升级，满级无 25 级入口。
- `V10-FORGE-002`：铁胚直接决定品质，品质不改变蓝图 1/2 器纹槽。
- `V10-FORGE-003`：随机炼纹刷新不重抽，器纹写入装备后无任何替换入口。
- `V10-FORGE-004`：打造固定成功，失败不扣材料、不生成半件装备。
- `V10-FORGE-005`：古宝没有铁胚或打造蓝图，页面不存在重铸与锻纹尘。
- `V10-FORGE-006`：永久强化只生效一次且只影响后续出征快照。

### 13. 不做

施工等待、打造失败、装备等级、器纹品质、定向普通炼纹、器纹替换、重铸、古宝打造和 25 级以上坊级。
