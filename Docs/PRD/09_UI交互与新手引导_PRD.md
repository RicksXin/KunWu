# 《昆吾禁地》PRD 09：UI、交互与新手引导

版本：0.2
日期：2026-07-30
模块：UX
负责人：产品、UI/UX、客户端

## 1. 模块目标

在竖屏Web中清晰呈现资源、修士、地图和战斗信息。UI必须同时支持鼠标和触控，不依赖颜色传达唯一信息。

## 2. 技术边界

- 使用 Cocos UI。
- 不引入React。
- UI 设计稿基准视窗为375×817；这是玩家可见窗口，不是大厅全景内容宽度。
- Cocos 内部设计坐标继续使用1080×1920，参考像素画布360×640；大厅全景保留独立内容宽度并在视窗内横滑。
- 适配浏览器安全区和地址栏变化。
- PC 浏览器按375:817视窗居中展示，高度优先占满可用区域，宽度按比例计算，视窗外为纯黑留边。
- H5、手机和平板同样保持375:817；设备比例不一致时等比缩小并留边，不拉伸视窗。
- 改变视窗尺寸不得把大厅全景、地图或其他横向内容整体压缩进一屏；超出可视窗口的内容继续通过横滑、滚动或分页查看。

## 4. 通用交互

- 最小触控区域48×48dp。
- 高风险操作二次确认。
- 长按显示物品/属性说明。
- 鼠标悬停与触控长按提供同等信息。
- 返回键先关弹窗，再返回页面。
- 加载期间禁止重复点击。
- 所有异步操作显示处理中状态。

## 5. 视觉信息

英雄品级、装备品质和危险等级同时使用：

- 颜色。
- 文字。
- 边框形状。
- 图标。

不能只靠颜色区分。

关键提示：

- 灵粮不足。
- 负重80%。
- 无法安全返回。
- 属性检定失败后果。
- Boss危险。
- 死亡和还魂。
- 存档失败。

## 6. 地图UI

常驻：

- 坐标。
- 当前灵粮。
- 当前/最大负重。
- 探查范围。
- 当前任务。
- 返回营地。

点击格子：

- 已知可达格显示路径和消耗。
- 未知格不显示内部对象。
- 固定POI显示类型、是否完成。
- 条件出口显示缺少条件。

## 6.1 大厅 UI

- 大厅的页面结构、建筑位置、横滑规则和未开放范围以 PRD-01 为唯一事实源。
- 顶部头像、五种生产资源和主线提示固定，不随营地全景横滑。
- 中央营地全景支持触控与鼠标横向拖动，默认定位城堡/出征所在的中部区域。
- 底部左侧固定显示设置、成就、排行榜、邮件、日常进度；右侧显示独立于顶部灵晶的灵石余额。
- 成就、排行榜、邮件、日常进度暂不实现，必须展示禁用或明确未开放状态。
- 宝石和全部付费入口隐藏，不保留可见占位。
- 横滑位移超过 PRD-01 定义的阈值后取消建筑点击，避免拖动误触。

## 8. 新手引导

目标：前10分钟完成第一次出征。

| 时间 | 引导 |
|---|---|
| 0–2分钟 | 营地资源和灵圃 |
| 2–5分钟 | 招募/领取固定队 |
| 5–8分钟 | 编队、装备、三技能 |
| 8–10分钟 | 灵粮、负重、出征 |
| 10–15分钟 | 逐格移动、迷雾、固定敌人 |
| 15–20分钟 | 属性检定和返回选择 |
| 20–35分钟 | 打造、还魂、武修一转 |
| 35–45分钟 | Boss和地图2预览 |

引导原则：

- 先操作后解释。
- 一次只要求一个动作。
- 可重看。
- P2之后允许跳过已完成的新手引导。

## 9. 可访问性

- 关闭震屏。
- 降低闪光。
- 字号档位。
- 音量分组。
- 颜色辅助图标。
- 自动战斗速度可选。
- 键盘Escape/浏览器返回一致。

## 11. 验收

- 新测试者三次点击内从大厅进入出征准备。
- 10分钟内第一次出征。
- 能说出灵粮和负重的区别。
- 能理解属性检定失败结果。
- 能识别三种Boss标记。
- 手机浏览器无被地址栏遮挡的关键按钮。
- 鼠标和触控均完成全流程。

## 12. 不做

- React UI。
- 横屏专用布局。
- 拖拽式大厅建造。
- 复杂手势作为唯一操作。
- 强制观看长教程。
