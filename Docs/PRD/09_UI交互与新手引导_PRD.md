# 《昆吾禁地》PRD 09：UI、交互与新手引导

版本：0.4
日期：2026-08-01
模块：UX
负责人：产品、UI/UX、客户端

## 1. 模块目标

在竖屏Web中清晰呈现资源、修士、地图和战斗信息。UI必须同时支持鼠标和触控，不依赖颜色传达唯一信息。

## 2. 技术边界

- 使用 Cocos UI。
- 不引入React。
- UI 设计稿基准视窗为375×817；这是玩家可见窗口，不是大厅全景内容宽度。
- `1080×1920` 仅是迁移中的旧 Cocos 工程坐标，不作为新 UI 的尺寸来源；`360×640`
  只可用于世界 Tile、角色等像素素材的内部参考，不参与 UI 布局与 UI 素材尺寸推导。
- 适配浏览器安全区和地址栏变化。
- PC 浏览器按375:817视窗居中展示，高度优先占满可用区域，宽度按比例计算，视窗外为纯黑留边。
- H5、手机和平板同样保持375:817；设备比例不一致时等比缩小并留边，不拉伸视窗。
- 改变视窗尺寸不得把大厅全景、地图或其他横向内容整体压缩进一屏；超出可视窗口的内容继续通过横滑、滚动或分页查看。

## 4. 通用交互

- 最小触控区域48×48dp。
- 高风险操作二次确认。
- 长按显示物品/属性说明。
- 鼠标悬停与触控长按提供同等信息。
- 返回键先关弹窗，再返回页面。
- 加载期间禁止重复点击。
- 所有异步操作显示处理中状态。

## 5. 视觉信息

英雄品级、装备品质和危险等级同时使用：

- 颜色。
- 文字。
- 边框形状。
- 图标。

不能只靠颜色区分。

关键提示：

- 灵粮不足。

- 无法安全返回。
- 属性检定失败后果。
- Boss危险。
- 死亡和还魂。

## 6. 地图UI

常驻：

- 坐标。
- 当前灵粮。
- 当前/最大负重。
- 探查范围。
- 当前任务。
- 返回营地。

点击格子：

- 已知可达格显示路径和消耗。
- 未知格不显示内部对象。
- 固定POI显示类型、是否完成。
- 条件出口显示缺少条件。

## 6.1 大厅 UI

- 大厅的页面结构、建筑位置、横滑规则和未开放范围以 PRD-01 为唯一事实源。
- 顶部头像、五种生产资源和主线提示固定，不随营地全景横滑。
- 中央营地全景支持触控与鼠标横向拖动，默认定位城堡/出征所在的中部区域。
- 底部左侧固定显示设置、成就、排行榜、邮件、日常进度；右侧显示独立于顶部灵晶的灵石余额。
- 成就、排行榜、邮件、日常进度暂不实现，必须展示禁用或明确未开放状态。
- 宝石和全部付费入口隐藏，不保留可见占位。
- 横滑位移超过 PRD-01 定义的阈值后取消建筑点击，避免拖动误触。

## 6.2 出征准备、编队与地图选择

出征准备不是独立页面。玩家点击大厅传送阵后，在原大厅上方打开 `375×817` 逻辑
尺寸的模态面板；顶部与底部大厅 HUD 被遮罩但不销毁。由上到下固定为：

1. 4 个横向英雄槽位：空位为人物黑影与“人选未定”；已上阵卡使用对应静态立绘，
   并显示精力、姓名、职业·等级和星级。
2. 操作栏：编辑队伍、队伍栏、补充精力。新档队伍栏仅开放 1 队；锁定队伍显示锁定
   标识与灵石费用。补充精力当前禁用并标注暂未开放。
3. 当前/最大负重 `x/y`。
4. 灵粮、十字镐、透镜三条装载行：显示已携带/当前拥有、单件重量和 `- / +`；触控区
   不小于 `48×48dp`，增减后立即刷新负重并保存。
5. 冒险、出发、离开三个按钮。冒险当前禁用；出发打开地图选择面板；离开无损关闭。

点击“编辑队伍”打开第二层选人面板。面板纵向滚动展示全部已拥有修士，每行包含头像
与星级、姓名、职业、等级、精力、评分以及选择/取消按钮；选中态同时使用描边、底色和
“取消/槽位编号”文字，不只依赖颜色。系统返回键先关闭选人面板，再关闭出征准备面板。

点击“出发”打开第二层地图选择面板。每行显示地图编号、名称、所需精力、每步灵粮和
最低携带灵粮；点击已解锁项目即执行最终校验并传送，不再增加一层确认。系统返回键先
关闭地图选择面板。任何修士精力不足、灵粮不足、负重超限、阵亡或跨队重复都必须用
文字说明具体原因。

### 6.3.2 尺寸与导出总则

- UI 唯一逻辑基准和玩家可见窗口为 `375×817`。
- 每张新 UI 素材都必须同时标注逻辑尺寸和最终 PNG 实际尺寸；本批默认交付
  `@3x` RGBA PNG。
- `360×640` 不参与本节任何 UI 布局或 UI 素材尺寸推导；`1080×1920` 只表示迁移中的
  旧工程坐标，不能静默换算成新素材尺寸。
- 像素边缘必须落在整数坐标，使用硬边缘、无抗锯齿和 Nearest 过滤。若 GPT Image
  无法直接输出精确尺寸，先生成高清透明母版，再离线裁切、像素化并缩放到表中尺寸。
- 九宫格素材表中填写的是“九宫格源图逻辑尺寸”，运行时可拉伸到指定目标尺寸；边角、
  纹样和描边必须全部位于不可拉伸区。
- 修士名、职业、等级、精力、评分、星级、队伍编号、地图名、地图消耗、数量、重量、
  锁定原因和所有按钮文案均由 Cocos Label/本地化表渲染，不得烘焙进 PNG。
- 模态暗色遮罩、英雄信息底部黑色渐隐、禁用态降亮度和按钮按下反馈优先由 Cocos
  颜色/透明度过渡完成，不单独占用美术图片。

### 6.3.6 面板、卡框与状态叠层提示词

### 6.3.12 制作顺序

1. 先从 Cocos 导出三张 `375×817` 灰盒截图，锁定实际信息密度和安全区。
2. 制作面板九宫格、英雄卡框和通用列表行，并在灰盒上试拉伸；边框定稿前不批量做人像。
3. 先生成石岩一张立绘，验证卡面、底部信息遮罩和 `62×76` 头像裁切。
4. 石岩通过后，以其眼高、像素密度和光照为参考生成陆清、白灵、墨言。
5. 制作空槽剪影、选中/锁定叠层，并同时检查正常、选中、禁用三态。
6. 最后制作十字镐、透镜、通用锁和负重图标；灵粮、按钮、加减号不重新生成。
7. 统一离线裁切为目标 `@3x` 尺寸，再由 Cocos Creator 导入并生成 `.meta`。
