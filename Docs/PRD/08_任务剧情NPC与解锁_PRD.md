# 《昆吾禁地》PRD 08：0.1 任务、剧情、NPC与系统解锁

版本：0.1-product.1  
日期：2026-08-04  
状态：试玩版本产品化落地  
模块：QUEST  
负责人：剧情策划、任务策划、客户端

## 1. 模块目标与事实源

用任务引导玩家理解营地、地图、职业和 Boss，并让剧情选择对 NPC、资源、战斗路径与
结局评价产生可感知反馈。剧情服务可玩的选择和系统解锁，不制作大量不可交互长演出。

0.1 内容按下列边界落地：

| 内容 | 上游事实源 | PRD职责 |
|---|---|---|
| 主线 NPC、场景、对白、选项、旗标与汇流 | [`20_0.1主线任务详细剧本_草案.md`](../0.1策划草案/20_0.1主线任务详细剧本_草案.md) | 状态、交互、异常与验收 |
| 支线 NPC、节点、不可逆选择与奖励 | [`21_0.1支线任务详细剧本_草案.md`](../0.1策划草案/21_0.1支线任务详细剧本_草案.md) | 可见性、结算与恢复 |
| 地图对象、坐标、首次奖励、商店与回访 | [`22_0.1四图固定对象与经济清单_草案.md`](../0.1策划草案/22_0.1四图固定对象与经济清单_草案.md) | 跨表引用和幂等验收 |
| 数据资产、稳定 ID 规范、任务命令和页面最小集 | [`23_0.1内容依赖与验收矩阵_草案.md`](../0.1策划草案/23_0.1内容依赖与验收矩阵_草案.md) | 产品化约束 |

本 PRD 不复制整段台词、奖励数值或人物小传，也不自行增加 NPC、阵营、任务链或结局。
策划内容变化时先修改对应 0.1 分册，再同步本 PRD；PRD 的交互、异常和验收调整不反向
改写策划。

## 2. 0.1 任务范围

0.1 恰有五条任务链：

| 类型 | 玩家可见名称 | 剧本编辑 ID | 产品稳定 ID |
|---|---|---|---|
| 主线 | 昆吾开山录 | `main_kunwu_opening_record` | `mq_kunwu_01` |
| 支线一 | 岑守一的旧阵簿 | `side_cen_old_ledger` | `sq_01_ledger` |
| 支线二 | 化仙宗遗命 | `side_huaxian_legacy` | `sq_02_huaxian_legacy` |
| 支线三 | 失主的本命元牌 | `side_gui_ling_nameplate` | `sq_03_gui_ling_nameplate` |
| 支线四 | 阴罗宗的五鬼袋 | `side_yinluo_five_ghosts` | `sq_04_yinluo_five_ghosts` |

- 营救、收集、探索、检定、突破和打造是任务节点的目标或命令，不因此生成新的剧情任务链。
- 0.1 不建立独立悬赏、日常、随机任务、职业任务或 60 任务数量目标。
- 支线强敌按精英处理，不新增 Boss；四图始终各有且仅有一个 Boss。
- 主线不能因未做支线或检定失败进入永久失败；支线选择可以不可逆，但必须提前展示后果。
- 剧本编辑 ID 用于追溯原场景，不直接作为存档 ID；产品稳定 ID 按上游实施矩阵格式落库。
  旧 ID `main_001_takeover_camp`不得进入新数据。

## 3. 任务状态与命令

节点状态：

```text
LOCKED → AVAILABLE → ACTIVE → READY_TO_TURN_IN → COMPLETED
                                      └──────────→ FAILED（仅剧本明确放弃的子分支）
```

- 主线不得进入没有恢复路径的 `FAILED`。
- 任务实例必须保存当前链、当前节点、变量、集合、已完成目标和已领取奖励 ID。
- 对话选项只能调用任务命令，不得由 UI 直接修改背包、地图、NPC、战斗或结局真相。
- `StartQuest`、`ChooseDialogueOption`、`InteractMapObject`、`CompleteEncounter`、
  `ClaimQuestReward`、`PerformBreakthrough`和`CraftEquipment`都必须先校验再原子保存。
- 奖励使用稳定 `reward_claim_id`幂等发放；重复点击、刷新和恢复不得重复给予。
- 任务更新由领域事件或任务命令触发，UI 不轮询地图并自行推断完成状态。

## 4. NPC、人物列表与系统解锁

### 4.1 营地人物列表

- 点击议事殿进入营地人物列表。
- 列表只显示已被任务状态或剧情 Flag 解锁、仍存活且当前允许联系的 NPC；未解锁 NPC
  不显示姓名、头像或剪影。
- 新档只显示岑守一。其他人物是否入驻、离营、死亡或仅可传讯，以主支线详细剧本的结果为准。
- 每项显示头像、姓名、营地身份和当前状态；状态至少包括`可交谈`、`有任务`、`可交付`、
  `等待线索`、`暂时离营`。
- 点击 NPC 直接进入对话；对话结束后返回人物列表，并刷新任务、建筑和 NPC 状态。
- UI 不根据章节标题、地图编号或显示名推断 NPC 状态。

### 4.2 解锁映射边界

| 上游剧情结果 | 产品落地 |
|---|---|
| 序章 P0-01 完成 | 解锁议事殿、灵圃、百宝库和当前主线目标 |
| 序章 P0-02 完成 | 固定四人进入第一队，解锁入山整备 |
| 顾南炉救援或剧本规定的替代路径完成 | 解锁炼器坊及对应配方来源 |
| 乌婆被带回或由支线条件解锁 | 解锁乌婆的人物条目与引魂交互；不得自动推断未在策划定义的建筑奖励 |
| 第三章完成 | 解锁地图 4、结丹试炼、第三档装备和储物法器功能 |
| 木青萝满足入驻条件 | 解锁封印研究人物条目与对应配方，不建立独立“阵营代表”系统 |

表中的 `P0-01`、`P0-02` 是上游剧本的序章场景编号，不是产品阶段或需求编号。

交易行、还魂相关功能和七座建筑的功能边界以 PRD-02 为准；其剧情解锁只能绑定上游已有
任务 Flag。PRD 不再使用“招贤人、灵脉管理者、器灵/工匠、阵营代表、净化者”等无上游
人物落点的占位角色，也不建立地图 5污染净化任务。

## 5. 关系变量与结局反馈

0.1 不建立独立的四阵营选择系统。叶家、化仙宗、阴罗宗、山中异类及各 NPC 的关系，
由主支线定义的信任、证据、封印完整度、魔气侵染、入驻状态和选择枚举表达。

- 变量影响可选对白、NPC状态、资源与战斗路径、支援效果和结局评价。
- 所有主线分支最终汇流到同一四图主线和银翅夜叉·尸煞化身战。
- 结局评价使用上游定义，不由 PRD 新增阵营结局或完全分叉主线。
- 每个不可逆选择至少在后续产生一次玩家可感知反馈，不能只写入隐藏 Flag。

## 6. 对话与回看

- 显示角色头像或像素半身、说话人、全文、选项、代价/检定与不可逆标识。
- 普通单句推荐不超过 36 个中文字符，超过时按语义拆页。
- 支持快速显示、跳过文字表现和按场景回看；跳过与回看都不得跳过或重复状态结算。
- 关键选择在确认前显示已知后果；不可逆选择必须二次确认。
- 检定前显示属性、聚合口径、当前值、阈值和失败后果；剧本明确未知时才隐藏结果。
- 对话中的物品、坐标和属性可以点击查看说明。
- 单段不可跳过演出不超过 3 秒；策划明确要求的关键留影可以连续播放，但必须允许后续回看。
- 回看不重新触发检定、奖励、关系变化、战斗或地图状态。

## 7. 任务数据

每条任务链至少定义：

- 稳定任务 ID 与节点 ID。
- 前置条件、开始条件和终止状态。
- 当前目标与可见进度。
- 对话、选项、代价、检定和后继节点引用。
- 完成、失败与恢复条件。
- 奖励及 `reward_claim_id`。
- 建筑、NPC、地图对象、遭遇和故事变量变化。

目标类型是产品配置能力，不代表新增剧情内容。0.1 可按剧本使用：

```text
VISIT_COORD
INTERACT_OBJECT
DEFEAT_ENEMY
DEFEAT_BOSS
COLLECT_ITEM
SUBMIT_ITEM
PASS_CHECK
PROMOTE_CAREER
CRAFT_EQUIPMENT
ASSIGN_WORKER
```

- 所有逻辑 ID 使用英文小写蛇形，不用显示名做判断。
- 授权名与原创替代名只切换本地化文本，不改变任务、人物、物品或存档 ID。
- 任务引用的 NPC、地图对象、道具、敌人、遭遇和奖励必须能跨表解析。

## 9. 验收

- 新档只显示岑守一；未解锁人物无姓名、头像或剪影泄露。
- 主线、四条支线及其节点全部能从上游剧本追溯，不存在 PRD 自创任务链。
- 不做任何支线也能完成四图主线，并在地图 4回答玩家身份、幸存原因和营主权限来源。
- 四条支线各自至少有一个不可逆选择、一个主线汇流反馈和确定性奖励。
- 支线强敌均按精英结算，四图 Boss 数量始终为 4。
- 任务坐标与固定地图对象一致，跨图后任务状态不丢失。
- 任务物品不能出售、误删或因全队阵亡损失；关键物品均有恢复路径。
- 对话可跳过和回看，但状态、检定、奖励与关系变化只结算一次。
- 结丹、任务交付、奖励领取、Boss 首杀和地图解锁保存失败时完整回滚或可安全重试。
- 新档可按任务引导完成地图 1→2→3→4；`map_05`只显示锁定预告，不能进入。

## 10. 不做

- 四套完全独立主线。
- PRD 自行新增人物小传、台词、任务奖励或结局。
- 独立四阵营系统和阵营专属 Boss。
- 现实时间限时主线、随机任务坐标或无限循环日常任务。
- 0.1 范围内的悬赏任务池、随机职业任务或 60 任务数量目标。
- 大量不可交互长过场。
