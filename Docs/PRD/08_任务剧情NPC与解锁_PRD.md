# 《昆吾禁地》PRD 08：任务、剧情、NPC与系统解锁

版本：0.2
日期：2026-07-30
模块：QUEST
负责人：剧情策划、任务策划、客户端

## 1. 模块目标

用任务引导玩家理解建筑、地图、职业和Boss，并通过NPC入驻让营地成长。剧情服务玩法解锁，不制作大量不可交互长演出。

## 2. 任务类型

- 主线：开放地图、阵眼、Boss和结局。
- NPC：营救、护送、寻找法器、入驻。
- 支线：可选Boss、区域故事和专属装备。
- 悬赏：击杀固定敌群或野外Boss。
- 收集：提交资源或材料。
- 探索：发现固定坐标、残碑、传送阵。

## 3. 任务状态

```text
LOCKED
AVAILABLE
ACTIVE
READY_TO_TURN_IN
COMPLETED
FAILED
```

- 主线不允许隐藏永久失败。
- 支线失败必须在选择前提示。
- 普通收集任务不设置现实时间限时。
- 任务更新通过领域事件触发，不由UI轮询地图。

### 4.1 营地人物列表

- 点击大厅城堡（议事殿）进入营地人物列表。
- 列表只显示已经随主线解锁并进入营地的 NPC；未解锁 NPC 不显示姓名、头像或剪影，避免剧透。
- NPC 按主线入驻顺序排列。每项显示头像、姓名、营地身份和当前状态。
- 状态至少包括：`可交谈`、`有任务`、`可交付`、`等待线索`、`暂时离营`。
- 点击 NPC 直接进入对话，不先进入角色详情页。对话结束后返回人物列表，并刷新任务、建筑和 NPC 状态。
- 新档人物列表只有首位留守管事；后续招贤人、炼器师、商人、引魂者等随主线逐步加入。
- NPC 解锁由任务状态或剧情 Flag 驱动，UI 不得根据章节标题自行推断。

### 4.2 首位 NPC：岑守一

| 项目 | 定义 |
|---|---|
| 稳定 ID | `npc_cen_shouyi` |
| 显示名 | 岑守一 |
| 常用称呼 | 岑伯 |
| 营地身份 | 留守管事、旧阵簿保管人 |
| 解锁条件 | 新档创建后默认解锁 |
| 初始位置 | 议事殿 |
| 主要功能 | 新手对话、营地交接、首批建筑解锁、主线提示 |

人物定位：

- 岑守一曾是山外联营负责粮册、阵钥和来客登记的低阶修士。十二年前外围禁制异动，旧营地人员或失踪、或撤离，只有他奉命留下看守营册与残存阵图。
- 他修为不高，左腿因一次封印反噬留下晶化伤痕，无法深入禁地，因此把探索与决策交给玩家，自己承担“管家”式的后勤、交接和提醒职责。
- 性格克制、务实、略显刻薄，不用长篇旁白解释世界观；他习惯用账目、损耗和具体行动提醒玩家危险。
- 表层目标是恢复营地运转；个人线索是查明上一任营地主事在封印异动当夜失踪的原因。该线索只作为后续支线钩子，不在新手阶段展开。

视觉锚点：

- 灰青旧袍、半白鬓发、腰挂一串木质阵钥，手持卷边账簿。
- 左腿衣摆下有低亮度青色晶纹，静止时偶尔微亮，暗示旧伤而非高阶力量。
- 头像表情以审视、无奈、警觉为主，避免仙风道骨的强者形象。

首轮主线职责：

1. `main_001_takeover_camp`：向玩家交付营册与阵图，解锁议事殿、灵圃、百宝库。
2. 引导玩家分配第一批杂役，解释灵粮既是营地维护也是出征补给。
3. 在营地恢复最低运转后给出招贤人的线索，推进招贤台解锁。
4. 提醒玩家外围阵灯熄灭，引出第一次出征，但不替玩家做路线选择。

初次见面对话基调：

> “山门外的灯，熄了十二年。你既接了这方营印，就先看粮册，再看阵图。禁地里的宝物不会跑，营里的人却会饿死。”

设计边界：角色只借用“古山封禁、旧宗遗迹、封印松动、各方来客”这类通用修仙母题，不复刻《凡人修仙传》的具体人物、法宝、组织关系或剧情事件。

## 5. 阵营

四类：

- 破禁世家。
- 正道联军。
- 魔道修士。
- 山中异类。

MVP不制作完全分叉主线。阵营影响：

- NPC是否入驻。
- 商店商品。
- 支线Boss。
- 一件专属装备。
- 结局评价。

主线地图和最终Boss保持同一套，控制内容成本。

## 6. 对话

- 角色头像或像素半身。
- 单句推荐不超过 36 个中文字符。
- 可快速显示、跳过和回看。
- 关键选择二次确认。
- 对话中的物品、坐标和属性可以点击查看说明。
- 单段不可跳过演出不超过 3 秒。

## 10. 验收

- 每个建筑解锁都有明确任务来源。
- 任务坐标与固定地图对象一致。
- 跨图后任务状态不丢失。
- 任务道具不能出售或误删。
- 主线无隐藏永久失败。
- 对话可跳过且不跳过状态结算。
- 新档可按任务引导完成五张地图。
- 新档人物列表只显示岑守一，点击后直接进入对话；其他 NPC 在对应主线完成前不可见。

## 11. 不做

- 四套完全独立主线。
- 大量动态过场动画。
- 现实时间限时主线。
- 随机生成任务坐标。
- 日常任务无限循环。
