# 《昆吾禁地》PRD 08：任务、剧情、NPC与系统解锁

版本：0.1  
模块：QUEST  
负责人：剧情策划、任务策划、客户端

## 1. 模块目标

用任务引导玩家理解建筑、地图、职业和Boss，并通过NPC入驻让营地成长。剧情服务玩法解锁，不制作大量不可交互长演出。

## 2. 任务类型

- 主线：开放地图、阵眼、Boss和结局。
- NPC：营救、护送、寻找法器、入驻。
- 支线：可选Boss、区域故事和专属装备。
- 悬赏：击杀固定敌群或野外Boss。
- 收集：提交资源或材料。
- 探索：发现固定坐标、残碑、传送阵。

## 3. 任务状态

```text
LOCKED
AVAILABLE
ACTIVE
READY_TO_TURN_IN
COMPLETED
FAILED
```

- 主线不允许隐藏永久失败。
- 支线失败必须在选择前提示。
- 普通收集任务不设置现实时间限时。
- 任务更新通过领域事件触发，不由UI轮询地图。

## 4. NPC与建筑解锁

| 事件 | NPC/结果 | 解锁 |
|---|---|---|
| 新手接管营地 | 营地执事 | 议事殿、灵圃、百宝库 |
| 新手招募任务 | 招贤人 | 招贤台 |
| 地图1炼器师救援 | 炼器师 | 炼器坊 |
| 地图1商队事件 | 商人 | 交易行 |
| 地图1残魂事件 | 引魂者 | 还魂坛 |
| 地图2阵眼 | 灵脉管理者 | 灵石岗位 |
| 地图3遗址 | 器灵/工匠 | 重铸、储物法器 |
| 地图4主殿 | 阵营代表 | 高阶任务和阵营 |
| 地图5污染 | 净化者 | 庚精岗位和净化 |

## 5. 阵营

四类：

- 破禁世家。
- 正道联军。
- 魔道修士。
- 山中异类。

MVP不制作完全分叉主线。阵营影响：

- NPC是否入驻。
- 商店商品。
- 支线Boss。
- 一件专属装备。
- 结局评价。

主线地图和最终Boss保持同一套，控制内容成本。

## 6. 对话

- 角色头像或像素半身。
- 单句推荐不超过 36 个中文字符。
- 可快速显示、跳过和回看。
- 关键选择二次确认。
- 对话中的物品、坐标和属性可以点击查看说明。
- 单段不可跳过演出不超过 3 秒。

## 7. 任务数据

任务定义：

- ID。
- 前置条件。
- 接取人。
- 目标列表。
- 完成条件。
- 失败条件。
- 对话。
- 奖励。
- 建筑/NPC/地图状态变化。

目标类型：

```text
VISIT_COORD
INTERACT_OBJECT
DEFEAT_ENEMY
DEFEAT_BOSS
COLLECT_ITEM
SUBMIT_ITEM
PASS_CHECK
RECRUIT_HERO
PROMOTE_CAREER
UPGRADE_BUILDING
```

## 8. 内容规模

| 阶段 | 累计任务 |
|---|---:|
| P1 | 3个灰盒目标 |

## 10. 验收

- 每个建筑解锁都有明确任务来源。
- 任务坐标与固定地图对象一致。
- 跨图后任务状态不丢失。
- 任务道具不能出售或误删。
- 主线无隐藏永久失败。
- 对话可跳过且不跳过状态结算。
- 新档可按任务引导完成五张地图。

## 11. 不做

- 四套完全独立主线。
- 大量动态过场动画。
- 现实时间限时主线。
- 随机生成任务坐标。
- 日常任务无限循环。
