## 2. 1.0 冻结边界

- 只使用石岩、陆清、白灵、墨言四名固定剧情修士，不存在随机修士。
- 招贤馆只解锁建筑和“后续版本开放”说明，不提供候选、刷新、招募、改名、遣散、馆级或容量。
- 修士上限 Lv30，覆盖炼气、筑基、结丹；每个初始职业有两个筑基分支，结丹沿所选分支晋升。
- 装备只启用武器、防具、饰品一、饰品二四槽；装备没有等级。
- 品质顺序为凡品、精制、上品、珍品、法宝、古宝。
- 铁胚直接决定非古宝装备品质；蓝图决定 1 或 2 个器纹槽；器纹写入后永久固定。
- 炼器坊共 24 级，只消耗灵木升级；装备、铁胚、器纹、工具、突破物和永久探索强化均在该页处理。
- `map_01` 至 `map_04` 为正式四图，`map_05` 只显示后续锁定入口。
- 首发资源副本只有 `rd_map03_refire_mine` 与 `rd_map04_soul_echo`，分别主产灵石、魂晶。
- 第 2、4 位主线 Boss 首杀魂魄可交乌婆，固定获得“封坛军魂甲”和“银翅魂衣”。
- 交易行只允许购买，固定为常备栏＋6 格随机栏；不存在玩家出售或回购。
- 每名修士灵息上限 100、营地每 5 分钟恢复 1；扎营每次免费恢复存活修士 35% 最大生命。
- 百宝库装备仓位 100；普通非古宝装备只能在百宝库分解，不能卖给交易行。

## 4. 主导航与返回栈

```text
启动页 → 新档/继续 → 营地大厅
营地大厅 → 各建筑页/固定 HUD 页面 → 原入口位置
营地大厅 → 入山整备 → 野外探索 ↔ 战斗 → 归营结算 → 营地大厅
营地大厅 → 入山整备 → 资源副本 → 战斗 → 副本结算 → 再次挑战/营地大厅
```

- 普通二级页面关闭后回到打开前的营地横滑位置，不把大厅重置到起点。
- 页面内二次确认优先关闭自身；系统返回依次关闭确认层、详情层、主页面。
- 战斗、启程、结算和导入存档等事务中禁止返回绕过权威结算。
- 刷新浏览器后读取唯一有效快照，恢复到安全页面；不得依赖视觉层内存猜测业务状态。

## 5. 页面写法与数值占位

### 5.1 页面章节固定内容

每个页面章节必须包含：

1. 上游事实源与页面边界；
2. 入口、退出和返回栈；
3. 信息架构与可执行动作；
4. 默认、加载、空、禁用、锁定、错误以及该页特有状态；
5. 正常流程、失败反馈、原子保存和刷新恢复；
6. 稳定页面 ID、命令、数据来源和需求编号；
7. Figma 必需稿件、组件状态与评审状态；
8. 美术素材引用、复用要求和缺口；
9. 可由用户执行的验收条件；
10. 明确不做项。

### 5.2 数值与配置规则

- 1.0 已启用的成本、产量、概率、倍率、持续时间、资源包和商店数值已从数值分册同步到对应页面。
- 页面只复制玩家需要预览、确认或验收的关键值；完整调参表仍以数值分册和版本化数据表为事实源。
- UI 与服务必须读取同一版本配置；配置缺失时禁用操作并显示“数据未配置”，不得用 0 或临时值继续。
- 后续境界版本尚未投放的辅材/配方可以显示“未开放”，但不属于 1.0 可执行数值占位。

## 6. 画布、布局与输入

- 玩家可见窗口和设计基准唯一为 `375×817`；营地横滑逻辑宽 `1050`。
- Safe Area、固定区、滚动区、Mask、遮罩与触控热区必须在设计稿分层标注。
- 可见按钮不足 `48×48` 逻辑触控区时，用透明热区扩展且不得与邻项重叠。
- 点击、拖动、长按必须有阈值与反馈；模态打开时底层不可穿透。
- 系统返回优先关闭最上层临时状态，不跳过确认和权威结算。
- 横屏显示转回竖屏提示；720×1280、1080×1920 等设备只做适配验收，不改变设计基准。

## 7. 通用页面状态

每页必须按实际业务交付下列状态，确实不适用时在页面 PRD 明确说明：

| 状态 | 通用要求 |
|---|---|
| `default` | 权威数据完整、主操作清晰 |
| `pressed/selected` | 有视觉与非颜色反馈，不改变业务结果 |
| `loading` | 防重复提交；列表加载与事务提交分开表达 |
| `empty` | 解释为何为空并给合法下一步，不放假数据 |
| `disabled` | 显示具体原因；仍可查看必要成本/条件 |
| `locked` | 显示解锁来源；与临时禁用视觉不同 |
| `error` | 显示错误类别、重试/返回/导出等可执行动作 |
| `offline` | 本地可继续时降级，不可继续时指出缺失资源 |
| `conflict` | 刷新权威数据并保留可安全保留的用户输入 |
| `success` | 只在保存成功后出现，不以动画完成代替事务完成 |

## 8. 反馈、文案与可访问性

- 资源不足同时显示当前值、所需值和合法来源；数据缺失显示“数据未配置”，不用“资源不足”掩盖。
- 错误文案面向玩家说明影响和下一步；技术错误码可折叠显示以便反馈。
- 品质、阵亡、锁定、成功、危险等状态不能只用颜色区分，必须配文字、图形或纹样。
- 动态文本支持长名字、长任务、四位以上数值和本地化扩展；关键按钮不得省略成含糊省略号。
- 所有正文、数字、价格、倒计时和条件由 Label/本地化渲染，不烘焙进 PNG。
- 减少屏幕震动开启时关闭非必要震屏，并用其他反馈补足命中/警告语义。

## 9. 异步、原子性与幂等

正式项目调用链固定为：

```text
Presenter → Application Service → API Port
          → Local Adapter / HTTP Adapter
          → Response → GameState/保存/事件 → Presenter 刷新
```

- Presenter 不直接 `fetch`、拼 DTO 或修改权威业务状态。
- Local Adapter 与 HTTP Adapter 实现同一异步接口，并能表达成功、业务失败、超时、断网和冲突。
- 战斗始终保持 `CombatCommand → 结算器 → CombatEvent → 表现层`，表现层不反向决定领域结果。
- 任何扣除/产出操作都有操作 ID；重复提交返回第一次结果。
- 事务失败恢复提交前状态，不能出现扣款成功但产出失败等半状态。
- 页面离开或浏览器刷新不取消已经提交的权威事务；重进后查询结果再决定表现。
- 随机结果在服务层生成并持久化，显示前刷新不能重抽。

## 10. 保存与刷新恢复矩阵

| 场景 | 必须恢复的权威状态 |
|---|---|
| 营地子页 | 来源页、选中对象、已完成事务结果 |
| 整备提交 | 唯一出征快照或未扣除的草稿 |
| 野外移动 | 最后保存坐标、灵粮、负重、对象与事件游标 |
| 战斗 | CombatSnapshot、命令序号和事件游标 |
| 结算 | 同一 run/expedition 的幂等结算记录 |
| 开包/交易/打造/分解 | 完整扣除与产出，不存在中间态 |
| 对话/任务 | 已提交选项、Flag、奖励和下一节点 |
| 导入存档 | 原档完整保留或新档完整生效 |

## 11. 数据与稳定 ID

- 逻辑 ID 使用英文小写蛇形；显示名、本地化名和授权名不参与逻辑判断。
- 七维键固定为 `strength magic technique speed constitution armor resistance`。
- 页面不硬编码数值；成本、概率、倍率、数量、时长和掉率读取版本化数据表。
- 冻结值从版本化配置读取；配置缺失使相关动作禁用并产生可定位错误。
- 地图、敌人、技能、装备、配方、任务、对话和奖励均能追溯到上游分册与 `V10` 需求。

## 12. Figma 交付门禁

每个页面实现前至少提供：

1. 页面流程与返回栈；
2. 默认、加载、空、禁用、锁定、错误和页面特有状态；
3. Component/Variant 状态表与主题 Variable；
4. 动态文本、长数字、安全区和小视窗压力稿；
5. 资源导出表，含逻辑尺寸、PNG 实际尺寸、九宫格/Mask/Tint 说明；
6. Figma 节点到 Cocos Scene/Prefab/节点映射；
7. `Draft → Review → Approved` 评审记录。

只有 `Approved` 节点可实现。当前 `Panel Item V2` 是唯一已明确批准的通用组件，其他稿件均需评审。

## 13. 美术交付门禁

- 先查 [ArtAssets 复用基线](../ArtAssets/README.md)，能用九宫格、Tint、Mask、Label 或组合节点时不画近似图。
- 每个资产登记稳定文件名、用途、透明规则、逻辑尺寸、@3x 交付尺寸、来源/许可和状态。
- Pixel Art 整数对齐、整数倍缩放、nearest；不使用模糊插值。
- 第三方素材只能进入规定目录并保留来源、许可快照和哈希。
- 新资源交由 Cocos Creator 导入并分配 UUID，禁止手写 `.meta`。
- 动画/特效说明触发事件、帧数/时长、锚点、循环和性能降级方案。

## 14. 页面级验收矩阵

每页至少由用户人工覆盖：

- 默认主流程一次；
- 空、锁定、禁用和配置缺失；
- 余额/容量刚好足够与刚好不足；
- 主按钮快速连点；
- 提交超时、业务失败、断网、冲突和保存失败；
- 提交前、提交中、保存后切场景前刷新；
- 375×817 及目标设备安全区、长文本和长数字；
- Approved Figma 对照和 PNG nearest/九宫格检查。

具体测试命令与构建门禁不由本 PRD 擅自执行；执行按仓库约定和用户授权。
