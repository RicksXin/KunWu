## 1. 模块目标与范围

0.1 使用石岩、陆清、白灵、墨言四名固定修士完成炼气至结丹的培养闭环。玩家通过升级、
筑基分支、结丹精通、装备和技能策略构建队伍，不通过随机招募替换角色。

本版本范围：

- 四名固定修士。
- 剑修、法修、医修、潜修四个炼气职业。
- 每个初始职业两个筑基分支，共八条路线。
- Lv1–30，覆盖炼气、筑基、结丹。
- 六档灵根资质及其初始七维、升级成长倍率。
- 每个修士固定三个当前主动技能。
- 单人阵亡、还魂与刷新恢复。

本版本不开放：

- 招贤台和随机招募；已有建筑入口显示“试玩版本暂未开放”，不得生成候选或扣除资源。
- 符修、体修及其转职路线。
- 元婴及以上境界。
- 洗髓、废功重修、自由切换职业和自由技能池。
- 解雇固定四人、角色碎片升星和修士交易。
- 职业天赋系统和付费调息。

## 2. 修士实例与状态

每名固定修士的运行实例至少包含：

- 稳定实例 ID、显示名和当前形象引用。
- 稳定 `spiritualRootId`。
- 当前职业阶段、职业成长历史和稳定 `realmId`。
- 等级、当前经验货币消耗状态和突破完成态。
- 基础、成长、装备、状态及最终七维。
- 当前三个技能 ID、技能熟练境界和自动策略。
- 当前装备关系。
- 当前/最大生命、灵息和阵亡状态。

战力是最终七维合计形成的派生值，不写入存档。页面不得另存或另算一份战力公式。

## 3. 固定修士

| 修士 | 初始职业 | 灵根资质 | 开局职责 | 筑基分支 |
|---|---|---|---|---|
| 石岩 | 剑修 | 伪灵根 | 引敌、承伤、稳定物理输出 | 护山剑卫 / 御剑修 |
| 陆清 | 法修 | 伪灵根 | 法术输出、群体清场、群体恢复 | 雷法师 / 玄冰师 |
| 白灵 | 医修 | 伪灵根 | 法术输出、群体恢复 | 丹医 / 毒丹师 |
| 墨言 | 潜修 | 杂灵根 | 单体收割、弱点发现、机关处理 | 绝影客 / 探秘使 |

- 新档直接获得四人，不经过招募页面。
- 四人全部进入名册，首次解锁入山整备时进入第 1 队。
- 固定四人不可解雇、出售或永久删除。
- 职业分支改变武器、服装轮廓、配色和战斗表现，不改变修士姓名与个体身份。

## 4. 灵根资质

灵根资质只表示成长资质，不表示职业、境界、装备品质、阵营或职业分支背景。

| 灵根资质 | `spiritualRootId` | Lv1 初始七维倍率 | 升级成长倍率 |
|---|---|---:|---:|
| 杂灵根 | `mixed_root` | 100% | 100% |
| 伪灵根 | `pseudo_root` | 108% | 110% |
| 三灵根 | `triple_root` | 116% | 122% |
| 双灵根 | `dual_root` | 124% | 136% |
| 天灵根 | `heavenly_root` | 133% | 152% |
| 异灵根 | `variant_root` | 152% | 190% |

计算口径：

```text
Lv1 最终基础属性
= floor(职业 Lv1 裸属性 × 初始七维倍率 / 100)

某职业成长段累计属性
= floor(该段升级次数 × 职业成长率 × 升级成长倍率 / 1000 / 100)
```

- 七维逐项计算并向下取整。
- 转职后的历史等级必须保留当时职业成长段，不得用当前职业成长率回算旧等级。
- 灵根不改变技能数量、技能 ID、装备资格或剧情变量。
- 墨言使用杂灵根也必须能够通过合理培养完成全部主线。
- UI 同时显示资质文字和非颜色唯一的边框纹样；异灵根不使用魔道专属暗红、血色或紫黑。

## 5. 灵息

- 每名修士灵息上限为 100。
- 灵息是否恢复只取决于该修士当前是否在营地。
- 修士在营地时每 300 秒恢复 1 点，最多恢复至 100；游戏在前台、后台或完全离线均按
  实际经过的 UTC 时间结算。
- 修士入山后停止恢复。关闭游戏时若仍存在有效入山状态，出战修士离线期间也不恢复。
- 归营或全队阵亡返回营地后，以返回时刻重新建立恢复锚点；野外经过的时间不补算。
- 启程时按地图配置立即扣除每名出战修士的灵息。任一出战修士不足时禁止启程，并指出
  具体修士和所需灵息。
- 地图加载失败时回滚本次灵息扣除和恢复锚点。
- 主线章节奖励的“全队调息”按策划配置直接恢复，不使用付费货币。

## 6. 境界、职业阶段与技能

修士个体、职业阶段和修炼境界是三个不同概念：

| 概念 | 决定内容 |
|---|---|
| 修士个体 | 姓名、灵根、基础形象、成长记录和存档身份 |
| 职业阶段 | 当前职责、成长率、武器适配、形象轮廓和三个技能 |
| 修炼境界 | 当前等级区间、突破门槛和属性上限 |

| 境界 | `realmId` | 等级 | 产品规则 |
|---|---|---:|---|
| 炼气 | `lian_qi` | 1–10 | 使用初始职业和三个过渡技能 |
| 筑基 | `zhu_ji` | 11–20 | Lv10 完成试炼后二选一，整体替换为分支三个核心技能 |
| 结丹 | `jie_dan` | 21–30 | 沿筑基分支晋升；技能 ID 不变，进入`【精通】`数值 |

职业阶段：

| 炼气 | 筑基 A → 结丹称号 | 筑基 B → 结丹称号 |
|---|---|---|
| 剑修 | 护山剑卫 → 玄甲剑卫 | 御剑修 → 御剑师 |
| 法修 | 雷法师 → 御雷师 | 玄冰师 → 凝霜师 |
| 医修 | 丹医 → 灵药师 | 毒丹师 → 炼毒师 |
| 潜修 | 绝影客 → 影刃使 | 探秘使 → 寻踪师 |

- 每名修士在任何时刻恰好拥有三个主动技能。
- 炼气进入筑基时替换三个技能 ID；旧技能不进入自由技能池。
- 筑基进入结丹时不更换技能 ID，只提高倍率、持续时间、状态强度等熟练数值，并在显示名
  前增加`【精通】`。
- 结丹职业名是既有筑基分支的进阶称号，不代表创建第二套技能节点。
- 技能 ID、目标、数值、状态和自动策略以 0.1 技能策划分册为准，PRD 不另写一套。

职业分支可通过故事背景、服装、武器、轮廓、配色和特效表达正邪倾向，但产品数据中不建立
独立“道途标签”，不得仅根据“正道、旁门、魔道、中立”等背景词改变数值、阵营、任务结果、
转职资格或 `demonic_taint`。剧情变量只由玩家实际完成的剧情选择改变。

## 7. 升级与突破交互

### 7.1 普通升级

- 升级消耗、逐级成本和成长率读取 0.1 成长数值分册对应数据。
- 达到 Lv10 或 Lv20 后可以继续获得魂晶，但完成对应突破前不能进入下一等级。
- 突破消耗与 Lv10→11、Lv20→21 的升级费用分开展示，并在同一原子操作中结算。

### 7.2 筑基

筑基页必须同时展示：

- 当前修士、职业、境界和七维。
- 两个职业分支的背景、修士形象预览和职责差异。
- 两组技能的名称、目标、倍率来源、状态与自动策略摘要。
- 两条成长率及突破后预估七维。
- 武器适配、试炼、信物、材料和魂晶。
- “本试玩版本不能洗髓回退”的明确提示。

页面不显示或保存独立道途标签。确认后统一校验等级、试炼、信物、材料、魂晶和当前状态；
成功时原子完成扣除、追加职业成长段、更新职业阶段、替换三个技能、重算属性和保存。任一步
失败均不得扣除部分资源或改变职业。

### 7.3 结丹

结丹页只展示：

- 进阶职业称号、个人试炼和全部消耗。
- 结丹一次性七维、后续成长和 Lv20→21 结果。
- 原三个筑基技能进入`【精通】`后的数值差异。
- 形象与装备适配变化。

成功时保持三个 `skillId` 不变，更新职业阶段、`realmId`、技能熟练境界、一次性属性、
成长记录和等级，并原子保存。

## 8. 七维与战力展示

| 属性 | 战斗作用 | 探索作用 |
|---|---|---|
| 力道 | 物理技能、负重 | 破门、搬运、强行破坏 |
| 法力 | 法术、治疗、护盾 | 灵脉感应、维持阵法 |
| 神识 | 技能命中、暴击和部分职业技能 | 识别机关、陷阱与禁制 |
| 遁速 | 行动间隔、部分闪避 | 追踪、逃脱、限时事件 |
| 肉身 | 生命上限 | 抵御毒雾、严寒和体力消耗 |
| 护体 | 物理减伤 | 抵御实体伤害 |
| 定力 | 法术减伤和异常抵抗 | 抵御禁制、幻术与魔气侵蚀 |

- 属性详情必须拆分显示基础、成长、装备、状态和最终值。
- 战力等于最终七维合计；生命、命中、暴击、治疗、负重和装备特效不进入战力。
- 战力只用于比较和推荐，不代替技能、装备特效、境界或 Boss 机制门槛。

## 9. 单人阵亡与还魂

- 修士生命降至 0 后进入阵亡状态并保存。
- 阵亡修士立即从可出战名单中排除，不能编队、启程或参加突破试炼。
- 阵亡修士进入还魂殿待处理；大厅对应入口显示强提示。
- 还魂后恢复为可用状态，并保留原等级、境界、职业阶段、三个技能、技能熟练境界、装备、
  灵根和全部成长记录。
- 还魂不得复制装备、重复突破奖励或重置职业选择。
- 单人阵亡不等于全队阵亡；只要本次入山仍有存活修士，就不触发全队阵亡结算。
- 固定四人不能解雇，阵亡也不会从名册中永久删除。

全队阵亡时的野外物品损失、归营和入山状态清理归地图与物品 PRD 负责，本模块只负责修士
阵亡状态和还魂后的培养数据保持。

## 10. 页面与异常反馈

修士详情页至少展示：

- 姓名、当前形象、灵根资质、境界、等级、职业阶段和战力。
- 当前/最大生命、灵息及恢复状态。
- 七维来源拆分。
- 三技能、熟练境界和自动策略。
- 四槽装备摘要。
- 当前突破条件或阵亡/还魂状态。

异常反馈：

- 灵息不足：指出具体修士、当前值和地图需求。
- 等级已到境界上限：指出待完成试炼与缺少材料。
- 突破条件不足：逐项列出，不允许只显示“条件不足”。
- 保存失败：保留操作前状态和全部资源，允许重试。
- 招贤台入口：固定显示“试玩版本暂未开放”，不打开空候选页。
- 高于结丹的境界入口：不展示；不得显示可点击但无内容的占位。

## 12. 验收

- 新档名册始终只有石岩、陆清、白灵、墨言四名固定修士；招贤台不产生候选或资源消费。
- 石岩、陆清、白灵为伪灵根，墨言为杂灵根；相同职业裸值使用表中倍率可复算出一致七维。
- 灵根倍率同时作用于 Lv1 初始七维和每次升级成长，且不改变任何技能 ID。
- 修士在营地时在线与离线恢复结果相同；在有效入山状态中经过相同时间不恢复灵息。
- 筑基后三个技能全部替换；结丹前后三个技能 ID 完全相同，只改变熟练境界和数值。
- 职业分支背景和形象变化不会自动改变 `demonic_taint`、阵营或任务结果。
- 单人阵亡不会误触发全队阵亡；阵亡修士不能编队，还魂后培养数据与装备不丢失、不复制。
- 所有升级、筑基、结丹、还魂和灵息扣除在保存失败时不会留下部分结果。
- 刷新页面后恢复正确的灵根、等级、境界、职业阶段、技能 ID、熟练境界、装备、灵息和阵亡状态。

## 13. 当前不做

- 随机招募、招贤刷新和修士容量升级。
- 符修、体修。
- 元婴至大乘职业树。
- 洗髓、废功重修和自由技能池。
- 解雇固定修士。
- 职业天赋、角色碎片和付费培养。
- 玩家间修士交易。
