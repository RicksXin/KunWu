## 1. 模块目标与范围

1.0 以石岩、陆清、白灵、墨言四名固定修士承载剧情，同时开放招贤馆补充随机修士。玩家可用
随机修士替换实际出战成员，并通过升级、筑基分支、结丹精通、装备和技能策略构建队伍；
固定四人的剧情身份、台词和任务状态不因是否出战而改变。

招贤馆和随机修士是1.0的可选队伍扩展，不是前四章通关门槛。主线任务、四个主线Boss和结局
不得要求玩家招募、培养或上阵第五、第六名修士；只培养固定四人且完全不挑战两座资源副本时，
仍须拥有完整的主线成长资源与可执行通关路径。两座首发资源副本只为可选新修士追赶、追加打造和
通关后成长提供主动重复收益。

本版本范围：

- 四名固定修士。
- 招贤馆随机修士、每批3名候选、整点/付费刷新、招募、改名与随机修士遣散。
- 金刚禅修、五行法修、玄箓修、剑修四个炼气职业。
- 每个初始职业两个筑基分支，共八条路线。
- Lv1–30，覆盖炼气、筑基、结丹。
- 六档灵根资质及其初始七维、升级成长倍率。
- 每个修士固定三个当前主动技能。
- 单人阵亡、还魂与刷新恢复。

本版本不开放：

- 当前四职业之外的新职业及其转职路线。
- 招贤馆10–24级及其元婴以上权限。
- 元婴及以上境界。
- 洗髓、废功重修、自由切换职业和自由技能池。
- 解雇固定四人、角色碎片升星和修士交易。
- 职业天赋系统和付费调息。

## 2. 修士实例与状态

每名修士的运行实例至少包含：

- 稳定实例 ID、固定/随机来源、显示名、初始姓名和当前形象模板引用。
- 稳定 `spiritualRootId`。
- 当前职业阶段、职业成长历史和稳定 `realmId`。
- 等级、当前经验货币消耗状态和突破完成态。
- 基础、成长、装备、状态及最终七维。
- 当前三个技能 ID、技能熟练境界和自动策略。
- 当前装备关系。
- 当前/最大生命、灵息和阵亡状态。
- 随机修士的招募批次、免费改名是否已使用、累计升级魂晶和历次突破实际道具成本。

战力是最终七维合计形成的派生值，不写入存档。页面不得另存或另算一份战力公式。

## 3. 固定修士

| 修士 | 初始职业 | 灵根资质 | 开局职责 | 筑基分支 |
|---|---|---|---|---|
| 石岩 | 金刚禅修 | 伪灵根 | 群体嘲讽、承伤、降伤 | 护法金身 / 魔相力士 |
| 陆清 | 五行法修 | 伪灵根 | 法术输出、中低群体恢复、技巧增益 | 雷法术式 / 蜃景幻法 |
| 白灵 | 玄箓修 | 伪灵根 | 符宝攻击、恢复、定力增益 | 镇幽符脉 / 万象符脉 |
| 墨言 | 剑修 | 杂灵根 | 飞剑或重剑物理输出 | 青冥剑修 / 玄岳剑修 |

- 新档直接获得四人，不经过招募页面。
- 四人全部进入名册，首次解锁入山整备时进入第 1 队。
- 固定四人不可解雇、出售或永久删除。
- 职业分支改变武器、服装轮廓、配色和战斗表现，不改变修士姓名与个体身份。

### 3.1 招贤馆候选

招贤馆开放后，每批固定显示3名候选，职业允许重复。候选按上游固定顺序生成：

```text
职业 → 形象属性模板 → 灵根 → 七维小幅随机 → 姓名与形象实例
```

- 每职业有两个分支倾向优秀模板和一个平庸模板；初始权重约`15% / 15% / 70%`，高馆级
  最多改善至约`20% / 20% / 60%`。
- 模板与灵根必须分两次独立抽取。杂灵根在所有馆级始终高于`90%`，异灵根始终低于
  `0.5%`；天灵根和异灵根都可出现。
- 模板确定Lv1七维基础轮廓，随后逐维小幅随机；灵根再按§4倍率同时影响Lv1七维与升级成长。
- 候选卡完整展示职业、形象、姓名、灵根、Lv1七维和成长预览，不显示内部模板名称、优秀/平庸
  标签或“坑”提示。
- 姓名、形象允许复用具名任务修士，也允许随机修士之间重复；每个候选和已招募修士仍有独立实例ID，
  不继承同名NPC的关系、任务或剧情状态。

逐馆级精确权重和七维随机幅度读取数据表；在经济数值冻结前不得由客户端自行插值。

### 3.2 刷新、招募与改名

- 每个自然整点自动生成新批次，每日24批；离线正常计时，但只保留玩家当前进入时所属小时的
  批次，不堆叠或补领离线期间的旧候选。
- 支付灵石可立即替换全部3名候选，但不改变`nextFreeRefreshAtUtc`。达到配置的临近整点阈值时，
  付费确认弹窗必须显示剩余时间并警告当前新批次也会在整点被替换。
- 候选不可锁定、不可找回。换批后旧候选立即失效；即使保存失败或重复点击，也不能同时存在
  两个当前批次或重复扣刷新费。
- 招募费按候选灵根六档读取，灵根越好费用越高；职业、模板、姓名和形象不改变价格。
- 招募成功后创建炼气`Lv1`修士实例、从当前批次移除目标候选并保留其余候选。名册已满、候选
  已失效或灵石不足时不得扣费。
- 招募确认页允许免费改名一次；跳过后视为已放弃本次免费机会。进入名册后的再次改名消耗少量
  灵石，且只改变显示名。

招贤馆馆级、名册容量、等级上限、境界权限与灵木升级交互由PRD-02负责；候选生成、修士实例和
招募事务由本PRD负责。馆级变更不重抽当前候选，新的概率仅从下一批开始生效。

### 3.3 随机修士遣散

- 固定四人不可遣散；只有随机修士显示遣散入口。
- 野外、副本挑战、任务锁定、阵亡待还魂或存档异常中的修士不可遣散，并显示具体占用原因。
- 二次确认必须列出退回仓库的装备、返还的全部历次突破道具、累计升级魂晶的`80%`返还值，
  以及明确不返还的刷新费、招募费、改名费和突破灵石。
- 魂晶返还按该修士累计实际升级消耗汇总后乘`80%`并向下取整；不得按当前等级重新套用可能已
  变更的成本表倒算。
- 确认后原子退装、返还道具与魂晶、清理编队/预设引用并删除实例。仓库容量不足或保存失败时
  整笔回滚，不得只删角色或只发返还。

## 4. 灵根资质

灵根资质只表示成长资质，不表示职业、境界、装备品质、阵营或职业分支背景。

| 灵根资质 | `spiritualRootId` | Lv1 初始七维倍率 | 升级成长倍率 |
|---|---|---:|---:|
| 杂灵根 | `mixed_root` | 100% | 100% |
| 伪灵根 | `pseudo_root` | 108% | 110% |
| 三灵根 | `triple_root` | 116% | 122% |
| 双灵根 | `dual_root` | 124% | 136% |
| 天灵根 | `heavenly_root` | 133% | 152% |
| 异灵根 | `variant_root` | 152% | 190% |

计算口径：

```text
Lv1 最终基础属性
= floor(职业 Lv1 裸属性 × 初始七维倍率 / 100)

某职业成长段累计属性
= floor(该段升级次数 × 职业成长率 × 升级成长倍率 / 1000 / 100)
```

- 七维逐项计算并向下取整。
- 转职后的历史等级必须保留当时职业成长段，不得用当前职业成长率回算旧等级。
- 灵根不改变技能数量、技能 ID、装备资格或剧情变量。
- 墨言使用杂灵根也必须能够通过合理培养完成全部主线。
- UI 同时显示资质文字和非颜色唯一的边框纹样；异灵根不使用魔道专属暗红、血色或紫黑。

## 5. 灵息

- 每名修士灵息上限为 100。
- 灵息是否恢复只取决于该修士当前是否在营地。
- 修士在营地时每 300 秒恢复 1 点，最多恢复至 100；游戏在前台、后台或完全离线均按
  实际经过的 UTC 时间结算。
- 修士入山后停止恢复。关闭游戏时若仍存在有效入山状态，出战修士离线期间也不恢复。
- 归营或全队阵亡返回营地后，以返回时刻重新建立恢复锚点；野外经过的时间不补算。
- 启程时按地图配置立即扣除每名出战修士的灵息。任一出战修士不足时禁止启程，并指出
  具体修士和所需灵息。
- 地图加载失败时回滚本次灵息扣除和恢复锚点。
- 主线章节奖励的“全队调息”按策划配置直接恢复，不使用付费货币。

## 6. 境界、职业阶段与技能

修士个体、职业阶段和修炼境界是三个不同概念：

| 概念 | 决定内容 |
|---|---|
| 修士个体 | 姓名、灵根、基础形象、成长记录和存档身份 |
| 职业阶段 | 当前职责、成长率、武器适配、形象轮廓和三个技能 |
| 修炼境界 | 当前等级区间、突破门槛和属性上限 |

| 境界 | `realmId` | 等级 | 产品规则 |
|---|---|---:|---|
| 炼气 | `lian_qi` | 1–10 | 使用初始职业和三个过渡技能 |
| 筑基 | `zhu_ji` | 11–20 | Lv10 完成试炼后二选一，整体替换为分支三个核心技能 |
| 结丹 | `jie_dan` | 21–30 | 沿筑基分支晋升；技能 ID 不变，进入`【精通】`数值 |

职业阶段：

| 炼气 | 筑基 A → 结丹称号 | 筑基 B → 结丹称号 |
|---|---|---|
| 金刚禅修 | 护法金身 → 不动金刚 | 魔相力士 → 三相魔君 |
| 五行法修 | 雷法术式 → 九霄雷君 | 蜃景幻法 → 蜃梦玄君 |
| 玄箓修 | 镇幽符脉 → 镇魂符君 | 万象符脉 → 天元符君 |
| 剑修 | 青冥剑修 → 青冥剑君 | 玄岳剑修 → 玄岳剑君 |

- 每名修士在任何时刻恰好拥有三个主动技能。
- 炼气进入筑基时替换三个技能 ID；旧技能不进入自由技能池。
- 筑基进入结丹时不更换技能 ID，只提高倍率、持续时间、状态强度等熟练数值，并在显示名
  前增加`【精通】`。
- 结丹职业名是既有筑基分支的进阶称号，不代表创建第二套技能节点。
- 技能 ID、目标、数值、状态和自动策略以 1.0 技能策划分册为准，PRD 不另写一套。
- 护法金身是常驻嘲讽防护分支；魔相力士放弃嘲讽，改为高肉身自恢复输出。
- 镇幽符脉提供中上群体恢复；万象符脉只提供中高单体恢复，但可召唤限时嘲讽符傀。
- 青冥剑修为高速暴击与剑煞 DoT；玄岳剑修为慢速重击、破甲、中低概率眩晕和中等群攻。

职业分支可通过故事背景、服装、武器、轮廓、配色和特效表达正邪倾向，但产品数据中不建立
独立“道途标签”，不得仅根据“正道、旁门、魔道、中立”等背景词改变数值、阵营、任务结果、
转职资格或 `demonic_taint`。剧情变量只由玩家实际完成的剧情选择改变。

## 7. 升级与突破交互

### 7.1 普通升级

- 升级消耗、逐级成本和成长率读取 1.0 成长数值分册对应数据。
- 达到 Lv10 或 Lv20 后可以继续获得魂晶，但完成对应突破前不能进入下一等级。
- 境界突破消耗灵石及结丹道具；Lv10→11、Lv20→21 的普通升级仍消耗魂晶。两类成本分开展示，
  并在同一原子操作中结算。

### 7.2 筑基

筑基页必须同时展示：

- 当前修士、职业、境界和七维。
- 两个职业分支的背景、修士形象预览和职责差异。
- 两组技能的名称、目标、倍率来源、状态与自动策略摘要。
- 两条成长率及突破后预估七维。
- 武器适配、试炼完成状态，以及唯一突破成本“灵石300”。筑基页不显示丹药、信物或材料栏。
- “本正式版本不能洗髓回退”的明确提示。
- 选择魔相力士时明确提示“队伍将失去石岩的常驻嘲讽”；若白灵同时选择万象符脉，则
  进一步提示“队伍仅剩限时符傀承伤与单体恢复”，但不得阻止确认。

页面不显示或保存独立道途标签。确认后统一校验等级、试炼、灵石和当前状态；
成功时原子扣除灵石300，追加职业成长段、更新职业阶段、替换三个技能、重算属性和保存。任一步
失败均不得扣除部分资源或改变职业。

### 7.3 结丹

结丹页只展示：

- 进阶职业称号、个人试炼，以及灵石1200、降尘丹1的突破消耗。
- 结丹一次性七维、后续成长和 Lv20→21 结果。
- 原三个筑基技能进入`【精通】`后的数值差异。
- 形象与装备适配变化。

降尘丹不足时显示炼器坊配方所需的凝丹灵草1、灵晶15，并提供“前往炼器坊”按钮；不得用灵石
直接替代降尘丹。成功时原子扣除灵石1200与降尘丹1，保持三个 `skillId` 不变，更新职业阶段、
`realmId`、技能熟练境界、一次性属性、成长记录和等级，并原子保存。

上游“借阵结丹”节点可以配置每人灵石减免300；结丹页必须同时显示基础成本、剧情减免和实际扣除。
任何剧情分支都不能减免、替代或返还降尘丹。

## 8. 七维与战力展示

| 属性 | 战斗作用 | 探索作用 |
|---|---|---|
| 力道 | 物理技能、负重 | 破门、搬运、强行破坏 |
| 法力 | 法术、治疗、护盾 | 灵脉感应、维持阵法 |
| 神识 | 技能命中、暴击和部分职业技能 | 识别机关、陷阱与禁制 |
| 遁速 | 行动间隔、部分闪避 | 追踪、逃脱、限时事件 |
| 肉身 | 生命上限 | 抵御毒雾、严寒和体力消耗 |
| 护体 | 物理减伤 | 抵御实体伤害 |
| 定力 | 法术减伤和异常抵抗 | 抵御禁制、幻术与魔气侵蚀 |

- 属性详情必须拆分显示基础、成长、装备、状态和最终值。
- 战力等于最终七维合计；生命、命中、暴击、治疗、负重和装备特效不进入战力。
- 战力只用于比较和推荐，不代替技能、装备特效、境界或 Boss 机制门槛。

## 9. 单人阵亡与还魂

- 修士生命降至 0 后进入阵亡状态并保存。
- 阵亡修士立即从可出战名单中排除，不能编队、启程或参加突破试炼。
- 阵亡修士进入还魂殿待处理；大厅对应入口显示强提示。
- 还魂确认页只显示配置表中的魂晶消耗；余额不足时禁用确认并显示差额。还魂固定成功，不显示
  降级、资质损失、装备损坏、限时保留或其他惩罚。
- 还魂后恢复为可用状态，并保留原等级、境界、职业阶段、三个技能、技能熟练境界、装备、
  灵根和全部成长记录。
- 还魂不得复制装备、重复突破奖励或重置职业选择。
- 单人阵亡不等于全队阵亡；只要本次入山仍有存活修士，就不触发全队阵亡结算。
- 固定四人不能解雇，阵亡也不会从名册中永久删除。
- 随机修士阵亡后同样先进入还魂流程；阵亡待还魂期间不可通过遣散绕过状态清理。

全队阵亡时的野外物品损失、归营和入山状态清理归地图与物品 PRD 负责，本模块只负责修士
阵亡状态和还魂后的培养数据保持。

## 10. 页面与异常反馈

修士详情页至少展示：

- 姓名、当前形象、灵根资质、境界、等级、职业阶段和战力。
- 当前/最大生命、灵息及恢复状态。
- 七维来源拆分。
- 三技能、熟练境界和自动策略。
- 四槽装备摘要。
- 当前突破条件或阵亡/还魂状态。

异常反馈：

- 灵息不足：指出具体修士、当前值和地图需求。
- 等级已到境界上限：指出待完成试炼与缺少材料。
- 突破条件不足：逐项列出，不允许只显示“条件不足”。
- 保存失败：保留操作前状态和全部资源，允许重试。
- 招贤馆候选未完成加载：显示可重试错误态，不展示旧批次为当前候选，也不允许消费。
- 招贤馆名册已满：允许查看和刷新，但禁用招募并跳转PRD-02的馆级升级或名册整理入口。
- 候选在确认期间跨整点失效：关闭确认页、刷新为当前批次，不扣招募费。
- 高于结丹的境界入口：不展示；不得显示可点击但无内容的占位。

## 12. 验收

- 新档先拥有石岩、陆清、白灵、墨言四名固定修士；招贤馆开放后可增加随机修士，且固定四人
  始终不可遣散、不会因未出战而缺席剧情。
- 完全不招募、培养或上阵其他修士且完全不挑战资源副本时，固定四人仍能获得结丹与完成四图
  主线Boss、结局所需的保底资源；任务、战斗和UI均不显示第五、第六人硬性阻断。
- 使用固定四人可完成两座首发资源副本的基础难度；资源本不能反向要求至少携带一名随机修士。
- 石岩、陆清、白灵为伪灵根，墨言为杂灵根；相同职业裸值使用表中倍率可复算出一致七维。
- 灵根倍率同时作用于 Lv1 初始七维和每次升级成长，且不改变任何技能 ID。
- 修士在营地时在线与离线恢复结果相同；在有效入山状态中经过相同时间不恢复灵息。
- 筑基后三个技能全部替换；结丹前后三个技能 ID 完全相同，只改变熟练境界和数值。
- 筑基材料栏始终为空且只扣灵石300；结丹缺少降尘丹时不能用灵石替代，并可跳转对应炼器坊配方。
- 职业分支背景和形象变化不会自动改变 `demonic_taint`、阵营或任务结果。
- 单人阵亡不会误触发全队阵亡；阵亡修士不能编队，还魂只扣一次魂晶，培养数据与装备不丢失、不复制。
- 所有升级、筑基、结丹、还魂和灵息扣除在保存失败时不会留下部分结果。
- 刷新页面后恢复正确的灵根、等级、境界、职业阶段、技能 ID、熟练境界、装备、灵息和阵亡状态。
- 连续跨整点、离线跨多个整点和整点前付费刷新都只产生一个当前合法批次；付费刷新不重置整点。
- 候选模板与灵根独立抽取；所有馆级杂灵根概率高于90%、异灵根概率低于0.5%，且候选页不暴露模板档次。
- 招募成功只扣一次对应灵根费用并创建炼气Lv1实例；容量满、候选失效、余额不足或保存失败均不扣费。
- 遣散随机修士准确返还装备、全部实际突破道具和累计升级魂晶80%向下取整，不返还任何灵石费用；
  固定四人、被占用修士和阵亡待还魂修士无法遣散。
