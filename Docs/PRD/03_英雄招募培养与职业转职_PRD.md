# 《昆吾禁地》PRD 03：修士、招募、培养与职业转职

版本：0.5  
日期：2026-08-02  
模块：HERO / CAREER  
负责人：系统策划、数值、客户端、角色美术

## 1. 模块目标

玩家通过招募获得不同灵根资质和职业的修士，通过升级、装备和转职构建队伍。随机招募提供变化，但不能成为主线通关门槛。

## 2. 修士数据

运行实例包括：

- 唯一 ID。
- 显示名和外观组合。
- 灵根资质，以及稳定的 `spiritualRootId`。
- 当前职业节点。
- 等级与境界，以及稳定的 `realmId`。
- 七维基础值、成长值和装备加成。
- 当前三个主动技能。
- 职业天赋。
- 装备。
- 灵息、伤势、死亡状态。

### 2.1 灵息

- 灵息满值固定为 100。
- 每张野外大地图定义单次入山灵息消耗；选择地图时校验当前队伍每一名修士。
- 只要任一上阵修士的当前灵息低于地图需求，本次入山即不可开始，并显示明确原因。
- 修士不在野外大地图时，按外置配置的周期与数量自然恢复灵息，最多恢复到 100。
- 启程进入野外时立即停止自然恢复；返回营地时以当时的 UTC 时间重新建立恢复锚点，
  野外经过的时间不补算为灵息恢复。
- “调息”未来可消耗预留高级货币“天符玉”；当前阶段只显示禁用入口，不展示价格，
  不实现购买、充值或立即恢复，也不得误扣灵石。

## 3. 灵根资质

修士资质在玩家显示、领域模型、数据表和存档中统一为六档灵根资质。只允许下表六个
稳定 ID，不再建立第七档，也不得用显示名参与逻辑判断：

| 强度顺序 | `spiritualRootId` | 玩家显示名 | 资质语义 | 主识别色 |
|---:|---|---|---|---|
| 1 | `mixed_root` | 杂灵根 | 五系驳杂，成长最慢但仍可培养 | 灰白 `#B8B3AA` |
| 2 | `pseudo_root` | 伪灵根 | 四系驳杂，略优于杂灵根 | 青绿 `#6FAE73` |
| 3 | `triple_root` | 三灵根 | 三系灵根，成长较稳定 | 湛蓝 `#5C8FD6` |
| 4 | `dual_root` | 双灵根 | 双系灵根，成长较快 | 靛紫 `#8B63C7` |
| 5 | `heavenly_root` | 天灵根 | 单一五行灵根，成长优秀 | 灵金 `#D9B24C` |
| 6 | `variant_root` | 异灵根 | 稀有变异灵根，拥有最高成长档 | 玄青底配青紫虹彩灵纹 |

资质迁移与境界迁移统一归入存档 Schema v5。旧七档兼容值的前五档按强度顺序映射到
前五种灵根，原最高两档统一映射为 `variant_root`；迁移成功后只保存
`spiritualRootId`，旧资质字段不再进入领域模型、新数据或新 UI。

异灵根在本项目中特指极稀有的优质变异灵根，不表达“所有变异灵根都强于天灵根”。
最高档不使用《地下城堡 2》的暗红品质色：暗红、血色和紫黑色专门表达魔道职业、
魔气、血煞与危险状态，避免玩家误解为“异灵根等于魔修”。

灵根资质影响初始七维、成长幅度和潜能，不改变职业技能数量。杂灵根修士必须能通过
合理培养与队伍搭配完成主线，主线不得设置必须拥有高阶灵根修士的硬门槛。灵根资质
只代表成长档，不决定正道、旁门或魔道；魔道归属由筑基时选择的一转分支决定。

## 4. 招贤台

### 候选

- 每批 3 名。
- 每 60 分钟免费刷新。
- 招募后对应栏位为空。
- 刷新网页不能改变候选。
- 自动刷新后手动刷新费用重新计算。

### 手动刷新

- 手动刷新先拉起二次确认，确认后消耗灵石并立即替换本批候选，不改变免费刷新倒计时。
- 同一个免费刷新周期内，每次手动刷新都会提高下一次费用；免费刷新倒计时归零时重置
  费用阶梯。
- 费用阶梯使用外置配置的临时值，本 PRD 不冻结具体数值，后续由统一数值阶段调整。

新手灵粮招募：

- 只在新手阶段开放。
- 只出现杂灵根、伪灵根和三灵根。
- 不与正式高阶灵根概率池混用。

### 招贤台升级

- 提高较高灵根资质概率，但不保证出现指定职业。
- 提高修士容量。
- 提高可培养等级上限。
- 解锁新初始职业池。

## 5. 修士个体、职业与境界的分层

《地下城堡 2》参考表中的“英雄模型”“基础职业”“星阶转职”在本项目中必须拆成三层，
不得再把某名修士直接等同于某个转职职业：

| 层级 | 示例 | 决定内容 |
|---|---|---|
| 修士个体 | 石岩、陆清、白灵、墨言 | 姓名、资质、七维成长、脸和基础身体外观 |
| 职业节点 | 剑修、护山剑卫、御剑修 | 当前三技能、成长权重、武器适配和职业轮廓 |
| 修炼境界 | 炼气、筑基、结丹、元婴等 | 等级阶段、属性上限和世界观中的修为层次 |

石岩是初始职业为“剑修”的修士个体，不是“重装护卫”或“护山剑卫”的固定人物模型；
达到转职条件后，他可以在护山剑卫和御剑修之间选择。其他随机招募修士同理。

职业美术使用“基础身体 + 当前职业轮廓”的组合。性别、年龄、脸型和发式不得锁死
职业；职业识别主要依靠武器、肩部轮廓、袖型、随身法器和主色。转职后角色卡和战斗
形象必须切换到当前职业节点的表现，不得永久沿用初始职业立绘。

### 5.1 六个初始职业

| 职业 | 主要属性 | 基础三技能 |
|---|---|---|
| 剑修 | 力道 | 剑斩、剑意震慑、踏罡突进 |
| 法修 | 法力 | 灵火弹、凝霜护、灵能震荡 |
| 医修 | 法力 | 回春术、清心诀、灵光击 |
| 潜修 | 神识 | 影袭、投刃、烟遁 |
| 符修 | 神识/法力 | 飞符、缚身符、护身符 |
| 体修 | 力道/肉身 | 重拳、护体功、战吼 |

### 5.2 四名固定新手修士

| 修士 | 初始职业 | 开局职责 | 可选择的一转 |
|---|---|---|---|
| 石岩 | 剑修 | 攻守兼备的前排，具备基础引敌和突进 | 护山剑卫 / 御剑修 |
| 陆清 | 法修 | 法术伤害、临时护体和群体震荡 | 雷法师 / 玄冰师 |
| 白灵 | 医修 | 治疗、净化和基础法术攻击 | 丹医 / 毒丹师 |
| 墨言 | 潜修 | 高速单体攻击、投刃和脱身 | 绝影客 / 探秘使 |

这四名修士只用于保证新手队构成，不代表游戏只有四种修士。招贤台完整职业池仍包含
剑修、法修、医修、潜修、符修、体修六个初始职业。

## 6. 职业树：炼气至大乘

### 6.1 阶位与实现边界

参考表中的“初阶—二星—三星—四星—五星—月阶”不再转成另一套职业星级，而是直接
使用修仙境界组织职业树。境界决定等级阶段，职业节点决定当前三技能和战斗职责；两者
仍是两个数据字段，但在职业树 UI 中按同一个突破节点推进：

| `realmId` | 境界列 | 等级范围 | 职业树作用 | 当前阶段 |
|---|---|---:|---|---|
| `lian_qi` | 炼气 | 1–10 | 六个初始职业，提供基础三技能 | 当前实装 |
| `zhu_ji` | 筑基 | 11–20 | 第一次职责分流，三个技能全部替换 | 当前实装；十二分支按阶段交付 |
| `jie_dan` | 结丹 | 21–30 | 延续所选路线并强化核心循环 | 境界与等级实装；高阶职业节点可预留 |
| `yuan_ying` | 元婴 | 31–40 | 补足路线的控制、续航或爆发短板 | 境界与等级实装；高阶职业节点可预留 |
| `hua_shen` | 化神 | 41–50 | 形成完整高阶职业套件 | 境界与等级实装；高阶职业节点可预留 |
| `lian_xu` | 炼虚 | 51–60 | 强化路线独有机制 | 当前实装上限为 `Lv60` |
| `he_ti` | 合体 | 61–70 | 进入终局前的完整道统形态 | Schema 锁定预留，不可进入 |
| `da_cheng` | 大乘 | 71–80 | 同一路线再次二选一，形成终局专精 | Schema 锁定预留，不可进入 |

显示示例为“筑基 · 护山剑卫 · Lv12”，而不是把“筑基”当成护山剑卫的另一个名字。当前
实现尚未提供结丹以后的职业节点时，修士可以提升境界但继续保留已选的一转职业；只有
对应高阶节点正式实装后，突破才替换职业名称和三技能。

规则：

- 达到炼气 10 级上限并完成筑基试炼后选择一转分支，确认后开放筑基阶段等级。
- 筑基和大乘是分支选择点；结丹至合体沿已选路线线性晋升。
- 每个职业节点始终恰好拥有三个主动技能，高阶名称预留不等于技能已经完成设计。
- 筑基一转消耗对应职业信物；结丹至合体消耗通用魂晶、突破材料并完成职业试炼。
- 大乘专精消耗对应专精信物。主线首次所需信物必须由任务或首通确定性获得，不得被随机
  掉落或高阶灵根修士门槛卡住。
- 稀有“洗髓”道具只能回退到最近一次分支选择点，不允许在战斗中自由切换职业。
- 结丹职业节点以后当前只冻结名称、职责方向和树结构；数值、技能与材料来源在
  对应阶段立项时另行验收。
- 一转表中的“魔道”是路线标签。一旦选择魔道分支，该修士从结丹到大乘的所有后续
  职业节点都必须保持魔道，不得在中途无代价跳回正道或旁门；改变道途只能通过专门的
  洗髓/废功重修流程完成。

## 7. 转职交互

转职页必须显示：

- 当前职业。
- 两个目标职业的定位。
- 七维成长差异。
- 转职后三个技能的名称、目标、倍率来源和效果。
- 装备适配变化。
- 转职消耗。
- 是否可以洗髓回退。

确认后：

1. 校验等级、任务和材料。
2. 更新职业节点。
3. 替换三技能。
4. 处理不符合条件的装备。
5. 重算属性。
6. 原子保存。

## 8. 七维属性

七维使用修仙题材的玩家显示名称。底层数据字段继续使用稳定英文 ID，显示名称由本地化表提供；授权版与原创版不得改变属性的数值职责或存档字段。

| 属性 | 战斗 | 探索 |
|---|---|---|
| 力道 | 物理技能、负重 | 破门、搬运、强行破坏 |
| 法力 | 法术、治疗、护盾 | 灵脉感应、维持阵法 |
| 神识 | 潜修与符修技能、命中、暴击 | 识别机关、陷阱与禁制 |
| 遁速 | 行动间隔、部分闪避 | 追踪、逃脱、限时事件 |
| 肉身 | 生命上限 | 抵御毒雾、严寒与体力消耗 |
| 护体 | 物理减伤 | 抵御落石、弩箭等实体伤害 |
| 定力 | 法术减伤、异常状态抵抗 | 抵御禁制、幻术与魔气侵蚀 |

术语边界：资质决定成长幅度，境界决定等级阶段，职业决定技能和成长方向；肉身仅表示生命与环境承受能力，不替代资质或境界。护体主要抵御实体伤害，定力主要抵御术法、幻术、魔气和异常状态。

属性详情必须区分基础、成长、装备、状态和最终值。

当前阶段的临时战力定义为修士“最终七维”的合计。战力必须由领域层统一计算，UI、编队、
招募等页面只能读取计算结果，不得各自复制公式；战力是派生值，不写入存档。七维权重或
正式战力公式尚未定稿，后续只替换领域层计算规则，不迁移已存战力值。

## 9. 境界与等级

- 境界名称、稳定 `realmId` 与等级范围以 §6.1 为准。
- 当前实装至炼虚 `Lv60`；合体和大乘只进入 Schema，并保持锁定。
- 达到 10 级并完成筑基试炼后开放一转，确认职业后开放 11 级。
- 高阶职业节点未实装时，修士提升境界后继续保留已选择的一转职业。
- 境界突破固定成功，不加入失败概率。
- 灵根资质与境界的旧档兼容统一迁移到 Schema v5；迁移后每名修士必须同时拥有合法的
  `spiritualRootId` 和 `realmId`。

## 10. 解雇、死亡和返还

- 解雇双灵根及以上修士需要二次确认，天灵根和异灵根默认锁定。
- 解雇返还部分已投入魂晶，比例由数值表配置。
- 装备自动卸下进入仓库。
- 死亡角色不能编队，进入还魂坛。
- 还魂后保留等级、职业、装备和成长。

## 12. 阶段验收

### P2

- 玩家能解释护山剑卫与御剑修的差异。
- 转职后三个技能立即替换。
- 刷新网页不能刷候选。
- 固定新手队可通关 Demo。
- 新数据与 UI 只使用六种合法 `spiritualRootId`，不存在第七档资质。
- 相同最终七维得到相同战力，且存档中不写入战力派生值。

### P3B

- 12 个一转均能进入至少一种有效队伍。
- 每对分支至少在两个技能上产生明显职责差异。
- 不存在只有高阶灵根修士才能通过的主线。

### P4

- 职业选择率不存在非设计预期的极端集中。
- 所有转职、洗髓、解雇和还魂都能恢复存档。
- v5 迁移后，每名修士都具有合法的 `spiritualRootId` 与 `realmId`；炼虚以上境界保持锁定。

## 13. 不做

- 自由组合所有职业技能。
- 二转实装。
- 付费抽卡。
- 角色碎片升星。
- 玩家间修士交易。
