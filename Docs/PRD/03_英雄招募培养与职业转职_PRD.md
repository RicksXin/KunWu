# 《昆吾禁地》PRD 03：英雄、招募、培养与职业转职

版本：0.1  
模块：HERO / CAREER  
负责人：系统策划、数值、客户端、角色美术

## 1. 模块目标

玩家通过招募获得不同品级和职业的修士，通过升级、装备和转职构建队伍。随机招募提供变化，但不能成为主线通关门槛。

## 2. 修士数据

运行实例包括：

- 唯一 ID。
- 显示名和外观组合。
- 品级。
- 当前职业节点。
- 等级与境界。
- 七维基础值、成长值和装备加成。
- 当前三个主动技能。
- 职业天赋。
- 装备。
- 精力、伤势、死亡状态。

## 3. 品级

```text
D → C → B → A → S → SS → SSS
```

品级影响初始七维、成长幅度和潜能，不改变职业技能数量。D 级角色必须能通过合理培养与队伍搭配完成主线，主线不得设置必须拥有高品级角色的硬门槛。

## 4. 招贤台

### 候选

- 每批 3 名。
- 每 60 分钟免费刷新。
- 招募后对应栏位为空。
- 刷新网页不能改变候选。
- 自动刷新后手动刷新费用重新计算。

### 手动刷新

仙铢建议：20、40、80、140、220，之后维持 220。

新手灵粮招募：

- 只在新手阶段开放。
- 只出现 D、C、B 级。
- 不与正式高品级概率池混用。

### 招贤台升级

- 提高较高品级概率，但不保证出现指定职业。
- 提高修士容量。
- 提高可培养等级上限。
- 解锁新初始职业池。

## 5. 六个初始职业

| 职业 | 主要属性 | 基础三技能 |
|---|---|---|
| 武修 | 力量 | 斩击、挑衅、冲撞 |
| 法修 | 魔力 | 灵火弹、凝霜护、灵能震荡 |
| 医修 | 魔力 | 回春术、清心诀、灵光击 |
| 潜修 | 技巧 | 影袭、投刃、烟遁 |
| 符修 | 技巧/魔力 | 飞符、缚身符、护身符 |
| 体修 | 力量/体质 | 重拳、护体功、战吼 |

## 6. 一转职业

角色 10 级完成职业试炼后，从两个方向选择：

| 初始 | 分支 A | 分支 B |
|---|---|---|
| 武修 | 护山卫 | 飞剑客 |
| 法修 | 雷法师 | 玄冰师 |
| 医修 | 丹医 | 炎丹师 |
| 潜修 | 绝影客 | 探秘使 |
| 符修 | 阵法师 | 咒印师 |
| 体修 | 金刚修 | 狂战修 |

每个一转节点重新定义三个技能和成长权重。旧主动技能不进入自由技能池。

## 7. 转职交互

转职页必须显示：

- 当前职业。
- 两个目标职业的定位。
- 七维成长差异。
- 转职后三个技能的名称、目标、倍率来源和效果。
- 装备适配变化。
- 转职消耗。
- 是否可以洗髓回退。

确认后：

1. 校验等级、任务和材料。
2. 更新职业节点。
3. 替换三技能。
4. 处理不符合条件的装备。
5. 重算属性。
6. 原子保存。

## 8. 七维属性

| 属性 | 战斗 | 探索 |
|---|---|---|
| 力量 | 物理技能、负重 | 破门、搬运 |
| 魔力 | 法术、治疗、护盾 | 灵脉、阵法 |
| 技巧 | 技巧技能、命中、暴击 | 机关、陷阱 |
| 速度 | 行动间隔、部分闪避 | 追踪、限时事件 |
| 体质 | 生命 | 毒雾、严寒 |
| 护甲 | 物理减伤 | 落石、弩箭 |
| 抗性 | 法术减伤、异常抗性 | 禁制、幻术 |

属性详情必须区分基础、成长、装备、状态和最终值。

## 9. 境界与等级

- 筑基：1–20。
- 结丹：21–40。
- 元婴：41–60。
- 10 级开放一转。
- 25 级以后预留二转接口，MVP 不实装。
- 境界突破固定成功，不加入失败概率。

## 10. 解雇、死亡和返还

- 解雇 A 级及以上角色需要二次确认，S 级及以上默认锁定。
- 解雇返还部分已投入魂晶，比例由数值表配置。
- 装备自动卸下进入仓库。
- 死亡角色不能编队，进入还魂坛。
- 还魂后保留等级、职业、装备和成长。

## 12. 阶段验收

### P2

- 玩家能解释护山卫与飞剑客的差异。
- 转职后三个技能立即替换。
- 刷新网页不能刷候选。
- 固定新手队可通关 Demo。

### P3B

- 12 个一转均能进入至少一种有效队伍。
- 每对分支至少在两个技能上产生明显职责差异。
- 不存在只有高品级角色才能通过的主线。

### P4

- 职业选择率不存在非设计预期的极端集中。
- 所有转职、洗髓、解雇和还魂都能恢复存档。

## 13. 不做

- 自由组合所有职业技能。
- 二转实装。
- 付费抽卡。
- 角色碎片升星。
- 玩家间英雄交易。
