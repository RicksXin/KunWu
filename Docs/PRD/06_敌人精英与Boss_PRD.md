# 《昆吾禁地》PRD 06：敌人、精英与 Boss

版本：0.1  
模块：ENEMY  
负责人：战斗策划、关卡策划、敌人美术、动画特效

## 1. 模块目标

敌人承担队伍构筑检验、资源消耗和地图危险标记。主线、支线、野外 Boss必须有不同职责，不只是在普通怪基础上放大数值。

## 2. 敌人层级

| 层级 | 作用 | 刷新 |
|---|---|---|
| 普通敌群 | 消耗、材料、职业克制教学 | 固定坐标，可刷新 |
| 精英 | 检验单一机制 | 固定坐标，按图配置 |
| 主线小 Boss | 推动任务或出口 | 首杀后不刷新 |
| 支线 Boss | NPC、装备、支线结果 | 通常不刷新 |
| 野外 Boss | 超当前主线的挑战 | 固定坐标，可周期刷新 |
| 最终 Boss | 结局与综合检验 | 独立战斗场景 |

## 3. 敌人族群

| 族群 | 核心机制 |
|---|---|
| 尸傀 | 高护体、中毒、复生 |
| 木魅 | 缠绕、吸取生命或法力 |
| 石灵 | 护体、反击、破碎阶段 |
| 禁制化形 | 控制、反伤、区域法术 |
| 邪修残魂 | 恐惧、夺魂、无视部分护体 |
| 魔气孽物 | 污染、狂暴、召唤 |

每个族群至少包含普通、精英和 Boss可复用的视觉部件，但战斗脚本独立。

## 4. Boss设计模板

每个 Boss需求单必须包含：

- 所在地图和固定坐标。
- Boss类型。
- 推荐等级和队伍强度。
- 三个核心机制以内。
- 可用克制方式。
- 嘲讽响应规则。
- 阶段切换条件。
- 预警时间。
- 首杀和重复掉落。
- 任务状态变化。
- 是否允许逃生。

Boss不可同时要求四种以上新机制。

## 6. AI规则

普通敌人：

- 按技能优先级和目标规则行动。
- 不使用通用复杂行为树。

Boss：

- 按生命比例、时间轴和关键状态进入阶段。
- 阶段脚本必须数据化。
- 关键机制技能不得因随机未命中而失效。
- 可以有 `ignore_taunt` 技能，但必须在描述和预警中明确。

## 7. 难度原则

- 主线小 Boss允许当前地图常规成长通过。
- 支线 Boss偏向特定职业或属性解法，但不唯一。
- 野外 Boss高于当前主线强度，允许玩家以后返回。
- 最终 Boss综合检验治疗、承伤、输出、净化和控制管理。
- 失败后玩家必须能判断原因。

## 8. 掉落

普通敌群：

- 常规材料。
- 少量魂晶、灵石。

精英：

- 特定制作材料。
- 较高品质装备概率。

主线 Boss：

- 固定任务物。
- 首杀固定装备或配方。

支线 Boss：

- 支线专属装备/NPC。

野外 Boss：

- 稀有材料。
- 重复挑战掉落表。

最高价值物品不能全部依赖低概率掉落。

## 10. 验收

- Boss危险技能有 0.6–1.5 秒预警。
- 主线 Boss至少两种有效队伍。
- 野外 Boss不阻断常规出口。
- 嘲讽响应与技能描述一致。
- 阶段切换不重复、不跳过。
- 逃生、战败、首杀和重复击杀结算正确。
- 固定 Boss重新进入地图仍在正确坐标或正确完成状态。

## 11. 不做

- 随机 Boss位置。
- 世界 Boss排行榜。
- 联机组队 Boss。
- 只增加生命和攻击的换色 Boss。
- 必须拥有单一稀有修士才能通过的主线机制。
