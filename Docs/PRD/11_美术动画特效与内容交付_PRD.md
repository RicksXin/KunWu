# 《昆吾禁地》PRD 11：0.1 美术、动画、特效与内容交付

版本：0.1-product.1  
日期：2026-08-04  
状态：试玩版本产品化落地  
模块：CONTENT  
负责人：美术负责人、动画、特效、音频、内容策划

## 1. 模块目标

建立可分阶段替换的像素修仙资产管线。0.1 地图、人物、敌人和剧情资产范围以
[`15_0.1版本完整策划案_草案.md`](../0.1策划草案/15_0.1版本完整策划案_草案.md)及
主支线、敌人详细分册为上游来源；本 PRD 只维护视觉规格、制作预算、状态、交付和验收，
不得根据旧五图规划新增资产。

具体素材表、GPT Image 提示词、已生成资源状态与跨页面复用关系统一见
[《昆吾禁地》美术素材制作总清单](../ArtAssets/README.md)；本 PRD 只维护通用
资产规格、动画、特效和内容交付规则。

## 2. 规格

- Tile源尺寸16×16。
- 探索角色32×32或48×48。
- 战斗标准单位动态立绘逻辑框为 `86×205`；动画运行时帧按 `86×205 px (@1x)` 像素清稿，
  `258×615 px (@3x)` 只作为 GPT Image 母版与静态展示源，不直接批量打入动画图集。
- 战斗首领动态立绘逻辑框最大 `172×256`；`96×96`、`128×128` 只保留给旧灰盒战斗
  小人或地图标记，不作为当前战斗页面的正式动态立绘规格。
- 玩家可见 UI 与战斗页面基准为 `375×817`；`360×640` 只可作为 Tile、角色等世界像素
  素材的内部参考，不参与 UI 布局与 UI 素材尺寸推导。
- Point过滤，无抗锯齿。
- 中文字体使用已登记OFL字体或原创替代。

| 地图 | 主题 |
|---|---|
| 1 破禁山麓·万修之门 | 青灰山道、废营、断裂阵灯、万修之门残碑 |

`map_05`只制作锁定入口/预告所需的最小 UI，不制作第五张地图场景或敌人资产。

## 4. 角色资产

- 石岩、陆清、白灵、墨言四名固定修士。
- 四个炼气职业、八个筑基分支及对应结丹进阶表现。
- 初始与一转共用身体底层。
- 分支至少重制两组Attack/Cast。
- 同分支三个技能拥有不同起手剪影。
- 探索四方向。
- 战斗单方向侧视。

0.1 优先：

- 四名固定修士的探索小人、角色卡和战斗动态立绘。
- 八个筑基分支至少通过武器、肩部/袖型轮廓、配色和施术动作形成可辨差异。
- 结丹沿既有分支升级表现，不创建第二套完全独立的三技能动画资产。
- 剧情立绘预算以策划总案为准；未形成实体立绘的回声、伪影和神念使用特效变体。

## 5. 敌人资产

0.1 制作预算：

- 普通敌人 20–24 个基础模板，可通过武器、颜色和技能组合形成固定敌群。
- 精英 14 个配置，可以复用普通骨架但必须有独立机制提示和辨识特征。
- Boss 4 个：守门石灵、封坛尸将、四臂铸灵傀、银翅夜叉·尸煞化身。

Boss必须有独立剪影、危险预警和阶段变化，不能只换色放大。

## 6. 动画

探索：

- Idle 4帧。
- Walk 6帧。
- Interact 4帧。
- Hurt 3帧。
- Down 6帧。

战斗：

- Idle 4–6。
- Attack 6–10。
- Cast 8–12。
- Hurt 3–4。
- Death 8–12。
- Revive 6–8。

标记`cast_commit`、`hit_frame`、`recover_start`和`animation_end`。

## 7. 特效

能量语言：

- 剑气青白锐角。
- 灵火朱红金橙。
- 雷法蓝紫分叉。
- 阵法靛蓝金色几何。
- 治疗青绿上升。
- 魔气紫黑回吸。

必须交付低画质变体。规则信息不能依赖高质量特效。

## 8. UI资产

- 七种资源图标。
- 七维属性图标。
- 六档灵根资质边框：杂灵根、伪灵根、三灵根、双灵根、天灵根、异灵根；颜色之外还
  必须有文字和轮廓差异，异灵根不得使用魔道专属暗红。
- 四档装备品质边框：粗制、精良、珍品、古宝；不制作 0.1 未开放的灵宝品质状态。
- Boss、精英与普通敌群使用不同地图标记。
- 建筑锁定、解锁、可升级状态。
- 技能、状态、物品和任务图标。

## 10. 资产交付要求

- 源文件。
- 导出PNG/图集。
- 规格、锚点、FPS。
- 事件帧。
- 使用场景。
- 作者和许可。
- 是否需署名。
- 预览GIF/视频。

第三方资产必须留在`ThirdParty`，不得混入原创目录。

## 11. 验收

- 25%缩放仍可识别职业。
- 可走、不可走和交互物清楚。
- 转职分支动作和轮廓不同。
- Boss、精英与普通敌群标记可辨认，不出现旧“三类 Boss”图例。
- 低画质保留技能预警。
- 资源按地图Bundle拆分。
- 对外构建不包含未经授权临摹。

## 12. 不做

- 3D资产。
- 长篇逐帧剧情动画。
- 免费素材简单换色作为商业成品。
- 写实血腥肢解。
- 与原著动画角色高度相似的造型。
