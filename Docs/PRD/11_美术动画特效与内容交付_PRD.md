# 《昆吾禁地》PRD 11：美术、动画、特效与内容交付

版本：0.3  
日期：2026-08-03  
模块：CONTENT  
负责人：美术负责人、动画、特效、音频、内容策划

## 1. 模块目标

建立可分阶段替换的像素修仙资产管线。Demo允许使用已登记许可的免费素材，MVP逐步替换为统一原创资产。

具体素材表、GPT Image 提示词、已生成资源状态与跨页面复用关系统一见
[《昆吾禁地》美术素材制作总清单](../ArtAssets/README.md)；本 PRD 只维护通用
资产规格、动画、特效和内容交付规则。

## 2. 规格

- Tile源尺寸16×16。
- 探索角色32×32或48×48。
- 战斗标准单位动态立绘逻辑框为 `86×205`；动画运行时帧按 `86×205 px (@1x)` 像素清稿，
  `258×615 px (@3x)` 只作为 GPT Image 母版与静态展示源，不直接批量打入动画图集。
- 战斗首领动态立绘逻辑框最大 `172×256`；`96×96`、`128×128` 只保留给旧灰盒战斗
  小人或地图标记，不作为当前战斗页面的正式动态立绘规格。
- 玩家可见 UI 与战斗页面基准为 `375×817`；`360×640` 只可作为 Tile、角色等世界像素
  素材的内部参考，不参与 UI 布局与 UI 素材尺寸推导。
- Point过滤，无抗锯齿。
- 中文字体使用已登记OFL字体或原创替代。

## 4. 角色资产

- 六初始职业。
- 十二一转职业。
- 初始与一转共用身体底层。
- 分支至少重制两组Attack/Cast。
- 同分支三个技能拥有不同起手剪影。
- 探索四方向。
- 战斗单方向侧视。

Demo优先：

- 六初始探索小人。
- 剑修、护山剑卫、御剑修完整战斗动画。
- 其余核心队伍使用可替换占位。

## 5. 敌人资产

族群：

- 尸傀。
- 木魅。
- 石灵。
- 禁制化形。
- 邪修残魂。
- 魔气孽物。

MVP累计：

- 普通敌人24。
- 精英8。
- Boss 13–15。

Boss必须有独立剪影、危险预警和阶段变化，不能只换色放大。

## 6. 动画

探索：

- Idle 4帧。
- Walk 6帧。
- Interact 4帧。
- Hurt 3帧。
- Down 6帧。

战斗：

- Idle 4–6。
- Attack 6–10。
- Cast 8–12。
- Hurt 3–4。
- Death 8–12。
- Revive 6–8。

标记`cast_commit`、`hit_frame`、`recover_start`和`animation_end`。

## 7. 特效

能量语言：

- 剑气青白锐角。
- 灵火朱红金橙。
- 雷法蓝紫分叉。
- 阵法靛蓝金色几何。
- 治疗青绿上升。
- 魔气紫黑回吸。

必须交付低画质变体。规则信息不能依赖高质量特效。

## 8. UI资产

- 七种资源图标。
- 七维属性图标。
- 六档灵根资质边框：杂灵根、伪灵根、三灵根、双灵根、天灵根、异灵根；颜色之外还
  必须有文字和轮廓差异，异灵根不得使用魔道专属暗红。
- 五装备品质边框。
- 三类Boss地图标记。
- 建筑锁定、解锁、可升级状态。
- 技能、状态、物品和任务图标。

## 10. 资产交付要求

- 源文件。
- 导出PNG/图集。
- 规格、锚点、FPS。
- 事件帧。
- 使用场景。
- 作者和许可。
- 是否需署名。
- 预览GIF/视频。

第三方资产必须留在`ThirdParty`，不得混入原创目录。

## 11. 验收

- 25%缩放仍可识别职业。
- 可走、不可走和交互物清楚。
- 转职分支动作和轮廓不同。
- 三种Boss标记可辨认。
- 低画质保留技能预警。
- 资源按地图Bundle拆分。
- 对外构建不包含未经授权临摹。

## 12. 不做

- 3D资产。
- 长篇逐帧剧情动画。
- 免费素材简单换色作为商业成品。
- 写实血腥肢解。
- 与原著动画角色高度相似的造型。
