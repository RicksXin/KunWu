# 《昆吾禁地》PRD 05：野外地图、探索与跨图连接

版本：0.2  
日期：2026-08-01  
模块：MAP  
负责人：关卡策划、客户端、地编、美术

## 1. 模块目标

通过完整二维方格大地图、迷雾、灵粮和负重制造远征压力。玩家自由选择目标坐标，而不是在主路/岔路菜单中选择路线。

## 2. 固定地图原则

- 每张地图由若干小格组成。
- 队伍只占一个格。
- 每次只移动上下左右一格。
- 敌人、资源、事件、小型副本、Boss、NPC和出口坐标固定。
- 重新进入地图不改变对象位置。
- 对象可改变完成、冷却、刷新状态。
- 野外 Boss逻辑位置固定。

## 5. 迷雾

状态：

- `UNKNOWN`：完全隐藏。
- `DISCOVERED`：显示地形和已发现固定 POI，不显示敌人实时状态。
- `VISIBLE`：显示全部。

探查范围：

- 基础 2。
- 探灵灯升级 3/4/5。
- 探查范围由探灵灯和特定地图效果决定；神识属性用于识别机关、陷阱与禁制，不直接扩大基础探查范围。

P2只做圆形半径，不做障碍遮挡；遮挡视线属于 MVP后优化。

## 6. 灵粮与负重

- 每步移动先校验灵粮，再扣除。
- 灵粮自身占负重。
- 出征准备面板可携带物固定为三类：灵粮、十字镐、透镜；各自重量与可携带数量从
  外置数据读取，不在 UI 中硬编码。
- 十字镐用于玄铁、水晶、庚金等资源点开采，也可用于部分副本推进；没有十字镐时，
  对应副本只能选择数据定义的替代代价。
- 透镜允许玩家在战斗开始前观察敌方属性；没有透镜时不显示完整敌方属性预览。
- 临时战利品占负重。
- 负重 80% 显示警告。
- 超重后不能继续拾取，但可以移动、丢弃和返回。
- 力道、肉身和储物法器提高负重。
- 地图 UI显示按当前最短路径返回所需的估算灵粮。

出征地图选择：

- 点击出征准备面板“出发”后，在其上方打开地图选择面板。
- 每个地图项目显示地图名称、地图编号、单次出征所需精力、每步灵粮消耗与最低建议
  携带灵粮；锁定地图显示解锁状态。
- 点击已解锁地图项目后再次校验队伍、每名修士精力、最低灵粮和负重；全部通过才原子
  扣除出征消耗并传送，加载失败不得提前扣除。

## 7. 固定对象

对象 ID：`map_id + object_id`。

类型：

- 敌群。
- 主线/支线/野外 Boss。
- 资源点。
- 宝箱。
- 属性检定。
- NPC。
- 临时营地。
- 小型副本入口。
- 传送阵。
- 跨图出口。

状态：

```text
HIDDEN
DISCOVERED
AVAILABLE
COMPLETED
COOLDOWN
REFRESHED
DISABLED
```

## 8. 属性检定

聚合方式：

- `SUM`：全队总和。
- `MAX`：最高单人。
- `COUNT`：达标人数。
- `ALL`：全员达标。

示例：

```text
神识总和 ≥ 30：安全拆除。
失败：全队损失当前生命 20%，仍可通过。
```

UI显示属性、口径、当前值、阈值和失败后果。隐藏检定必须由剧情明确说明“结果未知”。

## 9. 跨图出口

出口条件可以组合：

- 主线任务完成。
- Boss已死。
- 持有任务物品。
- 建筑或 NPC 状态。
- 七维检定。

地图 2 → 地图 4示例：

```text
完成东阵眼任务
持有古殿令
全队法力总和 ≥ 80
失败触发守阵敌人，不消耗古殿令
```

所有单向出口必须提前提示是否可返回。

## 12. 验收

- 固定对象重新进入地图后位置不变。
- 所有出口、Boss和 POI可达。
- 地图 2 → 地图 4条件正确。
- 不存在无法返回且未提示的死锁。
- 新玩家五分钟内理解坐标、迷雾、灵粮和负重。
- 没有超过 20 步的无事件空走区。
- 鼠标和触控寻路均不误触 UI。

## 13. 不做

- 随机地图生成。
- 随机重排敌人坐标。
- 主路/岔路选择界面。
- 斜向移动。
- 地图内动作战斗。
