# 《昆吾禁地》PRD 05：野外地图、探索与跨图连接

版本：0.3  
日期：2026-08-02  
模块：MAP  
负责人：关卡策划、客户端、地编、美术

## 1. 模块目标

通过完整二维方格大地图、迷雾、灵粮和负重制造远征压力。玩家自由选择目标坐标，而不是在主路/岔路菜单中选择路线。

## 2. 固定地图原则

- 每张地图由若干小格组成。
- 队伍只占一个格。
- 每次只移动上下左右一格。
- 敌人、资源、事件、小型副本、Boss、NPC和出口坐标固定。
- 重新进入地图不改变对象位置。
- 对象可改变完成、冷却、刷新状态。
- 野外 Boss逻辑位置固定。

## 5. 迷雾

状态：

- `UNKNOWN`：完全隐藏。
- `DISCOVERED`：显示地形和已发现固定 POI，不显示敌人实时状态。
- `VISIBLE`：显示全部。

探查范围：

- 基础 2。
- 探灵灯升级 3/4/5。
- 探查范围由探灵灯和特定地图效果决定；神识属性用于识别机关、陷阱与禁制，不直接扩大基础探查范围。

P2只做圆形半径，不做障碍遮挡；遮挡视线属于 MVP后优化。

## 6. 灵粮与负重

- 每步移动先校验灵粮，再扣除。
- 灵粮自身占负重。
- 入山整备面板可携带物固定为三类：灵粮、开山镐、探灵镜；各自重量与可携带数量从
  外置数据读取，不在 UI 中硬编码。
- 开山镐用于玄铁、水晶、庚金等资源点开采，也可用于部分副本推进；没有开山镐时，
  对应副本只能选择数据定义的替代代价。
- 探灵镜允许玩家在战斗开始前观察敌方属性；没有探灵镜时不显示完整敌方属性预览。
- 临时战利品占负重。
- 负重 80% 显示警告。
- 超重后不能继续拾取，但可以移动、丢弃和返回。
- 三支队伍分别保存自己的装载方案；切换队伍时恢复该队方案，不覆盖其他队伍的装载数量。
- 最大负重根据该队当前上阵修士的最终属性计算，包含装备与已生效的永久加成。力道、
  肉身和储物法器可按外置规则提高负重，具体数值不在本 PRD 固定。
- 地图 UI显示按当前最短路径返回所需的估算灵粮。

入山地图选择：

- 点击入山整备面板“启程”后，在其上方打开地图选择面板。
- 每个地图项目显示地图名称、地图编号、单次入山所需灵息、每步灵粮消耗与最低建议
  携带灵粮；锁定地图显示解锁状态。
- 点击已解锁地图项目后再次校验队伍、每名修士灵息、营地持有物、最低灵粮和负重。
- 启程成功后，实际携带物统一从营地持有中转入本次入山状态：灵粮从营地灵粮余额扣除，
  开山镐和探灵镜从百宝库库存扣除。三队保存的是装载方案，不提前占用三份物资。
- 入山扣款、物资转移、灵息结算与地图交接必须作为一个完整结果。地图加载失败时，灵息、
  灵粮、开山镐、探灵镜及其他玩家资源保持启程前状态，也不留下有效的野外状态。

### 6.1 入山状态

`ExpeditionState` 是“一次正在进行的入山”的持久化快照，不是额外背包，也不是第四支
队伍。它至少记录：地图 ID、队伍方案 ID、出发成员 ID、当前位置、已结算灵息、剩余携带物、
临时战利品、已揭示格子以及生命周期状态。

- 只允许在最终启程校验全部通过后创建；地图交接成功后才成为有效的进行中入山状态。
- 生命周期至少区分 `active`（野外进行中）与 `settling`（回城或阵亡结算中）；玩家在营地
  且结算完成后不存在有效快照，整备中的未启程方案也不属于 `ExpeditionState`。
- 有效状态用于网页刷新后恢复当前位置和物资，确保同一份物资不会同时存在于营地与野外。
- 地图加载失败时丢弃未生效状态，不得扣除灵息或转移物资。
- 启程时所有出发修士停止灵息自然恢复；回到营地时以当时的 UTC 时间重新建立恢复锚点，
  野外经过的时间不补算。

### 6.2 回城与全队阵亡结算

正常回城：

- 剩余灵粮全部返还营地灵粮余额。
- 未使用的开山镐和探灵镜全部返还百宝库库存。
- 临时战利品合并进营地库存；仓库满时进入待处理区，不静默丢失。

野外全队阵亡：

- 仅当本次入山队伍所有修士均已死亡时触发；单个修士死亡不触发物品减半。
- 对本次入山内所有“可损失物”统一减半，包括剩余装载物资、普通/消耗/材料物品、临时
  战利品，以及修士携带或穿戴的装备。
- 关键物品和任务物品不参与减半，全部带回营地。
- 可堆叠物的返还数量为 `floor(结算时数量 / 2)`；因此奇数向下取整，数量为 1 时返还 0。
- 非堆叠装备按可损失装备实例组成集合，按稳定实例 ID 升序排列后保留前
  `floor(装备实例数 / 2)`，其余损失；不得依赖 UI 顺序、结算时机或临时随机数。
- 减半后保留的物品按正常回城路径返还营地；结算完成后清除本次 `ExpeditionState`。

物品分类、装备范围和仓库满处理以 PRD-07 为准，持久化与失败回滚以 PRD-10 为准。

## 7. 固定对象

对象 ID：`map_id + object_id`。

类型：

- 敌群。
- 主线/支线/野外 Boss。
- 资源点。
- 宝箱。
- 属性检定。
- NPC。
- 临时营地。
- 小型副本入口。
- 传送阵。
- 跨图出口。

状态：

```text
HIDDEN
DISCOVERED
AVAILABLE
COMPLETED
COOLDOWN
REFRESHED
DISABLED
```

## 8. 属性检定

聚合方式：

- `SUM`：全队总和。
- `MAX`：最高单人。
- `COUNT`：达标人数。
- `ALL`：全员达标。

示例：

```text
神识总和 ≥ 30：安全拆除。
失败：全队损失当前生命 20%，仍可通过。
```

UI显示属性、口径、当前值、阈值和失败后果。隐藏检定必须由剧情明确说明“结果未知”。

## 9. 跨图出口

出口条件可以组合：

- 主线任务完成。
- Boss已死。
- 持有任务物品。
- 建筑或 NPC 状态。
- 七维检定。

地图 2 → 地图 4示例：

```text
完成东阵眼任务
持有古殿令
全队法力总和 ≥ 80
失败触发守阵敌人，不消耗古殿令
```

所有单向出口必须提前提示是否可返回。

## 12. 验收

- 固定对象重新进入地图后位置不变。
- 所有出口、Boss和 POI可达。
- 地图 2 → 地图 4条件正确。
- 不存在无法返回且未提示的死锁。
- 新玩家五分钟内理解坐标、迷雾、灵粮和负重。
- 没有超过 20 步的无事件空走区。
- 鼠标和触控寻路均不误触 UI。
- 三支队伍的装载方案相互独立，负重按当前队伍最终属性计算。
- 地图加载失败后，队伍灵息、营地物资和进行中入山状态均与启程前一致。
- 正常回城完整返还剩余灵粮与未使用工具；全队阵亡减半含装备，但不损失关键物品和任务物品。

## 13. 不做

- 随机地图生成。
- 随机重排敌人坐标。
- 主路/岔路选择界面。
- 斜向移动。
- 地图内动作战斗。
