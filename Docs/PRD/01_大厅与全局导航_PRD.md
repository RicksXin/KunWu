# 《昆吾禁地》PRD 01：大厅与全局导航

版本：0.2
日期：2026-07-30
模块：HALL
负责人：产品、UI策划、客户端

## 1. 模块目标

大厅是玩家每次登录、出征和回城后的中心。玩家应在 10 秒内知道当前资源、当前主线目标、可处理入口以及如何出征。

大厅不做角色自由行走，也不允许玩家自由摆放建筑。主体是一张可横向连续滑动的营地全景；顶部信息层和底部快捷入口层固定在屏幕上，不随全景移动。

`assets/refer/lobby_left.jpg`、`assets/refer/lobby_mid`、`assets/refer/lobby_right.jpg` 只作为信息层级和空间关系参考，不作为可发布美术资产，也不要求照搬原作 UI、名称或建筑造型。

## 2. 页面分层

大厅由三个相互独立的层组成：

| 层级 | 是否随横滑移动 | 内容 |
|---|---|---|
| 顶部固定 HUD | 否 | 玩家头像、五种生产资源、当前主线任务提示 |
| 营地全景 | 是 | 建筑、场景锚点、出征入口、建筑状态和红点 |
| 底部固定 HUD | 否 | 左侧系统快捷入口；右侧金币、付费宝石与付费入口预留位 |

顶部与底部 HUD 始终位于安全区内。营地全景可从 HUD 下方延伸作为背景，但交互热区不得被 HUD 遮挡。

## 3. 顶部固定 HUD

### 3.1 玩家与资源

- 左上显示玩家头像。P1 仅要求展示；头像是否作为玩家信息入口待产品确认，如配置为可点击则未接入页面前必须显示“尚未开放”，不能无反馈。
- 头像右侧常驻显示五种生产资源，顺序固定为：食物、木材、铁、水晶、秘银。
- 当前修仙题材显示名暂沿用：食物=`灵粮`、木材=`灵木`、铁=`玄铁`、水晶=`灵石`、秘银=`庚精`。
- 每项同时显示图标和当前数量；数值较长时使用统一缩写规则，长按或悬停显示完整值。
- 资源接近上限、生产停工或有可领取收益时，通过图标状态提示；详细生产规则以 PRD-02 为准。

### 3.2 当前主线任务

- 主线任务提示位于头像下方，显示任务图标和一行当前目标。
- 点击提示进入对应任务详情；任务页未接入前显示明确反馈。
- 文案超过一行时单行省略，不得挤压资源栏；任务详情中显示完整文本。
- 没有进行中主线时显示“暂无主线任务”，不隐藏整块区域，避免布局跳动。

## 4. 可横滑营地全景

### 4.1 基础交互

- 首次进入、新档进入和普通回城时，默认停在中部区域，使城堡和出征入口可见。
- 玩家可用触控横向拖动；桌面端支持鼠标按住拖动。横向滑动不得触发页面返回手势。
- 全景采用连续滚动和惯性减速，左右边界受限；本阶段不强制按整屏分页吸附。
- 按下建筑后，累计横向位移不超过 `12dp` 视为点击；超过则判定为拖动并取消该次建筑点击，防止误入建筑。
- 拖动开始后应在 `100ms` 内产生位移反馈。松手后的惯性应可控，玩家一次反向拖动即可停止。
- 在默认中部视口的左右边缘保留相邻建筑的局部轮廓或环境引导，帮助玩家理解场景还能横滑。
- 顶部资源、主线提示和底部入口在拖动期间保持固定且可读。
- 从建筑子页面返回时优先恢复离开前的横向位置；重新登录和回城结算后回到中部默认位置。

### 4.2 建筑与锚点布局

下表描述从左到右的逻辑空间关系，不规定最终美术的精确像素坐标：

| 区域 | 入口与锚点 | 状态与说明 |
|---|---|---|
| 左部 | 仓库（百宝库）、墓园（还魂坛）、圣迹、教会 | 仓库、墓园为功能入口；圣迹、教会暂不实现，只保留场景锚点 |
| 中部 | 城堡（议事殿）、出征、酒馆（招贤台）、市场（交易行） | 默认视口；城堡在中上方，出征在中下方，酒馆偏左、市场偏右 |
| 中部右缘 | 竞技场、工坊（炼器坊） | 默认视口只露出部分轮廓，提示玩家继续向右滑动 |
| 右部 | 竞技场、工坊（炼器坊）、庄园（灵圃）、遗迹 | 前三者显示完整入口；遗迹暂不实现，只保留场景锚点 |

说明：

- 议事殿、灵圃、招贤台、百宝库、炼器坊、交易行、还魂坛仍是 PRD-02 定义的七座可成长建筑。
- 竞技场是额外玩法入口，不计入七座生产/成长建筑。首发不包含 PvP；竞技场具体玩法和解锁条件需另行确认，确认前只接入口壳和“尚未开放”反馈。
- 出征是大厅主行动入口，不计入建筑，点击后进入出征准备页。
- 遗迹、圣迹、教会在当前版本不可点击、不显示红点、不参与新手引导和完成度统计；美术上应表现为远景、封闭或未激活状态，不能伪装成已开放按钮。

### 4.3 功能入口映射

| 大厅显示语义 | 当前题材名 | 功能去向 |
|---|---|---|
| 城堡 | 议事殿 | 主线、NPC、营地总览 |
| 酒馆 | 招贤台 | 招募与修士容量 |
| 市场 | 交易行 | 买卖与订单 |
| 竞技场 | 待定 | 非 PvP 的玩法入口待确认 |
| 工坊 | 炼器坊 | 打造、工具与重铸 |
| 庄园 | 灵圃 | 杂役、生产与离线收益 |
| 仓库 | 百宝库 | 仓库与出征装载 |
| 墓园 | 还魂坛 | 阵亡修士与还魂 |
| 出征 | 出征 | 出征准备页 |

## 5. 底部固定 HUD

### 5.1 左侧系统快捷入口

从左到右固定为：

1. 设置：进入音频、画面、语言、存档导入导出等设置。
2. 成就：进入成就总览；成就系统页面由后续独立需求定义。
3. 排行榜：暂不实现，入口以禁用/未开放态展示。
4. 邮件：暂不实现，入口以禁用/未开放态展示。
5. 日常进度：暂不实现，入口以禁用/未开放态展示。

小图标必须同时具备可识别图形和可访问名称。排行榜、邮件、日常进度不产生红点；设置和成就页未接入期间，点击后显示明确说明。

### 5.2 右侧货币与付费预留区

- 显示金币余额；当前经济系统对应显示名为`仙铢`。
- 显示付费宝石的信息位，以及礼包/充值等付费入口的视觉预留位。
- 当前版本不实现充值、礼包购买、商店跳转、广告、真实订单、支付 SDK 或付费宝石发放与消耗。
- 在付费系统立项前，付费入口必须为禁用或“暂未开放”状态，不得跳转外链，也不得展示伪造的折扣、倒计时或可购买状态。
- 付费宝石是否显示 `0`、`--` 或整体隐藏，待产品确认；研发不得将现有`魂晶`直接当作付费宝石。魂晶仍按 PRD-02 作为战斗、升级和还魂资源。

## 6. 建筑状态与反馈

```text
LOCKED：未解锁，显示台基、封闭建筑或锁定标识
AVAILABLE：满足剧情，可点击解锁
UNLOCKED：可正常使用
UPGRADABLE：材料与条件满足
UPGRADING：预留，不用于 MVP 实时施工
MAX_LEVEL：已达当前版本上限
DISABLED：因剧情、版本范围或资源原因暂不可用
```

- 解锁条件由任务或 NPC 状态驱动，UI 不能自行判断章节名称。
- 点击 `LOCKED`、`DISABLED` 或尚未接入的入口时，显示不可用原因；不能表现为“点了没反应”。
- 可交互建筑需具有统一的静态识别方式，例如名称底板、呼吸高光或入口标识，不能只在悬停时出现。
- 建筑标签与建筑一起横滑；固定 HUD 和其红点不随建筑移动。

## 7. 核心用户故事

- 作为玩家，我进入大厅后能立刻看到五种生产资源和当前主线目标。
- 作为玩家，我能通过横滑发现全部建筑，并能看出哪些场景尚未开放。
- 作为玩家，我能从默认中部视口直接进入出征准备。
- 作为玩家，我能在底部快速进入设置和成就，并识别尚未开放的系统。
- 作为玩家，我回城后能立即看到战利品、伤亡、任务推进和建筑状态变化。
- 作为玩家，我不会因拖动全景而误触建筑，也不会因多个红点而不知道先处理什么。

## 9. 回城结算

展示顺序：

1. 出征结果：主动返回、逃生、战败或剧情返回。
2. 临时战利品转入仓库。
3. 丢失或放弃的物品。
4. 修士伤势、死亡和状态。
5. 完成的任务和建筑解锁。
6. 资源与魂晶变化。

允许跳过动画，但不可跳过数据结算。关闭结算后回到中部默认视口，并刷新资源、主线提示、建筑状态和红点。

## 10. 红点规则

- 同一建筑或底部入口只显示一个总红点。
- 红点只表示“有可执行动作”，不表示“有可查看信息”。
- 资源不足、未满足条件不产生红点。
- 招贤台出现高品级候选可产生红点，但同一批只提醒一次。
- 还魂坛存在未处理死亡修士必须提示。
- 同屏最多三个一级红点，其余收纳到对应入口内部。
- 暂不实现的遗迹、圣迹、教会、排行榜、邮件、日常进度和付费入口不产生红点。

## 11. 页面返回规则

- 系统返回键优先关闭最上层弹窗。
- 无弹窗时返回上一级页面。
- 大厅是根页面，返回键不能退出到空白页面。
- 出征地图中返回键不能直接退出，打开暂停/返回确认。
- 战斗中返回键打开暂停，不直接判负。
- 浏览器刷新前若有未保存状态，先同步存档。

## 12. 异常与边界

- 全景美术尚未加载时显示可操作的灰盒或加载占位，不影响设置入口和错误反馈。
- 资源或任务数据未加载完成时显示占位符，不显示场景默认假数值。
- 快速连续拖动和点击期间，同一入口只响应一次。
- 横向内容宽度不足一屏时自动居中并禁用横滑，不允许露出空白区域。
- 浏览器地址栏伸缩、刘海和底部 Home Indicator 不得遮挡资源、主线、出征或底部入口。
- 720×1280 至 1080×1920 范围内保持默认中部视口可见城堡、出征、酒馆和市场；竞技场、工坊至少露出一个可辨识的局部引导。

## 13. 阶段验收

### P1

- 初次进入大厅默认位于中部，城堡和出征完整可见，酒馆与市场可识别。
- 玩家无需引导即可横滑到左右边界，并找到仓库、墓园、竞技场、工坊和庄园。
- 中部右缘能看到竞技场和工坊的局部轮廓，继续右滑后能看到完整入口。
- 连续完成 20 次“拖动经过建筑”不发生误触；轻点建筑能正常响应。
- 顶部显示真实 Wallet 中的五种生产资源和当前主线提示，不使用场景默认假值。
- 底部图标顺序与本 PRD 一致；所有入口可操作或给出明确不可用原因。
- 出征从大厅直达出征准备页，总点击数不超过 1 次。
- 从任一已接入子页面返回后，大厅资源、主线、状态和红点刷新，且恢复离开前的横向位置。

### P2

- 新玩家在无指导时能找到招募、编队相关入口和出征。
- 七座成长建筑的锁定、解锁、可用状态无歧义。
- 第一次出征在开始游戏 10 分钟内发生。

### P3C

- 营地成长能从视觉上识别 1、3、5 级。
- NPC 和建筑状态与任务一致。

### P4

- 所有页面支持鼠标与触控。
- 720×1280 到 1080×1920 不遮挡。
- 浏览器安全区、地址栏伸缩和后台恢复正常。

## 14. 当前不做

- 遗迹、圣迹、教会功能。
- 排行榜、邮件、日常进度功能。
- 充值、礼包、付费商店、广告、支付 SDK 与任何真实货币交易。
- PvP 竞技场。
- 自由摆放建筑。
- 大厅角色自由行走。
- 建筑施工等待队列。
- 多个营地。
- 社交访问其他玩家营地。

## 15. 待产品确认

以下问题不阻塞大厅灰盒和横滑框架，但会影响最终文案、路由或数据结构：

1. 大厅最终展示通用名“食物/木材/铁/水晶/秘银”，还是题材名“灵粮/灵木/玄铁/灵石/庚精”。
2. 竞技场在单机首发中的具体玩法、开放阶段和入口名称；当前范围明确不含 PvP。
3. 城堡点击后是进入主线/NPC 页面，还是打开营地总览面板。
4. 成就页面的首发范围，以及它是否需要在 P1 核心闭环中接入。
5. 付费宝石未开放时显示 `0`、`--` 还是隐藏；金币是否确认对应现有仙铢。
6. 横滑是否需要左/中/右三段吸附；当前按连续滚动、不强制分页设计。
7. 正式大厅美术采用一张连续全景，还是背景/建筑/前景分层拼装；还需确定横向总宽度和各建筑点击热区稿。
