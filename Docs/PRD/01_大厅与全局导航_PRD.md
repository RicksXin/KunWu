## 1. 模块目标

大厅是玩家每次登录、入山和回城后的中心。玩家应在 10 秒内知道当前资源、当前主线目标、可处理入口以及如何入山。

大厅不做角色自由行走，也不允许玩家自由摆放建筑。主体是一张可横向连续滑动的营地全景；顶部信息层和底部快捷入口层固定在屏幕上，不随全景移动。

`assets/refer/lobby_left.jpg`、`assets/refer/lobby_mid.jpg`、`assets/refer/lobby_right.jpg` 只作为信息层级和空间关系参考，不作为可发布美术资产，也不要求照搬原作 UI、名称或建筑造型。

后续输入或参考资料中若出现《地下城堡》术语，需求整理时按功能语义自动转换为《昆吾禁地》的修仙题材名称；产品界面、配置显示名和研发文档不直接沿用原作术语。语义无法唯一对应时再单独确认。

## 2. 页面分层

大厅由三个相互独立的层组成：

| 层级 | 是否随横滑移动 | 内容 |
|---|---|---|
| 顶部固定 HUD | 否 | 玩家头像、五种生产资源、当前主线任务提示 |
| 营地全景 | 是 | 建筑、场景锚点、传送阵（入山入口）、建筑状态和红点 |
| 底部固定 HUD | 否 | 左侧系统快捷入口；右侧灵石余额 |

顶部与底部 HUD 始终位于安全区内。营地全景可从 HUD 下方延伸作为背景，但交互热区不得被 HUD 遮挡。

## 3. 顶部固定 HUD

### 3.1 玩家与资源

- 左上显示玩家头像并保留点击能力；具体点击行为待后续定义。在功能确定前，点击统一显示“功能待定”，不能无反馈。
- 头像右侧常驻显示五种生产资源，名称与顺序固定为：`灵粮`、`灵木`、`玄铁`、`灵晶`、`庚精`。
- 每项同时显示图标和当前数量；数值较长时使用统一缩写规则，长按或悬停显示完整值。
- 资源接近上限、生产停工或有可领取收益时，通过图标状态提示；详细生产规则以 PRD-02 为准。

### 3.2 当前主线任务

- 主线任务提示位于头像下方，显示任务图标和一行当前目标。
- 主线提示保留点击能力，具体点击行为待后续定义。在功能确定前，点击统一显示“功能待定”，不默认跳转任务详情或目标地点。
- 文案超过一行时单行省略，不得挤压资源栏；任务详情中显示完整文本。
- 没有进行中主线时显示“暂无主线任务”，不隐藏整块区域，避免布局跳动。

## 4. 可横滑营地全景

### 4.1 基础交互

- 首次进入、新档进入和普通回城时，默认停在中部区域，使议事殿和传送阵可见。
- 玩家可用触控横向拖动；桌面端支持鼠标按住拖动。横向滑动不得触发页面返回手势。
- 全景采用连续滚动和惯性减速，左右边界受限，不进行左/中/右分页吸附。
- 营地全景逻辑总宽固定为设计屏幕宽度的 `2.8` 倍；以 `1080` 设计宽计算为 `3024`，不按三个整屏分页。
- 场景美术采用分层结构，至少拆分背景层、建筑交互层和前景遮挡层；建筑、标签、状态和点击热区不得烘焙进不可拆分的背景长图。
- 按下建筑后，累计横向位移不超过 `12dp` 视为点击；超过则判定为拖动并取消该次建筑点击，防止误入建筑。
- 拖动开始后应在 `100ms` 内产生位移反馈。松手后的惯性应可控，玩家一次反向拖动即可停止。
- 在默认中部视口的左右边缘保留相邻建筑的局部轮廓或环境引导，帮助玩家理解场景还能横滑。
- 顶部资源、主线提示和底部入口在拖动期间保持固定且可读。
- 从建筑子页面返回时优先恢复离开前的横向位置；重新登录和回城结算后回到中部默认位置。

### 4.2 建筑与锚点布局

下表描述从左到右的逻辑空间关系，不规定最终美术的精确像素坐标：

| 区域 | 入口与锚点 | 状态与说明 |
|---|---|---|
| 左侧下行线 | 招贤馆、百宝库、还魂殿 | 招贤馆在中部靠左；百宝库位于其左下；还魂殿继续位于百宝库左下 |
| 中部 | 议事殿、传送阵 | 默认视口；议事殿在中上方，传送阵在中下方 |
| 右侧下行线 | 交易行、炼器坊、灵圃 | 交易行在中部稍靠右；炼器坊位于其右下；灵圃继续位于炼器坊右下 |
| 外围锚点 | 左侧圣迹、教会；右侧竞技场、遗迹 | 当前不实现；由背景图直接画出远景轮廓，不设独立节点 |

说明：

- 议事殿、灵圃、招贤馆、百宝库、炼器坊、交易行、还魂殿仍是 PRD-02 定义的七座可成长建筑；内部稳定 ID 暂不迁移。
- 竞技场暂不实现，不计入七座生产/成长建筑，仅作为背景中的远景元素；当前不制作 PvP 或单机竞技玩法。
- 传送阵是大厅主行动入口，不计入建筑，点击后在大厅上方唤起入山整备面板。
- 竞技场、遗迹、圣迹、教会在当前版本不可点击、不显示红点、不参与新手引导和完成度统计；美术上应表现为远景、封闭或未激活状态，不能伪装成已开放按钮。
- 2026-07-31 起这四处不再使用独立场景节点，改由营地背景图直接画出远景轮廓。这样天然满足「不可点击、不伪装成按钮」，也免去灰盒占位块与正式背景冲突。`validate:scene` 会在有人重新建出同名节点却未同步契约时报错。

| 大厅显示语义 | 当前题材名 | 功能去向 |
|---|---|---|
| 城堡 | 议事殿 | 营地人物列表（NPC List） |
| 酒馆 | 招贤馆 | 招募与修士容量 |
| 市场 | 交易行 | 买卖与订单 |
| 竞技场 | 暂不实现 | 仅保留不可交互的场景锚点 |
| 工坊 | 炼器坊 | 打造、工具与重铸 |
| 庄园 | 灵圃 | 杂役、生产与离线收益 |

| 墓园 | 还魂殿 | 阵亡修士与还魂 |
| 入山 | 传送阵 | 入山整备面板（含编队、装载、地图选择） |

## 5. 底部固定 HUD

### 5.1 左侧系统快捷入口

从左到右固定为：

1. 设置：进入音频、画面、语言、存档导入导出等设置。
2. 成就：暂不实现，入口以禁用/未开放态展示。
3. 排行榜：暂不实现，入口以禁用/未开放态展示。
4. 邮件：暂不实现，入口以禁用/未开放态展示。
5. 日常进度：暂不实现，入口以禁用/未开放态展示。

小图标必须同时具备可识别图形和可访问名称。成就、排行榜、邮件、日常进度不产生红点，也不创建对应页面；如保留点击响应，只显示统一的“暂未开放”反馈。

### 5.2 右侧灵石区

- 参考图中的“金币”在本项目统一表现为`灵石`，显示灵石图标和当前余额。
- 右下角读取现有 `Wallet.immortalCoin` 字段；该字段保持稳定以兼容存档，但产品显示名由“仙铢”统一调整为“灵石”。
- 顶部第四种生产资源读取 `Wallet.spiritStone`，产品显示名调整为“灵晶”。灵晶与灵石是两种独立资源，不共用余额。
- 天符玉、充值按钮、礼包按钮和其他付费入口全部隐藏，不保留可见占位。
- 当前版本不实现充值、礼包购买、付费商店、广告、真实订单、支付 SDK 或付费货币发放与消耗。
- 魂晶仍按既有系统规则存在，但不作为大厅右下角的付费货币展示。

## 6. 建筑状态与反馈

```text
LOCKED：未解锁，显示台基、封闭建筑或锁定标识
AVAILABLE：满足剧情，可点击解锁
UNLOCKED：可正常使用
UPGRADABLE：材料与条件满足
UPGRADING：预留，不用于 MVP 实时施工
MAX_LEVEL：已达当前版本上限
DISABLED：因剧情、版本范围或资源原因暂不可用
```

- 解锁条件由任务或 NPC 状态驱动，UI 不能自行判断章节名称。
- 点击 `LOCKED`、`DISABLED` 或尚未接入的入口时，显示不可用原因；不能表现为“点了没反应”。
- 可交互建筑需具有统一的静态识别方式，例如名称底板、呼吸高光或入口标识，不能只在悬停时出现。
- 建筑标签与建筑一起横滑；固定 HUD 和其红点不随建筑移动。

## 7. 核心用户故事

- 作为玩家，我进入大厅后能立刻看到五种生产资源和当前主线目标。
- 作为玩家，我能通过横滑发现全部建筑，并能看出哪些场景尚未开放。
- 作为玩家，我能从默认中部视口直接进入入山整备。
- 作为玩家，我能在底部快速进入设置，并识别成就等尚未开放的系统。
- 作为玩家，我归营后能从大厅资源、伤亡提示、任务与建筑状态看到本次入山产生的变化。
- 作为玩家，我不会因拖动全景而误触建筑，也不会因多个红点而不知道先处理什么。

## 9. 归营结算与转场

- 归营不展示独立结算面板。确认归营并保存成功后，画面缓动至纯黑，在黑屏期间切换到
  营地大厅，再缓动恢复画面。
- 主动归营、入口传送阵归营和战败返回均使用同一黑屏转场；转场期间必须拦截输入。
- 临时战利品、剩余携带物、修士伤亡、任务推进和建筑解锁必须在转场前原子结算；保存
  失败时留在原页面并允许重试，不能先切场再补写存档。
- 战斗胜利获得的魂晶在战利品弹窗内展示并即时入账，不进入普通背包、不占负重。
- 回到大厅后定位中部默认视口，并刷新资源、主线提示、建筑状态和红点。

## 10. 红点规则

- 同一建筑或底部入口只显示一个总红点。
- 红点只表示“有可执行动作”，不表示“有可查看信息”。
- 资源不足、未满足条件不产生红点。
- 招贤馆出现高阶灵根候选可产生红点，但同一批只提醒一次。
- 还魂殿存在未处理死亡修士必须提示。
- 同屏最多三个一级红点，其余收纳到对应入口内部。
- 暂不实现的竞技场、遗迹、圣迹、教会、成就、排行榜、邮件和日常进度不产生红点。

## 11. 页面返回规则

- 系统返回键优先关闭最上层弹窗。
- 无弹窗时返回上一级页面。
- 大厅是根页面，返回键不能退出到空白页面。
- 入山地图中返回键不能直接退出，打开暂停/返回确认。
- 战斗中返回键打开暂停，不直接判负。
- 浏览器刷新前若有未保存状态，先同步存档。

## 12. 异常与边界

- 全景美术尚未加载时显示可操作的灰盒或加载占位，不影响设置入口和错误反馈。
- 资源或任务数据未加载完成时显示占位符，不显示场景默认假数值。
- 快速连续拖动和点击期间，同一入口只响应一次。
- 横向内容宽度不足一屏时自动居中并禁用横滑，不允许露出空白区域。
- 浏览器地址栏伸缩、刘海和底部 Home Indicator 不得遮挡资源、主线、传送阵或底部入口。
- 720×1280 至 1080×1920 范围内保持默认中部视口可见议事殿、传送阵、招贤馆和交易行；炼器坊至少露出一个可辨识的局部引导（竞技场已并入背景图，不单独校验）。

## 13. 阶段验收

### P1

- 初次进入大厅默认位于中部，议事殿和传送阵完整可见，招贤馆与交易行可识别。
- 玩家无需引导即可横滑到左右边界，并找到仓库、墓园、工坊和庄园。
- 中部右缘能看到工坊的局部轮廓；继续右滑后能看到完整工坊入口。竞技场等四处远景由背景图表现，能看出是未开放场景即可，不要求可辨识为独立入口。
- 连续完成 20 次“拖动经过建筑”不发生误触；轻点建筑能正常响应。
- 顶部显示真实 Wallet 中的灵粮、灵木、玄铁、灵晶、庚精和当前主线提示，不使用场景默认假值。
- 底部图标顺序与本 PRD 一致；所有入口可操作或给出明确不可用原因。
- 点击城堡进入营地人物列表（NPC List），不得跳转营地总览或主线任务页。
- 底部右侧灵石读取 `Wallet.immortalCoin`；顶部灵晶读取 `Wallet.spiritStone`，两者数值互不串用；天符玉和所有付费入口不可见。
- 点击传送阵从大厅唤起入山整备面板，总点击数不超过 1 次。
- 从任一已接入子页面返回后，大厅资源、主线、状态和红点刷新，且恢复离开前的横向位置。

### P2

- 新玩家在无指导时能找到招募、编队相关入口和入山。
- 七座成长建筑的锁定、解锁、可用状态无歧义。
- 第一次入山在开始游戏 10 分钟内发生。

### P3C

- 营地成长能从视觉上识别 1、3、5 级。
- NPC 和建筑状态与任务一致。

### P4

- 所有页面支持鼠标与触控。
- 720×1280 到 1080×1920 不遮挡。
- 浏览器安全区、地址栏伸缩和后台恢复正常。

## 14. 当前不做

- 遗迹、圣迹、教会功能。
- 成就功能。
- 排行榜、邮件、日常进度功能。
- 充值、礼包、付费商店、广告、支付 SDK 与任何真实货币交易。
- 竞技场功能，包括 PvP 和单机竞技玩法。
- 自由摆放建筑。
- 大厅角色自由行走。
- 建筑施工等待队列。
- 多个营地。
- 社交访问其他玩家营地。

## 15. 待产品确认

以下行为暂不阻塞大厅框架，确认前统一显示“功能待定”反馈：

1. 玩家头像点击后的目标页面或弹窗。
2. 当前主线提示点击后打开任务详情、目标指引或其他行为。

美术交付已确定采用分层拼装；横向总宽度和各建筑点击热区随正式布局稿一并交付。
