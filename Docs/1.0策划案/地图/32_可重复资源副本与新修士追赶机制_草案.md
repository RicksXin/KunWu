## 1. 本轮固定结论

1. 不制作队伍挂机派遣，不把现实离线时间换算成灵石、魂晶、装备或材料。
2. 不设置每日次数、周常次数、体力券、入场门票、限时开放、广告翻倍和离线扫荡。
3. 主线、地图首次探索和Boss首杀负责首次通关保底；资源副本负责主动可重复经济。
4. 灵石副本和魂晶副本分开设置，避免一个“万能本”垄断所有长期收益。
5. 资源副本必须存在于具体大地图和世界叙事中，首次发现后可通过永久捷径或营地传送快速重返。
6. 单次挑战控制在约5–10分钟，由战斗、机关或短机制首领构成，不要求重跑整张野外大地图。
7. 难度层级随世界进度永久解锁，不按现实日期轮换；高难度的单位时间收益必须高于低难度。
8. 魂晶副本提供主动等级培养，灵石副本帮助突破、炼制器纹、重复打造和专精重置；后续开放招募后共同承担新修士追赶。
9. 特定Boss要求玩家凑齐特定**职能组合**，不把随机抽到某个指定姓名作为强制主线门槛。
10. 每个主线必需的Boss克制职能，必须在Boss前提供确定性获取路径，并至少存在两套可行阵容。
11. 1.0首发包含`map_03`“铸灵堂·回火矿窟”和`map_04`“封魂间·镇魂残响”。
12. 1.0不存在第五、第六名可招募修士；两座资源本是固定四人的自选扩展，不进入主线硬门槛。
13. 两座副本各有三个随进度永久解锁的固定难度，每个难度有一次性首通奖励。
14. 1.0不设置可选挑战词条；重复结算可以低概率掉落凡品至上品制式装备，不产珍品、法宝或古宝。

## 2. 长期经济结构

### 2.1 四层来源

| 经济层 | 主要来源 | 负责内容 | 是否可重复 |
|---|---|---|---|
| 首通保底 | 主线、固定探索、精英、Boss和章节结算 | 当前队伍达到下一阶段最低等级、突破和基础配装 | 否 |
| 资源副本 | 特定地图的灵石本、魂晶本 | 1.0追加培养与打造；后续新修士追赶 | 是，主动挑战 |
| 世界回访 | 普通地图重返、支线、条件事件、高危敌群 | 地区材料、装备模板、特定装备前置与证据 | 按对象规则 |
| 回收经济 | 百宝库分解制式装备 | 把无用装备转成少量再打造材料；玩家不能出售或回购 | 是 |

### 2.2 首次通关与长期培养分工

- 玩家完全不刷资源副本，也能依靠首次内容完成当前主线章节；
- 1.0反复炼纹、打造高品质装备和专精重置时，资源副本成为主要可重复来源；后续开放招募后再
  承担第二/第三队培养；
- 随机装备掉落不计入主线最低保底，避免因职业、槽位和七维不合适而卡关；
- 资源副本不能发放剧情证据、Boss核心、特定装备、古宝成品和跨图唯一锚点。

### 2.3 不强迫现实等待

所有主线门槛都按“玩家已经完成的主动内容”计算。经济验收必须以以下最保守条件通过：

- 不领取任何离线收益；
- 不等待灵圃生产完成；
- 不计算随机装备好运；
- 不依赖每日或每周重置；
- 完成规定的首次地图内容后即可继续推进。

资源副本提供的是玩家主动选择的重复培养，而不是藏在标称游玩时长之外的强制挂机时间。

### 3.2 投放原则

- 不要求每张地图都有资源本；每种核心资源保留少量有世界意义的长期产地；
- 早期副本不会因后期副本开放而失效，仍可定向获取早期打造材料；
- 高阶副本提供更好的单位时间核心货币收益，避免玩家长期秒刷最低难度；
- `map_09`复用既有三层和五灯战斗环，不违背“不再新增普通套娃副本”的地图规则；
- 资源副本的重复状态与主线状态分离，不复活主线Boss、不重置NPC选择、不刷新唯一宝箱。

### 3.3 首次发现与快速重返

1. 玩家先在对应大地图完成主线或副本净化，发现资源本入口；
2. 首次通关基础难度后开启永久捷径；
3. 后续可从营地传送阵选择“重返资源副本”，直接落在副本整备区；
4. 快速重返只是省去已清长路，不自动结算战斗，也不是扫荡；
5. 玩家仍需选择队伍、难度、挑战条件并实际完成战斗。

### 3.4 1.0解锁边界

- `map_03`回火矿窟在四臂铸灵傀首杀、战后工坊稳定后开放基础难度，服务地图4前的追加打造与自选培养；
- `map_04`镇魂残响在封魂间首清、对应魂印稳定后开放基础难度，不要求先击败1.0最终Boss；
- 两座副本的更高难度按筑基、结丹和实际世界里程碑永久开放，具体难度数值另表冻结；
- 首次通关基础难度后才出现营地快速重返；发现入口但未首通时，仍需从对应大地图前往；
- 两座副本不属于主线任务节点，不计入章节完成条件、地图Boss数量或结局完成度；
- 固定四人不挑战两座副本也能获得主线所需魂晶、灵石、突破材料和基础配装。

## 4. 灵石副本

### 4.1 定位

灵石副本是1.0及长期版本中灵石的主要可重复来源，服务以下消耗：

- 固定四人的额外突破与高成本专精重置；
- 制式装备打造；
- 器纹炼制与制式装备重复打造；
- 交易行购买限量材料、资源包和防卡死工具；
- 通关后重复打造；后续版本开放招募后再承担多队伍基础配装。

### 4.2 玩法骨架

灵石副本不能只是三波怪后开箱。推荐由三个阶段构成：

1. **勘脉：** 在多个矿脉中判断真实高产点，神识、法力或地图证据可缩短路径；
2. **护炉/运输：** 矿傀与夺宝者攻击炉心或运输阵，玩家需要处理目标优先级；
3. **回火首领：** 在过热前打破护甲、关闭错误炉口或击败短机制首领。

失败不扣门票。玩家可以立即调整阵容重试；已消耗的普通战斗消耗品按统一战斗规则处理。

### 4.3 收益目标

- 当前最高合格难度挑战约2–3次，应能覆盖一次同阶段普通突破费用，或一件同档制式装备的主要灵石成本；
- 器纹炼制和重复打造仍是长期消耗，不保证一次挑战就能完成一件目标构筑；
- 灵石本只附带少量玄铁、灵晶、庚精等主题材料，不大量产魂晶；
- 首次难度奖励可以包含配方、捷径或展示物，重复奖励只发可再生资源。

1.0绝对数值读取§6.4；平衡复核必须继续按实际通关时间计算`每分钟灵石收益`，不能只按单次奖励比较。

## 5. 魂晶副本

### 5.1 定位

魂晶副本是1.0及长期版本中的主动等级培养来源，并在后续开放招募后成为新修士追赶的主要
可重复来源。魂晶继续进入公共钱包，由玩家决定培养对象，不在副本结束时自动
给参战者升级，也不按四名队员重复乘算。

### 5.2 叙事边界

- 副本击败的是阵法残响、伪忆化形或无主能量凝结，不以炼化真实亡魂作为常规经济；
- 已净化、超度或封存的剧情NPC不能因为副本刷新重新出现并被反复击杀；
- 玩家在五鬼、双魂等支线中的道德选择不能被一句“这是副本模式”抹除；
- 魂晶奖励来自稳定阵法回收，不表现为抽取具体人物灵魂。

### 5.3 玩法骨架

1. **辨识残响：** 在真假目标中保护带正确时间戳或魂印的对象；
2. **稳定阵位：** 敌群试图破坏命灯、镜面或封魂节点；
3. **残响首领：** 根据本轮随机组合处理恐惧、摄魂、无名或记忆崩塌机制；
4. **结算：** 记忆完整度影响额外材料，不改变基础魂晶保底。

### 5.4 培养与追赶目标

- 1.0收益先按固定四人的Lv24至Lv30自由培养校验；后续开放招募时，当前世界进度最高难度挑战
  约3–5次，应能让一名Lv1新修士追到“上一主线阶段推荐等级下限”；
- 从上一阶段下限继续追到当前主力上限，需要参与当前地图、Boss或更多主动挑战；
- 不设置“新修士离线经验”或自动等级同步；
- 后期开放更高难度时，旧魂晶本仍可服务低阶队伍，但单位时间效率低于新本。

## 6. 难度与重复挑战

### 6.1 永久难度层级

1.0两座副本各配置三个随世界进度永久开放的固定难度；后续版本可以随新境界增加新难度，例如：

```text
炼气残层 → 筑基残层 → 结丹残层 → 元婴残层 → 化神残层……
```

难度名称与具体地图叙事结合，不在玩家界面直接显示“材料本1/2/3”。同一难度的敌人、机制和奖励固定在版本数据中，
不按玩家即时战力动态抬升，保证配装成长有真实意义。

### 6.2 收益效率约束

```text
repeatEfficiency = 核心货币期望值 / 合格队伍平均通关分钟数
```

- 新难度的`repeatEfficiency`必须明显高于旧难度；
- 低难度可快速清，但不能因加载和结算更短而成为最高效率刷法；
- 1.0不设置可选挑战词条、限时加码、禁用恢复或追加精英等额外收益条件；
- 连续挑战不触发递减收益，玩家投入的主动时间得到稳定回报。

### 6.3 奖励组成

重复奖励可以包含：

- 对应核心货币；
- 少量地区普通材料；
- 灵木、玄铁、灵石、灵晶、庚精的已配置档位资源包；资源包回营后才能打开；
- 低概率同档制式装备或装备匣；1.0品质上限为上品；
- 玄铁、庚精或器灵残片等普通再打造材料。

重复奖励不得包含：

- 主线任务物、剧情证据和NPC遗物；
- Boss核心、首次配方核心和跨图钥匙；
- 特定装备、古宝成品和结局锚点；
- 已完成支线中的真实残魂或唯一资源。

### 6.5 固定敌群与机制首领

每档固定为两场常规战加一场首领战，不按玩家战力动态缩放。下表HP已经包含在对应敌人实例中；
首领护盾计入成长分册的标准耐久，不能在实现时再额外乘难度系数。

残羽未处理和输出超时给出最高优先级诊断。

## 7. 后续新修士追赶循环

### 7.1 基础循环

```text
招贤馆获得新修士
  → 查看职业、技能与Boss克制标签
  → 挑战魂晶副本提升等级
  → 挑战灵石副本支付突破与打造
  → 从世界回访取得职业材料和装备模板
  → 与老修士组成新阵容
  → 挑战需要该阵容的Boss或高难副本
```

该循环不进入1.0，在正式开放招募的版本启用；后续长期Boss再逐步把多阵容储备变成必须掌握的核心玩法。

### 7.2 老带新

- 允许三名成熟修士带一名新修士进入资源副本；
- 奖励按难度和挑战结果结算，不因带低级修士自动提高总产出；
- 低级修士在战斗中仍要遵守承伤、阵亡和技能规则，不作为不受攻击的挂件；
- 玩家也可以用成熟队刷公共魂晶，再回营培养新修士；两种方式都合法；
- 资源副本不检查“必须让新修士参战”，避免玩家为了效率被迫拖一个完全无用单位。

### 7.3 追赶而非瞬间满级

资源本帮助新修士追到可参与当前内容的下限，不把新招修士一键同步到全队最高等级。最后一段培养仍需要装备、
职业理解和当前阶段战斗，使获取新修士既不会完全重练，也不会失去成长过程。

## 8. Boss阵容克制

### 8.1 设计目标

1.0用四个Boss预告不同职能的重要性，但不要求培养固定四人之外的修士；固定四人的合理分支与配装必须覆盖全部主线机制。
后续长期Boss不允许玩家用一套固定坦克、治疗、输出阵容解决全部内容。每个重要Boss至少检查两个阵容维度：

- 输出类型：物理、法术、神识、持续伤害、爆发；
- 攻击范围：单体、群体、召唤物处理；
- 目标高度：地面、飞行、空间错位；
- 生存方式：护盾、群体恢复、状态抵抗、分摊、召唤承伤；
- 控制方式：眩晕、打断、行动条、定界；
- 特殊职能：破甲、对空、镇魂、反隐、驱散或阵法操作。

### 8.2 要求职能，不锁随机姓名

主线Boss使用能力标签和替代组合，不直接写“必须拥有修士甲”：

```text
BossRequirementSet
  A: anti_air >= 2 AND sustain >= 1
  B: ranged_magic >= 2 AND forced_landing >= 1
```

满足A或B都能处理飞行阶段。招贤馆随机修士、剧情修士和不同职业分支可以提供相同标签，使玩家根据实际名册组队。

只有人物关系本身就是剧情主题的可选事件，才允许要求某个具名修士在场；这种要求可以改变对白、额外奖励或结局，
不能成为随机未获得该人物时无法继续主线的硬门槛。

### 8.3 机械硬要求，不做队伍表单硬锁

- 除境界、人数和剧情通行权外，Boss入口不按标签直接拒绝玩家；
- 玩家可以入场试战，但Boss机制会让缺少关键职能的阵容难以或无法解决；
- 探灵、失败诊断和任务情报必须说明缺的是何种能力；
- 编队界面显示当前阵容已满足、替代满足和未满足的职能；
- 玩家理解失败原因后，可以去招募、培养、转配装备或更换修士，而不是只看到“战力不足”。

### 8.4 确定性可获得约束

每个主线Boss的必需职能必须满足：

1. Boss前至少有一名确定性剧情修士、保底招募或可选职业分支能提供；
2. 至少再有一种不同来源提供替代者，避免单一路径选择后存档锁死；
3. 任一必需职能不依赖付费、限时卡池、现实日期或低概率抽取；
4. 若玩家已做出不可逆选择失去某名修士，任务页必须指出仍可取得的替代者；
5. 同一Boss至少有两套经过验证的四人阵容，不把“多阵容”写成纸面可能。

### 8.5 Boss职能示例

| Boss类型 | 主要检查 | 可行组合示例 |
|---|---|---|
| 飞行首领 | 对空、强制落地、远程续航 | 双对空＋群疗；双远程法术＋落地控制 |
| 重甲傀儡 | 破甲、混合伤害、打断修复 | 破甲物理队；法术爆发＋打断队 |
| 魂狱首领 | 镇魂、定力、全队恢复 | 镇魂辅助＋群疗；高定力护盾＋快速击杀残响 |
| 召唤首领 | 群攻、控场、主体爆发窗口 | 群法清场；召唤承伤＋范围剑阵 |
| 空间首领 | 定界、遁速、行动条控制 | 定界阵师；高速队＋多段打断 |
| 血祭首领 | 打断、护盾、目标保护 | 连续打断队；高护盾保护＋阶段爆发 |

具体Boss不必覆盖全部标签。每场只突出一至两个主问题，避免为了强迫换人而堆满互相冲突的硬克制。

## 9. 前四章Boss向长期系统的过渡

1. **守门石灵：** 检查物法混合和破反震，不要求精确姓名；后续同类石灵可让不同法系或破纹修士替代陆清。
2. **封坛尸将：** 检查魂旗优先级、持续恢复和对象破坏；不同单体爆发与护魂辅助均可进入替代阵容。
3. **四臂铸灵傀：** 检查部件选择、控制打断和物法护罩；1.0只预告未来阵容轮换，固定四人的合理分支与配装必须能够解决。
4. **银翅夜叉残蜕：** 检查群体恢复、尸毒承压和对空；长期正式版本应允许青冥剑修、远程法修、对空特装修士等多种组合。

1.0前四章明确不要求培养其他修士：固定四人的任一合理筑基分支组合都必须有可执行的通关路径，且无需刷两座资源本。
后续随机招贤修士只提供替代解法、降低难度和展示长期换阵容价值，不能反向改写1.0主线口径。

## 10. 信息揭示与编队体验

### 10.1 Boss情报

Boss职能要求通过世界内信息逐步揭示：

- NPC证词、尸体伤痕和副本机关提供初步机制；
- 探灵镜显示伤害类型、飞行、护罩、召唤和关键状态；
- 首次失败后给出最高优先级阵容缺口；
- 完成相关资源副本或职业试炼，可以解锁更详细的应对说明。

不在首次见Boss前直接列出唯一标准答案，但也不能要求玩家无提示地反复送死。

### 10.2 编队页

选择Boss目标后，编队页显示：

- Boss的已知机制标签；
- 当前四人的覆盖标签；
- 缺少或仅有一人的薄弱职能；
- 名册中可替换修士与其培养缺口；
- 对应魂晶、灵石资源副本的快捷追踪，而不是直接跳过战斗发资源。

### 10.3 装备与修士分工

- 修士技能决定核心职能，装备用于补强或提供有限替代，不让一件通用装备抹平全部职业差异；
- 对空、反隐、定界等特装可以让已有修士临时承担次级职能，但效率低于专职修士；
- 换阵容前可在营地无损卸装和调整预设，禁止为每次换人收取现实时间或付费成本；
- 一键套用队伍预设时仍校验同一装备实例不能被多人同时使用。

## 12. 后续版本与实现边界

1. 1.0两座资源本的时间、绝对收益、敌群、首领、首通和装备概率读取§6.4至6.5，不再留空。
2. 快速重返、难度选择、连续挑战和失败诊断的布局由对应页面PRD与视觉稿落地，不改变本表收益。
3. 后续新修士追赶次数需在开放招募版本按当时等级成本复核；不得直接沿用1.0最高档收益冒充高阶值。
4. 1.0之后从哪个Boss开始正式要求第五、第六名修士，以及`map_09`、`map_13`的事件与对象ID，
   在对应版本冻结，不属于1.0数值缺口。

## 13. 验收口径

1. 游戏不存在队伍挂机派遣和按离线时长发放战斗资源的系统。
2. 玩家不刷资源本也能完成当前主线首次通关；需要额外培养或打造时可以主动重复获取灵石和魂晶。
3. 资源副本无每日、周常、体力、门票、现实时间窗口和付费加速。
4. 首次发现后可快速重返，但每次奖励都必须实际完成挑战。
5. 单次挑战约5–10分钟，高难度单位时间收益明确高于低难度。
6. 灵石本与魂晶本主产出分离，不存在长期唯一最优万能副本。
7. 重复挑战不推进主线、复活Boss、重置NPC或重复发放唯一物。
8. 魂晶奖励来自阵法残响，不反复炼化已处理的真实剧情亡魂。
9. 后续开放招募后，新修士能通过3–5次当前合格魂晶挑战追到上一阶段推荐下限，具体次数由数值仿真确认。
10. 特定Boss确实要求不同职能组合，同一套四人队不能无视机制打穿全部长期内容。
11. 主线Boss不要求低概率抽到指定姓名；每个必需职能至少有两种来源和两套已验证阵容。
12. 入口不做无说明标签硬锁，探灵、失败诊断和编队页能告诉玩家缺少何种能力。
13. 换阵容、卸装和重组队伍不收取现实时间成本，也不依赖挂机培养。
14. 1.0首发可进入并重复完成回火矿窟和镇魂残响，两者均支持首清后快速重返。
15. 只使用固定四人且完全不挑战资源副本，仍可完成1.0全部主线Boss与结局。
16. 1.0没有任务、Boss入口、阵容标签或奖励条件要求第五、第六名修士。
