## 3. 统一设计口径

1. 地图数据边界可以是矩形，可玩轮廓必须由山体、建筑、深坑、封印墙等塑造成异形。
2. 主线对象应被地标、光照、声音和路径宽度共同引导，不依赖悬浮箭头单独指路。
3. 支路至少提供故事、资源、捷径、精英或副本中的一项明确价值，不能只有空走。
4. 精英承担路线门卫、机制预演或高风险收益，不得成为唯一主线的强制数值墙。
5. Boss前必须有安全整备区、机制预告和退出机会；不可返回与阶段锁逃生均提前明示。
6. 回访状态要改变环境、NPC、敌群和可处理对象，不能只换一段对白或重刷旧Boss。
7. 所有固定奖励、剧情分支和一次性对象按同一结算事务保存，刷新页面不得重复领取或回滚选择。
