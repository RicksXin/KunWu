## 1. 数值目标

本分册冻结 1.0 的 Lv1–30 成长、魂晶消耗、筑基/结丹突破成本、七维与生命计算、战斗二级
属性、状态结算和十小时资源投放。所有数值均为首轮可仿真基线，不允许 UI 另写一份公式。

设计目标：

1. 固定四人无需随机招募即可在 8–12 小时内全员结丹并通关。
2. 等级、装备和策略均有贡献；任何一项都不能单独覆盖最终 Boss 机制。
3. 主线和固定探索提供通关所需资源，重复刷怪只负责容错和通关后培养。
4. 筑基与结丹固定成功，不设置概率、保底、掉境界或付费加速。
5. 杂灵根墨言仍能完成主线，不要求替换为高资质同职业修士。

### 1.1 四阶段总控基线

下表中的持续输出是合格四人队在自动策略正确、命中与减伤已经结算后的全队秒伤区间，不是

首轮敌人数值必须围绕该表回算；装备特效、控制和阶段机制仍可使实际时间上下浮动。

### 2.3 筑基突破

通用条件：Lv10、完成地图 2 四阵眼与对应职业试炼、当前不在野外、未阵亡。

每人突破只消耗灵石 `300`，不消耗魂晶、丹药、职业信物或普通材料。第一次完成四阵眼固定
解锁四名修士的筑基试炼，并由章节结算发放灵石 `1200`，确保四人均可完成首次筑基。

洗髓不属于 1.0，因此选择前必须展示完整技能、成长、职业分支背景与修士形象差异，并二次确认。
分支背景不是参与数值或剧情判断的独立道途标签。突破完成后，再按普通升级表支付魂晶 `130`
执行 Lv10→11；两笔成本分栏展示并在同一事务中结算。

### 2.4 结丹突破

通用条件：Lv20、完成地图 3 主线、完成个人结丹试炼、当前不在野外、未阵亡。

每人基础消耗：

- 灵石 `1200`。
- 降尘丹 `1`。

支线“借阵结丹”可将每人的实际灵石消耗降低 `300`，但任何剧情分支都不能免除或替代降尘丹。

| 筑基分支 | 结丹职业 | 试炼重点 |
|---|---|---|
| 护法金身 | 不动金刚 | 连续三轮嘲讽冲击，使三名幻影队友存活并以金轮反照完成反伤 |
| 魔相力士 | 三相魔君 | 在自身低生命时开启魔纹，以吞元炼血恢复并完成限时输出 |
| 雷法术式 | 九霄雷君 | 控制雷印与雷链顺序，并在雷池过载前用雷泽回元稳住队伍 |
| 蜃景幻法 | 蜃梦玄君 | 同时维持三类减益和迷神 DoT，以夺念还元完成自恢复 |
| 镇幽符脉 | 镇魂符君 | 击破三类鬼物并使幻影队伍全程不低于 20% 生命 |
| 万象符脉 | 天元符君 | 用力士符傀承受三次定点攻击，并用六甲增元箓救回重伤幻影 |
| 青冥剑修 | 青冥剑君 | 以连续暴击叠加剑煞，在时限内击破飞行剑靶 |
| 玄岳剑修 | 玄岳剑君 | 先破甲、再用剑脊震岳打断蓄力，最后以重锋击破剑靶 |

降尘丹用于收束周身灵力、稳定丹田并凝结金丹，是结丹的必要丹药而非成功率加成。炼器坊3级
解锁降尘丹配方，并按固定配方炼制，不生成随机品质或七维。当前配方基线为凝丹灵草 `1`、
灵晶 `15`，固定成功并产出降尘丹 `1`；该配方即为1.0首轮冻结值。地图 3 主线结算固定提供
凝丹灵草 `4`、灵晶 `60`与灵石 `4800`；
地图上的额外凝丹灵草只用于追加炼制突破物和为后续大境界储备，不参与装备、工具或剧情交换；
额外灵晶仍可用于其他炼制。凝丹灵草不依赖战斗随机掉落，主线保底外由可重复野外灵草点提供。

结丹突破固定成功并给予一次性属性，随后按普通升级表支付魂晶 `520` 执行 Lv20→21。降尘丹
只在突破成功事务中扣除；保存失败时灵石、降尘丹、试炼状态、境界和等级全部回滚。

## 3. 七维成长

### 3.1 灵根资质倍率

灵根资质同时影响修士的 Lv1 初始七维，以及每次升级获得的七维成长。六档灵根使用两条
独立倍率；初始倍率较平缓，成长倍率差异更明显，但杂灵根仍必须能通过合理培养完成主线。

| 灵根资质 | 稳定 ID | 初始七维倍率 `basePercent` | 升级成长倍率 `growthPercent` |
|---|---|---:|---:|
| 杂灵根 | `mixed_root` | 100% | 100% |
| 伪灵根 | `pseudo_root` | 108% | 110% |
| 三灵根 | `triple_root` | 116% | 122% |
| 双灵根 | `dual_root` | 124% | 136% |
| 天灵根 | `heavenly_root` | 133% | 152% |
| 异灵根 | `variant_root` | 152% | 190% |

固定四人采用以下资质，不进行随机生成：

| 修士 | 初始职业 | 灵根资质 |
|---|---|---|
| 石岩 | 金刚禅修 | 伪灵根 `pseudo_root` |
| 陆清 | 五行法修 | 伪灵根 `pseudo_root` |
| 白灵 | 玄箓修 | 伪灵根 `pseudo_root` |
| 墨言 | 剑修 | 杂灵根 `mixed_root` |

```text
Lv1 最终基础属性
= floor(职业 Lv1 裸属性 × basePercent / 100)

某职业成长段累计属性
= floor(该段升级次数 × 职业成长率 × growthPercent / 1000 / 100)
```

倍率逐维计算并向下取整。灵根资质不改变职业、技能数量、技能 ID、装备资格、剧情阵营或
职业分支背景。1.0不开放随机修士；后续招贤馆独立抽取灵根时，抽取范围、生成顺序与概率
边界以总案 §4.7 为准，逐馆级精确概率在开放招募的版本另行冻结，不由本成长倍率表反推。

### 3.2 计算方式

```text
最终七维
= 灵根缩放后的 Lv1 基础
+ 炼气阶段逐级成长
+ 筑基/结丹所选路线的分段逐级成长
+ 结丹一次性属性
+ 装备
+ 状态
```

成长率使用千分位整数，`3000` 表示每级 `+3.0`；每段内部先累计、后向下取整。不能用
当前职业成长率回算 Lv1 至当前等级，否则转职会篡改已经获得的历史属性。

目标数据模型至少保存 `careerHistory[{careerId, fromLevel, toLevel}]`，或在突破时固化
`accumulatedGrowth`。现有 `HeroFactory` 只根据当前职业和 `(level-1)` 回算，无法满足本规则。

#### 3.2.1 高成本专精重置

- 已筑基且当前位于营地、存活、未处于战斗/出征/任务锁定状态的修士，可以支付高额灵石切换
  到同一初始职业的另一条筑基分支；不新增洗点道具、冷却或现实时间等待。
- 保留灵根、等级、境界、累计魂晶、突破完成状态、装备、剧情选择和个人试炼记录；不返还历史
  升级、突破或打造消耗。
- 用目标分支替换Lv11至当前等级的路线成长段；若已经结丹，同时替换对应结丹称号和一次性属性。
  系统从稳定的Lv1基础、炼气成长段、目标路线成长段和结丹记录确定性重建裸装七维。这是玩家
  主动执行专精重置时的唯一重算入口，不允许普通登录、换装或版本刷新调用。
- 三个核心技能整体替换为目标分支的三个稳定技能ID；筑基阶段使用基础数值，结丹阶段直接进入
  对应`【精通】`数值，不保留原分支技能形成自由技能池。
- 最大生命变化时按重置前生命比例折算当前生命并向下取整，存活修士最低保留1点，不能借重置
  免费回满；阵亡修士必须先还魂。
- 筑基修士每次重置消耗灵石 `3000`，结丹修士每次消耗灵石 `9000`。价格只读取执行时境界，
  不随重置次数、现实日期或当前灵石余额变化。校验、扣费、职业历史替换、七维重建、
  技能替换和保存必须在同一事务完成，失败时全部回滚。

## 4. 战斗二级属性与公式

### 4.1 基础公式

```text
生命上限 = 职业基础生命 + 肉身 × 8 + 装备生命
物理基础伤害 = 力道 × 主倍率 + 神识 × 副倍率
法术基础伤害 = 法力 × 主倍率 + 神识 × 副倍率
物理减伤 = 护体 / (护体 + K(等级))
法术减伤 = 定力 / (定力 + K(等级))
K(等级) = 100 + floor(24 × (等级 - 1) / 10)
行动间隔 = clamp(基础间隔 × 100 / (100 + 最终遁速), 4, 200) tick
```

模拟频率 20Hz，`20 tick=1 秒`。所有乘法先乘后除并向下取整，最终直接伤害至少 1。

### 4.2 命中、暴击与状态命中

```text
命中率 = clamp(90% + (攻方神识-守方神识) × 0.25%, 70%, 100%) + 装备命中
闪避率 = clamp((守方遁速-攻方神识) × 0.20%, 0%, 15%) + 技能/装备闪避
最终命中率 = clamp(命中率-闪避率, 50%, 100%)
暴击率 = clamp(5% + 攻方神识 / (攻方神识+200) × 25%, 5%, 30%) + 装备暴击
暴击伤害 = 150% + 装备暴伤
状态命中率 = clamp(技能基础命中 + (攻方神识-守方定力) × 0.3%, 25%, 100%)
```

治疗、护盾、确定性 Boss 机制技能不做普通命中判定。每次战斗使用稳定随机种子；刷新重打
可以产生新战斗种子，但同一快照回放必须一致。

### 4.3 状态统一语义

| 状态 | 数值语义 | 叠加 |
|---|---|---|
| 护盾 | 先于生命吸收伤害 | 不同来源相加；同来源取较高并刷新 |
| 加速/迟缓 | 最终行动间隔乘以 `(1-加速%)` / `(1+迟缓%)` | 各取最强，互相抵消后结算 |
| 聚灵/嘲讽 | 单体技能优先选取最高嘲讽强度者 | 取最高 |
| 伤害提升 | 最终伤害乘算 | 同来源刷新，不同来源相加，上限 60% |
| 破甲/降抗 | 目标护体/定力按百分比降低 | 相加，上限 50% |
| 中毒/灼烧 | 每 `20 tick` 结算一次，伤害由施加者属性快照计算 | 中毒最多 3 层；灼烧取最高并刷新 |
| 流血 | 每 `20 tick` 结算；不暴击，忽略护体与定力 | 最多 3 层；同来源刷新，不同来源独立 |
| 再生 | 每 `20 tick` 治疗；使用施加时属性快照，不暴击 | 同来源取较高并刷新；不同来源最多 2 个 |
| 导电 | 本身不造成伤害；为雷系技能提供增伤和连锁依据 | 最多 3 层；新层刷新全部剩余时间 |
| 弱点 | 把配置的命中/暴击/飞行命中加成给所有攻击者 | 同目标只保留效果较强者并刷新 |
| 眩晕 | 无法行动，行动计时暂停 | Boss 同战共享硬控计数：前三次持续 100%/60%/30%，第四次起免疫 |
| 冻结 | 无法行动，行动计时暂停；只能等待持续结束 | 与眩晕共用同一硬控递减计数 |
| 缠绕 | 无法行动，不阻止被动效果；只能等待持续结束 | 同上 |
| 沉默/封灵 | 不能使用带法术/状态标签的技能，可普通攻击 | 取最长 |
| 恐惧 | 行动就绪时基础 50% 概率延后 20 tick；每次施加最多触发一次 | 持续时间取最长，等待自然结束 |
| 尸毒 | 中毒类且降低受治疗效果 | 最多 3 层 |
| 空间错位 | 立即把行动计时增加 30 tick，不再另加持续减速 | 每次命中独立执行；空间错位免疫可阻止此次行动计时增加 |
| 魔气侵蚀 | 每层造成伤害+4%、受到伤害+6%，地图与战斗跨系统 | 最多 5 层，安全归营清除 |
| 飞行 | 单位标签，使普通近战最终命中-35% | 法术、御剑、弱点和明示可对空效果忽略惩罚 |

持续伤害共同规则：中毒、尸毒和流血忽略护体/定力；灼烧属法术伤害并经定力减伤；全部 DoT
不暴击、不触发“直接攻击”特效，且使用施加时的属性快照。某个效果若明示写“固定伤害”，则不受任何增减伤修正。

“状态抵抗 +X%”从最终状态命中率中减 X 个百分点，仍受 25% 下限约束；“控制抵抗 +X%”只把眩晕、
冻结、缠绕和恐惧的成功持续时间乘以 `(1-X%)`，向上取整，不改变命中率。受伤减免同来源取最高，
不同来源相加后上限 50%；命中、闪避、暴击最后仍分别经 §4.2 的上下限截断。

### 4.4 当前实现缺口

详细技能表落地前必须扩展现有技能 Schema：

- `appliesStatus` 改为 `effects[]`，支持一次技能同时伤害、治疗、护盾、吸血和附加状态。
- DoT 增加 `tickIntervalTicks`、属性倍率、最大层数和来源快照；不得继续每个 20Hz tick 跳伤害。
- 增加 `hitCount`、`baseHitChance`、`baseCritChance`、`cannotCrit`、`tags`。
- 目标规则增加按任意七维取最高/最低、按状态层数和按生命百分比选择；不能继续把
  “最高属性目标”硬编码为只比较力道。
- 护盾数值改为属性倍率而非只能填静态 `magnitude`。
- 加速、迟缓、伤害提升、反击、群体恢复和自吸血真正进入公式。
- 百分比破甲与当前平铺数值削减分开建模。
- 支持生命阈值、目标状态和敌人数等 AI 条件。
- 支持 Boss 阶段、部件、召唤物和不受普通抵抗影响的阶段状态。
- `StatusKind` 补入恐惧、尸毒、魔气侵蚀、弱点、导电、飞行和空间错位；飞行、部件状态和阶段标记是单位/战斗状态，不是常规减益。

## 6. 数值验收

1. 任选四个合法筑基分支组合，都能在全员结丹、队伍战力 `1550–1750` 且满足续航、承伤与
   对空职能时击败最终 Boss；完全忽略机制时不能只靠战力数字过关。
2. 不做支线仍可结丹并通关，但装备选择更窄、最终战容错更低。
3. 全支线玩家不需要重复清同一张图的普通敌群超过两轮。
4. Lv20 未结丹队伍即使战力达到 `1550`，也不能进入最终 Boss；UI 明确说明境界条件。
5. 分段成长在转职前后不重算历史属性，存档刷新后面板完全一致。
6. DoT 只按配置间隔跳伤，不随渲染帧率或 20Hz 每 tick 错误放大。
7. 魂晶、突破材料和打造消耗均有事务回滚，任何保存失败不产生半完成角色。
8. 不挑战任何重复资源副本时，首次内容仍能完成固定四人结丹与主线通关；
   两座1.0资源本的高难度单位主动游玩时间收益必须高于低难度，且不得出现现实等待门槛。
