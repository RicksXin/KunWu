版本：1.0-draft.3

关联：[成长与战斗数值](16_1.0成长经济与战斗数值_草案.md)

## 1. 技能定型规则

1. 炼气期每个初始职业有 3 个过渡技能。
2. Lv10 完成筑基转职后，一次性替换为该分支的 3 个核心技能；自此技能 ID、目标类型和核心机制全部锁定。
3. Lv20 突破结丹不更换技能，只将原技能提升到 `mastery` 数值，显示名增加 `【精通】`前缀。
4. 后续版本预留：元婴为`【小圆满】`、化神为`【大圆满】`，仍只增强属性；到炼虚期才允许替换新技能。
5. 1.0 共有 `36` 个稳定技能 ID：12 个炼气过渡技能+8 条筑基分支×3 个核心技能。
6. 本轮职业重构以下表的 36 个 ID 为新基线；旧草案的护山、玄冰、丹医、毒丹、绝影和探秘技能 ID 不再属于 1.0 内容。
7. 1.0 暂不提供战斗净化技能。减益通过持续时间、抵抗、恢复、护盾和机制打断应对。

### 1.1 表格口径

- `I/CD`：基础行动间隔/冷却，单位 tick；20 tick=1 秒。
- `筑基`：Lv11–20 使用的基准数值。
- `结丹【精通】`：Lv21–30 使用的增强数值；未写变化的目标、标签和规则完全沿用筑基版。
- 伤害、治疗、护盾和 DoT 先按属性倍率向下取整，再进入战斗公式。
- 多段技能逐段结算命中和暴击；DoT、反伤和临时生命不暴击。
- 群体“技巧”增益写入内部字段 `technique`，当前七维展示名仍为“神识”。

## 7. 默认自动策略

- 护法金身：自身无嘲讽→狮吼震心；无金轮反照→金轮反照；否则对高威胁单体使用镇狱掌印。
- 魔相力士：自身生命<60%→吞元炼血；无魔纹开体→魔纹开体；否则三相轰杀。
- 雷法术式：全队平均生命<65%→雷泽回元；可命中目标≥2→雷链追身；否则引雷落印。
- 蜃景幻法：自身生命<60%且有目标含≥2减益→夺念还元；敌人≥2→蜃雾蚀神；否则镜花惑心。
- 镇幽符脉：全队平均生命<70%或有人<40%→安魂回元箓；鬼类目标≥2→诛邪符阵；否则镇幽符宝。
- 万象符脉：敌方存在高威胁单体且无符傀→力士符傀；友方最低生命<45%→六甲增元箓；否则破灵符矢。
- 青冥剑修：目标剑煞≥3层且剑煞归流可用→剑煞归流；分光追影可用→分光追影；否则青冥点星。
- 玄岳剑修：敌方正在准备高威胁技能→剑脊震岳；敌人≥3→横剑断山；主目标无破甲→玄岳破甲；否则玄岳破甲。

## 8. 技能与 Boss 机制对应

| 需求 | 主解 | 替代解 | 装备容错 |
|---|---|---|---|
| 稳定承伤 | 护法金身嘲讽 | 万象力士符傀；魔相/玄岳高肉身 | 镇魔宝甲、封魔令 |
| 处理飞行 | 青冥飞剑、法术 | 装备明示对空 | 残翅骨环、镇魔剑胚 |
| 群体续航 | 镇幽安魂回元箓 | 五行归元、雷泽回元 | 回春玉、太清符印 |
| 危急单体保护 | 万象六甲增元箓 | 力士符傀吸引后续单体技能 | 清灵囊、黑风定界珠 |
| 鬼物/残魂 | 镇幽符脉 | 雷法、对鬼装备 | 护魂牌、太清护魂符 |
| 打断/拆护甲 | 玄岳剑脊震岳/玄岳破甲 | 镇狱掌印、破灵符矢 | 铸灵指环 |

最终 Boss 不要求战斗净化。尸毒只考验持续恢复、定力/装备抵抗、嘲讽保护与阶段输出速度。

## 9. 技能验收

1. 数据表恰有 36 个稳定技能 ID；四个炼气职业和八个筑基分支各引用 3 个。
2. 结丹前后的修士技能 ID 完全相同，只有 proficiency 与数值变化。
3. 结丹后显示`【精通】技能名`，存档不保存带前缀的文本。
4. 金刚怒目与狮吼震心均能强制可嘲讽单体技能改选目标；魔相力士和玄岳剑修不拥有嘲讽。
5. 五行归元和雷泽回元为中低群疗并增加少量技巧；安魂回元箓为中上群疗；六甲增元箓只是中高单疗并只增加恢复对象的护体。
6. 力士符傀首次召唤获得等于最大生命100%的临时生命；受伤优先扣临时生命，到期消失，重复释放不回满本体或临时生命。
7. 金轮反照只按实际直接承伤反伤，不由 DoT 或环境伤害触发，不形成反伤递归。
8. 青冥剑修暴击可稳定叠加剑煞 DoT；玄岳剑脊震岳为低伤、中低概率眩晕，横剑断山为中等群伤。
9. 所有减益都能自然结束，没有战斗必需的净化检查。
10. 在同属性、同敌人和同随机种子下，`【精通】`版不得比筑基版伤害、治疗、反伤、临时生命或状态强度更低。
