# 《昆吾禁地》视觉特效方案

版本：0.2  
引擎基线：Cocos Creator 3.8 LTS，TypeScript，Web Mobile/WebGL

## 1. 特效目标

特效负责表达四件事：

1. 战斗规则：攻击范围、命中、控制、增益、减益和危险预警。
2. 修仙题材：灵气、符箓、剑光、阵法、法宝、雷火与魔气。
3. 空间氛围：封印松动、古殿尘埃、雾雨、魂火和空间裂隙。
4. 操作反馈：按钮、招募、升级、掉落、建筑解锁。

特效不能掩盖单位、伤害数字和技能预警。像素主体与柔光特效可以混合，但边缘要保持清晰。

## 2. 技术栈

| 能力 | Cocos Creator 实现 |
|---|---|
| 序列帧 | `Animation` + `AnimationClip` + SpriteFrame |
| 粒子 | `ParticleSystem2D`；低端使用减少发射量的变体 |
| 材质 | `Material` + 自定义 Effect Asset |
| Shader | Effect/Pass 中的 2D Shader |
| 动态光 | 加法混合光晕 Sprite 或自定义材质，严格限制 |
| 屏幕后处理 | 独立 RenderTexture/Camera 或全屏 Sprite 材质 |
| 轨迹 | Graphics、预制序列帧、采样点带状网格 |
| 镜头反馈 | Camera 节点位移、缩放、色闪 |

特效数据与技能分离：

```json
{
  "effect_id": "vfx_sword_pierce",
  "prefab": "db://assets/bundles/shared/vfx/combat/vfx_sword_pierce.prefab",
  "attach": "target",
  "duration": 0.55,
  "quality": "all",
  "shake": {"strength": 2.0, "duration": 0.12}
}
```

## 3. 视觉语言

### 3.1 职业能量语言

| 类别 | 色彩 | 形状 | 动态 |
|---|---|---|---|
| 金身护法 | 赤金/铜褐 | 掌印、金轮、经纹 | 沉稳外扩、受击回震 |
| 魔相炼体 | 暗金/血褐 | 魔纹、臂影、吞元涡流 | 贴身爆发、回吸 |
| 五行与雷法 | 青蓝/蓝紫/白 | 法盘、五行环、分叉电弧 | 聚合后瞬发、连锁跳跃 |
| 蜃景幻法 | 月白/雾青/灰紫 | 镜片、水雾、重影 | 错位、叠层、缓慢侵蚀 |
| 玄箓符法 | 朱砂/靛金 | 符纸、法印、符傀关节 | 掷出、展开、逐段点亮 |
| 青冥飞剑 | 青白 | 细剑光、分光残影、剑煞蚀痕 | 快、直、多段回旋 |
| 玄岳重剑 | 岩褐/冷铁 | 厚重剑弧、碎甲、地裂 | 慢起、强停顿、大范围横扫 |
| 恢复与护持 | 青绿/米白 | 经脉符纹、呼吸圆环 | 向上汇聚、舒缓扩散 |

同类技能共享视觉语法，玩家不看文字也能判断效果。

### 3.2 技能表现级别控制

- 普通技能：1 个主图形 + 1 个命中闪。
- 强技能：前摇阵纹 + 主体 + 命中 + 余波。
- 终结技：短镜头聚焦，但完整时长不超过 1.5 秒。
- Boss 技能：预警必须早于伤害 0.6–1.5 秒。

### 4.2 通用反馈

- 物理命中：8–12 px 火花，0.15 秒。
- 法术命中：对应元素色的圆形冲击。
- 暴击：更锐利闪光 + 2 px 震屏；不要只放大数字。
- 格挡：弧形护体光片 + 兵刃震响。
- 嘲讽：嘲讽者头顶持续显示赤金印记；敌方锁定时短暂出现指向线。项目没有前后排，不能用站位表现谁承担攻击。
- 闪避：灰白残影，不出现“MISS”也应能理解。
- 死亡：主体变暗、魂火逸散；禁止夸张肢解。
- 复活：魂火回流、阵纹反转、角色由灰恢复。

## 6. 迷雾与神识

探索地图的黑暗不是简单黑色遮罩：

- `UNKNOWN`：95% 黑，边缘有低频噪声流动。
- `DISCOVERED`：降低饱和度和亮度，保留地形轮廓。
- `VISIBLE`：正常画面，边缘有青白神识晕光。

实现建议：

- 使用低分辨率 Viewport 生成视野 Mask。
- 地图坐标转 Mask 像素，使用平滑步进扩散边缘。
- 移动时 0.15 秒插值，避免视野一格一格硬跳。
- 低端模式关闭动态噪声，只保留静态遮罩。

### 6.1 固定地图对象提示

- 固定资源点首次进入神识范围时，播放一次 0.3 秒高光，不重复闪烁。
- 每图唯一Boss使用实心朱印；剧情精英和高危精英使用不同边框的精英标记，不出现旧三类Boss图例。
- 条件跨图出口在未达标时显示锁纹；属性达标后锁纹逐段熄灭。
- 重新进入地图时固定对象不播放“新出现”特效，除非其状态发生了刷新。

### 6.2 七维属性检定

- 检定开始：属性图标从四个队员头像汇聚到门槛条。
- 成功：当前值越过门槛，青白印章落下。
- 失败：赭红裂纹停在门槛前，再明确播放掉血、污染或道具消耗结果。
- 力量、魔力、技巧使用独立图形，不能只换颜色。

## 7. Shader 列表

### 必须

1. Sprite 闪白/受击换色。
2. 溶解：死亡、传送、封印解除。
3. 调色：章节色彩与中毒/魔化。
4. UI 灰度：未解锁建筑、不可用按钮。
5. 迷雾 Mask。
6. 水面与雾的 UV 扰动。

### 可选

1. 像素热扭曲。
2. 局部描边。
3. 空间裂隙折射。
4. CRT/老旧画面效果；仅作为特殊剧情，不用于常驻。

所有 Shader 参数必须有默认值和低画质降级方案。

## 8. 屏幕反馈

镜头震动分三级：

| 等级 | 位移 | 时长 | 场景 |
|---|---:|---:|---|
| 轻 | 1–2 px | 0.08–0.12s | 普通命中 |
| 中 | 3–4 px | 0.15–0.25s | 暴击、重击 |
| 重 | 5–7 px | 0.3–0.45s | Boss 砸地、封印破裂 |

- 同时触发时取最大值，不叠加到不可控。
- 设置中提供“关闭震屏”“降低闪光”。
- 全屏纯白闪不得超过 2 帧；光敏模式将高频闪烁替换为色调脉冲。

## 9. UI 特效

- 资源增加：资源图标轻弹 + 绿色数字上浮。
- 资源不足：图标横向轻震，不使用全屏红闪。
- 招募普通：卷轴展开。
- 招募高资质：符纹逐层点亮；最高资质不超过 2 秒。
- 建筑解锁：灰影 → 线稿 → 完整色彩，配合营地远景光。
- 装备打造：炉火、锤击三次、成品剪影。
- Boss 首杀掉落：宝物从封印环中缓慢浮出。

## 10. 对象池与生命周期

池化对象：

- 高频命中火花。
- 伤害数字。
- 子弹/飞剑。
- 状态图标。
- 环境落叶与灵萤。

不池化：

- 一次性页面过渡。
- 极少出现的 Boss 终结特效。
- 生命周期复杂、容易残留状态的剧情特效。

每个 VFX 场景必须：

- 有最长寿命保险。
- 结束时自动释放或归还池。
- 不在 `_process` 中频繁查找节点。
- 不独占修改全局时间缩放。

## 11. 性能分级

| 项目 | 低 | 中 | 高 |
|---|---:|---:|---:|
| 环境粒子 | 24 | 60 | 120 |
| 战斗粒子上限 | 250 | 600 | 1000 |
| 同时动态光 | 0 | 2 | 4 |
| 扭曲 | 关闭 | 关键技能 | 全部 |
| 雾噪声 | 静态 | 低频 | 完整 |
| 屏幕余辉 | 关闭 | 低 | 标准 |

Web 首发只使用 WebGL 普遍支持的 2D 能力，不依赖实验性 WebGPU 或计算着色器。特效必须在桌面 Chrome/Firefox、Android Chrome 和 iOS Safari 验证，不能只看编辑器。

## 12. 特效制作流程

1. 策划提供技能意图、伤害时刻、范围和状态。
2. 动画确定动作命中帧。
3. 特效制作灰盒：形状、时长、预警。
4. 接入战斗事件，不绑定伤害计算。
5. 手机实机检查可读性。
6. 补色彩、粒子、镜头和音效。
7. 制作低画质变体。
8. 录制 10 秒预览并登记版本。

## 13. Demo 资产复用

`ThirdParty/DemoAssets/VFX/SpellEffects_CC0` 可用于：

- Fireball：赤霞灵火占位，换色并叠加符纹。
- Icespear：剑气/冰针占位。
- Thundersphere：雷法与阵眼占位。

不得只改文件名作为1.0成品；1.0至少重制轮廓、节奏、色盘和命中段。

## 14. 验收标准

- 不看技能名，测试者能分辨伤害、治疗、护盾、控制和危险预警。
- 所有 Boss 大招有明确前摇。
- 四人同时释放技能时仍能看清生命和状态。
- 低画质不丢失规则信息。
- 光敏模式下没有高频全屏闪烁。
- 自动战斗 20 分钟无粒子、节点池或纹理引用泄漏。
