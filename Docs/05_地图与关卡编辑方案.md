# 《昆吾禁地》地图与关卡编辑方案

版本：0.1  
地图形态：竖屏 2D、固定方格骨架、动态遭遇与有限随机事件

## 1. 地编目标

地图要同时制造三种压力：

1. 信息压力：迷雾遮蔽，无法一次掌握全图。
2. 补给压力：每一步消耗灵粮，越深入越难安全返回。
3. 负重压力：带更多补给能走更远，但能带回的战利品更少。

地图不是随机拼接迷宫。主路径、关键建筑、任务坐标和 Boss 区域由地编手工设计；普通怪、采集点和部分事件按种子刷新。

## 2. 昆吾山空间改编

原作相关资料描述了白玉广场附近通向昆吾殿、灵宝阁、镇魔塔的三处主要方向，另有万修之门及多处古修建筑。游戏将其改造成清晰的章节结构，而不逐段复述原著剧情。

参考：[昆吾殿、灵宝阁、镇魔塔空间关系](https://www.hetushu.com/book/38/25725.html)、[万修之门与镇魔塔概述](https://www.readnovel.com/chapter/22305390000123802/9734063480965401)

## 4. 方格与 Tile 规则

### 4.1 Tile 尺寸

- 源 Tile：16×16。
- 引擎逻辑：每格一个坐标。
- 显示：默认 3 倍。
- 人物始终站在格中心，碰撞不参与移动判断。

### 4.2 地形数据

每格包含：

```json
{
  "terrain": "jade_floor",
  "walkable": true,
  "move_cost": 1,
  "vision_block": false,
  "danger": 0.2,
  "height": 0,
  "tags": ["indoor", "ancient"]
}
```

### 4.3 TileMap 图层

1. Ground
2. Ground Detail
3. Walls/Cliffs
4. Props Below
5. Interactables
6. Dynamic Units
7. Props Above
8. Weather/VFX
9. Fog
10. Debug

碰撞和可走性来自数据，不依赖美术碰撞形状。

## 5. 探索节奏

每 8–12 步至少出现一个小决策：

- 分岔。
- 可见但需绕路的资源。
- 补给点。
- 风险事件。
- 战斗。
- 捷径门。

每 40–60 步出现一个中目标：

- 阵眼。
- 营地。
- NPC。
- 精英。
- 地图碎片。

一张地图从入口到章节 Boss 的最短路径约消耗初始最大补给的 55%–65%。玩家若搜刮支路，必须依靠营地、补给技能或升级负重。

## 6. 迷雾和视野

- 基础神识半径：2。
- 探灵灯 I/II/III：3/4/5。
- `UNKNOWN` 完全隐藏。
- `DISCOVERED` 保留地形与固定建筑，隐藏动态怪物和随机采集。
- `VISIBLE` 显示全部。

视野升级的价值：

- 更早看到危险。
- 减少无效绕路。
- 看见可选资源和隐藏岔路提示。

“半径 2”是本项目的主动取舍，用于强化未知感；不照搬参考游戏更大的火把视野。

## 7. 补给与负重的关卡使用

地形移动成本：

| 地形 | 灵粮/步 | 备注 |
|---|---:|---|
| 石道/玉砖 | 1 | 基础 |
| 林地/碎石 | 2 | 常见绕路 |
| 魔雾 | 2 | 另加污染 |
| 水潭/泥地 | 3 | 可由工具减免 |
| 传送阵 | 0 | 需先激活 |

负重设计：

- 出征灵粮也占负重。
- 临时战利品会增加负重。
- 超过 80% 时显示预警。
- 超重后不能继续捡取，但仍可移动。
- 紧急情况下可丢弃普通战利品。

地编必须在 Boss 前设置至少一个撤退判断点，不能让玩家毫无预警地陷入必死局。

## 8. POI 类型

| 类型 | 图标 | 功能 |
|---|---|---|
| 阵眼 | 八角阵 | 主线目标、改变地图 |
| 古修洞府 | 石门 | 宝物、敌人或 NPC |
| 临时营地 | 帐篷 | 休息、少量制粮 |
| 灵脉 | 晶石 | 解锁营地产能上限 |
| 断桥/封门 | 锁链 | 捷径，需要工具 |
| 残碑 | 碑文 | 世界观、地图线索 |
| 传送阵 | 圆阵 | 地图内快速移动 |
| 污染源 | 紫焰 | 持续危险，可净化 |
| 宝匣 | 箱 | 战利品与负重决策 |
| 逃生符点 | 符纸 | 单向回营地 |

## 9. 动态遭遇

### 9.1 普通怪刷新

- 地图初次进入根据种子生成。
- 不在入口视野内生成。
- 不阻断唯一主路径超过两处。
- 清理后本次出征不重生。
- 重新出征可按章节规则刷新 30%–60%。

### 9.2 随机事件

事件由条件与权重选择：

```text
队伍有丹霞子 → 可识别毒泉
携带破禁锥 → 可开启侧门
污染值 > 50 → 增加幻觉事件
负重 > 80% → 增加被伏击概率
完成 NPC 任务 → 原敌对点变为补给点
```

随机事件不改变关键剧情结局，只改变资源、路径和战斗。

## 10. 环境灯光

本项目 2D 灯光主要用于强调，不模拟真实全局照明。

- 营地：暖黄灯，边缘冷色月光。
- 古道：环境亮度 55%，探灵灯为青白局部光。
- 白玉广场：冷天光，阵眼激活后逐步增亮。
- 主殿：梁柱遮挡形成明暗带。
- 镇魔塔：低亮度，紫黑魔气局部吞光。

动态光数量受技术文档限制。大量灯笼使用预烘焙光晕 Sprite。

## 11. 天气与时间

营地有昼夜循环，但不使用真实 24 小时强绑定：

- 一个游戏昼夜 20 分钟。
- 时间只改变环境表现和少量 NPC，不限制核心功能。
- 离线回来不强制跳过完整昼夜演出。

天气：

| 天气 | 表现 | 玩法影响 |
|---|---|---|
| 晴/云 | 基础 | 无 |
| 灵雨 | 雨线、地面波纹 | 木魅增多，灵植收益提高 |
| 山雾 | 低层雾 | 视野 -1，伏击概率上升 |
| 雷暴 | 远雷、电闪 | 雷法增强，部分阵眼活跃 |
| 魔潮 | 紫黑尘 | 污染增长，稀有掉落提高 |

Demo 天气只做表现；MVP 再启用数值影响。

## 12. 地编工具链

推荐直接使用 Godot TileMapLayer；若地图编辑效率不足，再接入 Tiled。

地图导出必须校验：

- 出入口连通。
- Boss 可达。
- 没有关键物件出现在阻挡格。
- 最短路径补给消耗在预算内。
- 传送阵成对。
- 所有 POI ID 唯一。
- 入口安全半径内没有敌人。

建议编辑器插件：

- 地图规则检查。
- POI 可视化。
- 最短路径与补给热力图。
- 视野预览。
- 遭遇密度热力图。
- 一键试玩当前坐标。

## 15. 地编验收标准

- 从任何关键点都存在补给合理的返回路径。
- 新玩家在五分钟内理解坐标、迷雾、补给和负重。
- 地图没有超过 20 步的纯走路空段。
- 关键路线可通过地标识别，不完全依赖小地图。
- 隐藏路线有环境提示，不是无理由撞墙。
- 天气和前景不遮挡交互格。
- 手机上长按寻路不会误触底部 UI。
