# 《昆吾禁地》地图与关卡编辑方案

版本：0.2  
地图形态：竖屏 2D、五张完整方格大地图、固定坐标内容、条件式跨图连接

## 1. 地编目标

地图要同时制造三种压力：

1. 信息压力：迷雾遮蔽，无法一次掌握全图。
2. 补给压力：每一步消耗灵粮，越深入越难安全返回。
3. 负重压力：带更多补给能走更远，但能带回的战利品更少。

地图不是随机拼接迷宫，也不按“主路、支路、岔路”组织。每张地图都是一块完整二维区域，由大量小格组成；队伍只占其中一个格子，每次移动一格。敌人、事件、副本、资源、Boss、建筑和出口全部由地编放在固定坐标。

## 2. 昆吾山空间改编

原作相关资料描述了白玉广场附近的昆吾殿、灵宝阁、镇魔塔等重要区域，另有万修之门及多处古修建筑。游戏不把三处建筑做成一张地图内的“路线选择”，而是将其转化为五张可独立进出、彼此存在条件连接的完整野外地图。

参考：[昆吾殿、灵宝阁、镇魔塔空间关系](https://www.hetushu.com/book/38/25725.html)、[万修之门与镇魔塔概述](https://www.readnovel.com/chapter/22305390000123802/9734063480965401)

## 3. 五张完整野外地图

首发制作 5 张，数据和工具不设硬上限，后续增加到 30 张以上时无需重写地图系统。

| 地图 | 尺寸建议 | 视觉与玩法主题 | 固定 Boss 配置 | 跨图连接 |
|---|---:|---|---|---|
| 地图 1：破禁山麓 | 48×64 | 山道、废营、外层禁制；教学 | 主线小 Boss“守门石灵”；可选精英“尸傀头领” | 常规出口至地图 2 |
| 地图 2：白玉广场 | 64×64 | 开放玉庭、阵眼、古修洞府 | 主线小 Boss“封坛尸将”；支线 Boss“木魅妖母”；野外 Boss“银甲尸王” | 常规至地图 3；高门槛出口直达地图 4 |
| 地图 3：灵宝遗址 | 56×72 | 机关区、库房、残器和高负重收益 | 主线小 Boss“铸灵傀儡”；支线 Boss“失控器灵”；野外 Boss“夺宝邪修” | 至地图 4；返回地图 2 |
| 地图 4：古殿群 | 72×64 | 宫殿、阵营 NPC、封印令 | 主线小 Boss“护殿残魂”；支线 Boss“玄岩古兽”；野外 Boss“魔道猎手” | 至地图 5；隐藏出口回地图 2 |
| 地图 5：镇魔禁域 | 64×80 | 封链、魔气、塔域与终局压力 | 主线小 Boss“镇塔妖物”；支线 Boss“封链魔灵”；野外 Boss“游荡古尸”；最终 Boss 单独战斗场景 | 至封印核心 |

从地图 2 开始，每张图最低内容量：

- 1 个主线小 Boss：通常控制主线任务或常规出口。
- 1 个支线 Boss：控制 NPC、装备或支线结局。
- 1 个野外 Boss：固定坐标，高于当前主线强度。
- 8–16 个固定普通敌群。
- 8–15 个固定资源点。
- 3–6 个固定事件。
- 1–3 个固定小型副本入口。
- 1 个常规跨图出口，按需要增加高门槛出口。

Demo 完成山外营地、地图 1 全图，以及地图 2 的可进入预览区域，形成 30–45 分钟垂直切片。

## 4. 方格与 Tile 规则

### 4.1 Tile 尺寸

- 源 Tile：16×16。
- 引擎逻辑：每格一个坐标。
- 显示：默认 3 倍。
- 人物始终站在格中心，碰撞不参与移动判断。

### 4.2 地形数据

每格包含：

```json
{
  "terrain": "jade_floor",
  "walkable": true,
  "move_cost": 1,
  "vision_block": false,
  "danger": 0.2,
  "height": 0,
  "tags": ["indoor", "ancient"]
}
```

### 4.3 TileMap 图层

1. Ground
2. Ground Detail
3. Walls/Cliffs
4. Props Below
5. Interactables
6. Dynamic Units
7. Props Above
8. Weather/VFX
9. Fog
10. Debug

碰撞和可走性来自数据，不依赖美术碰撞形状。

## 5. 探索节奏

每 8–12 步至少出现一个小决策：

- 选择下一个固定目标坐标。
- 是否绕过障碍取得资源。
- 补给点。
- 属性检定事件。
- 固定敌群。
- 是否挑战高强度 Boss。

每 40–60 步出现一个中目标：

- 阵眼。
- 营地。
- NPC。
- 精英。
- 地图碎片。

一张地图的多个目标散布在整个二维区域。地编需要计算“入口 → 主线目标 → 常规出口”的最低补给消耗，也要计算“入口 → 远端资源/Boss → 返回”的往返消耗。前者约占初始最大补给的 55%–65%；全面搜刮需要营地、补给技能或更高负重。

## 6. 迷雾和视野

- 基础神识半径：2。
- 探灵灯 I/II/III：3/4/5。
- `UNKNOWN` 完全隐藏。
- `DISCOVERED` 保留地形、固定建筑和已发现的固定 POI；隐藏当前视野外敌人的实时状态。
- `VISIBLE` 显示全部。

视野升级的价值：

- 更早看到危险。
- 减少无效绕路。
- 看见可选资源、事件和高门槛出口提示。

“半径 2”是本项目的主动取舍，用于强化未知感；不照搬参考游戏更大的火把视野。

## 7. 补给与负重的关卡使用

地形移动成本：

| 地形 | 灵粮/步 | 备注 |
|---|---:|---|
| 石道/玉砖 | 1 | 基础 |
| 林地/碎石 | 2 | 困难地形 |
| 魔雾 | 2 | 另加污染 |
| 水潭/泥地 | 3 | 可由工具减免 |
| 传送阵 | 0 | 需先激活 |

负重设计：

- 出征灵粮也占负重。
- 临时战利品会增加负重。
- 超过 80% 时显示预警。
- 超重后不能继续捡取，但仍可移动。
- 紧急情况下可丢弃普通战利品。

地编必须在 Boss 前设置至少一个撤退判断点，不能让玩家毫无预警地陷入必死局。

## 8. POI 类型

| 类型 | 图标 | 功能 |
|---|---|---|
| 阵眼 | 八角阵 | 主线目标、改变地图 |
| 古修洞府 | 石门 | 宝物、敌人或 NPC |
| 临时营地 | 帐篷 | 休息、少量制粮 |
| 灵脉 | 晶石 | 解锁营地产能上限 |
| 断桥/封门 | 锁链 | 固定障碍，需要工具或属性检定 |
| 残碑 | 碑文 | 世界观、地图线索 |
| 传送阵 | 圆阵 | 地图内快速移动 |
| 污染源 | 紫焰 | 持续危险，可净化 |

| 逃生符点 | 符纸 | 单向回营地 |
| 跨图出口 | 山门 | 连接另一张完整地图，可能有任务/属性条件 |

## 9. 固定对象与刷新

### 9.1 固定坐标

- 普通怪、精英、Boss、资源、事件、小型副本和出口都有稳定 `object_id` 与坐标。
- 首次进入、读档和重新出征都不能改变对象坐标。
- 固定对象允许改变状态：未发现、已发现、已击败、已采集、冷却中、永久完成。
- 普通敌群若刷新，只在原坐标重生。
- 野外 Boss 固定在唯一坐标；美术可以播放原地待机，但逻辑位置不移动。
- 主线 Boss 永不刷新；支线 Boss 根据任务设计决定；野外 Boss 可按现实时间或出征次数刷新。

### 9.2 固定事件和七维检定

事件位置固定，但结果可以由职业、道具、剧情状态和七维属性决定：

```text
技巧总和 ≥ 30 → 安全拆除小型遗迹机关
技巧不足 30 → 全队损失当前生命的 20%，仍可通过

力量最高值 ≥ 25 → 推开石门
力量不足 → 需要消耗破禁锥

抗性全员 ≥ 18 → 穿过魔雾不受伤
未通过 → 每名队员获得一层污染
```

检定类型：

- `SUM`：全队属性总和。
- `MAX`：最高单人属性。
- `COUNT`：达到个人阈值的人数。
- `ALL`：所有存活队员达标。

事件 UI 必须显示检定属性、口径、当前值、门槛和失败后果；剧情明确要求未知时才隐藏数值。

### 9.3 Boss 类型

| 类型 | 位置 | 刷新 | 作用 |
|---|---|---|---|
| 主线小 Boss | 固定坐标 | 不刷新 | 主线阶段、关键出口 |
| 支线 Boss | 固定坐标/小副本终点 | 通常不刷新 | NPC、装备、支线结果 |
| 野外 Boss | 固定坐标 | 可刷新 | 高难挑战、稀有材料 |
| 最终 Boss | 独立战斗场景 | 首杀后剧情处理 | 章节结局 |

## 10. 环境灯光

本项目 2D 灯光主要用于强调，不模拟真实全局照明。

- 营地：暖黄灯，边缘冷色月光。
- 古道：环境亮度 55%，探灵灯为青白局部光。
- 白玉广场：冷天光，阵眼激活后逐步增亮。
- 主殿：梁柱遮挡形成明暗带。
- 镇魔塔：低亮度，紫黑魔气局部吞光。

动态光数量受技术文档限制。大量灯笼使用预烘焙光晕 Sprite。

## 11. 天气与时间

营地有昼夜循环，但不使用真实 24 小时强绑定：

- 一个游戏昼夜 20 分钟。
- 时间只改变环境表现和少量 NPC，不限制核心功能。
- 离线回来不强制跳过完整昼夜演出。

天气：

| 天气 | 表现 | 玩法影响 |
|---|---|---|
| 晴/云 | 基础 | 无 |
| 灵雨 | 雨线、地面波纹 | 木魅增多，灵植收益提高 |
| 山雾 | 低层雾 | 视野 -1，固定敌人更晚被看见 |
| 雷暴 | 远雷、电闪 | 雷法增强，部分阵眼活跃 |
| 魔潮 | 紫黑尘 | 污染增长，稀有掉落提高 |

Demo 天气只做表现；MVP 再启用数值影响。

## 12. 地编工具链

推荐使用 Tiled 制作 TMX/TSX，再由 Cocos Creator `TiledMap` 组件加载；固定对象放在 Tiled Object Layer，并通过构建脚本导出为带类型的地图 JSON。大地图美术层与逻辑对象层分离。

地图导出必须校验：

- 所有常规与条件出口连通。
- 所有 Boss 和固定 POI 可达。
- 没有关键物件出现在阻挡格。
- 每组“入口—目标—出口/返回”的最短补给消耗在预算内。
- 传送阵成对。
- 所有 POI ID 唯一。
- 入口安全半径内没有敌人。
- 不同地图间不存在无法返回且未提示的单向死锁。
- 地图 2 → 地图 4 等高门槛连接正确校验任务、道具与属性。

建议编辑器插件：

- 地图规则检查。
- POI 可视化。
- 任意两固定坐标的最短路径与补给热力图。
- 视野预览。
- 固定敌群、资源与事件密度热力图。
- 跨图连接关系图。
- 一键试玩当前坐标。

## 15. 地编验收标准

- 从任何关键点都存在补给合理的返回路径。
- 新玩家在五分钟内理解坐标、迷雾、补给和负重。
- 地图没有超过 20 步的纯走路空段。
- 固定目标可通过地标和坐标识别，不完全依赖小地图。
- 条件出口有环境提示，不是无理由撞墙。
- 重新进入地图后固定对象位置不改变。
- 从地图 2 开始，每张图同时拥有主线小 Boss、支线 Boss 和野外 Boss。
- 天气和前景不遮挡交互格。
- Web 端鼠标点击与移动浏览器触控寻路都不会误触底部 UI。
