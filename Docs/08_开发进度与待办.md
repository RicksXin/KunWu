### `#1` P0-TECH-002 IndexedDB 和备份 — 已完成

按 PRD-10 §4 四步写入流程实现：序列化校验 → 旧主档进 backups → 同一 transaction
写新档 → 失败保留旧档。

| 文件 | 作用 |
|---|---|
| `services/SaveChecksum.ts` | 稳定序列化 + FNV-1a 32 位校验 |
| `services/SaveBackend.ts` | 事务抽象接口（仅类型） |
| `services/SaveRepository.ts` | 备份轮转、校验、逐版本迁移 |
| `services/MemorySaveBackend.ts` | 内存后端，供单测与 IndexedDB 降级 |
| `services/IndexedDbSaveBackend.ts` | 浏览器后端 |

设计取舍：把「一次原子读改写」作为后端最小单元，而非暴露零散 get/put，
因为 PRD 要求备份与写新档同事务，这条约束只能在事务层表达。

已覆盖的 PRD-10 §11 验收：连续 20 次保存不坏档、20 份历史存档可迁移。
未覆盖（需真实浏览器，归入 `#8`）：后台 30 分钟恢复、清数据后导入恢复、断网运行。

### `#3` P0-MAP-001 Tiled 导入 — 已完成

`domain/TiledImport.ts`。处理干净了两个坐标系差异，不让它们泄漏到领域层：

用 `ThirdParty/` 五张真实 TMJ 验证过。对象 ID 取自定义属性 `object_id`
而非 Tiled 数字 `id`——后者编辑时会变，存档依赖稳定 ID。

### `#6a` P0-TECH-001 文件侧 — 已完成

| 文件 | 作用 |
|---|---|
| `build-templates/web-mobile/index.html` | 竖屏 meta、`viewport-fit=cover`、WebGL 预检、启动失败兜底页 |
| `build-templates/web-mobile/style.css` | 禁滚动/选中/缩放、安全区留白、像素图 `image-rendering: pixelated`、横屏提示 |
| `services/BrowserLifecycle.ts` | WebGL 上下文丢失/恢复、断网、`pagehide` 转领域事件（11 测） |
| `services/BundleManifest.ts` | Bundle 清单、首屏白名单、预载规则（14 测） |

三处要点：

- **`viewport-fit=cover` 是安全区的前提**。不加它 `env(safe-area-inset-*)` 恒为 0，
  `ViewportAdapter.readCssSafeAreaInsets` 就永远读到 0，刘海适配静默失效。
- **`webglcontextlost` 必须 `preventDefault`**，否则浏览器不再触发 `restored`，
  恢复逻辑永远等不到（PRD-10 §8）。
- **`BundleManifest.validateManifest()` 抓出了我自己写错的规则**：
  原先 `map_03 → map_04` 的无条件预载会抹掉 `map_02 → map_04` 的条件预载。
  按 PRD-05 §3 修正为「条件预载以来源地图为键」——地图 3 到地图 4 是常规出口，
  地图 2 到地图 4 才是隐藏条件出口。

顺带修掉：`tsconfig.tests.json` 的 `lib` 缺 DOM。`BrowserLifecycle` 是第一个
被测试导入且引用浏览器类型的文件，此前未暴露。

### 顺带修掉的三个真问题 — 已完成

   补了 `include`/`exclude`；`lib` 从 ES2015 放宽到 ES2020
   （`Object.entries`、`padStart` 原本不可用）。
