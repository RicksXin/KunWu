# 《昆吾禁地》游戏策划案

版本：0.1  
类型：竖屏 2D 像素修仙、营地经营、方格探索、四人半自动战斗  
目标玩家：喜欢资源规划、队伍构筑、黑暗探索和低操作强策略的玩家

## 1. 产品定位

一句话：

> 玩家经营一座临时修士营地，招募并培养不同流派的修士，在补给和负重限制下逐格探索一座封印松动的上古仙山，争夺宝物并阻止魔物脱困。

核心卖点：

1. 食物既是生产成本也是探索步数，营地和野外形成闭环。
2. 方格迷雾、补给、负重共同制造“是否继续深入”的风险选择。
3. 四人队伍的职业、装备和技能策略决定战斗，而不是手速。
4. 建筑与 NPC 随探索逐步解锁，营地从破败据点成长为修士联军。
5. 像素修仙美术降低产能压力，同时形成差异化。

## 2. IP 与发行策略

本策划分为两种显示层：

### A. IP 授权版

- 地点可使用昆吾山、万修之门、昆吾殿、灵宝阁、镇魔塔等名称。
- 剧情可在授权范围内还原相关势力、人物、法宝与事件。
- 必须以权利合同约定的媒介、地区、期限和审核流程为准。

### B. 原创商业版

- 世界改为“玄阙山封印遗迹”。
- 角色、势力、对白、怪物和宝物全部原创。
- 仅保留不受特定作品独占的通用机制：营地经营、招募、方格迷雾、资源和队伍战斗。

研发默认使用原创稳定 ID；文本表决定显示层。未取得授权前，只能公开原创商业版。

## 3. 世界观

上古修士曾在大山深处建立仙府群，以三座主建筑维持地脉封印。多年后，一支修仙世家秘密破开外围禁制，导致仙山现世。正魔宗门、散修、异族、古妖和魔道势力相继进入。封印持续松动，山内禁制失控、尸傀苏醒、空间裂隙扩张。

玩家不是原著主角，而是“山外联营”的执事，负责：

- 收容幸存修士。
- 调度杂役和资源。
- 组织探索队。
- 与不同势力交易或周旋。
- 决定优先夺宝、救人还是修复封印。

这种视角允许玩家组建自己的队伍，不依赖某一名固定主角。

## 4. 核心循环

```text
分配杂役生产
→ 升级建筑
→ 招募/培养修士
→ 打造装备与准备灵粮
→ 组成四人队伍
→ 进入方格地图
→ 消耗灵粮移动
→ 战斗、采集、解谜、夺宝
→ 在负重与生存之间决定继续或回城
→ 结算战利品
→ 解锁 NPC、建筑、职业和新区域
```

## 5. 资源系统

### 5.1 生产资源

| 资源 | 作用 | 核心来源 |
|---|---|---|
| 灵粮 | 工匠维护、出征移动、营地制作 | 灵圃 |
| 灵木 | 建筑、阵旗、低阶装备 | 林场 |
| 玄铁 | 炼器、工具、建筑 | 矿洞 |
| 灵石 | 高阶建筑、法器、阵法 | 灵脉 |
| 庚精 | 顶级装备、封印工程 | 稀有矿脉/Boss |

### 5.2 战斗与货币

| 资源 | 作用 | 来源 |
|---|---|---|
| 魂晶 | 修士升级、还魂 | 战斗、任务 |
| 仙铢 | 招募、刷新、坊市 | 探索、悬赏、出售 |
| 天符玉 | 高级货币预留 | MVP 不售卖 |

### 5.3 生产公式

初始结算周期 30 秒。

| 岗位 | 每人每周期产出 | 每人每周期灵粮维护 |
|---|---:|---:|
| 灵粮 | 1 | 0 |
| 灵木 | 1 | 2 |
| 玄铁 | 1 | 3 |
| 灵石 | 1 | 4 |
| 庚精 | 1 | 9 |

例如，10 名杂役生产灵木，需要至少 20 点同期灵粮供给。若灵粮不足，高级资源岗位按“庚精 → 灵石 → 玄铁 → 灵木”的顺序停工，防止出现负数。

### 5.4 离线收益

- Demo：最多累计 4 小时。
- MVP：建筑升级后从 4 小时提高至 8 小时。
- 离线只结算生产，不自动进行战斗或剧情。
- 回归时只显示总收益，不逐周期播放。

## 6. 营地建筑

### 6.1 建筑一览

| 建筑 | 功能 | 解锁 |
|---|---|---|
| 议事殿 | NPC、主线、建筑总览 | 初始 |
| 灵圃 | 杂役生产 | 初始 |
| 招贤台 | 招募、英雄容量 | 完成新手任务 |
| 百宝库 | 仓库与出征装载 | 初始 |
| 炼器坊 | 打造、重铸、工具 | 第一章营救炼器师 |
| 交易行 | 购买、出售、定时刷新 | 第一章找到商队 |
| 还魂坛 | 复活阵亡修士 | 击败第一只残魂精英 |

### 6.2 招贤台

- 每次展示 3 名候选修士。
- 每 60 分钟免费刷新。
- 手动仙铢刷新费用建议：20、40、80、140、220，之后维持 220。
- 免费刷新后手动计数清零。
- 新手阶段可使用灵粮进行“广招杂修”，只出现凡品至上品。
- 天符玉刷新仅保留接口，MVP 不接充值。
- 招贤台升级提高高资质概率、修士容量和等级上限。

资质概率示例：

| 招贤台等级 | 凡 | 良 | 上 | 玄 | 地 | 天 |
|---|---:|---:|---:|---:|---:|---:|
| 1 | 65% | 25% | 9% | 1% | 0 | 0 |
| 3 | 40% | 34% | 20% | 5.5% | 0.5% | 0 |
| 5 | 20% | 35% | 30% | 12% | 2.7% | 0.3% |

正式数值必须通过模拟验证。高资质不应成为通关唯一条件，低资质队伍通过装备和策略也能完成主线。

### 6.3 还魂坛

- 阵亡修士进入还魂名单。
- 复活消耗与等级、境界和资质相关的魂晶。
- 每次出征最多免费保留 1 名阵亡者 24 小时，其余永久保留但占用容量。
- 当还魂名单达到上限时禁止继续出征，并引导玩家处理。
- 允许“安葬”永久移除，返还部分已投入魂晶。

### 6.4 炼器坊

- 打造武器、防具、饰品和探索工具。
- 工坊等级决定配方和基础词条区间。
- Demo 不做装备强化失败。
- 重铸只改变一个指定词条，避免完全随机吞资源。

### 6.5 交易行

- 6 个普通商品栏，每 2 小时刷新。
- 1 个需求订单，玩家提交材料换仙铢。
- 关键任务物品不进入随机商店。
- 坊市不直接出售最高资质修士或毕业装备。

## 7. 修士系统

### 7.1 资质

六阶：

```text
凡品 → 良品 → 上品 → 玄品 → 地品 → 天品
```

资质影响成长率、初始天赋数量和最高潜能，不等于职业或境界。

### 7.2 境界与等级

MVP：

- 筑基：1–20 级。
- 结丹：21–40 级。
- 元婴：41–60 级。

突破需要等级、魂晶、材料和职业试炼。突破成功固定，不做概率失败。

### 7.3 首发职业

| 职业 | 定位 | 核心技能 |
|---|---|---|
| 青锋客 | 单体输出、破甲 | 青锋斩、破罡刺、御剑诀 |
| 玄甲士 | 坦克、反击 | 玄岩护体、镇岳击、不动身 |
| 丹霞子 | 治疗、火伤 | 回春丹气、赤霞灵火、清心散 |
| 伏阵生 | 控制、护盾 | 缚灵阵、移星换位、聚灵阵 |

MVP 扩展驭灵师、影符客。

### 7.4 属性

| 属性 | 用途 |
|---|---|
| 体魄 | 生命、物理承伤 |
| 灵力 | 法术伤害、治疗 |
| 筋骨 | 护甲、负重 |
| 身法 | 行动速度、闪避 |
| 神识 | 命中、抗控、探索事件 |
| 道心 | 暴击抵抗、魔化抗性 |

队伍负重：

```text
基础负重 + Σ(成员筋骨 × 系数) + 储物法器加成
```

## 8. 编队

- 一队 4 人。
- 阵位：前排 2、后排 2。
- 前排更容易被单体攻击。
- 部分技能要求前排或后排。
- 每名修士可配置 3 个主动技能和 1 个被动。
- 玩家可为每个技能设置启用、目标优先级和生命阈值。

推荐新手队：

```text
玄甲士 + 青锋客
丹霞子 + 伏阵生
```

## 9. 战斗

### 9.1 基础

- 实时半自动。
- 普通速度 1×，通关后开放 2×。
- 玩家可以点按角色头像，手动释放已就绪技能。
- 自动策略按照从上到下的规则判断。

### 9.2 伤害公式初稿

```text
物理伤害 = 技能倍率 × 攻击 × 100 / (100 + 护甲) × 浮动
法术伤害 = 技能倍率 × 灵力 × 100 / (100 + 法抗) × 浮动
浮动 = 0.95–1.05
暴击伤害 = 基础伤害 × (1.5 + 暴击增伤)
```

命中率上下限为 70%–100%，Boss 关键机制技能不使用随机未命中。

### 9.3 状态

- 增益：护盾、加速、聚灵、反击、净化。
- 减益：破甲、中毒、灼烧、迟缓、封灵。
- 控制：眩晕、缠绕、沉默。
- 特殊：污染、尸煞印、空间错位。

控制递减：同类硬控连续命中后持续时间按 100%、60%、30% 衰减，Boss 另有抗性。

### 9.4 战败

- 普通战败：所有临时战利品遗失，成员进入重伤或死亡。
- 使用逃生符：保留 50% 临时战利品，队伍返回。
- 主线关键物品取得后不会因战败永久丢失。
- 新手前三次出征提供一次自动救援，减少开局流失。

## 10. 野外探索

### 10.1 出征准备

玩家选择：

- 4 名修士。
- 灵粮数量。
- 逃生符。
- 工具：破禁锥、避水珠、阵盘等。
- 预留负重。

### 10.2 移动

- 四方向逐格。
- 基础地形每步 1 灵粮，困难地形 2–3。
- 灵粮耗尽不能继续普通移动。
- 玩家可以丢弃战利品、使用应急丹或回城。

### 10.3 神识迷雾

- 初始半径 2。
- 探灵灯升级到 3/4/5。
- 已探索区域保留地形，不保留动态敌人位置。

### 10.4 营地

地图临时营地可以：

- 休息，恢复 40% 生命。
- 用采集材料制作少量灵粮。
- 保存地图内临时复活点。
- 每次出征使用次数有限。

## 11. 剧情和阵营

玩家会遇到四类势力：

1. 破禁世家：目标是取得古宝。
2. 正道联军：优先重新封印。
3. 魔道修士：争夺魔功与魂魄。
4. 山中异类：希望取回本命禁制并脱离仙山。

MVP 的选择不做完全分叉主线，而是影响：

- 某些 NPC 是否入驻。
- 商店货物。
- 支线 Boss。
- 结局评价。
- 一件专属装备。

避免制作四套完全不同的关卡造成内容爆炸。

## 12. 任务系统

任务类型：

- 主线：开启区域、修复阵眼、击败 Boss。
- NPC：救援、护送、寻找法器。
- 悬赏：击杀指定精英。
- 收集：提交材料。
- 探索：发现坐标、残碑或传送阵。

任务状态：

```text
LOCKED → AVAILABLE → ACTIVE → READY_TO_TURN_IN → COMPLETED
                         └→ FAILED（仅限明确限时事件）
```

不使用隐藏永久失败。会改变关系的选择必须明确提示。

## 13. 建筑与剧情解锁

| 进度 | 解锁 |
|---|---|
| 新手 1 | 灵圃、百宝库、议事殿 |
| 新手 2 | 招贤台 |
| 第一章营救炼器师 | 炼器坊 |
| 第一章找到商队 | 交易行 |
| 第一章残魂事件 | 还魂坛 |
| 第二章修复第一阵眼 | 灵石岗位 |
| 灵宝支线 | 重铸、储物法器 |
| 主殿支线 | 高阶招募与阵营系统 |
| 镇魔支线 | 庚精岗位、污染净化 |

## 14. 装备

槽位：

- 武器
- 法衣
- 护具
- 饰品
- 本命法器

品质：粗制、精良、珍品、古宝、灵宝。装备品质与英雄资质使用不同名称和边框，避免混淆。

词条池：

- 主属性。
- 元素/流派增伤。
- 抗性。
- 治疗。
- 负重。
- 探索灵粮减免。
- 对特定敌族加成。

最佳装备不能全靠抽取，至少一半来自确定性配方或 Boss 首杀。

## 15. 经济设计原则

- 灵粮永远有价值，但不应让玩家因缺粮彻底无法游戏。
- 提供低效率的“休整”救济：等待 5 分钟可领取少量灵粮，每日有限。
- 高级资源需要食物维护，形成产业选择。
- 魂晶投入可部分返还，允许换队但保留成本。
- 招贤刷新是仙铢消耗口，但主线给定的基础修士必须能通关。
- Demo/MVP 不加入充值、抽卡付费或广告。

## 16. 新手流程

0–5 分钟：

- 接管营地。
- 分配 6 名杂役生产灵粮。
- 开启招贤台，获得固定的新手四人组。

5–12 分钟：

- 学会装备、技能策略、负重。
- 携带 60 灵粮出征。
- 移动、迷雾和第一次普通战斗。

12–20 分钟：

- 找到临时营地。
- 选择救人或先采集。
- 解锁炼器师。

20–35 分钟：

- 返回打造装备。
- 第二次出征，挑战精英。
- 解锁还魂坛。

35–45 分钟：

- 击败守门 Boss。
- 看到白玉广场和三条远期路线。
- Demo 结束。

## 19. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 未获 IP 授权 | 无法使用昆吾山专有设定发行 | 双命名、原创角色与资产 |
| 营地等待感过强 | 玩家无事可做 | 地图掉落、救济粮、短周期新手 |
| 刷英雄过度随机 | 挫败和数值膨胀 | 固定新手队、保底、低资质可通关 |
| 双视角动画成本高 | 美术延期 | Demo 复用免费素材，MVP 限定职业 |
| 地图重复 | 探索疲劳 | 手工地标、机制章节化、动态事件 |
| 负重过于惩罚 | 频繁回城 | 清晰预估、营地、捷径、逃生符 |

## 20. 策划验收标准

- 玩家无需阅读长教程即可理解“灵粮 = 生产成本 + 探索步数”。
- 第一次出征在 10 分钟内发生。
- 第一次有意义的继续/回城选择在 15 分钟内发生。
- 免费新手队能完成 Demo。
- 同一 Boss 至少有两种有效队伍解法。
- 所有永久损失有明确确认。
- 30–45 分钟 Demo 展示完整循环并以新区域悬念结束。
