# 《昆吾禁地》游戏策划案

版本：0.8  
类型：竖屏 2D 像素修仙、营地经营、完整方格大地图探索、四人半即时回合战斗  
目标玩家：喜欢资源规划、队伍构筑、黑暗探索和低操作强策略的玩家

## 1. 产品定位

一句话：

> 玩家经营一座临时修士营地，招募并培养不同流派的修士，在补给和负重限制下逐格探索一座封印松动的上古仙山，争夺宝物并阻止魔物脱困。

核心卖点：

1. 灵粮既是生产成本也是探索步数，营地和野外形成闭环。
2. 方格迷雾、补给、负重共同制造“是否继续深入”的风险选择。
3. 四人队伍的转职路线、七维属性、装备和三技能策略决定战斗，而不是手速。
4. 建筑与 NPC 随探索逐步解锁，营地从破败据点成长为修士联军。
5. 像素修仙美术降低产能压力，同时形成差异化。

## 2. IP 与发行策略

本策划分为两种显示层：

### A. IP 授权版

- 地点可使用昆吾山、万修之门、昆吾殿、灵宝阁、镇魔塔等名称。
- 剧情可在授权范围内还原相关势力、人物、法宝与事件。
- 必须以权利合同约定的媒介、地区、期限和审核流程为准。

### B. 原创商业版

- 世界改为“玄阙山封印遗迹”。
- 角色、势力、对白、怪物和宝物全部原创。
- 仅保留不受特定作品独占的通用机制：营地经营、招募、方格迷雾、资源和队伍战斗。

研发默认使用原创稳定 ID；文本表决定显示层。未取得授权前，只能公开原创商业版。

## 3. 世界观

上古修士曾在大山深处建立仙府群，以三座主建筑维持地脉封印。多年后，一支修仙世家秘密破开外围禁制，导致仙山现世。正魔宗门、散修、异族、古妖和魔道势力相继进入。封印持续松动，山内禁制失控、尸傀苏醒、空间裂隙扩张。

玩家不是原著主角，而是“山外联营”的执事，负责：

- 收容幸存修士。
- 调度杂役和资源。
- 组织探索队。
- 与不同势力交易或周旋。
- 决定优先夺宝、救人还是修复封印。

这种视角允许玩家组建自己的队伍，不依赖某一名固定主角。

## 4. 核心循环

```text
分配杂役生产
→ 升级建筑
→ 招募/培养修士
→ 打造装备与准备灵粮
→ 组成四人队伍
→ 进入方格地图
→ 消耗灵粮移动
→ 战斗、采集、解谜、夺宝
→ 在负重与生存之间决定继续或回城
→ 结算战利品
→ 解锁 NPC、建筑、职业和新区域
```

## 5. 资源系统

### 5.1 生产资源

| 资源 | 作用 | 核心来源 |
|---|---|---|
| 灵粮 | 工匠维护、入山移动、营地制作 | 灵圃 |
| 灵木 | 建筑、阵旗、低阶装备 | 林场 |
| 玄铁 | 炼器、工具、建筑 | 矿洞 |
| 灵晶 | 高阶建筑、法器、阵法 | 灵脉 |
| 庚精 | 顶级装备、封印工程 | 稀有矿脉/Boss |

### 5.2 战斗与货币

| 资源 | 作用 | 来源 |
|---|---|---|
| 魂晶 | 修士升级、还魂 | 战斗、任务、镇魂残响主动副本 |
| 灵石 | 招募、刷新、坊市 | 探索、回火矿窟主动副本、出售 |
| 天符玉 | 高级货币预留 | 1.0不展示、不售卖 |

### 5.3 生产公式

初始结算周期 30 秒。

| 岗位 | 每人每周期产出 | 每人每周期灵粮维护 |
|---|---:|---:|
| 灵粮 | 1 | 0 |
| 灵木 | 1 | 2 |
| 玄铁 | 1 | 3 |
| 灵晶 | 1 | 4 |
| 庚精 | 1 | 9 |

例如，10 名杂役生产灵木，需要至少 20 点同期灵粮供给。若灵粮不足，高级资源岗位按“庚精 → 灵晶 → 玄铁 → 灵木”的顺序停工，防止出现负数。

### 5.4 离线收益

- Demo：最多累计 4 小时。
- 1.0：建筑升级后从4小时提高至8小时。
- 本节离线只结算灵圃生产，不自动进行战斗或剧情；游戏不设置修士挂机派遣或离线战斗收益。
- 回归时只显示总收益，不逐周期播放。

## 6. 营地建筑

### 6.1 建筑一览

| 建筑 | 功能 | 解锁 |
|---|---|---|
| 议事殿 | 营地人物列表与 NPC 对话 | 初始 |
| 灵圃 | 杂役生产 | 初始 |
| 招贤馆 | 招募、修士容量、等级上限与境界权限 | 完成新手任务 |
| 百宝库 | 仓库与入山物资库存；实际装载在传送阵面板 | 初始 |
| 炼器坊 | 打造、重铸、工具 | 第一章营救炼器师 |
| 交易行 | 购买、出售、定时刷新 | 第一章找到商队 |
| 还魂坛 | 复活阵亡修士 | 击败第一只残魂精英 |

### 6.2 招贤馆

- 每批固定3名炼气Lv1候选，职业允许重复；形象属性模板和灵根独立抽取。
- 每个自然整点自动换批，每日24批；支付灵石可立即换批，但不重置下一整点。
- 候选不可锁定或找回；招募费用按灵根提高，招募时可免费改名一次。
- 所有馆级中杂灵根概率始终高于90%，异灵根始终低于0.5%；天灵根和异灵根都可出现。
- 馆级决定全部修士的等级上限、境界权限和名册容量。1.0只开放1–9级，长期结构共24级。
- 固定四人不可遣散；随机修士遣散时退回装备、全部突破道具和80%累计升级魂晶，不返还灵石费用。

候选生成、馆级表、刷新与遣散的完整规则以
[1.0版本完整策划案 §4.7](1.0策划案/15_1.0版本完整策划案_草案.md#47-招贤馆与随机修士)为准。
逐馆级概率、刷新费用、招募费用和灵木升级成本必须通过经济定表验证；高资质不得成为通关条件。

### 6.3 还魂坛

- 阵亡修士进入还魂名单。
- 还魂只消耗魂晶，不附加降级、资质损失、装备损坏或限时惩罚。
- 阵亡修士永久保留在还魂名单，处理前不能编队或突破。
- 固定四人不可永久移除；随机修士也必须先还魂，不能用遣散绕过阵亡状态。

### 6.4 炼器坊

- 打造武器、防具、饰品和探索工具。
- 工坊等级决定配方和基础词条区间。
- Demo 不做装备强化失败。
- 重铸只改变一个指定词条，避免完全随机吞资源。

### 6.5 交易行

- 6 个普通商品栏，每 2 小时刷新。
- 1 个需求订单，玩家提交材料换灵石。
- 关键任务物品不进入随机商店。
- 坊市不直接出售最高资质修士或毕业装备。

## 7. 修士系统

### 7.1 资质

六档灵根资质：

```text
杂灵根 → 伪灵根 → 三灵根 → 双灵根 → 天灵根 → 异灵根
```

灵根资质影响成长率、初始天赋数量和最高潜能，不等于职业、境界或正魔道途。异灵根
使用玄青底配青紫虹彩灵纹；暗红保留给魔道、血煞和危险状态。

### 7.2 境界与等级

长期境界：

- 炼气：1–10 级。
- 筑基：11–20 级。
- 结丹：21–30 级。
- 元婴：31–40 级。
- 化神：41–50 级。
- 炼虚：51–60 级。
- 合体：61–70 级，当前不实装。
- 大乘：71–80 级，当前不实装。

突破需要等级、魂晶、材料和职业试炼。突破成功固定，不做概率失败。

职业与境界仍使用两个数据字段，但职业树 UI 直接以八个境界为列，不再增加星级或
“道阶”计数。达到炼气 10 级上限后完成筑基试炼并选择一转，确认后开放 11 级；
结丹以后的职业节点为远期预留，1.0前四章不实装。

### 7.3 职业与转职规则

> 本节保留长期职业树设想，不作为1.0正式版本事实源。1.0只开放金刚禅修、五行法修、
> 玄箓修、剑修四个初始职业、八个筑基分支和对应结丹称号，源头规则见
> [1.0版本完整策划案 §4](1.0策划案/15_1.0版本完整策划案_草案.md#4-四名修士与职业名阶系统)
> 与[1.0四职业技能数值](1.0策划案/数值/17_1.0职业技能数值_草案.md)。

长期职业树不再沿用旧六职业方案。职业根系固定为四个炼气职业，并在筑基时各分为两条
路线；同一路线随境界提升使用更资深的职业名阶。炼气至大乘的完整命名以
[1.0版本完整策划案 §4.6](1.0策划案/15_1.0版本完整策划案_草案.md#46-炼气至大乘职业名阶谱)
为长期事实源。1.0只实现炼气、筑基和结丹，元婴至大乘只预留名称，不进入产品范围。

1.0的境界、职业阶段与技能落地统一见
[修士名册 PRD](PRD/05_修士成长突破与还魂_PRD.md#page-09) 与
[筑基、结丹及专精重置 PRD](PRD/05_修士成长突破与还魂_PRD.md#page-10)。本总案中的
元婴以上境界和长期职业名阶均不进入1.0产品范围。

职业规则：

- 每个职业阶段固定拥有 3 个主动技能。
- 炼气进入筑基时由新职业整体替换三个技能，不把旧技能继续堆叠；筑基进入结丹时技能 ID
  不变，只进入`【精通】`数值。
- 同一初始职业的两个分支必须产生不同战斗职责。
- “正道、旁门、魔道、中立”只表达职业分支背景和修士形象，不建立参与数值、阵营、任务
  或转职判断的独立道途标签。
- 1.0允许按成长分册支付高额灵石切换同一初始职业的另一筑基分支；不新增洗髓道具或随机重算。
- 职业是技能和成长方向，资质决定成长幅度，境界决定等级阶段，三者相互独立。

| 炼气职业 | 筑基路线 A | 筑基路线 B | 路线差异 |
|---|---|---|---|
| 金刚禅修 | 护法金身 | 魔相力士 | 嘲讽承伤与反伤防守 / 魔功炼体输出 |
| 五行法修 | 雷法术式 | 蜃景幻法 | 雷法爆发、连锁与减速 / 减益、持续伤害与汲取 |
| 玄箓修 | 镇幽符脉 | 万象符脉 | 镇幽符宝与群体续航 / 单体符攻、增益、单疗与符傀承伤 |
| 剑修 | 青冥剑修 | 玄岳剑修 | 高速暴击、飞剑与剑煞持续伤害 / 慢速重击、破甲、眩晕与承伤 |

### 7.4 七维属性

| 属性 | 战斗作用 | 探索作用 |
|---|---|---|
| 力量 | 剑修、体修等物理技能的主要伤害来源 | 推开石门、搬运重物、强行破坏 |
| 魔力 | 法术伤害、治疗量和法术护盾来源 | 感应灵脉、维持阵法、抵御灵力侵蚀 |
| 技巧 | 玄箓、飞剑、幻法等技能的倍率来源，并影响命中、暴击等 | 拆除机关、识破陷阱、精细采集 |
| 速度 | 决定时间轴上的行动间隔与部分闪避 | 追踪、逃脱、限时通过 |
| 体质 | 决定生命上限 | 抵抗毒雾、严寒、灼热与体力消耗 |
| 护甲 | 降低物理伤害 | 抵挡落石、机关弩箭等物理环境伤害 |
| 抗性 | 降低法术伤害与部分异常持续时间 | 抵抗禁制、魔气、幻术等法术环境伤害 |

前三维同时承担“职业技能来源”和“地图探索门槛”两类作用；后四维主要决定战斗生存与出手效率，也可被少量特殊事件检定。

队伍检定支持四种口径：

- 总和：四人技巧总和达到 30。
- 最高值：队内至少一人力量达到 25。
- 人数：至少两人抗性达到 20。
- 全员：所有存活队员体质达到 15。

失败结果由事件配置。例如：

```text
小型遗迹机关：全队技巧总和 ≥ 30，可安全拆除。
不足 30：仍可强行通过，但全队损失当前生命的 20%。
```

队伍负重：

```text
基础负重 + Σ(成员力量 × 0.5 + 体质 × 0.25) + 储物法器加成
```

## 8. 编队

- 一队 4 人。
- 没有前排、后排、站位承伤或距离规则。
- 默认情况下，敌方可从四名存活队员中自由选择目标。
- 嘲讽生效时，所有未标记“无视嘲讽”的敌方单体技能必须攻击嘲讽者。
- 群体攻击、随机多段攻击和部分 Boss 技能不受嘲讽影响。
- 每名修士固定拥有当前职业的 3 个主动技能，并可拥有 1 个职业天赋。
- 玩家可为每个技能设置启用、目标优先级和生命阈值。

固定新手队：

```text
金刚禅修 + 五行法修
玄箓修 + 剑修
```

## 9. 战斗

### 9.1 基础

- 时间轴驱动的半即时回合制；我方修士行动条充满后显示三个技能供玩家选择，开启该修士
  的自动施法后才按预设策略自动选择。
- 战斗只提供正常速度 `1×`，不开放倍速入口。
- 玩家可以点按已就绪技能手动释放；点按修士名称切换该修士的自动施法状态。
- 自动策略按照从上到下的规则判断。
- 速度越高，行动间隔越短；设置最小行动间隔，防止速度无限堆叠。

### 9.2 伤害公式初稿

```text
物理伤害 = (力量 × 力量倍率 + 技巧 × 技巧倍率) × 100 / (100 + 目标护甲) × 浮动
法术伤害 = (魔力 × 魔力倍率 + 技巧 × 技巧倍率) × 100 / (100 + 目标抗性) × 浮动
行动间隔 = 技能基础间隔 × 100 / (100 + 速度)
生命上限 = 职业基础生命 + 体质 × 职业生命系数 + 装备生命
浮动 = 0.95–1.05
暴击伤害 = 基础伤害 × (1.5 + 暴击增伤)
```

具体技能可以只依赖一种属性，也可以混合依赖。例如玄岳剑修主要依赖力量，雷法术式主要
依赖魔力，青冥剑修和玄箓修会从技巧取得额外收益。

命中率上下限为 70%–100%，Boss 关键机制技能不使用随机未命中。

### 9.3 状态

- 增益：护盾、加速、聚灵、反击、净化。
- 减益：破甲、中毒、灼烧、迟缓、封灵。
- 控制：眩晕、缠绕、沉默。
- 特殊：污染、尸煞印、空间错位。

控制递减：同类硬控连续命中后持续时间按 100%、60%、30% 衰减，Boss 另有抗性。

### 9.4 战败

- 普通战败：所有临时战利品遗失，成员进入重伤或死亡。
- 使用逃生符：保留 50% 临时战利品，队伍返回。
- 主线关键物品取得后不会因战败永久丢失。
- 新手前三次入山提供一次自动救援，减少开局流失。

## 10. 野外探索

### 10.1 入山整备

玩家选择：

- 最多 4 名修士；任一修士灵息低于目标地图需求时不能入山。
- 1 支当前队伍；新档仅开放 1 队，后续消耗灵石解锁第 2、3 队。
- 灵粮数量；野外地图每移动一步按地形消耗。
- 开山镐数量；用于资源开采和部分副本推进。
- 探灵镜数量；用于战斗前观察敌方属性。
- 当前/最大负重。

编队不设独立页面。点击营地传送阵唤起入山整备面板，“编辑队伍”在其上方打开选人
面板，“启程”在其上方打开地图选择面板；点击地图项目直接执行最终校验并传送。

### 10.2 移动

- 四方向逐格。
- 每张野外地图是一张完整的大地图，地图由若干小格组成，队伍在任意时刻只占一个格。
- 基础地形每步 1 灵粮，困难地形 2–3。
- 灵粮归零时显示“灵粮已尽”警示，护体灵息允许队伍再移动 4 步；每一次位移都计步。
- 顶部状态依次为“断粮”（归零及第 1 步）、“气血亏空”（第 2 步）、“步履维艰”
  （第 3 步）、“生机将绝”（第 4 步）。第 4 步移动结束后全队阵亡，修士进入还魂殿。
- 玩家可在倒计步耗尽前用野外食材补充灵粮、消耗归营符归营，或返回入口传送阵；
  不提供绕过断粮阵亡的紧急撤离。
- 敌人、事件、资源点、小型副本入口、每图唯一Boss和跨图出口均位于固定坐标；支线强敌按精英处理。
- 一张地图不是由“主路和岔路”组成；玩家是在完整二维地图上自由选择目标坐标和移动路线。

### 10.3 神识迷雾

- 初始半径 2。
- 探灵灯升级到 3/4/5。
- 已探索区域保留地形，不保留动态敌人位置。

### 10.4 营地

地图临时营地可以：

- 休息，恢复 40% 生命。
- 用采集材料制作少量灵粮。
- 保存地图内临时复活点。
- 每次入山使用次数有限。

### 10.5 1.0四张野外地图

1.0只制作`map_01`至`map_04`四张完整地图，`map_05`保留锁定预告。地图顺序固定为
破禁山麓·万修之门 → 白玉广场 → 灵宝遗址 → 镇魔塔外层，不存在地图2直达地图4的隐藏出口。

| 地图 | 定位 | 唯一Boss | 跨图关系 |
|---|---|---|---|
| 地图1：破禁山麓·万修之门 | 新手、山门与第一次身份线索 | 守门石灵 | 通往地图2 |
| 地图2：白玉广场 | 开放玉庭、阵眼与筑基 | 封坛尸将 | 通往地图3，可回地图1 |
| 地图3：灵宝遗址 | 机关、夺宝、装备构筑与降尘丹 | 四臂铸灵傀 | 通往地图4，可回地图2 |
| 地图4：镇魔塔外层 | 高压终局、结丹与封链 | 银翅夜叉·尸煞化身 | 通关后显示锁定的`map_05` |

每图恰好一个Boss；支线强敌、危险区强敌和路线门卫统一按精英处理，不另设支线Boss或野外Boss。
尺寸、固定对象、捷径、副本和回访状态以`Docs/1.0策划案/地图/README.md`索引的27–31号文档为准。

## 11. 剧情和阵营

玩家会遇到四类势力：

1. 破禁世家：目标是取得古宝。
2. 正道联军：优先重新封印。
3. 魔道修士：争夺魔功与魂魄。
4. 山中异类：希望取回本命禁制并脱离仙山。

1.0的选择不做完全分叉主线，而是影响：

- 某些 NPC 是否入驻。
- 商店货物。
- 支线强敌与精英处理结果。
- 结局评价。
- 一件专属装备。

避免制作四套完全不同的关卡造成内容爆炸。

## 12. 任务系统

任务类型：

- 主线：开启区域、修复阵眼、击败 Boss。
- NPC：救援、护送、寻找法器。
- 悬赏：击杀指定精英。
- 收集：提交材料。
- 探索：发现坐标、残碑或传送阵。

任务状态：

```text
LOCKED → AVAILABLE → ACTIVE → READY_TO_TURN_IN → COMPLETED
                         └→ FAILED（仅限明确限时事件）
```

不使用隐藏永久失败。会改变关系的选择必须明确提示。

## 13. 建筑与剧情解锁

## 14. 装备

每名修士固定四槽：武器1、防具1、饰品2。装备分为白色粗制、绿色精制、蓝色上品、
紫色珍品和金色古宝五档；装备品质与灵根资质使用不同名称和边框，避免混淆。

制式装备词条只有七维且不做职业倾向：武器与饰品通常不出现护体、定力；玄甲不加定力，
法衣不加护体，行衣可随机全部七维但护体、定力偏低。只有少量特定装备拥有固定特殊效果，
其七维仍按品质随机。

前期地图通关只稳定获得白、绿、蓝装；中后期地图仅小概率获得紫装。大部分紫装与金色古宝
来自跨地图任务链和炼制，金装强度明显高于紫装。制式配方可重复打造，重铸整件七维后由玩家
在新旧结果中二选一；不提供单词条锁定或定向属性。

## 15. 经济设计原则

- 灵粮永远有价值，但不应让玩家因缺粮彻底无法游戏。
- 提供低效率的“休整”救济：等待 5 分钟可领取少量灵粮，每日有限。
- 高级资源需要灵粮维护，形成产业选择。
- 魂晶投入可部分返还，允许换队但保留成本。
- 招贤刷新是灵石消耗口，但主线给定的固定四人必须能通关。
- 0.1 Demo与1.0正式版本都不加入充值、抽卡付费或广告。

## 16. 新手流程

0–5 分钟：

- 接管营地。
- 分配 6 名杂役生产灵粮。
- 直接获得固定的新手四人组；1.0完成营地引导后开放招贤馆随机候选，0.1 Demo不开放招募。

5–12 分钟：

- 学会装备、技能策略、负重。
- 携带 60 灵粮入山。
- 移动、迷雾和第一次普通战斗。

12–20 分钟：

- 找到临时营地。
- 在完整地图上选择先救人、采集还是挑战固定敌群。
- 解锁炼器师。

20–35 分钟：

- 返回打造装备。
- 固定剑修达到 10 级，玩家在青冥剑修和玄岳剑修之间选择筑基分支，并立即看到三技能替换。
- 第二次入山，挑战精英。
- 解锁还魂坛。

35–45 分钟：

- 击败守门 Boss。
- 进入地图2的白玉广场预览，看到唯一Boss与精英使用不同地图标记。
- Demo 结束。

## 19. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 未获 IP 授权 | 无法使用昆吾山专有设定发行 | 双命名、原创角色与资产 |
| 营地等待感过强 | 玩家无事可做 | 地图掉落、救济粮、短周期新手 |
| 刷修士过度随机 | 挫败和数值膨胀 | 固定新手队、保底、低资质可通关 |
| 四初始职业、八筑基分支及结丹进阶的动画成本高 | 美术延期 | 共用身体底层与受击/死亡帧，分支重点重制三技能动作；结丹沿用分支骨架 |
| 地图重复 | 探索疲劳 | 手工地标、机制章节化、动态事件 |
| 负重过于惩罚 | 频繁回城 | 清晰预估、营地、捷径、逃生符 |

## 20. 策划验收标准

- 玩家无需阅读长教程即可理解“灵粮 = 生产成本 + 探索步数”。
- 第一次入山在 10 分钟内发生。
- 第一次有意义的继续/回城选择在 15 分钟内发生。
- 免费新手队能完成 Demo。
- 同一 Boss 至少有两种有效队伍解法。
- 所有永久损失有明确确认。
- 30–45 分钟 Demo 展示完整循环并以新区域悬念结束。
