# 《昆吾禁地》Demo 范围与体验闭环

适用产品版本：0.1 Demo  
文档修订：1.0  
日期：2026-08-02  
关联事实源：[PRD-00](../PRD/00_产品范围与阶段路线图.md)

## 1. Demo 的唯一目标

用最小内容验证以下核心循环是否成立：

```text
进入营地
→ 理解资源与当前目标
→ 调整灵圃生产
→ 编成四人队伍并携带补给
→ 入山逐格探索与揭开迷雾
→ 触发一场可观看的战斗
→ 获得魂晶与战利品并归营
→ 黑屏缓动返回营地
→ 刷新后继续当前进度
```

任何不能直接增强这条流程的工作，默认不进入 D0。

## 2. D0 可玩样机

目标时长：15–20 分钟。运行入口：Cocos 编辑器预览或 localhost Web。

必须包含：

- Boot、新档、存档恢复和明确的加载/失败反馈。
- 一个可横滑营地大厅，顶部和底部 HUD 固定。
- 灵圃三种基础资源的调岗、在线结算、招募和储量升级。
- 四名固定修士、一个队伍预设、灵息、负重和灵粮装载。
- 一张最小固定方格地图、相邻格移动、迷雾和一个固定敌人。
- 每次入山 1 次野外休整、野外食材补给、运功疗伤和归营符直接归营。
- 灵粮归零后的四步衰竭警示、全队阵亡与还魂殿待处理状态。
- 一场自动可结束的最小战斗。
- 一次无结算面板的归营流程：奖励真实进入存档，黑屏缓动返回营地。

D0 明确不做：

- 新增独立建筑功能页、完整背包、完整任务列表和正式转职树。
- 地图 2–5、随机地图、天气数值、复杂副本和多 Boss。
- 联网账号、真实 HTTP 服务端、排行榜、邮件、支付、广告和 PvP。
- 为未进入闭环的系统提前制作正式美术。

## 3. D1 公开切片

目标时长：30–45 分钟。D1 只能在 D0 闭环通过后扩展。

在 D0 基础上增加：

- 地图 1 完整内容和地图 2 的可进入预览。
- 固定四人的四个炼气职业，并选择一个职业展示两个筑基方向。
- 8 个敌人、1 个主线 Boss、1 个可选精英。
- 约 30 件物品和支持 Demo 流程的最小任务线。
- 统一的公开 Demo 资产、音效、引导、性能和发布页面。

详细数量只作为0.1 Demo内部范围，不使用1.0 PRD需求编号，也不扩张正式内容承诺。

## 4. Demo 与正式项目的边界

| 内容 | Demo | 正式项目 |
|---|---|---|
| 地图 | D0 最小地图；D1 地图 1 + 地图 2 预览 | 前四章的4张完整地图及跨图网络 |
| 职业 | D0 固定四人；D1四个炼气职业 + 一组双分支展示 | 四个初始职业、8条筑基分支及结丹进阶 |
| 建筑 | 只做闭环必需的灵圃和入口反馈 | 七座建筑的完整成长功能 |
| 美术 | 可登记使用占位，D1 关键路径统一 | 全量原创正式资产与长期维护 |
| 服务端 | Demo 不强制 API First；优先本地闭环，保留已有 Port/Adapter | 需要联网功能时接独立 Server |
| 发布 | 本地验收与公开 Demo 包 | 1.0 Alpha/Beta/RC/正式发行 |

## 5. 减范围顺序

Demo 延期时按以下顺序删减，不再向后顺延所有内容：

1. 删除非闭环页面和装饰性交互。
2. 删除可选敌人、可选事件和支线文本。
3. D1 减少物品与任务数量，但保留完整循环。
4. 缩小地图，不删除逐格移动、迷雾、补给和固定遭遇。
5. 降低表现复杂度，不删除战斗过程与回城结果。

营地经营、入山整备、逐格探索、战斗和回城结算五段不得删除。

## 6. 停止条件

- D0：新玩家无需控制台或编辑器操作即可完成 15–20 分钟闭环，无 Sev-1/Sev-2。
- D1：目标玩家可以独立完成 30–45 分钟内容，理解核心规则，并愿意继续进入地图 2。
- 未达到当前停止条件时，只修阻断、可理解性和体验节奏，不开启下一阶段内容生产。
