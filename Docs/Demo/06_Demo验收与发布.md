# 《昆吾禁地》Demo 验收与发布

版本：1.0  
日期：2026-08-02

## 1. D0 可玩样机门禁

必须由玩家入口实际完成，不以领域测试或后台日志代替：

1. 新档进入营地，看到真实资源和明确主线目标。
2. 横滑经过建筑不触发点击，轻点建筑正常响应。
3. 在灵圃完成调岗并观察至少一个真实生产周期。
4. 打开入山整备，选择修士、调整灵粮并理解灵息/负重阻断。
5. 进入最小地图，逐格移动、消耗灵粮并揭开迷雾。
6. 使用一次休整，确认食材补给、运功疗伤和刷新恢复不能重复获利。
7. 用独立验收档耗尽灵粮，确认警示与四步衰竭状态正确，第 4 步全队阵亡并进入
   还魂殿待处理状态；补粮与刷新不能重置或重复结算。
8. 接触固定敌人，看到一场有过程且能结束的战斗。
9. 消耗归营符从任意坐标归营，完成结算后 Wallet/Inventory 真实变化。
10. 刷新浏览器，资源、队伍、地图、休整和结算状态正确恢复。

通过条件：

- 全流程 15–20 分钟。
- Sev-1、Sev-2 为 0。
- 所有可见按钮都有结果或不可用原因。
- 控制台无未处理异常、Missing Script 和持续刷屏警告。
- 留存一份逐步验收记录或完整录屏。

## 2. D1 公开切片门禁

在 D0 基础上增加：

- 目标玩家无需讲解完成 30–45 分钟流程。
- 地图 1、地图 2 预览、职业、敌人、首领、物品和任务达到 D1 范围。
- 关键路径不使用未登记来源的素材；第三方许可可追溯。
- 首包、帧率、浏览器兼容、存档迁移达到 PRD-10 的 Demo 预算。
- 公共页面、版本号、更新说明、已知问题、反馈入口和回滚包齐全。

## 3. 缺陷等级

| 等级 | Demo 示例 | 处理 |
|---|---|---|
| Sev-1 | 无法启动、档案损坏、资源无限复制 | 立即阻断发布 |
| Sev-2 | 闭环中断、横滑误入页面、战斗无法结束、结算重复发奖 | 当前阶段必须清零 |
| Sev-3 | 局部错位、提示不清、非关键动画异常 | 评估后修复或登记 |
| Sev-4 | 纯装饰优化 | 不阻塞 Demo |

## 4. 验收职责

- Codex/开发代理：完成实现后只提供刷新步骤、建议命令和人工验收要点，不代替用户运行。
- 用户：在 Cocos Creator 刷新资源，运行预览并完成视觉、触控和流程验收。
- 产品：确认没有把正式项目需求重新塞回 Demo。
- 发布前：按 PRD-12 执行对应阶段的测试、版本、许可和回滚门禁。
